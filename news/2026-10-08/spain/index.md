<ul>
<li>取得記事にはスペインが直接関与する新しい国際案件が乏しい。第三国の事件を並べず、文化・音楽という編集軸を守る。</li>

<h2>スペイン国内ニュース</h2>
<ul>
<li>CCOOとUGTは住宅価格と投機への対策を求め、11月11日のゼネストを呼びかけた。</li>
<li>エル・ムンドは、スペイン世帯が動かさずに保有する資金を9430億ユーロと報じた。住宅不足と巨額の待機資金が同時にある点が争点である。</li>
<li>日本にも預金を厚く持つ家計は多いが、スペインでは住宅運動と労組の街頭行動が結びつきやすい。</li>
</ul>
<h2>文化・芸能ニュース</h2>
<ul>
<li>ロサリアは2026年の国家現代音楽賞を受賞した。審査はアルバム『Lux』を「野心的、革新的、変革的」と評価し、12か月の世界ツアーにも注目した。</li>
<li>文化省は作家ハビエル・マリアスの個人資料を50万ユーロで取得した。タイプ原稿、手書き修正、記事、書簡が国立図書館へ入り、削除と推敲の過程も研究できる。</li>
<li>教員フランシスコ・ラミレス・ロペスは詩集『四本の釘』でロエベ詩賞を得た。創作をひらめきでなく、生活の中の反復する仕事として見せる三題である。</li>
</ul>
<h2>フラメンコニュース</h2>
<ul>
<li>パンプローナ市はフラメンコ・オン・ファイアと連携し、エル・ペレのバルコニー公演と未成年向けギター・舞踊講習を組んだ。</li>
<li>セビリア県ランテフエラの第31回祭とマラガ県アロサイナのアルメナ・フラメンカは、ともにカンテ、ギター、バイレを一つの番組へ置く。</li>
<li>三部門の名人芸だけでなく、歌の息、ギターの合図、足のレマーテの受け渡しが聴きどころだ。マドリードの国家ブランドとは別に、アンダルシアの小都市が生活文化を保つ。</li>
</ul>
<h2>フラメンコギタリスト列伝</h2>
<ul>
<li>ニーニョ・ミゲル、本名ミゲル・ベガ・デ・ラ・クルス（1952–2013）はウエルバ生まれ。ギタリストの父ミゲル・エル・トマテから、港町のファンダンゴを学んだ。</li>
<li>1975年の第一作と翌年の『Diferente』という少数の録音が、後続の奏者に繰り返し参照された。</li>
<li>右手は太い親指の低音と、細い高音のアルペジオを一つの句で交代させる。ピカードは頂点だけへ置き、その後の休符で次の低音を大きく聞かせる。</li>
<li>左手は開放弦を残し、内声を半音で動かす。ウエルバの明るさを残しながら、解決直前へ濁りを置く。</li>
<li>精神疾患と依存症で長く舞台から離れた。病を天才の証しとして美化せず、作品の価値と支援を要した生活を分けて見る必要がある。</li>
<li>公開演奏<a href="https://www.youtube.com/watch?v=4cpei0yTOPc">『ニーニョ・ミゲル、ブレリア』</a>では、親指の直後に高音を軽くし、休符を挟んで低音へ戻る呼吸を聴きたい。均す前に語る音を残した奏者である。</li>
</ul>
<h2>フラメンコバイレ列伝</h2>
<ul>
<li>ブランカ・デル・レイ（1946年コルドバ生）は、マドリードのコラル・デ・ラ・モレリアを創作と上演の拠点にした。</li>
<li>代表作「ソレア・デル・マンタ」は、大判のショールを装飾でなく身体の延長にする。肩、肘、手首の順に力を伝え、布の端を一拍遅れて着地させる。</li>
<li>サパテアードを連打せず、長いブラソの線から短いレマーテへ移る。音の少なさで観客の時間感覚を支配する。</li>
<li>DeFlamenco公式収録<a href="https://www.youtube.com/watch?v=blfRVCSe9to">『ブランカ・デル・レイ、アレグリアス』</a>では、明るい曲でも腕を急がず、足の短い区切りで場面を閉じる箇所を見たい。</li>
<li>タブラオを観光の見世物に限定せず、日々の営業と作品創作を接続したことも後進への遺産である。</li>
</ul>
<h2>フラメンコカンテ列伝</h2>
<ul>
<li>マイテ・マルティン（1965年バルセロナ生）はレコードで歌を学び、1987年にラ・ウニオンのランパラ・ミネーラを受賞した。</li>
<li>低い声域でも輪郭が崩れず、子音の立ち上がりと母音の長さを細かく配る。大声より詩の文意が前へ出る歌唱である。</li>
<li>フラメンコだけでなくボレロも歌う。ジャンルを混ぜるのでなく、歌詞を語る時間の取り方を共通軸にする。</li>
<li>公開演奏<a href="https://www.youtube.com/watch?v=gwklxyiRe08">『マイテ・マルティン、カンテ』</a>では、語頭を明瞭に置き、母音を細く保ってギターの返答へ空間を渡す箇所を聴きたい。</li>
<li>抑制された声でも、コンパスと詩を精密に扱えば緊張を作れることを後進へ示した。</li>
</ul>
<h2>フラメンコギター工房だより</h2>
<ul>
<li>全履歴の既出工房を避け、国外編として高知の製作家、田村満と田村廣を扱う。戦後の日本でスペイン式ギターを研究した兄弟である。</li>
<li>輸入楽器が限られた時代、実物を測り、表板の厚み、扇状力木、ネック角度を試作で確かめ、日本の湿度に合わせた。</li>
<li>フラメンコ用は軽い胴と薄めの表板で、長い余韻より速い立ち上がりを優先する。<a href="https://www.youtube.com/watch?v=fIxkgroJipU">田村ギターの演奏例</a>では、低音の余韻が膨らみすぎず、高音のラスゲアードへ場所を譲る点を聴きたい。</li>
</ul>
<h2>フラメンコのパロ解説</h2>
<ul>
<li>今日のパロはカーニャ。ソレアに近い12拍系の古いカンテで、成立を一人へ帰せない。エル・フィージョやアントニオ・チャコンとの関係が語られる。</li>
<li>重く厳粛で、レトラの間に「アイ」という長い嘆声が入る。嘆声は次の詩節へ移る呼吸と調性の緊張を保つ。</li>
<li>三、六、八、十、十二拍付近に重心があり、十から十二、次の三へ回るまとまりを聴くとよい。</li>
<li>和声はフリジア旋法を基礎に、Aマイナー、G、F、Eへ降りる終止型を使う。</li>
<li>公開映像<a href="https://www.youtube.com/watch?v=Mklp9zj4_HM">『カーニャのカンテとバイレ』</a>では、長い嘆声の間もギターが12拍の帰着点を保ち、踊りが十拍付近からレマーテへ入る箇所に注目したい。</li>
</ul>
<h2>まとめ</h2>
<ul>
<li>10月8日は、賞や資料保存という公的な記憶と、舞台で受け渡す身体の記憶を結んだ。作品を残すのは天才の一瞬でなく、推敲、稽古、伴奏、製作を繰り返す手である。</li>
</ul>
