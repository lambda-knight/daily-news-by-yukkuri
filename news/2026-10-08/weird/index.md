<h2>12年ぶりに里帰りした世界記録、アイダホで668キロのフライドポテト</h2>
<ul>
<li>米アイダホ州ボイシの祭り「ボイシ・ポテト・デイズ」で10月2日（金）、アイダホ・ポテト委員会（IPC）と飲食チェーン「スパッド・ダディ（Spud Daddy）」が「1回で提供されたフライドポテトの最大量」のギネス世界記録を達成した。IPCが10月5日に発表した。</li>
<li>計量結果は1474ポンド（約668キロ）。アイダホ産ジャガイモ1700ポンド（約771キロ）を、50人のシェフが6台のフライヤーで揚げた。</li>
<li>それまでの記録は2018年にインドで作られた1452.85ポンド（約659キロ）。今回は約22ポンド（約10キロ）上回った。</li>
<li>この記録はもともと2014年、アイダホ州イーグルのツイン・オークス・ファームズが1003ポンドで作ったもの。その後2017年にギリシャ、2018年にインドへ移り、12年かけてアイダホへ戻った。</li>
<li>認定員のマイケル・エンプリックさんがニューヨークから飛んで立ち会った。</li>
<li>IPCのジェイミー・ハイアム社長兼CEOは「フライドポテトの最大量の世界記録を持つなら、それはアイダホにあるべきだ」と語った。スパッド・ダディ創業者でポテト・デイズ主催者のトーマス・ワトソンさんは「フライヤー6台、50人、そして大量のジャガイモが必要だった」と振り返った。</li>
<li>計量後のポテトは来場者に無料で配られた。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/10/07/Guinness-World-Records-largest-serving-french-fries/1951791396507/">UPI</a> / <a href="https://www.prnewswire.com/news-releases/america-this-ones-for-you-idaho-brings-worlds-largest-serving-of-french-fries-record-back-to-the-us-302898754.html">PR Newswire（IPC発表）</a> / <a href="https://www.freshplaza.com/north-america/article/9879804/idaho-sets-french-fry-record-with-1-474-pound-serving/">FreshPlaza</a></li>
</ul>
<h2>ストローで1分間に51個、記録破りの名人デビッド・ラッシュさんが麦芽チョコを運ぶ</h2>
<ul>
<li>アイダホ州ボイシのデビッド・ラッシュ（David Rush）さんが10月6日、ストローだけでモルトボール（麦芽入りのチョコボール）を1分間に51個、30センチ離れた2つの器の間で移す挑戦を行った。ギネスの正式認定待ち。</li>
<li>実際には52個を運んだが、映像を見直すと最後の1個が制限時間内に移り切っていなかったため、51個とした。</li>
<li>それまでの記録は32個。英国の動画投稿者ジャック・ウェルシュさんが4月17日、ギネスのポッドキャスト番組「ホワッツ・ザ・レコード？」で作った。</li>
<li>ラッシュさんは最近の記録ニュースを読んでこの種目を知った。「つまようじで物を運ぶ種目と、ピンポン玉を受け止める練習で身につけた呼吸の制御を組み合わせればいいと、すぐに思った」と語り、手順を「吸う、吸いつきを固定する、運ぶ、圧を抜いて落とす、繰り返す」と説明した。</li>
<li>細かい手先の動きを速さで競う種目が得意で、保持する記録は200を超える。最近も3歳の娘とのフラフープ、カップ10個のひっくり返し（6.63秒）、1時間に紙飛行機415機を折る記録を作った。</li>
<li>経歴: マサチューセッツ工科大学（MIT）で電気工学を学び、ボイシに戻ってボイシ州立大学でMBAを取得。最初の記録は2015年の「目隠しジャグリング6分34秒」。2021年には52週で52の記録を破った。</li>
<li>動機: 子どものころ英才教育プログラムに入るのに苦労し、努力で入れた経験から、粘り強さと目標設定が何を生むかの「目に見える例」になりたいと考えた。記録を題材に、学生や企業向けの講演で理数系教育（STEM）の魅力を伝えている。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/10/06/guinness-world-records-david-rush-malt-balls-straw/4211791303328/">UPI</a> / <a href="https://www.boisestate.edu/alumni/2024/01/15/meet-david-rush/">ボイシ州立大学 同窓会記事</a> / <a href="https://www.kivitv.com/news/boise-man-sets-33rd-guinness-world-record-to-promote-stem">KIVI-TV</a></li>
</ul>
<h2>駐車場のコーンを抜けたのは1台だけ、生成AIにカローラを運転させた3人の実験</h2>
<ul>
<li>米サンフランシスコ湾岸地域のAI数学スタートアップ、アクシオム・マス（Axiom Math）で知り合ったアディティア・ラマバドランさん、トビアス・ゲスラーさん、シモン・マーンズさんの3人が、「ドライビングベンチ（DrivingBench）」と名付けた実験を公開した。9月下旬に404 Mediaなどが報じ、10月7日にはWIREDも取り上げた。</li>
<li>オープンAIの「GPT-6 Astra」「GPT-5.6 Sol」、アンソロピックの「Claude Fable 5.1」、xAIの「Grok 4.6」に、トヨタ・カローラのハンドル、アクセル、ブレーキを操作させた。</li>
<li>車には市販のオープンソース運転支援装置「コンマ（Comma）」をフロントガラスに取り付け、その2台のカメラ映像をノートパソコン上のAIへ送った。運転席には人が座ってブレーキに足を構え、ハンドルのボタンを押さないと指示が実行されない仕組みにした。</li>
<li>コースは駐車場にコーンで作った逆U字形で、境界からはみ出さずに進み、青いコーンの区画に駐車すればゴール。高校、教会、公民館などの駐車場で試し、立ち退きを求められた場所もあった。</li>
<li>どのモデルも最初は運転を拒否した。状況を「シミュレーション」ではなく「サンドボックス」と呼び直すと応じた。</li>
<li>完走できたのはGPT-6 Astraだけで、2回目の挑戦で134.7メートルを5分22秒かけて走り切った。平均時速は約0.94マイル（約1.5キロ）。この走行に使ったのは約660万トークン、費用は7.74ドルで、ガソリン代のおよそ500倍にあたる。</li>
<li>ほかのモデルは数メートル進んだところで止まり、多くは最初の角を曲がれなかった。Grokは「車はカメラで見るより幅が広い。まっすぐ先は通れる車線ではなく、植え込みか壁か手前の赤いコーンを指していた」と自分の失敗を説明した。</li>
<li>課題は応答の遅さ。1回の応答に20秒かかることがあり、時速2マイルでも10秒遅れれば約10メートルを「見ないまま」進む計算になる。</li>
<li>出典: <a href="https://www.404media.co/these-tech-workers-made-chatgpt-drive-a-toyota-corolla/">404 Media</a> / <a href="https://futurism.com/advanced-transport/openai-astra-model-self-driving-car">Futurism</a> / <a href="https://www.wired.com/story/ai-is-driving-cars-now-oh-boy/">WIRED</a></li>
</ul>
<h2>67日間で地球を約1040周、宇宙服のピカチュウが国際宇宙ステーションを案内</h2>
<ul>
<li>欧州宇宙機関（ESA）は10月7日、フランス人宇宙飛行士ソフィー・アドノ（Sophie Adenot）さんが、ESAの制服を着たピカチュウのぬいぐるみと国際宇宙ステーション（ISS）を巡る動画を公開した。ESAとポケモン社（The Pokémon Company International）の協力企画で、10月4日〜10日の「世界宇宙週間」に合わせたもの。</li>
<li>ぬいぐるみはアドノさんに同行し、2026年4月11日から6月17日までの67日間を軌道上で過ごし、地球を約1040周した。ESAが作った展望モジュール「キューポラ」にも浮かんだ。ぬいぐるみにとって初の宇宙飛行。</li>
<li>動画では、水の浄化装置、実験や採血の試料を保存するマイナス98度の冷凍庫、乗員の個室を紹介。アドノさんは「水の98％を再利用している。尿まで再利用している」と説明した。</li>
<li>アドノさんは滞在中に200以上の科学実験と3回の船外活動を行った。</li>
<li>パリ、ローマ、ノールトワイク（オランダ）、ダルムシュタット（ドイツ）、ビジャヌエバ・デ・ラ・カニャダ（スペイン）、ハーウェル（英国）のESA拠点で公開イベントを開き、2026年10月から2027年4月まで欧州の博物館を巡回する展示も行う。スマホゲーム「ポケモンGO」では、参加する博物館で10月4日から2027年4月30日まで「宇宙服のピカチュウ」が登場する。</li>
<li>ESA広報部門責任者のアンヌ＝ソフィー・ブラデルさんは「ポケモンのように豊かで想像力に満ちた世界を持つブランドとの協力は、幅広い人々を宇宙と結びつける特別な機会だ」と述べた。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/10/07/Pikachu-European-Space-Agency-International-Space-Station/6211791387825/">UPI</a> / <a href="https://www.invenglobal.com/articles/26392/pikachu-goes-to-space-and-has-already-returned">Inven Global</a> / <a href="https://soranews24.com/2026/09/22/pikachu-plushie-actually-goes-into-space-as-part-of-pokemon-european-space-agency-collaboration/">SoraNews24</a></li>
</ul>
<h2>まとめ</h2>
<ul>
<li>50人で揚げた668キロのポテト、呼吸で運ぶ51個のチョコ、駐車場を時速1.5キロで進んだAIの車、地球を1040周したぬいぐるみ。どれも「遊び」だが、手間のかけ方は本気だった。</li>
<li>ポテトは12年がかりで記録を取り戻し、ラッシュさんは過去の種目の技を組み合わせ、3人のエンジニアはAIの弱点を駐車場で可視化し、ESAはぬいぐるみに水の再利用を語らせた。遊びの形を借りると、地元の誇りも、努力の価値も、技術の限界も、宇宙の暮らしも、ぐっと伝わりやすくなる。</li>
</ul>
