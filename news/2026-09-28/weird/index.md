<h2>オープニング：2026年9月28日 — 世界の珍ニュース</h2>
<p>ごみ箱のレシートを丸めて遊び道具にし、それを家族へ伝えたメキシコの小さなアライグマ。同僚の冗談からギネス世界記録になった身長147センチの消防士。6840リットルの豆の煮込みで地元の豆を売り込んだトルコの町。電源の入らないガラケーを数分で起こし、昔の写真と再会させる東京の催し。今回は、見過ごされがちな「小さなもの」「忘れられたもの」が、思わぬ形で主役になった四つの話をたどる。</p>
<h2>レシートを濡らして丸めてボールに、絶滅寸前のコスメルアライグマが「遊び方」を伝える</h2>
<ul>
<li>メキシコ・コスメル島だけにすむコスメルアライグマ（ピグミーアライグマ）は、国際的に近絶滅種とされる小型のアライグマ。観光客の集まるビーチクラブ周辺で暮らす群れもいる。</li>
<li>2026年1月、米マイアミ大学の大学院生ネッシー・オニール氏が、若いメスがごみ箱からレシートを取り出す様子を観察した。レシートを水飲み用の器に何度も浸し、前足でこねて砂の上で転がし、固くて砂まじりの小さなボールに仕上げてから、地面で転がして追いかけた。</li>
<li>母親と姉妹もこれを見て、それぞれ出来栄えに差はあるものの自分で紙のボールを作るようになった。共著者のミシェル・シドロウスキー氏は「一頭の手触り遊びではなく、社会的な活動になった」と説明する。約30キロ離れた比較地点では、同じような紙ごみがあっても若い個体が紙のボールを作る姿は確認されなかった。</li>
<li>研究は学術誌「ワイルド」に9月初めに掲載され、物を加工して採食以外の目的に使う行動が個体から個体へ伝わる「物質文化」の、アライグマ科（アライグマ、ハナグマ、カコミスルなど）での初の記録の可能性があるとした。これまでチンパンジーやブタ、イルカなどで似た伝達が報告されてきた。</li>
<li>最初にボールを作った個体は、その後の保護・リハビリ中に死んだ。栄養不足と、人間のごみに含まれる有害物質が関わった可能性があるという。残された姉妹は、その後も一頭で紙のボールを作り続けた。発見者のオニール氏自身、当初は「大発見というより、見て、かわいい、だった」と振り返る。ごみが遊び道具になり、同時に命を削る原因にもなった点が、この小さな発見の重さでもある。</li>
<li>出典: <a href="https://www.scientificamerican.com/article/an-endangered-pygmy-raccoon-turned-trash-into-toys-and-taught-her-family-how-too/">Scientific American</a> / <a href="https://phys.org/news/2026-09-critically-endangered-pygmy-raccoons-paper.html">Phys.org</a> / <a href="https://laughingsquid.com/pygmy-raccoons-make-paper-toys/">Laughing Squid</a></li>
</ul>
<h2>身長147センチの消防士、同僚の冗談からギネス世界記録に</h2>
<ul>
<li>フロリダ州セントピートビーチ消防救助隊の消防士オータム・ケルソ氏が、「最も背の低い消防士（女性）」としてギネス世界記録に認定された。身長は147.32センチ（4フィート10インチ）。計測・認定は2026年1月18日、9月25日に広く報じられた。</li>
<li>20代は企業勤めだったが、消防の仕事をしている友人たちに勧められて転身し、消防士になって5年になる。記録挑戦は署内の冗談から始まった。同僚の一人が記録を調べると条件を満たしそうだと分かり、正式な計測を経て本物の世界記録になった。</li>
<li>身長は他の隊員と並んで働くうえで妨げにならず、むしろ有利な場面もある。狭い場所へよじ登って入り込めるため、同僚からは「スパイダーモンキー」と呼ばれ、窓からの進入や、背の高い隊員では入りにくい屋根裏へ送り込まれることが多い。本人は「必要なら何にでもよじ登る」と話す。</li>
<li>所属先は二つの署で、全長約5マイル（約8キロ）の砂州の島の町を受け持つ。男性の同種記録はビンス・ブラスコ氏の4フィート2インチ（約127センチ）。</li>
<li>ケルソ氏は「リスクを取って。他人に自分の限界を決めさせないで。身長が4フィート10インチでも6フィート3インチでも、この仕事は楽ではない」と語る。背が低いことを弱点として克服した話ではなく、狭い空間に強い隊員として役割が決まっている点が、この記録の面白さだ。</li>
<li>出典: <a href="https://www.guinnessworldrecords.com/world-records/706940-shortest-firefighter-female">Guinness World Records</a> / <a href="https://www.upi.com/Odd_News/2026/09/25/florida-firefighter-guinness-record/7301790373982/">UPI</a></li>
</ul>
<h2>6840リットルの豆の煮込み、トルコ・ケルキトが地元の「砂糖豆」で世界記録</h2>
<ul>
<li>トルコ北東部ギュミュシュハーネ県ケルキト郡の市場広場で、8月22日、ギネス世界記録「最大の鍋の豆料理」が認定された。量は6840リットル。缶詰にすると約1万5000缶分にあたると報じられ、9月下旬に海外の珍ニュースとしても紹介された。</li>
<li>材料は地元産「ケルキト砂糖豆（シェケル・ファスリエスィ）」1300キロ、肉208キロ、油脂60キロ、玉ねぎ54キロ、トマトペースト80キロ、水4020リットル。料理はトルコの定番家庭料理「クル・ファスリエ（白いんげん豆の煮込み）」で、英語の記録名は「ベイクドビーンズ」でも中身はトマト味の肉入り煮込みだった。</li>
<li>大鍋は黒海沿岸の都市トラブゾンで特注し、1週間かけて試験した。調理は8月21日夜に始まり、翌22日午後2時に完成。できた煮込みは集まった数千人に振る舞われ、ギネスの審査員が認定書を渡した。</li>
<li>それまでの記録は2012年8月7日、北マケドニアのサルチエボ村の5600リットル。約14年ぶりの更新となった。県知事、郡長、市長のほか法務副大臣も立ち会った。</li>
<li>企画はギュミュシュハーネ県、ケルキト市、ケルキト商工会議所の共同。砂糖豆は地理的表示の登録産品だが、農家は販路に苦しんできた。ユナル・ユルマズ市長は「目的は記録を破ることではなく、農家が正当な対価を得て、豆を価値に見合う値段で売れるようにすること」と語った。巨大な鍋は、郷土料理の祭りであると同時に、地元産品の見本市でもあった。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/09/22/turkey-Guinness-World-Records-baked-beans/3451790098927/">UPI</a> / <a href="https://www.sabah.com.tr/gumushane/2026/08/22/6-bin-840-litre-kuru-fasulye-pisirildi-guinness-rekorlar-kitabina-girdi">Sabah</a> / <a href="https://www.haber29.net/dunyanin-en-buyuk-kuru-fasulye-kazani-kelkitte-kaynadi">Haber29</a></li>
</ul>
<h2>電池に「電池だと思い出させる」、10年眠ったガラケーを起こす東京の催し</h2>
<ul>
<li>KDDIの無料催し「おもいでケータイ再起動」は、電池の過放電で充電できなくなった古い携帯電話を専用機器で充電し、電源を入れ直して中の写真やメールと再会させる。au以外の携帯電話も受け付けるが、スマートフォンやタブレットは対象外で、電池を外せる機種に限られる。予約制。</li>
<li>手順は、電池パックを外して専用機器にセットし、数分待ってから電源ボタンを押すだけ。スタッフは「電池が、自分が電池であることを忘れているような状態なので、思い出させてあげる」と説明する。復活した写真は1枚を大きく印刷して渡し、壁面に投影もする。</li>
<li>ロケットニュース24の夏野ふとん記者は、約10年使っていなかったauのWIN時代の折りたたみ携帯を持ち込んだ。待ち受け画面には中日ドラゴンズの優勝パレードで撮った荒木雅博選手、フォルダには初めての一人暮らしの部屋、初めての車、家族や友人の写真が残っていた。</li>
<li>2016年7月に東京・新宿の店舗で初めて開かれ、2019年7月からは全国を巡回して47都道府県すべてで開催した。KDDIは、2017年の調査で約9割が過去の携帯電話を持ち、約6割は写真などのデータが端末に残っていると答えたことを始めた理由に挙げている。</li>
<li>9月25〜27日には東京都庁第一本庁舎1階でも開かれた。東京都の「都庁舎リチウムイオン電池回収キャンペーン」（6月26日〜9月30日）の一環で、9月10日時点で小型充電式家電9607個が集まっている。中身を確かめてから手放せるようにして、回収とリサイクルにつなげる狙いだ。次回は銀座の「GINZA 456」で10月2〜4日と11月6〜8日、福岡県福津市で10月10〜12日に予定されている。思い出の救出が、そのまま引き出しの中の「都市鉱山」を掘り出す入口になっている。</li>
<li>出典: <a href="https://rocketnews24.com/2026/09/24/2799382/">ロケットニュース24</a> / <a href="https://soranews24.com/2026/09/26/japans-cell-phone-memory-restart-event-reunites-users-with-old-photos-and-past-selves/">SoraNews24</a> / <a href="https://www.au.com/omoidekeitai/eventlist/">au おもいでケータイ再起動</a> / <a href="https://www.metro.tokyo.lg.jp/information/press/2026/09/2026091104">東京都</a> / <a href="https://newsroom.kddi.com/news/detail/kddi_pr-631.html">KDDI</a></li>
</ul>
<h2>まとめ</h2>
<ul>
<li>コスメルアライグマは紙ごみを遊び道具に変えて家族へ伝え、ケルソ氏は小柄さを狭い現場での強みに変え、ケルキトは売り先に困っていた豆を世界記録の主役にし、KDDIは引き出しの古いガラケーを思い出とリサイクルの入口にした。</li>
<li>どれも、見過ごされがちな小さなものに別の役割を与えた話だ。一方で、アライグマのボールの材料は命を縮めるごみでもあり、豆の記録の先には農家の値段という現実の課題が残る。</li>
