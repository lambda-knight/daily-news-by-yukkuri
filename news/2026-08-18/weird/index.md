<h2>ネタ1 4か月かけて作った500キロのウエディングケーキ、砂糖細工の花で埋め尽くす</h2>
<ul>
<li>スペイン・カタルーニャの菓子職人マルク・スアレス氏が、自身にとって最大規模となるウエディングケーキを発表した</li>
<li>制作期間は4か月。重さは約500キログラムで、砂糖細工（シュガーペースト）で作った花びらを数万枚使い、表面全体を覆っている</li>
<li>花びらは1枚ずつ手作業で成形・着色されており、乾燥・組み立てには特別な支持構造を要した</li>
<li>スアレス氏はこれまでも大型ケーキで知られる職人で、今回の作品も「これまでで最も印象的な一作」と位置づけている</li>
<li>出典: <a href="https://www.odditycentral.com/art/pastry-chef-spends-four-months-creating-awe-inspiring-500-kilogram-wedding-cake.html">Oddity Central</a></li>
</ul>
<h2>ネタ2 セミの声を4時間浴び続けた18歳、両耳がむくんで一時的な難聴に</h2>
<ul>
<li>中国で18歳の男子高校生が、木の下でセミの鳴き声を4時間以上聞き続けた後、一時的な難聴を発症し病院で治療を受けた</li>
<li>セミの鳴き声は種によって90〜100デシベルに達することがあり、電動芝刈り機に匹敵する音量とされる</li>
<li>診察した医師は、長時間・近距離での高周波音の曝露が原因とみられると説明し、聴力は治療後に回復したと報告した</li>
<li>医師は、屋外で大音量の自然音に長時間さらされる場合も難聴のリスクがあるとして注意を呼びかけている</li>
<li>出典: <a href="https://www.odditycentral.com/news/teenage-boy-suffers-temporary-hearing-loss-after-listening-to-cicadas-for-four-hours.html">Oddity Central</a></li>
</ul>
<h2>ネタ3 空気抵抗を減らすため？女子ツール・ド・フランスで「ブラにパッド」疑惑</h2>
<ul>
<li>女子ツール・ド・フランスの一部選手が、バストサイズを大きく見せるためにブラジャーにパッドを入れ、空気抵抗（エアロダイナミクス）を改善しているとの疑惑がSNS上で指摘された</li>
<li>疑惑は、体形の変化に気づいたファンや他の観戦者の投稿がきっかけで広がった</li>
<li>空力の専門家は、上半身の形状が高速走行時の抵抗に影響しうる点は否定しないが、パッドの効果を裏付ける公式データは示されていない</li>
<li>大会主催者や所属チームからの正式なコメントは確認されておらず、真偽は明らかになっていない</li>
<li>出典: <a href="https://www.odditycentral.com/news/female-cyclists-accused-of-using-bra-paddding-to-increase-bust-size-and-improve-aerodynamics.html">Oddity Central</a></li>
</ul>
<h2>ネタ4 銀行の手数料を拒否、無料で「預金小切手」を手に入れた抜け道</h2>
<ul>
<li>ある男性が銀行で預金小切手（キャッシャーズチェック）の発行を依頼したところ、銀行側が手数料の上乗せを提示した</li>
<li>男性はその場で別の方法を思いつき、手数料なしで同じ目的を達成できる手続きに切り替えた</li>
<li>具体的には、銀行の別サービスや口座条件を使うことで、通常の手数料を回避する抜け道を見つけたと投稿で説明している</li>
<li>投稿はSNSで拡散し、同様の手数料に不満を持つ人々から「知らなかった」「今度試す」との反応が相次いだ</li>
<li>出典: <a href="https://twistedsifter.com/2026/08/his-bank-tried-to-charge-a-surcharge-for-a-cashiers-check-so-he-used-a-clever-loophole-to-get-it-for-free/">Twisted Sifter</a></li>
</ul>
<h2>ネタ5 境界線を巡る隣人トラブル、木を植えさせてから本当の境界を明かした顛末</h2>
<ul>
<li>ある男性が隣人と敷地の境界線をめぐって言い争いになった際、あえて反論せず、隣人の主張通りの位置に木を植えることを黙認した</li>
<li>隣人たちは自分たちの言い分が正しいと信じ、その位置に沿って一列の木を植えた</li>
<li>その後、男性は正式な測量記録や登記情報を示し、実際の境界線が隣人の主張とは異なる位置にあったことを明らかにした</li>
<li>結果として、隣人たちが植えた木は境界の内側・外側どちらであっても男性側に有利な位置関係となり、隣人側は自分たちの誤りを認めざるを得なくなった</li>
