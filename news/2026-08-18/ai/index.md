<h2>Amazon、稀少本をAI訓練のため破棄か——追跡装置が証拠に</h2>
<ul>
<li>404 Mediaは2026年8月17日、稀少本にAirTagなどの追跡装置を仕込み、その本がラスベガスにあるAmazonの物流施設「VGT3」（恐竜が本を爪で掴むシンボルで識別される拠点）に到着したことを確認したと報じた</li>
<li>書店業界では約1年前から、AI企業が稀少本を大量に買い集め、スキャン後に廃棄しているとの疑いが持たれていたが、これまで直接の証拠はなかった</li>
<li>Amazonは声明で「顧客が使用する製品やサービスを改善するため、商業チャネルを通じて書籍を購入している」と説明し、破棄そのものは否定していない</li>
<li>対象となりやすいのは絶版本やインターネット上で入手困難な稀少本で、2022年以前に出版されたためAI生成テキストが混入していない「クリーンなデータ」とされる</li>
<li>大規模言語モデルはインターネット上の主要なテキストを既に学習済みで新規データが枯渇しつつあり、AI生成テキストで再学習すると品質が劣化する「モデル崩壊」のリスクがあるため、稀少本のような未学習データの価値が上がっている</li>
<li>追跡装置による今回の証拠は、書店業界の疑惑を裏付ける具体例の一つであり、Amazon以外の企業がどこまで同様の手法を取っているかは今回の報道の範囲では確認できていない</li>
</ul>
<h2>Stripe、AIモデル仲介のOpenRouterを70億ドル超で買収</h2>
<ul>
<li>Bloombergの報道によると、決済大手Stripeは2026年8月16日までにAIゲートウェイ企業OpenRouterを70億ドル以上で買収する取引を確定させた</li>
<li>OpenRouterは、顧客がタスクごとに異なるAIモデルを選び分けられるプラットフォームで、単一のアクセスポイントから400以上のモデルを利用でき、特定ベンダーへのロックインを避けられる仕組みを提供している</li>
<li>同社は2026年5月にシリーズBで1億1,300万ドルを調達したばかりで、当時の評価額は13億ドルだった。Sequoia、Andreessen Horowitz、Menlo Ventures、Alphabet傘下のCapitalGなどが投資家に名を連ねる</li>
<li>グローバルユーザー数は約800万人に達しており、今回の買収額はわずか3か月前の評価額の5倍を超える水準になる</li>
<li>OpenRouterのCEOはかねて自社を「AI向けのStripeに相当する」と表現しており、決済の仲介・統合で成長したStripeがAIモデルの仲介・統合という同型の事業に進出する狙いがうかがえる</li>
<li>決済インフラ企業がAIモデル選択のインフラを取り込む動きは、AI関連の「配管」部分を巡る主要プレイヤーの布石争いが決済領域にも広がっていることを示している</li>
</ul>
<h2>Nvidia、SoftBank系データセンターへ15億ドル投資——OpenAIプロジェクトの計算基盤を独占</h2>
<ul>
<li>Nvidiaは2026年8月17日、SoftBankとOpenAIが既存投資家であるSB Energyに15億ドルを投資し、加えて最大1,050億ドル規模のクレジットを提供すると発表した</li>
<li>この投資により、Nvidiaはオハイオ州シンシナティ近郊、旧米エネルギー省用地に建設されるデータセンター向けの「唯一の計算インフラ供給業者」になるとされ、当該施設はOpenAIプロジェクト向けとされている</li>
<li>データセンターの規模は初期段階で4.25ギガワット、将来的に最大8ギガワットまで拡張する計画で、電力供給のために92ギガワット規模の天然ガス発電所を建設費330億ドルで新設する</li>
<li>Nvidiaにとっては、自社チップが大型AI基盤施設に確実に採用される状態を作ることが狙いであり、GPU供給網の川下にあたるデータセンター事業への出資を通じて競争力を強化する動きになる</li>
<li>電力インフラの規模から見ると、AI向け計算資源の拡張が半導体だけでなく発電設備の新設まで巻き込む段階に入っていることが分かる</li>
<li>天然ガス発電所の稼働時期や環境面への影響については、今回の発表の範囲では示されていない</li>
</ul>
<h2>Groq、AIチップ企業からネオクラウドへ——3億5,000万ドル調達</h2>
<ul>
<li>AI推論チップを手がけてきたGroqは2026年8月17日、3億5,000万ドルの資金調達を発表した。評価額は35億ドルで、2025年9月時点の69億ドルから大きく下がっている</li>
<li>同社は「下方ラウンド」ではなく、2025年12月にNvidiaが創業者兼CEOのジョナサン・ロス氏と主要人材を約200億ドルのライセンス契約で獲得して以降の「新たな評価基準」だと説明している</li>
<li>独自チップ「LPU（言語処理ユニット）」でNvidiaに対抗する路線から、Nvidia製システムを運用するクラウド・データセンター事業者、いわゆる「ネオクラウド」への転換を進めている</li>
<li>2026年6月にも6億5,000万ドルを調達しており、現在は北米・欧州・中東・アジア太平洋の13拠点でデータセンターを運営し、600万以上の開発者・企業にサービスを提供している</li>
<li>2027年には現在の54メガワットから200メガワット以上へ拡張する計画で、独自チップの開発企業から計算資源の提供企業へと事業の重心を移している</li>
<li>主要人材の引き抜きを受けた路線転換であるため、独自LPU路線の技術的な位置づけが今後どう扱われるかは、今回の発表だけでは明らかになっていない</li>
</ul>
<h2>Quantinuum、Oracleと量子コンピュータ提携——クラウド経由でHeliosを提供</h2>
<ul>
<li>量子コンピュータ企業Quantinuum（NASDAQ: QNT）は2026年8月11日、Oracleとの戦略的パートナーシップを発表し、同社の量子コンピュータ「Helios」をOracle Cloud Infrastructure（OCI）経由で提供すると発表した</li>
<li>Heliosは2025年11月に商業化されたQuantinuumの第3世代システムで、物理キュービット数は98個、48個の論理キュービットを使ったデモンストレーション実績を持つ</li>
<li>2量子ビットゲートの忠実度は平均99.921%で、業界の「3ナイン」基準を上回る水準とされ、電力消費は約60キロワットとスーパーコンピュータの1%未満にとどまる</li>
<li>OCIの顧客はHeliosを、既存のクラウドインフラと同じガバナンス・アクセス制御の枠組みの中でHPCやGPU基盤と並べて利用できるようになる</li>
<li>Quantinuumは今後のロードマップとして、2027年に次世代機「Sol」、2029年に「Apollo」の投入を予定している</li>
<li>調査会社IDCの量子研究リードは、プライベートクラウド環境での展開が既存のAI・HPCワークフローへの統合を容易にすると評価しており、量子コンピュータが専用施設の外へ出て一般のクラウド基盤に組み込まれる動きの一例になっている</li>
</ul>
<h2>まとめ</h2>
<ul>
<li>今日の5本は、学習データ（Amazon）、AIモデル仲介の資本移動（Stripe）、計算インフラへの投資（Nvidia）、チップ企業の事業転換（Groq）、量子コンピュータのクラウド統合（Quantinuum）という、いずれもAIを支える「土台」に関わる動きだった</li>
<li>AmazonとStripeの案件は、AI企業がこれまで表に出にくかった資源——未学習データと資金の流れ——をどう取り込むかという点で共通する</li>
<li>NvidiaとGroqの案件は対照的で、Nvidiaは自社チップの採用を確実にするためインフラへ資本を投じ、Groqは独自チップから他社製システムの運用へ軸足を移すことで生き残りを図っている</li>
<li>Quantinuumの提携は、量子コンピュータが専用の研究施設からクラウドという一般的な計算基盤へ組み込まれつつあることを示しており、今日の他の4本とは異なる技術層の話だが、AIと同様に「インフラ化」という共通の方向性を持つ</li>
</ul>
