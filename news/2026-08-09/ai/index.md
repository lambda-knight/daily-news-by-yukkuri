<h2>OpenAI、スライド作成AIスタートアップ「NextSlide」を買収</h2>
<ul>
<li>OpenAIが2026年8月8日、プレゼン資料作成AIスタートアップ「NextSlide」を買収したと発表</li>
<li>NextSlideは「プロンプト・メモ・文書・調査結果を、洗練された編集可能なプレゼン資料に変換する」プロダクトを開発していた</li>
<li>創業者アハメド・ベシュリ氏は目標を「ビジュアルコミュニケーションを誰でも扱えるものにすること」と説明</li>
<li>チームはChatGPTチームに合流し、今後ChatGPT上でのプレゼン資料生成機能に統合される見込み</li>
<li>OpenAIはここ数カ月、周辺スタートアップの人材・技術買収（アクハイア）を積み重ねている</li>
</ul>
<h2>OpenAIが新モデル「Astra」の開発を意図的に減速、安全懸念で</h2>
<ul>
<li>OpenAIは2026年8月7日、開発中のモデル「Astra」の開発速度を意図的に落としたと明らかにした</li>
<li>理由は、Astraが「重大サイバーセキュリティ閾値」に達したため。これは、通常は堅牢に防御されている実システムに対し、AIが自律的に脆弱性を発見し攻撃を実行できる水準を指す</li>
<li>OpenAIはモデルの能力向上と安全対策整備のバランスを取るため、リリースペースを落とす判断を下した</li>
<li>どのような能力・用途のモデルかは公表されておらず、公開時期も未定のままである</li>
<li>攻撃的サイバー能力を持つAIモデルの安全評価をどう制度化するかが、業界全体の次の論点になる</li>
</ul>
<h2>メタに567億円の追加支払い命令、若者のメンタルヘルス被害巡り公共妨害と認定</h2>
<ul>
<li>ニューメキシコ州の裁判所は2026年8月7日（現地時間）、メタに対し追加で5億6700万ドル（日本円で約850億円規模）の支払いを命じた</li>
<li>同州では3月にも3億7500万ドルの制裁金が科されており、合計は9億4200万ドルに達する</li>
<li>争点はソーシャルメディアのアルゴリズム設計が未成年の依存・メンタルヘルス被害を引き起こしたという「公共妨害（public nuisance）」の認定</li>
<li>裁判所はメタに対し、同州内で「いいね」件数表示を原則廃止し、18歳未満に表示する場合は保護者の承認を要求するよう命令</li>
<li>未成年ユーザーへのプッシュ通知は午後10時〜午前7時に一時停止するよう義務付けられた</li>
<li>AIが選ぶレコメンドやエンゲージメント最適化アルゴリズムの設計そのものが法的責任の対象になった点が今回の特徴</li>
</ul>
<h2>中国のAI恋人規制で大手2社がキャラクター機能を一斉停止</h2>
<ul>
<li>中国では2026年7月15日、「AI擬人化対話サービス管理暫定弁法」が施行された</li>
<li>国家インターネット情報弁公室（CAC）など5当局が4月10日に共同で公布したもので、感情的な依存を生むAI恋人・AIコンパニオン型サービスを対象とする</li>
<li>規則施行と同じ日、中国国内最大手2社が、利用者が長期間育ててきたカスタムAIペルソナ機能の提供を停止した。停止通知からわずか10日での対応だった</li>
<li>規則は感情的苦痛の検知や危機介入、依存的利用の抑制を事業者に義務付け、利用者とのやり取りで得た機微な個人データをモデル訓練に使うことも禁じる</li>
<li>違反には最大20万元（生命・健康に関わる被害を伴う場合）の罰金が科される</li>
<li>AIとの感情的な関係構築サービスに国が直接介入した初の全国規模の枠組みとして、他国の規制にも参照される可能性がある</li>
</ul>
<h2>Eaton・Infleqtion・ペン州立大、量子コンピュータで電力網防衛の実証実験へ</h2>
<ul>
<li>電力機器大手イートンは、米空軍研究所（AFRL）から700万ドルの契約を獲得したと発表</li>
<li>Infleqtion（量子計算スタートアップ）、ペンシルベニア州立大学と組み、24カ月かけてハイブリッド量子・古典アルゴリズムを開発する</li>
<li>目的は、電力網インフラに対する複雑な脅威（サイバー攻撃や物理的擾乱を含む）の検知・緩和</li>
<li>量子コンピュータを研究段階でなく、重要インフラの防衛という実運用課題に直接組み込もうとする産業応用型の事例</li>
<li>商用量子コンピュータの「実用化はいつか」という議論に対し、まず軍事・インフラ分野で限定的な実証を積み上げる流れが続いている</li>
</ul>
<h2>OpenAI、300〜400ドルのAIスマートスピーカーを準備中と報道</h2>
<ul>
<li>OpenAIが開発中とされる謎のAIデバイスについて、新たに価格帯の詳細が報じられた</li>
<li>想定価格は300〜400ドルで、スマートスピーカー型の製品になる見込み</li>
<li>ChatGPTを軸としたハードウェア展開の一環とみられ、Amazon EchoやGoogle Nestなど既存のスマートスピーカー市場への参入が想定される</li>
<li>ソフトウェア企業だったOpenAIがハードウェアに踏み込む動きとして、価格発表以降の実機情報が注目される</li>
</ul>
