<h2>ネタ1 候補が多すぎると選べない、雌のアマガエル</h2>
<ul>
<li>8月12日公開の研究では、雄の鳴き声が多い合唱を聞いた雌のアマガエルは、少数から選ぶ場合より相手を慎重に選ばなくなった。</li>
<li>選択肢の多さが必ずしも良い選択につながらない現象を、鳴き声を使う配偶行動で示した。</li>
<li>出典: <a href="https://www.nature.com/articles/d41586-026-02554-w">Nature: Too much mate choice overwhelms frogs</a></li>
</ul>
<h2>ネタ2 ヤドカリとゴキブリが種を運ぶ、日本の島の森</h2>
<ul>
<li>8月21日のモンガベイは、日本の島でヤドカリとゴキブリが植物の種を運ぶ意外な役割を報じた。</li>
<li>鳥や哺乳類だけでなく、地面近くを動く小動物も森の更新に関わるという視点である。</li>
<li>出典: <a href="https://news.mongabay.com/short-article/2026/08/hermit-crabs-and-cockroaches-emerge-as-unlikely-seed-dispersers-on-a-japanese-island/">Mongabay: Hermit crabs and cockroaches emerge as unlikely seed dispersers</a></li>
</ul>
<h2>ネタ3 満月に城壁へ現れる白い貴婦人、エストニアの町祭り</h2>
<ul>
<li>エストニアのハープサルでは8月28日から30日、満月に近い週末に「白い貴婦人祭」が開かれる。</li>
<li>旧市街は市場と文化公演の会場になり、日没後は司教城で伝説に基づく野外劇を上演する。祭りは約30年続いている。</li>
<li>出典: <a href="https://visitestonia.com/en/white-lady-festival">Visit Estonia</a></li>
</ul>
<h2>ネタ4 若いタコの縄張り争い、魚を選んで腕でたたく</h2>
<ul>
<li>ブラジル沿岸などで若いリーフオクトパスと10種の魚の接触101件を観察した研究が、8月12日に紹介された。</li>
<li>タコは魚を無差別に攻撃せず、縄張りを守って突いてくる種類へ素早く腕を振る行動を見せた。</li>
<li>出典: <a href="https://www.livescience.com/animals/octopuses/young-wild-octopuses-may-form-a-fight-club-and-slap-territorial-fish-if-they-get-too-close">Live Science</a></li>
</ul>
