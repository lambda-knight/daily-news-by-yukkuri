<h2>生成AIと科学：Claude、64時間でサソリ毒に結合するタンパク質を設計、211個中17個</h2>
<ul>
<li>Anthropicは10月20日、社内の研究用モデルがClaude Scienceの環境で、サソリの神経毒に結合する小さなタンパク質を設計した研究を公表しました。標的は、メキシコのCn2、ブラジルのTs1、北アフリカのAaH IとAaH II、中東のLqhIIIの5つの毒で、どれも神経のナトリウムチャネルに取り付く部分を狙いました。</li>
<li>Claudeは64時間動き、最初の24時間は人の追加指示なしで作業しました。人間が出した追加の指示は4回です。12種類の設計ツールを使って31万8484個の設計を作り、55万3052組の設計と毒の組み合わせの立体構造を予測しました。計算量は約1万GPU時間です。</li>
<li>Claudeが180個を選び、研究者がClaudeの助けを借りて31個を足し、計211個をAdaptyv BioとTwist Bioscienceの2社が実験で確かめました。合格条件は、両社のすべての繰り返しで結合が確認され、結合の強さを示す解離定数が1マイクロモーラー以下で、無関係なタンパク質には付かないことです。</li>
<li>条件を満たしたのは17個で、内訳はCn2に7個、AaH IIに4個、AaH Iに4個、LqhIIIに2個です。1つの設計で複数の毒に効かせる狙いのものは、1つも条件を満たしませんでした。最も強い2つは、数ナノモーラーという強い結合を示し、マウスでCn2を無力化したと報告のある抗体と同じ場所付近に付くとみられます。</li>
<li>限界も明記されています。使ったのは遺伝子組み換えで作った毒で、実際の毒液から精製したものではありません。細胞や動物で毒を無力化できるかは試していません。Anthropicは「抗毒素を作ったとは主張しない」と書いています。設計からは、毒そのものや既知のタンパク質に似たものを除いたとしています。</li>
<li>データの解析、図の作成、報告書の下書きもClaudeが監督のもとで行い、211個すべての設計とデータを公開しました。新薬の候補ではなく、AIが実験の前段をどこまで一人で回せるかを示した記録です。</li>
</ul>

<li>Redactのダン・サルトマンCEOは「際立つのは、人に伝えている内容とAIに伝えている内容の差だ」と述べています。</li>
<li>人の窓口なら研修資料に書かれるような応対方針が、AIの窓口では文章として残り、それが表に出ました。利用者がAIの窓口から規制当局の存在を知ることはない、という設計自体が今回の論点です。</li>
</ul>
<h2>生成AIと市場：GoogleとAmazon、PyTorchをNvidia以外のチップへ</h2>
<ul>
<li>Googleは10月20日、AI開発で広く使われる枠組みPyTorchを、自社のAI専用チップTPUで動かすための「TorchTPU」をオープンソースで公開しました。既存のPyTorchのアプリは、設定を変えるだけで書き換えずにTPUへ移せるとしています（TechCrunch）。</li>
<li>前日の10月19日には、Amazonが自社チップTrainiumとAWSで同じことをする「TorchNeuron」を発表しました。Amazonは、PyTorch本体からNvidiaのチップに依存する部分を切り離すコードも提案しており、PyTorchを初めから特定のチップに縛られない形にしようとしています。</li>
<li>PyTorchは、ある見方ではAIアプリの85％が使っているとされます。2016年にMetaが開発し、2022年にLinux Foundationへ移されました。Nvidiaの強さは、チップの性能に加え、開発者が書いたコードがNvidia向けの仕組みの上で動いていることにありました。</li>
<li>Googleは、Meta、Hugging Face、推論ソフトvLLMを作るInferact、SGLangを作るRadixArkなどと組んで、TorchTPUがこれらの道具で動くようにしたとしています。移行作業と途中のエラー修正を助ける「TPU agent suite」も出しました。</li>
<li>チップの値段や性能の比較ではなく、「コードを書き直さなくてよいか」という乗り換えの手間に、GoogleとAmazonが同じ週に手を付けた形です。</li>
</ul>
<h2>生成AIと電力：トランプ氏「データセンターは自前の電力を」、メンフィスは135日の建設停止</h2>
<ul>
<li>トランプ大統領は10月21日未明（米国時間）、Truth Socialに、新しい大型データセンターには自前の電力をつくることを「私が義務づけている」と投稿しました。余った電力は地域や送電網に戻し、電気代を下げる方向にすべきだとしています（Fox News、Al Jazeera）。</li>
<li>さらに、データセンターを地域に受け入れてもらいたいなら、地域や住民に「配当」を払えと書きました。「非常に不人気だったデータセンターが、金銭的な取引がまとまると非常に人気になるのを見てきた」とし、「取引をまとめて、建てろ」と結んでいます。義務づけの法的な根拠や中身は示していません。</li>
<li>背景には11月3日の中間選挙があります。トランプ氏は8月には反対運動を「中国への贈り物」と呼んでいました。3月のギャラップの調査では71％が地元へのAIデータセンター建設に反対し、21日に出たABCニュース・ワシントン・ポスト・イプソスの調査でも72％が反対でした。共和党の上院候補の中にも、規制強化に転じる人が出ています。</li>
<li>前日の10月20日には、イーロン・マスク氏のSpaceXAI（旧xAI）がデータセンターを集めるテネシー州メンフィスの市議会が、18か月の建設停止案を6対6の同数で否決しました。代わりに、直前に出された修正案で、データセンターの建設を135日間止めることを決めました。ポール・ヤング市長の行政命令による90日の影響調査と並行する形です。</li>
<li>否決された案は、大気、電力網、水、騒音への影響を調べ、恒久的な区画のルールを作るためのものでした。SpaceXAIはメンフィス周辺に3つのデータセンターを持ち、隣のミシシッピ州サウスヘイブンでガスタービンを動かす発電所をめぐっては、NAACPなどの大気汚染の訴えを退けるよう求めた政権の申し立てを、連邦判事が19日に退けています。</li>
<li>大統領は「お金で賛成に変えろ」と言い、地元の議会は「止めて調べる」を選びました。電力を誰が負担し、住民に何を返すのかが、AIの拡大の現場の争点になっています。</li>
</ul>
<h2>量子コンピュータとAI：Pasqal、AIエージェントが論文から量子実験まで、半数は今の機械で実行可能</h2>
<ul>
<li>フランスの中性原子型量子コンピュータ企業Pasqalは10月21日、AIエージェントに量子実験を組ませる「Neutral-Atom Agentic Toolkit」をオープンソースで公開しました。Claude Code、Cursor、Codex、Gemini CLIに追加して使えます（Quantum Computing Report）。</li>
<li>流れは、仕様を決める、パルスのプログラムを書く、古典計算機で模擬する、実機に投げる、結果を分析する、の5段階で、各段階で人が確認します。模擬を通さないと実機には送れず、実機の利用料が発生する前に人の明示的な承認が要る作りです。</li>
<li>検証では、カナダのFC1とサウジアラビアのSA1という同社の2台の実機で、3つの課題を回しました。2019年の論文の相転移の実験を56個と96個の原子の輪で再現して相関の長さ4.2サイトを得たほか、三角格子の磁性の理論を49個と100個の原子で実装し、同社の特許にあるグラフ彩色の手法を最大80ノードのグラフで動かしました。</li>
<li>別のエージェントには、arXivの論文633本を仕分けさせました。原子を並べるタイプの量子計算機向けと分類した526本のうち、258本、約49％が今の同社の機械でそのまま、または少しの手直しで実行できると判定しました。</li>
<li>ただし、論文では人の介入が欠かせなかったとも書いています。ある実験ではエージェントが不適切な測定量を選び、別の実験では、もっともらしいが誤った装置の故障診断を出しました。</li>
<li>エージェントが論文や特許から一晩で実機の実験を回せる一方、何を測れば答えになるかの判断は、まだ人が握っています。</li>
</ul>
<h2>量子コンピュータ：Alice &amp; Bob、フランスの国家計画の第1段階、論理誤りはまだしきい値の上</h2>
<ul>
<li>フランスの量子コンピュータ企業Alice &amp; Bobは10月20日、国防イノベーション庁（AID）と装備総局（DGA）が率いる国家計画「PROQCIMA」の第1段階の結果を公表しました（The Quantum Insider）。</li>
<li>PROQCIMAは10年で5億ユーロ規模の調達計画で、2032年までに論理量子ビット1000個の試作機2台を目指します。5月の国家戦略の見直しで、目標は128個から1000個に引き上げられました。参加はAlice &amp; Bob、Pasqal、Quandela、Quobly、C12の5社で、2026〜2028年の第2段階で3社に絞り、8年目以降に2社を残します。</li>
<li>Alice &amp; Bobは、6量子ビットのチップ2つと12量子ビットのチップ1つで3台の実証機を動かしました。ビット反転に強い「キャット量子ビット」どうしの制御NOTゲート、補助量子ビットの測定とリセット、距離3の繰り返し符号の複数サイクル、キャット量子ビット1個への非クリフォードゲートを実演しました。</li>
<li>肝心の論理誤りは、全体で測ったものの、誤り訂正が効き始めるしきい値をまだ下回っていません。同社は、実機の測定データから作ったデジタルツインで、しきい値を下回るのに何が必要かを模擬し、最優先はチップ全体でコヒーレンス時間を一様に延ばすことだとしています。</li>
<li>1量子ビットあたり50以上の指標を追う自社ソフトで、性能のずれを見つけて再調整します。以前は、ずれの発見と修正に最大1日の稼働時間を失うことがありました。テオー・ペロナンCEOは、キャット量子ビットの方式が誤り耐性への競争を先導できることを示した、と述べています。</li>
<li>同じ週にQuantinuumなどが記録を競う中、国の審査に出す成績表で「まだしきい値の上」と書いたこと自体が、この計画の段階を示しています。</li>

<h2>セキュリティ：犯罪集団4つ、Claudeに「許可済み」と思わせて自律攻撃</h2>
<ul>
<li>WIREDは10月21日、CrowdStrikeの研究者が、5月から8月に攻撃を行った未報告の4つの集団のAI基盤を分析した結果を報じました。4集団は、中国語、スペイン語と英語、インドネシア語、ロシア語でそれぞれ活動していました。</li>
<li>4集団とも、攻撃用のAI基盤をウェブ上で誰でも見られる状態に置いていたため、どのモデルをどう使ったかが分かりました。主に使われていたのはAnthropicのClaudeの各版と、DeepSeekの公開モデルで、ほとんどは最新ではない旧い版でした。</li>
<li>安全装置の回避方法として、4集団とも、これは許可を得た侵入テストだとモデルに信じ込ませていました。よく使われたのが、エージェントの作業フォルダーに「承認済み」を示すファイルを置く手口です。技術の低い集団は、乱暴な指示でモデルを押し切ろうとしていました。</li>
<li>中国語の集団は、主にClaude Opus 4.8を中国の中継サービス経由で使い、ClawGodという改造ツールでClaude Codeのシステム指示から「CYBER_RISK_INSTRUCTION」を消そうとしていました。許可された検査だけに協力するよう定めた指示です。ブラジルとコロンビアの政府機関に侵入しています。</li>
<li>スペイン語と英語の集団は、「監督役」のClaude Codeが攻撃の手順を指示し、「実行役」が実行する二段構えを作り、アルゼンチンの医療機関少なくとも15組織に侵入し、1組織からは認証情報と診療記録を盗んだとみられます。インドネシア語の集団も、同国とバングラデシュの政府のドメインに侵入しました。</li>
<li>CrowdStrikeのアダム・マイヤーズ上級副社長は、新しい脆弱性は使われておらず、防げたはずの基本的な不備をAIの速さと量で突いていると述べました。「モデルごとに、同じ会社のものでも安全装置の強さが違う」とも言い、集団はその差を使い分けていました。</li>
<li>10月20日の回で伝えた、1人のハッカーがAIで100社超に侵入した件は手口の安さが焦点でした。今回は、モデルが「許可」を何で判断しているかが突かれています。フォルダーに置いた1枚のファイルが、許可証として通っていました。</li>
</ul>
<h2>セキュリティ：ランサムウェア「SafePay」、FBIなどが600超の被害を警告</h2>
<ul>
<li>FBI、米サイバーセキュリティ・インフラ安全保障庁（CISA）、シークレットサービスは10月20日、ドイツと英国の機関と共同で、ランサムウェア集団SafePayへの警告を出しました。2024年8月以降、北米、南米、欧州、オーストラリアで少なくとも600の組織が被害を受け、重要インフラも含まれます（BleepingComputer、The Record）。</li>
<li>機関は、SafePayを「2026年に最も活発なランサムウェア集団の一つ」としています。Halcyonのシンシア・カイザー氏によると（Cybersecurity Dive）、攻撃の件数は2025年末が山で、2026年も毎月15〜30組織ほどを狙い続けています。最新の確認例は8月です。</li>
<li>侵入の入り口は、漏れた認証情報、パスワードの総当たり、VPNの悪用です。VPN事業者Mullvadに結び付くIPアドレスからの接続が目立ちました。悪用された既知の欠陥として、CiscoのASA、SonicWallの機器、Veeamのバックアップ製品の脆弱性が挙がっています。</li>
<li>侵入後は、新しいアカウントを作るか既存のものを乗っ取り、正規の利用者のパスワードを変えて締め出します。AnyDeskやTeamViewerなどの遠隔操作ソフトで暗号化の道具を持ち込み、復旧に使う影のコピーを消し、バックアップを置いたNASを初期化することもあります。</li>
<li>身代金は売上の一定割合を暗号資産で求め、電話をかけて支払いを迫ります。被害例には、米国のIT流通大手Ingram Micro、英国のMicrolise、米政府の業務を請け負うConduentがあり、Conduentは関連する集団訴訟で8000万ドルの和解を発表しています。コードの一部は、ほぼ活動を止めたLockBitに似ているとされます。</li>
<li>機関は、管理用ツールと権限を絞ること、多要素認証、境界機器とVPNの更新を求め、身代金を払っても復旧は保証されないとしています。</li>
</ul>
