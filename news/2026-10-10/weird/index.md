<h2>61歳が5時間のプランク、カナダの元副校長が自分の世界記録を更新</h2>
<ul>
<li>カナダ・アルバータ州のドナジーン・ワイルドさん（61歳）が、ユタ州セントジョージで開かれた「ハンツマン・ワールド・シニアゲームズ」の開会式で、腹筋のプランク姿勢を5時間保ちました。</li>
<li>自身が2024年に樹立した女性のギネス世界記録「4時間30分11秒」を、約30分上回る数字です。大会側によると、本人は約半年前に「この大会で記録を破りたい」と申し出ていました。</li>
<li>大会は10月5日から17日まで、50歳以上の選手が集う総合競技会です。5時間到達の瞬間を収めた動画は400万回以上再生されました。</li>
<li>始めたきっかけは約12年前の手首の骨折。ギプスで走ることも重量挙げもできず、代わりにプランクを選びました。</li>
<li>普段は1日最大3時間、前回の挑戦前は3時間を2回、計6時間練習。姿勢を保ちながら読書や映画鑑賞をし、修士課程の勉強もこなしたと報じられています。</li>
<li>元高校副校長で、5人の子と12人の孫がいます。前回の記録挑戦は勤務していた高校で行い、夫ランディさんが支えました。</li>
<li>大会のカイル・ケースCEOは「今いる場所を認めれば、やめる必要はない。好きなことは年を重ねても続けられる」と語りました。</li>
<li>5時間の記録がギネスに正式認定されたかは、現時点の報道では示されていません。</li>
<li>出典: <a href="https://www.ksl.com/article/51633497/61-year-old-woman-holds-5-hour-plank--a-new-world-record--at-huntsman-world-senior-games">KSL</a> / <a href="https://www.upi.com/Odd_News/2026/10/08/Guinness-World-Records-abdominal-plank/1261791480174/">UPI</a> / <a href="https://www.scrippsnews.com/life/good-news/grandmother-of-12-beats-world-record-for-longest-plank-held-by-a-woman">Scripps News（2024年の記録）</a></li>
</ul>
<h2>下水管の詰まりから1965年の卒業指輪、アラバマ州の作業員が持ち主を探し当てる</h2>
<ul>
<li>アラバマ州シェフィールドで、下水本管の詰まりを清掃していた作業員2人が、汚れた卒業記念指輪を見つけました。</li>
<li>指輪には「バレル・スレーター高校」の文字と1965年卒業の刻印、内側に頭文字「OJM」。同校は隣町フローレンスにあった黒人生徒のための学校で、人種統合の流れの中で1969年に閉校しています。</li>
<li>下水処理場の運転員ジュニア・ライナーさんが指輪を磨き、同窓生のフェイスブックに投稿。数か月は手掛かりがありませんでした。</li>
<li>娘婿がネット上で1965年卒の写真を見つけ、「オスカー・ジェームズ・メレディス」という名前と頭文字が一致。市議会議員を務める娘婿の父の伝手で、娘のエイプリル・メレディス・ムーアさんにたどり着きました。</li>
<li>父のメレディスさん（79歳）は、指輪を高校時代からの恋人で後の妻アンナさんに贈っていました。アンナさんは結婚の数年前に「なくした」と話していたといいます。アンナさんは数年前に亡くなっています。</li>
<li>指輪が見つかった下水管は、アンナさんが育った家の真向かい。ライナーさんは、洗面台の排水口から落ちたとみています。</li>
<li>手渡された指輪は今も指に入り、メレディスさんは家のケースに飾るつもりだと話しました。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/10/08/class-ring-sewer-Sheffield-Alabama/7991791477667/">UPI</a> / <a href="https://dnyuz.com/2026/10/07/a-1965-class-ring-surfaced-in-a-sewer-then-came-a-remarkable-search/">The Optimist（ワシントン・ポスト）転載</a></li>
</ul>
<h2>685人の壁にあと少し、ニューヨーク・コミコンのスパイダーマン大集合</h2>
<ul>
<li>10月8日夜、ニューヨークのジャビッツ・センターで開かれたニューヨーク・コミコンで、「スパイダーマンの衣装を着た人の最大集合」のギネス世界記録挑戦が行われました。</li>
<li>主催は玩具メーカーのジャズウェアーズとディズニー・コンシューマー・プロダクツ。会場にはギネスの公式認定員が立ち会いました。</li>
<li>現行記録は685人。2023年、ソニー・ピクチャーズ・エンタテインメント・マレーシアが映画「スパイダーマン：アクロス・ザ・スパイダーバース」の公開記念で樹立したものです。</li>
<li>条件は厳格で、マスク、ブーツ、スーツ、クモの巣模様、クモの紋章までそろった「公認の姿」であること。別の公式スーツは可、ヴェノムの衣装は不可でした。主催者は大人用・子ども用の衣装を無料で配りました。</li>
<li>数百人が集まりましたが、主催者は最終集計が「685人の記録にわずかに届かなかった」と認めています。正式な人数は公表されていません。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/10/09/Guinness-World-Records-spider-man/4421791569448/">UPI</a> / <a href="https://comiccrusaders.com/pop-culture/convention-coverage/nycc-spider-man-guinness-world-record-jazwares-2026/">Comic Crusaders（挑戦の条件）</a></li>
</ul>
<h2>開館前の水族館に約24匹の子猫、ミネソタの保護団体が6年目の社会科見学</h2>
<ul>
<li>10月5日の朝、ミネソタ州ブルーミントンのショッピングモール「モール・オブ・アメリカ」内の水族館シーライフに、保護された子猫約24匹が訪れました。</li>
<li>連れてきたのは、親を失った乳飲み子猫の預かり先を探す保護団体「ビティ・キティ・ブリゲード」。この見学は今年で6年目で、団体は今年約1000匹の子猫を担当しています。</li>
<li>一般客が入る前の約2時間、長さ約90メートルの水中トンネル、シロワニ、ウミガメ、クマノミの水槽を見て回りました。</li>
<li>「ターキーレッグ」と名付けられた子猫は後ろ足で立ち上がり、クマノミの泳ぐガラスを前足でたたきながら鳴きました。薄暗い青い光の中で昼寝をする子猫もいました。</li>
<li>団体のイベント責任者カイヤ・アンダーソンさんは、外の刺激に慣れる社会化が、譲渡後の新しい家への適応を助けると説明しています。</li>
<li>水族館は別の日に、別の保護団体の子犬も受け入れました。広報担当のジョン・サルウォルドさんは「子犬はずっと走り回る」と違いを語っています。</li>
<li>出典: <a href="https://www.mprnews.org/story/2026/10/07/orphaned-kittens-meet-sharks-and-stingrays-on-an-aquarium-field-trip-at-the-mall-of-america">MPR News（AP通信）</a> / <a href="https://www.upi.com/Odd_News/2026/10/09/Sea-Life-Aquarium-kittens/4211791564630/">UPI</a></li>
</ul>

<li>記録を破った話も、届かなかった話も、続ける人と探す人と集まる人がいて初めて生まれた出来事です。</li>
