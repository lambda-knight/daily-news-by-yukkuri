<h1>世界の珍ニュース（2026年10月4日）</h1>
<h2>オープニング：2026年10月4日 — 世界の珍ニュース</h2>
<p>カナダの巨大カボチャ大会は、670キロ級のカボチャ同士の勝負がわずか1ポンド、約450グラムの差で決まった。愛知・名古屋アジア大会では、ウズベキスタンの男子バレー代表がコンビニで買える靴下で試合に出て、ファミリーマートが「大変光栄」とコメントした。宇宙では、女優ファラ・フォーセットの名を持つと伝えられる冷戦期のスパイ衛星が、打ち上げから38年後に軌道上でばらばらになった。アラスカでは、子グマのころ母の背中に乗っていた20歳のクマが「太ったクマ」の頂点に立ち、三重県の湯の山温泉では、458年前の焼き討ちを語り継ぐ重さ約600キロの火炎みこしが10月4日夜の第55回僧兵まつりで温泉街の坂を上る。今回は、ほんのわずかな差と、とても長い時間が同じ話の中に並んだ5つの出来事をたどる。</p>
<h2>670キロ級が1ポンド差、カナダの巨大カボチャ大会と2598ポンドの州記録</h2>
<ul>
<li>カナダ西部ブリティッシュコロンビア州ラングレーで10月3日、13回目の「BC巨大カボチャ計量大会」が開かれた。優勝はケロウナのジョーダン・アバテさんの1485ポンド（約674キロ）。2位の「チーム・ハリデー」は1484ポンドで、差は1ポンド（約450グラム）だった（CP24）。</li>
<li>アバテさんは半年間、毎日およそ2時間を世話に充てた。「何か月も水やり、剪定、株の手入れを続けた。冬のあいだも土づくりをしていた」と話し、結果には「満足している」と答えた。巨大カボチャは成長のピークの約2週間、1日に最大60ポンド（約27キロ）増えることがある。</li>
<li>同じ大会では、巨大スカッシュの1149ポンド（約521キロ）と、長さ131.5インチ（約3.3メートル）のロングゴードが州の新記録になった。大会は国際団体「グレート・パンプキン・コモンウェルス」の基準で計量する。</li>
<li>米マサチューセッツ州トップスフィールドでは、10月2日に開幕したトップスフィールド・フェアの「第42回オール・ニューイングランド巨大カボチャ計量大会」で、地元のウッディ・ランカスターさんが2598ポンド（約1178キロ）を記録した。2025年の州記録2507ポンドを91ポンド上回り、州記録とフェア史上最大を同時に更新した（NBCボストン）。</li>
<li>カボチャは小型車ほどの大きさで、フェア会期の10月12日まで温度管理された展示スペースに置かれる。フェアの広報担当デイブ・トムソンさんは「生育条件がちょうどよかった。生産者たちは毎日何時間もかけて準備してきた」と話した。</li>
<li>世界記録は英国のパトン兄弟の2800ポンド超で、カナダの優勝カボチャのほぼ2倍にあたる。</li>
<li>出典: <a href="https://www.cp24.com/news/canada/2026/10/03/oh-my-gourd-bc-giant-pumpkin-weigh-off-comes-down-to-1-pound-difference/">CP24</a> / <a href="https://www.nbcboston.com/news/local/topsfield-fair-returns-giant-pumpkin-weigh-off/4024687/">NBC Boston</a></li>
</ul>
<h2>ウズベキスタン代表の足元にファミマの靴下、アジア大会男子バレーで話題に</h2>
<ul>
<li>第20回アジア競技大会（愛知・名古屋）の男子バレーボールで9月27日、日本はウズベキスタンを3対0（25-17、25-20、25-17）で下した。会場は愛知県岡崎市の岡崎中央総合公園総合体育館（週刊女性PRIME、ハッシュアウト）。</li>
<li>試合後、SNSでは「ファミマの靴下にしか見えない」と話題になった。ウズベキスタンの選手がそろって履いていたのは、白地に青と黄緑のラインが入った靴下で、ファミリーマートの衣料品シリーズ「コンビニエンスウェア」の定番品「ラインソックス コンビニホワイト」と同じデザインだった。</li>
<li>商品は本体390円（税込429円）。男女兼用で、サイズは22〜25センチと25〜28センチの2種類。綿とポリエステルの混紡で足裏はパイル編み。コンビニエンスウェアは2021年度のグッドデザイン賞を受けている。</li>
<li>ファミリーマートは着用を「認識しております」としたうえで、「国際大会という貴重な舞台で弊社のラインソックスをご着用いただき、大変光栄に感じております」とコメントした。</li>
<li>毎日新聞の取材に対し、選手たちは大会の用具規定を把握していなかったと何度も謝っていたという。ファミマの靴下は「とても気に入った様子」で、その後スポーツ用の靴下を手に入れ、翌28日のパキスタン戦では白い靴下に替わっていた。着用は1日限りだった。</li>
<li>青・白・緑のラインは、ウズベキスタン国旗の色とも、ファミリーマートのロゴの色とも重なる（SoraNews24）。</li>
<li>出典: <a href="https://www.jprime.jp/articles/-/43871">週刊女性PRIME</a> / <a href="https://hashout.jp/sns/11612/">ハッシュアウト</a> / <a href="https://soranews24.com/2026/10/01/foreign-sports-team-competing-in-japan-finds-critical-uniform-item-at-convenience-store/">SoraNews24</a></li>
</ul>
<h2>女優の名を持つ冷戦期のスパイ衛星「ファラーⅢ」、38年後に軌道上で分裂</h2>
<ul>
<li>米宇宙軍の宇宙部隊（U.S. Space Forces–Space）は、機密衛星「USA 32」が世界時の9月13日21時13分ごろ、高度約775キロの低軌道で分裂したと確認した。「追跡できる破片はすべて通常の接近評価に組み込んだ」「差し迫った脅威は確認されていない」としている。</li>
<li>USA 32は1988年9月5日に打ち上げられた米国家偵察局（NRO）の電子情報収集衛星で、ソ連のレーダー電波を傍受する目的だったとされる。コードネームは「ファラーⅢ（FARRAH III）」で、女優ファラ・フォーセットにちなむと報じられている。同じ「プログラム989」には、ラクエル・ウェルチ、ウルスラ・アンドレスの名を思わせる「RAQUEL」「URSULA」という衛星もあった（Popular Science）。</li>
<li>機密のため軌道要素も設計情報も公開されておらず、分裂の原因は分かっていない。38年間、日なたと日陰を繰り返すうちに圧力タンクや電池が破裂した可能性や、デブリとの衝突の可能性が挙がっている。</li>
<li>高度775キロ前後は混雑した軌道帯で、周囲には少なくとも200機の衛星が飛んでいる。</li>
<li>宇宙状況監視の企業オカピ・オービッツは、公開情報から構造を推定して40通りの分裂シミュレーションを実施した。10センチ以上の破片は5〜約250個とばらつき、1センチ以上は約3500個。10年後には500個をわずかに下回るまで減ると試算した。3枚の大型アンテナは比較的形を保ったまま分離したとみている。</li>
<li>出典: <a href="https://www.popsci.com/science/farrah-fawcett-satellite-explosion-explained/">Popular Science</a> / <a href="https://www.wionews.com/trending/us-spy-satellite-farrah-iii-breaks-up-775km-above-earth-1790156002967">WION</a> / <a href="https://www.okapiorbits.space/en/blog/what-survives-a-breakup-modelling-the-fragmentation-of-usa-32">OKAPI:Orbits</a></li>
</ul>
<h2>母の背中に乗っていた子グマが王者に、ファット・ベア・ウィーク2026は「89番バックパック」</h2>
<ul>
<li>9月26日の本番組で、投票初日にサーバーが過負荷になったと紹介したアラスカ州カトマイ国立公園の「ファット・ベア・ウィーク」は、9月29日（現地）の決勝で「89番バックパック」が優勝した。得票は10万3334票対9万8253票で、差は約5000票だった（CBSニュース）。</li>
<li>決勝の相手「910番」は、元王者「409番ビードノーズ」の子。バックパックの母「ホリー」は2019年の王者で、元王者の子ども同士の決勝になった。前年王者の「32番チャンク」は第1ラウンドで敗退していた。出場は16頭で、大会全体の投票は200万票を超えた。</li>
<li>バックパックは2006年、ホリーが初めてブルックス川に連れてきた、生まれて1年目の子グマだった。川を渡るとき母の背中によじ登る癖があり、それが名前の由来になった。</li>
<li>2歳ごろに脚に大けがを負い、レンジャーたちは生き延びられるか危ぶんだが、回復して2008年に独り立ちした。2012年から公園のカメラに映り続けている。</li>
<li>いまは20歳で、推定体重は1000〜1200ポンド（約450〜540キロ）。同年代のオスとしては傷が少ないことで知られる。レンジャーのサラ・ブルースさんは「もめごとに加わったり騒ぎを起こしたりしない」と語り、ひとりで静かに座る「穏やかな立ち位置」のクマとされる。</li>
<li>米内務省はバックパックを「ラードの君主、胴回りの伯爵、牛肉の司令官」とたたえた。ブルースさんは「太ったクマは成功したクマ」と話し、出場したすべてのクマがサケの遡上で冬に備えられたことを強調した。</li>
<li>出典: <a href="https://www.cbsnews.com/news/fat-bear-week-2026-winner-backpack/">CBS News</a> / <a href="https://www.deseret.com/lifestyle/2026/09/30/backpack-bear-89-crowned-champion-fat-bear-week-katmai-national-park-alaska-salmon/">Deseret News</a> / <a href="https://www.upi.com/Odd_News/2026/09/30/fat-bear-week-katmai-national-park-backpack-winner/1461790779913/">UPI</a></li>
</ul>
<h2>458年前の焼き討ちを伝える火炎みこし、三重・湯の山温泉で第55回僧兵まつり</h2>
<ul>
<li>三重県菰野町の湯の山温泉で10月4日（日）、第55回「僧兵まつり」が開かれる。主催は僧兵まつり実行委員会で、メイン会場は御在所ロープウエイの広場。午後5時から10時までで入場は無料（観光三重、共同通信）。</li>
<li>祭りの元になったのは天台宗の三嶽寺。大同2年（807年）に建てられ、760年あまり続いたのち、永禄11年（1568年）の織田信長の伊勢進攻で焼き討ちにあった。そのとき戦った僧兵たちの姿を、明治時代から再現して伝えてきたとされる（菰野町観光協会）。</li>
<li>主役の「火炎みこし」は、重さ約600キロの大きな樽みこしに、松明およそ100本を立てたもの。松明には油分を多く含む松の芯材「ジン」を使うため、猛烈な炎と火の粉が上がる。</li>
<li>三嶽寺でおはらいを受けたみこしは、白頭巾に法衣姿の男衆に担がれ、寺からロープウエイ乗り場まで温泉街の急な坂道約2キロを約1時間かけて進む。熱が強いため、火事を防ごうと沿道から水が浴びせられる。2025年の第54回は午後8時30分に出発した。</li>
<li>道幅が狭く、松明の燃えかすや火の粉が落ちるため、観光三重はみこしの両脇に近づかないよう呼びかけている。</li>
<li>会場では僧兵の装束をまとった打ち手による「僧兵太鼓」や打ち上げ花火があり、温泉街の旅館や飲食店では、僧兵のスタミナ源とされた「僧兵鍋」が出される。イノシシ、シカ、鶏肉と地元の山の幸を、特製の僧兵みそと甘酒で煮込んだ郷土料理だ。</li>
<li>出典: <a href="https://www.kyodo.co.jp/life/2026-09-27_4037605/">共同通信</a> / <a href="https://www.kanko-komono.com/spots/2724/">菰野町観光協会</a> / <a href="https://www.kankomie.or.jp/event/34204">観光三重（第55回）</a> / <a href="https://www.kankomie.or.jp/topic/1025">観光三重（火炎みこし）</a></li>
</ul>
<h2>まとめ</h2>
<ul>
<li>カナダの巨大カボチャ大会は、半年かけて育てた670キロ級のカボチャ同士が、わずか1ポンド差で勝負を分けた。マサチューセッツでは2598ポンドの州記録が生まれた。</li>
<li>ウズベキスタンの男子バレー代表は、規定を知らずにファミマの429円の靴下で試合に出て、1日で本来の靴下に戻した。</li>
<li>女優の名を持つと伝えられる冷戦期のスパイ衛星ファラーⅢは、打ち上げから38年後に高度775キロでばらばらになった。</li>
<li>母の背中に乗っていた子グマのバックパックは、大けがを乗り越えて20歳でファット・ベア・ウィークの王者になった。</li>
<li>湯の山温泉の僧兵まつりは、458年前の焼き討ちを、600キロの火炎みこしと温泉街の坂道で語り継いでいる。</li>
</ul>
