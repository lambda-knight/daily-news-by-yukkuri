<h2>オリーブの木が1本もないフィンランド、クロアチアのオリーブ摘み世界選手権で優勝</h2>
<ul>
<li>クロアチアのブラチ島にある人口約1500人の町ポスティラで、9回目の「オリーブ摘み世界選手権」が開かれ、フィンランドのチームが優勝しました。オリーブオイル専門誌オリーブ・オイル・タイムズが10月12日に、UPIが19日に伝えています。</li>
<li>参加は10チーム。フィンランド、スウェーデン、セルビア、リトアニア、ポーランド、チェコ、アメリカ、ボスニア・ヘルツェゴビナ、地元クロアチア、それにデジタルノマドの国際混成チームです。前回王者のフランスは出場しませんでした。</li>
<li>ルールは、男女2人ずつの4人1組で、45分間にどれだけ摘めるか。機械は使わず手作業だけで、実は「サケテ」と呼ばれる伝統の麻袋のエプロンに集め、チームの箱へ移します。聖ヨセフのオリーブ畑で金曜に競技し、重さは地元の農業協同組合の検量責任者と各チームの主将だけが知り、結果は土曜の表彰式まで伏せられました。</li>
<li>結果は、1位フィンランド55.4キロ、2位チェコ48.4キロ、3位ポーランド46.6キロ。地元クロアチアは43.2キロで5位、アメリカは42.4キロで7位、最下位のデジタルノマドは31.6キロでした。</li>
<li>前年のフィンランドは4位。主将のペトリ・ウトリアイネンさんは「フィンランドにはオリーブの木が1本もないのに、世界王者になった。信じられない」と話しています。前年（8回目）の優勝はフランスで、45分で64キロでした。4位だった前年のフィンランドは58キロで、今年は前年より少ない量で頂点に立ちました。</li>
<li>大会は2017年に始まり、2019年には創造的観光の国際ネットワークから賞を受けています。主催はポスティラ観光協会、ポスティラ町、ポスティラ農業協同組合、アルドゥラ・スポーツ。土曜にはシュクリプのオリーブオイル博物館や、伝統的な村ドルの散策も組まれました。観光協会のイヴァナ・イェリンチッチ代表は「まねではなく、刺激を与える観光地のブランドをつくっている」と述べています。</li>

</ul>
<h2>「何をしているか分からない」と掲げた33歳、カナダ・ケロウナ市議選で8人の枠に入る</h2>
<ul>
<li>カナダ西部ブリティッシュコロンビア州ケロウナで10月17日に市議選があり、37人が8議席を争いました。市の暫定集計で、地元の事業主ブレイディ・ロジャーズさん（33）が1万2635票の4位で当選圏に入りました。最下位当選者とは1165票差です。結果は21日までに正式に確定する見込みです。</li>
<li>選挙サイトの冒頭は「政治は好きか？ いいえ。何をしているか分かっているか？ いいえ。では資格はあるか？ これもいいえ」。看板には「まあ、やるよ」「どれだけ難しいっていうんだ」「心配するな、全部直す（諸条件が適用されます）」「ほとんどやりたくない」「家賃を払いたいだけ」と書きました。</li>
<li>「市長選に立候補」と書いてから市議会に訂正した看板もありました。初期の看板では council（議会）のつづりを2通りに間違えていましたが、印刷所が刷る前に気づいて直したといい、本人は「母は英語の教師」と付け加えています。</li>
<li>本人は地元育ちで、ブリティッシュコロンビア大学オカナガン校を卒業し、ロボットによる自動化のエンジニアとして4年働きました。仕事に「魂がない」と感じて辞め、2019年から妻と、地元で回収したプラスチックごみを新しい製品に変える店「ザ・ロジェリー」を中心街で営んでいます。</li>
<li>公約は、車を持たなくても暮らせる公共交通、土地への課税を重くして建物への課税を軽くすること（州法では現在、市にこの選択肢はない）、ホームレス対策、小さな商店の支援です。</li>
<li>「資格がない」という文句は冗談で、関係する経験はあると、本人はグローバル・ニュースに説明しました。当選が見えると「どうやら市議になったらしい」と投稿し、仕事は真剣にやるとも話しています。投票率は約30％でした。</li>

</ul>
<h2>最後の貸出は1983年9月1日、43年ぶりにカナダの図書館へ戻った戦争小説</h2>
<ul>
<li>カナダ西部ビクトリアのグレーター・ビクトリア公共図書館で、返却された本の中から、ほこりをかぶったハーマン・ウォークの長編小説「戦争と追憶」が見つかりました。1978年刊行で、「戦争の嵐」の続編。1941年12月から1945年8月6日までの2つの家族を描く第二次世界大戦の物語です。</li>
<li>背表紙は割れ、バーコードはありません。中には、今のコンピューター管理より前の紙の貸出カードが残っていました。記録では1970年代末から何度も借りられ、最後の貸出は1983年9月1日。UPIによると、返却先はオークベイ分館でした。</li>
<li>誰が返したのか、どこにあったのかは分かりません。メモもなく、貸出記録は定期的に消去されるため、借り手はたどれません。職員のケイトリン・オッテンブライトさんは「バーコードはどこ？ どうやって返却処理するの？」と顔を見合わせたと話しています。</li>
<li>不在の期間は、オッテンブライトさんの計算で約1万5742日。1995年の延滞料（1日20セント）で計算すると3148.40ドルになりますが、図書館は2024年から延滞料を取っておらず、何十年遅れの返却でも請求はありません。</li>
<li>オッテンブライトさんは「世界一の物語があるのか、誰かのベッドの下にあったのか」と言います。運営担当のデリア・フィリペスクさんは「勇気か良心で、返しに来てくれた人がいたことがうれしい」と述べました。</li>
<li>UPIが地元紙タイムズ・コロニストの報道として伝えたところでは、この図書館の最長記録は別にあり、1916年に借りられて1998年に戻った、スティーブン・リーコックの「小さな町の日だまりスケッチ」の82年です。</li>
<li>出典: <a href="https://www.cp24.com/news/canada/2026/10/08/43-year-overdue-library-book-finally-returned-to-greater-victoria-library/">CP24（CTV News）</a> / <a href="https://www.upi.com/Odd_News/2026/10/19/canada-greater-victoria-public-library-43-years-overdue/1141792431813/">UPI</a></li>
</ul>
<h2>4×4のルービックキューブを9.806秒、ニュージーランドの学生4人が作ったロボット</h2>
<ul>
<li>ニュージーランドのカンタベリー大学で、機械と電子を融合したメカトロニクス工学科の4年生4人が作ったロボットが、10月16日（金）の公式挑戦で、4×4×4のルービックキューブを9.806秒でそろえました。ギネス世界記録の認定待ちです。</li>
<li>大学の発表では、これまでのロボットの記録は45秒、人間の記録は15秒。ロボットの45秒は、英ブリストル大学の学生マット・ピデンさんのロボットが2025年5月に出した45.305秒で、それ以前は2015年の1分18秒でした。</li>
<li>始まりは卒業研究です。45秒で解くロボットの動画をSNSで見て、ロボットと人間の両方の記録を抜くことを目標にしました。分担は、機械設計がケイレブ・エヴェリットさん、電気とモーター制御がヨハン・トーレスさん、画像認識がヘイデン・ワトソンさん、ソフトウエアがマズ・キャメロンさん。</li>
<li>仕組みは、4台のカメラで色を読み取り、公開されている解法プログラムで手順を計算するもの。従来機と違って3つの軸すべての面を回せるため、キューブの向きを変えるだけの無駄な動きがいりません。吸盤でキューブをより速く正確に動かし、モーターはドローン用の高速なものを専用の制御装置と組み合わせました。解法の計算は公開プログラムのままで、短縮は回す仕組みの工夫によるものです。</li>
<li>予算は機械工学科が出した「とても限られた」もの。キャメロンさんは「ロボットは人間より上を行けると分かっていた」と話しています。ロボットは大学に残り、4人とも国内での技術職が決まっています。</li>
<li>出典: <a href="https://www.canterbury.ac.nz/news-and-events/news/2026/uc-engineering-students-design-record-breaking-robot-">University of Canterbury</a> / <a href="https://www.upi.com/Odd_News/2026/10/19/nz-Guinness-World-Records-rubiks-cube-robot/6671792423259/">UPI</a> / <a href="https://bristol.ac.uk/news/2025/may/rubiks-cube-world-record.html">University of Bristol（2025年の記録）</a></li>
</ul>
<h2>まとめ</h2>
<ul>
<li>オリーブの木がない国のフィンランドが、前年4位から55.4キロで優勝。前回王者フランスは不在でした。</li>
<li>「資格はない」と冗談で掲げたロジャーズさんは、37人中4位の1万2635票。公約は交通、土地課税、ホームレス対策と、中身は真面目です。</li>
<li>「戦争と追憶」は、1983年9月1日の貸出から約1万5742日ぶりに戻りました。延滞料は2024年に廃止済みで、請求はありません。</li>
<li>カンタベリー大学の学生ロボットは9.806秒。ロボットの45秒も人間の15秒も下回り、ギネスの判断を待っています。</li>
</ul>
