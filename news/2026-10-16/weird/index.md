<li>4本の比較軸は「年月」です。99年生きた人の初挑戦、7年かけて伸ばした尾、100年前の本と同じ日に起きた出来事、そしてだれかが何年も使った品を1000円で引き取る店。積み重なった時間が、何に変わったのかを見ていきます。</li>

<h2>99歳のヘルガ・ダフィーさん、飛ぶ飛行機の翼の上に立ち最高齢ウイングウォーカーに</h2>
<ul>
<li>英国の99歳、ヘルガ・ダフィーさんが、飛行中の小型機の翼の上に立つ「ウイングウォーキング」で、ギネス世界記録の最高齢記録を作りました。10月14日から15日にかけてUPIや英国のニュースサイトが伝えています。</li>
<li>会場はイングランド南西部グロスターシャー州サイレンセスター近くのRFCレンドコム飛行場。運航はウイングウォーキングの専門チーム「エアロスーパーバティクス」で、ギネスの公式認定員が現地で認定証を手渡しました。</li>
<li>当初は99歳の誕生日の9月23日に飛ぶ予定でしたが、延期されていました。</li>
<li>きっかけは、前の記録保持者ベティ・ブロメージさんのニュースです。ブロメージさんは8月4日、同じサイレンセスターの飛行場で97歳145日で翼の上に立ち、宙返りもこなして、女性の最高齢ウイングウォーカーと宙返りウイングウォークの記録を作っていました。</li>
<li>ダフィーさんは7人きょうだいの長女。長くサマセット州フロームで暮らし、いまはウィルトシャー州ディバイジズの介護施設に住んでいます。子どもに高い期待をかけた亡き父について「誇りに思ってくれるはず」と話しています。</li>
<li>飛んだ感想は「妙な感じ」。「わくわくしすぎて、怖くなかった」と語りました。見守っためいのジャッキー・ローズさんは、ダフィーさんを「独立心が強く、はっきりものを言う人」と呼び、「ずっと何か違うことをしたがっていた」と話しています。</li>
<li>挑戦でウィルトシャー・アンド・バース航空救急に1300ポンド以上を集めました。見守っためいのジャッキー・ローズさんとジュリー・プリースさんの母が、この航空救急で最期の搬送をされたためです。同団体のサム・コンウェイさんは「人生最高の時間を過ごしたように見える」とたたえました。</li>
<li>記録を抜かれたブロメージさんはお祝いを述べつつ、BBCに「100歳になったらもう一度やって、また抜き返す」と宣言しています。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/10/15/guinness-world-records-wing-walker/4971792082759/">UPI</a> / <a href="https://www.yahoo.com/lifestyle/articles/woman-99-becomes-worlds-oldest-164805621.html">Yahoo News</a> / <a href="https://whatsthejam.com/uk-news/daredevil-99-becomes-worlds-oldest-wing-walker/">What's The Jam</a> / <a href="https://www.guinnessworldrecords.com/news/2026/9/brave-betty-becomes-oldest-person-to-do-the-loop-the-loop-as-she-wing-walks-at-97">Guinness World Records（ブロメージさん）</a></li>
</ul>
<h2>尾の長さ4メートル12センチ、オハイオの馬ジェニーが19年ぶりに世界記録</h2>
<ul>
<li>米国オハイオ州スプリングバレーの乗馬学校にいる雌馬ジェニー（登録名「マウントジョイズ・アイス・プリンセス」）の尾が、412.62センチ（13フィート6インチ）と計測され、「最も長い馬の尾」のギネス世界記録に認定されました。認定は7月25日、ギネスの発表は9月22日、UPIが10月15日に伝えています。</li>
<li>品種はアメリカン・サドルブレッド。長く流れる尾がショーで評価される品種です。</li>
<li>それまでの記録は、2007年に計測されたカンザス州オーガスタの馬「JJSサマーブリーズ」の381センチ（12フィート6インチ）。19年ぶりの更新で、約31センチ上回りました。ギネスは長さを「フォルクスワーゲン・ビートルとほぼ同じ」と表現しています。</li>
<li>飼い主はマッケンジー・ロウさんとレイチェル・エステスさん。ジェニーは2019年、ロウさんの13歳の誕生日に贈られました。ロウさんは「最高の誕生日プレゼント」と振り返ります。</li>
<li>実はジェニーは若いころ、自分で尾を引き抜いてしまったことがあり、ロウさんのもとに来たときの尾は地面に届く程度でした。品種のショーで長い尾が求められるため伸ばし始め、伸び続けるので記録を目指すことにしました。ここまで約7年です。</li>
<li>手入れは月に1回ほど。三つ編みをほどき、洗い、コンディショナーをつけ、乾かし、もつれをほぐして編み直すまで4〜5時間かかります。ジェニーや他の馬が踏まないよう、付け根側はゆるく、先の方はきつく編み、ふだんは尾袋に入れています。袋から出すのは洗うときとショーのときだけです。</li>
<li>計測のあと、ジェニーの尾は切りそろえられました。ロウさんは「長い尾の手入れが減るのを、ジェニーも楽しみにしている」と話しています。</li>
<li>同じギネスには、ポニー部門の記録もあります。インディアナ州のシェトランドポニー「トッパー」の408センチで、2010年から破られていません。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/10/15/guinness-world-records-longest-horse-tail/8351792085400/">UPI</a> / <a href="https://www.guinnessworldrecords.com/news/2026/9/no-tall-tale-horse-with-magnificent-tail-swishes-aside-rival-record-of-19-years">Guinness World Records</a> / <a href="https://www.dexerto.com/entertainment/jenny-the-horse-smashes-19-year-guinness-record-with-tail-as-long-as-a-car-3411490/">Dexerto</a></li>
</ul>
<h2>くまのプーさん100歳の朝、カリフォルニアの図書館に本物のクマがはちみつを取りに来る</h2>
<ul>
<li>米国カリフォルニア州のモノ郡立図書館マンモスレイクス分館に、午前6時ごろクマが入り込みました。10月14日の水曜日で、A・A・ミルンの『クマのプーさん』の刊行（1926年10月14日）から100年の日でした。UPIが10月15日に伝えています。</li>
<li>クマが向かったのは職員用のおやつ置き場です。持ち去ったのは、ピーナツバター、カップ入りの桃いくつか、クッキーひとつかみ、そしてはちみつ1瓶でした。</li>
<li>そのあと書棚の間を少し見て回り、自分で出ていきました。棚は倒れず、本の被害もありませんでした。図書館はその映像をSNSに投稿しています。</li>
<li>記事が出た時点で、はちみつの瓶は返却されていません。</li>
<li>マンモスレイクス分館は、モノ郡立図書館の分館のなかで最も新しく、最も大きい館です。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/10/15/bear-library-Mono-County-winnie-the-pooh/5921792087119/">UPI</a> / <a href="https://visitmammoth.com/directory/mammoth-lakes-library">Visit Mammoth（図書館案内）</a> / <a href="https://interlude.hk/?p=152251">Interlude（刊行日）</a></li>
</ul>
<h2>かご1杯1000円、藤沢の「詰め放題」リサイクルショップ</h2>
<ul>
<li>神奈川県藤沢市の善行団地にある商業施設に、かごに詰めた量で値段が決まるリサイクルショップ「詰め放題の店 リサイクルギャラリー」があります。英語圏の日本情報サイトSoraNews24の記者が訪れ、10月15日に紹介しました。</li>
<li>小田急江ノ島線の善行駅から歩いて約15分。営業は月・火・木・土曜の正午から午後5時までです。</li>
<li>かごには目盛りの色があり、青の線までなら250円、灰色まで500円、ピンクまで750円。あふれるほど詰めても1000円です。値札の付いた品は対象外で、返品はできません。</li>
<li>DVDは「1枚100円」の張り紙がありましたが、店員に聞くと詰め放題に入れてよいとのことでした。</li>
<li>記者が1000円で持ち帰ったのは16点。未使用の直径18センチの土鍋、未開封のアルミホイルとクッキングシート、ソフトバンクのキャラクター「お父さん」の未使用マグカップと弁当箱のセット、東京都水道局のキャラクター「すいてきくん」のハンカチなどです。</li>
<li>映画『スピード・レーサー』と『スクービー・ドゥー』のDVDはどちらも再生でき、1988年に生まれたキャラクター「リトルボブドッグ」のぬりえ、ペン、歯ブラシも入っていました。ペンは「意外なほどよく書けた」そうです。</li>
<li>着物、ショルダーバッグ、大量の食器、ノート、封筒、掃除用品、充電コード付きの電化製品も並んでいました。記者は「すばらしい買い物」と評価し、また来る価値があると書いています。</li>
<li>出典: <a href="https://soranews24.com/2026/10/15/we-hunt-for-treasure-at-an-all-you-can-stuff-kanagawa-secondhand-shop-for-just-1000-yen/">SoraNews24</a></li>
</ul>
<h2>まとめ</h2>
<ul>
<li>99歳のヘルガ・ダフィーさんは、97歳の記録保持者のニュースを見て翼に立ち、めいたちの母を運んだ航空救急に1300ポンド以上を届けました。抜かれたブロメージさんは100歳での再挑戦を宣言しています。</li>
<li>馬のジェニーは、一度は自分で抜いてしまった尾を7年かけて412.62センチまで伸ばし、19年続いた記録を約31センチ更新しました。</li>
<li>プーさん100歳の朝、図書館に入ったクマが持ち去ったのは、本ではなく職員のはちみつでした。</li>
<li>藤沢では、だれかが何年も使わずにしまっていた土鍋やマグカップが、かご1杯1000円で次の持ち主へ移っています。</li>
</ul>
