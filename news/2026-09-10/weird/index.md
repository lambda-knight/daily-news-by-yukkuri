<h2>70日かけて107万まで数えたファヴォール・オゲチ・アニさん</h2>
<ul>
<li>ナイジェリアのファヴォール・オゲチ・アニさんは、2025年10月8日から12月16日まで70日連続で数を声に出し、107万に到達した。ギネス世界記録が「声に出して数えた最大の数」として認定している</li>
<li>挑戦はユーチューブで連日ライブ配信された。従来記録はジェレミー・ハーパーさんが2007年に達成した100万で、18年ぶりの更新となった</li>
<li>1日最大14時間を費やしたと報じられ、記録は速さより、同じ作業を毎日途切れさせず証拠に残す持続力を競うものだった</li>
<li>出典: <a href="https://www.guinnessworldrecords.jp/world-records/100483-highest-number-counted-out-loud">ギネス世界記録</a> / <a href="https://www.odditycentral.com/news/woman-spends-70-days-counting-out-loud-to-1070000-breaks-18-year-old-record.html">Oddity Central</a></li>
</ul>
<h2>監視カメラ235台をゲーム内で壊すと1台600ドル</h2>
<ul>
<li>アーティストのモーリー・コルマンさんは、ゲーム「グランド・セフト・オート・ファイブ」の架空都市ロスサントスへ、ナンバー自動読み取りカメラ235台を加える改造データを公開した</li>
<li>プレイヤーがカメラを壊すとゲーム内通貨600ドルを得る。金額は市民団体アイズ・オフが現実のフロック製カメラを分解して見積もった1台分の費用に由来する</li>
<li>改造データは通過回数や破壊回数も記録する。コルマンさんは現実の器物損壊を勧めるものではなく、監視への不満を架空世界で可視化する作品だと説明している</li>
<li>出典: <a href="https://www.wired.com/story/you-can-now-destroy-flock-cameras-for-cash-in-gta-v/">WIRED</a></li>
</ul>
<h2>3万3000枚の砂糖の花びらで作った高さ3.5メートルのケーキ</h2>
<ul>
<li>カタルーニャ出身のパティシエ、マルク・スアレスさんは、パリのオペラ・ガルニエで開かれた結婚式のため、高さ3.5メートル、幅1.8メートル、重さ約500キロの作品を制作した</li>
<li>表面には手作りの砂糖ペーストの花びら3万3000枚を配置。構想から完成まで約1800時間を要し、普段は一人で働く本人も友人や家族を含む約20人の助けを借りた</li>
<li>依頼主は「ケーキに見えない記念碑」を望んだ。白いチョコレートと砂糖細工が構造の大半を占め、実際のケーキ部分は全体の約0.1パーセントと本人が説明している</li>
<li>出典: <a href="https://www.rainbowdust.co.uk/blogs/news/a-sugarpaste-masterpiece-by-marc-suarez">Rainbow Dust</a> / <a href="https://www.lavanguardia.com/relatos/20260426/11522726/marc-suarez-pastelero-hecho-pastel-bodas-lujo-opera-garnier-paris-0-1-comestible-epm.html">La Vanguardia</a></li>
</ul>
<h2>3年間わなを避けた野良猫「ナインライブズ」</h2>
<ul>
<li>ニュージーランド北島のプレルア半島で、保全チームが「ナインライブズ」と呼んだ野良猫を2026年8月に捕獲した。約3年間、設置したカメラやわなを避け続けていた</li>
<li>チームによると、2024年に放した希少なカモ、パテケ20羽のうち15羽が襲われた。猫は在来種を守る現場では外来捕食者であり、笑い話だけでは済まない側面もある</li>
<li>行動時刻が一定せず追跡を難しくしたが、3晩連続で同じ場所に現れたため、サーモン、フライドチキン、ウサギ肉を餌にして捕獲した。保全団体は胃の内容物を調査するとしている</li>
<li>出典: <a href="https://www.odditycentral.com/animals/nine-lives-the-legendary-feral-cat-that-feasted-on-endangered-birds-and-eluded-capture-for-3-years.html">Oddity Central</a></li>
</ul>
<h2>まとめ</h2>
<ul>
<li>107万という数、235台の仮想カメラ、3万3000枚の花びら、3年の追跡。大きな数字の裏には、70日の配信、現物分解、1800時間の制作、夜ごと変わる動物の行動という具体的な手間があった</li>
<li>珍しさを生むのは派手な結果だけでなく、同じ行為を続けたり、目的に合わせて仕組みを組み替えたりする執念でもある</li>
</ul>
