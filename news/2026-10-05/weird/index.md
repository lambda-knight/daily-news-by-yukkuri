<h2>父の「背中かき」を商売に、深圳の32歳が月商10万元の専門店</h2>
<ul>
<li>中国・深圳の張小超さん（32）は、妻が夫の背中を掻く短い動画と「お金を払ってでも頼みたい」という反応を見て、2026年5月に宝安区で「掻く」ことに特化したサロンを開いた。</li>
<li>張さん自身も、子どものころ父に背中をやさしく掻いてもらいながら眠るのが好きだった。大学卒業後は1年で7回転職し、二つの起業にも失敗した後、この記憶を事業にした。</li>
<li>客は横になり、先の細いプラスチック製の付け爪を着けたスタッフが体をやさしく掻く。前例が乏しく、張さんは独自の手技も考案したという。</li>
<li>料金は1時間300元。2店舗の月商は合計約10万元に達したと張さんは説明し、常連客から「マッサージよりくつろげる」と言われたと話す。</li>
<li>張さんは100店舗への拡大と、掻く仕事を一つの職業として定着させる構想を語る。ただし売上や効果は本人の説明であり、医療行為ではなくリラクゼーションサービスとしての話である。</li>
<li>出典: <a href="https://www.odditycentral.com/news/entrepreneur-opens-unique-salons-where-customers-relax-by-being-gently-scratched.html?utm_source=rss&amp;utm_medium=rss&amp;utm_campaign=entrepreneur-opens-unique-salons-where-customers-relax-by-being-gently-scratched">Oddity Central</a></li>
</ul>
<h2>3時間の山道を30分へ、雲南省の断崖に288メートルの通学用エレベーター</h2>
<ul>
<li>中国・雲南省の尼珠河大峡谷では、奥地の尼珠河村から官寨村小学校の寄宿舎へ通う子どもが、約3週間ごとに荷物を持って危険な山道を3時間登っていた。往復なら6時間だった。</li>
<li>当局は2022年、高さ268メートルの「青雲梯」を断崖沿いに整備。子どもは無料で利用でき、山を登る部分は数分になった。</li>
<li>景勝地として観光客が集まり、混雑時には子どもも長い列を待つことになったため、隣に2基目の「扶揺梯」が開業した。谷底から288メートル、初代より立坑が20メートル長く、速く広い。</li>
<li>現在もシャトルバスとロープウェーへの乗り継ぎは必要だが、学校までの所要時間は約30分。待ち時間も半減したと報じられている。</li>
<li>児童は新華社に、以前は荷物を持って3時間歩き、注意を怠ると滑って転びそうだったと説明した。観光設備の人気が通学を圧迫し、増設が生活者の時間を取り戻した例でもある。</li>
<li>出典: <a href="https://www.odditycentral.com/architecture/china-builds-288-meter-outdoor-elevator-to-help-children-reach-school-easier.html?utm_source=rss&amp;utm_medium=rss&amp;utm_campaign=china-builds-288-meter-outdoor-elevator-to-help-children-reach-school-easier">Oddity Central</a></li>
</ul>
<h2>人には派手、監視AIには「人ではない」— 機械が教えた迷彩シャツ</h2>
<ul>
<li>ドイツのデザイナー、ジーモン・ヴェッカートさんは、監視カメラの人物検出を混乱させる「デジタル・カモフラージュ」というハワイアンシャツを制作した。</li>
<li>人の目には派手な抽象模様だが、ヴェッカートさんが試した人工知能の検出器では、着用者を人物として認識する確信度が下がったという。</li>
<li>模様は人が勘で描いたのではない。候補を生成し、検出器に見せ、人物と判断する確信度を測り、修正する「敵対的ループ」を反復した。同じ種類の人工知能が、監視をかわす模様を教えた構図である。</li>
<li>ヴェッカートさんは、人物検出器が人間そのものを理解するのではなく、輪郭、コントラスト、頭と肩、胴体と手足の比率など、学習画像の統計的な特徴を組み合わせていると説明する。</li>
<li>成果は作者が試した検出システムについてのもの。あらゆる機種や角度で姿を消す万能マントではないが、人間には目立つ服が機械には見えにくいという逆転が、機械知覚の弱点を可視化する。</li>
<li>出典: <a href="https://www.odditycentral.com/news/worlds-ugliest-hawaiian-shirt-was-designed-to-make-you-invisible-to-ai-surveillance-cameras.html?utm_source=rss&amp;utm_medium=rss&amp;utm_campaign=worlds-ugliest-hawaiian-shirt-was-designed-to-make-you-invisible-to-ai-surveillance-cameras">Oddity Central</a></li>
</ul>
<h2>海藻で包んだ丸いコーヒー、キューリグがプラスチック製ポッドから転換</h2>
<ul>
<li>米キューリグは10月4日、プラスチックとアルミを使わない一杯抽出式「アルタ」を紹介した。1998年に登場した使い捨て容器「Kカップ」からの転換を狙う。</li>
<li>新しい「アルタラウンド」は、圧縮したコーヒーを植物由来の海藻素材で包む堆肥化可能な円盤。機械は円盤を刺し、10バールの圧力で抽出し、使用後は内蔵容器へ落とす。</li>
<li>画面で飲み物を選べば、通常のコーヒー、シングルとダブルのエスプレッソを作れる。ミルク泡立て器と従来のKカップ用抽出部も備える一方、本体は大型だと試用記者は評した。</li>
<li>米国の先行セットは本体、4箱の円盤、グラスを含め500ドルで完売。円盤8個は10〜11ドルの予定で、環境負荷を減らす着想に対し、普及を左右する価格は高い。</li>
<li>円盤の二次包装にはホイルと段ボールが残り、機械は二次元コードで種類を読み取る。開始時点の円盤は同じ親会社傘下のキューリグとピーツ製で、他社が参入できるかも焦点になる。</li>
<li>出典: <a href="https://www.wired.com/story/keurig-alta-coffee-brewer/">WIRED</a></li>
</ul>
<h2>まとめ</h2>
<ul>
<li>4本に共通するのは、触覚、通学、視覚認識、コーヒー容器という小さな不便を、店、巨大設備、敵対的模様、新規格へ変えた発想である。</li>
<li>奇抜さの後ろには、本人の失敗と記憶、子どもの移動時間、機械の認識原理、価格と囲い込みという具体的な条件がある。</li>
</ul>
