<h2>文化・芸能ニュース</h2>
<ul>
<li>El Paísは、詩人フェデリコ・ガルシア・ロルカが創設した大学移動劇団ラ・バラッカの1937年バレンシア公演を写す未公開写真45点が見つかったと報じた。撮影者はドイツ出身の写真家ワルター・ロイター。内戦下でも古典劇を町や前線へ届けた劇団の、最大規模の上演を視覚的にたどれる資料である。</li>
<li>El Mundoは映画監督・俳優のハビエル・カルボとハビエル・アンブロッシ、通称ロス・ハビスの映画『ラ・ボラ・ネグラ』がハリウッドとアカデミー賞を視野に入れる動きを紹介した。ロルカの未完の着想を現代映画へ接続し、スペイン内戦の記憶を国際市場へ運ぶ作品である。</li>
<li>マドリードではギタリカデラフエンテが『ラ・ボラ・ネグラ』、ロルカ、住宅危機を一つの送別公演へ束ねた。詩を記念碑として飾るのでなく、家賃と立ち退きという現在の身体感覚へ戻す。地域の祭りや古典を生活へ引き寄せる点は、日本で古典芸能を現代の社会問題と結び直す試みにも通じる。</li>
</ul>
<h2>フラメンコニュース</h2>
<ul>
<li>マドリードのコンデドゥケ文化センターに「トリロヒア・フラメンカ」が登場する。三部作という枠で、カンテ、ギター、バイレを別々の余興ではなく、一つの舞台言語として組み上げる企画だ。</li>
<li>マラガ県アロサイナの「アルメナ・フラメンカ」は8月15日にカンテ、ギター、バイレを一夜へ集める。大都市の国立劇場だけでなく、小さな町の広場や城壁が継承の場所になる点が重要である。</li>
<li>エヘア・デ・ロス・カバジェロスではリカルド・フェルナンデス・デル・モラル舞踊団の『ヌエストロ・フラメンコ』が三部門を近距離で示す。一人の演者を孤立した名人として見るより、歌の伸縮、ギターの合図、足の応答を同時に聴く企画である。</li>
<li>これらを単に「スペイン文化」と一括りにすると、アンダルシアの土地性が薄れる。セビリア、ヘレス、コルドバ、グラナダで育った実践を、マドリードが国の顔として提示する。その普及の力と、出自を見えにくくする危うさは同時にある。</li>
</ul>
<h2>フラメンコギタリスト列伝</h2>
<ul>
<li>今日の一人は<strong>モライート・チコ</strong>（Moraíto Chico、本名マヌエル・モレノ・フンケーラ、1956–2011）。ヘレス・デ・ラ・フロンテーラのサンティアゴ地区に生まれ、11歳で伯父マヌエル・モラオ主催のフェスティバルへ出演した。翌年、マノロ・サンルーカルが寄贈したギターを賞として受け取った。</li>
<li>最初の仕事はラ・パケーラ・デ・ヘレスの伴奏。のちにカマロン・デ・ラ・イスラ、マヌエル・アグヘタスらを支え、とりわけ少年時代から縁のあったホセ・メルセの専属伴奏を長く務めた。独奏者が前へ出る時代にも、彼の評価の核は歌い手が息を吸い、レトラを伸ばし、着地できる空間を作る仕事だった。</li>
<li>右手の親指は低音を太く短く置き、ラスゲアードを鳴らし切らず、次のパルマや声へ場所を渡す。ブレリアでは十二拍を均等に塗りつぶさず、後半の重心を少し引く。歌い手はその空きへ言葉を差し込める。左手の和音は華美な転調を競わず、開放弦の乾いた響きを残してヘレスの終止へ戻る。</li>
<li>独奏作は1992年『モラオ・イ・オロ』と1999年『モラオ、モラオ』。前者はアカデミー・シャルル・クロ大賞を受けた。録音枚数が少ないのは創作力の不足ではなく、伴奏の現場が活動の中心だったためである。</li>
<li><a href="https://www.youtube.com/watch?v=73XfrIjMSBc">『Morao, Morao』</a>では、速い音型より、低音を一つ置いた後の沈黙を聴きたい。旋律を急がせず、次の句が入れる余白を残す点に、ヘレスの伴奏者としての時間感覚が現れる。</li>
<li>日本の合奏では「全員が正確にそろう」ことが価値になりやすい。モライートの伴奏は、歌い手がその夜だけ少し長く伸ばす自由を守りながら、全体をコンパスへ戻す。支えるとは同じ音量で並ぶことではなく、相手の選択肢を増やすことだと分かる。</li>
<li>息子ディエゴ・デル・モラオは開放弦を使う現代的な和音と休符を増やし、父の乾いた拍感を継いだ。継承は父のフレーズの複製ではなく、カンテが入りやすい空間を次世代の音響で設計し直すことにある。</li>
</ul>
<h2>フラメンコバイレ列伝</h2>
<ul>
<li>今日の一人は<strong>カルメン・アマヤ</strong>（Carmen Amaya、1918–1963）。バルセロナの海辺にあったソモロストロ地区で、ギタリスト「エル・チノ」ことホセ・アマヤの娘として生まれ、幼い頃から父の伴奏で踊った。</li>
<li>1930年代にパリへ進み、内戦後は南北アメリカを巡演した。女性の踊りを腕や衣装の優美さへ限定せず、低い重心と高速のサパテアードを正面へ出した。踵、つま先、足裏の音を粒として分け、上体を大きく飾らないから、足が打楽器であることが明瞭になる。</li>
<li>カタルーニャ公共放送3Catの伝記映像<a href="https://www.3cat.cat/3cat/carmen-la-capitana/video/5484798/">『Carmen! la Capitana』</a>では、記録映像の足技と、腕を抑えた直線的な姿勢を見たい。足数の多さだけでなく、連打の直前に身体が沈み、床へ重さを渡す瞬間が音の強さを作っている。</li>
<li>映画『ロス・タラントス』は彼女の代表的な映像記録となり、外国語映画賞候補にもなった。ソモロストロを舞台にした撮影は、故郷の貧困と国際的スターの身体を同じ画面へ戻した。</li>
<li>カルメン・アマヤの革新を「男のように踊った」とだけ言うと、女性の表現を男性基準で測ることになる。重要なのは、どの身体にも強い足技、直線、沈黙、爆発を選ぶ権利があると舞台で示したこと。サラ・バラスら後世の舞踊家が技法と演出を広げる出発点になった。</li>
</ul>
<h2>フラメンコカンテ列伝</h2>
<ul>
<li>今日の一人は<strong>ホセ・メルセ</strong>（José Mercé、本名ホセ・ソト・ソト、1955年ヘレス生）。歌い手の家系に育ち、メルセ教会の少年聖歌隊にいたことが芸名の由来である。</li>
<li>モライート・チコとは少年期から同じ舞台に立ち、2011年にギタリストが亡くなるまで長い協働を続けた。メルセの声は低いところにざらつきを持ちながら、高音では母音を細く伸ばす。モライートは終止を先回りせず、その伸びを待って短い和音を返した。</li>
<li>1998年、ビセンテ・アミーゴの制作による『デル・アマネセール』で広い聴衆へ届き、2000年の『アイレ』は大きな商業的成功を収めた。ポップな制作へ移っても、ヘレスのブレリアで短い句を拍の後ろへ置く感覚は消えない。</li>
<li>公式映像<a href="https://www.youtube.com/watch?v=xC9vDCMW6Rs">『Aire』</a>では、題名句を繰り返すたび語尾の長さが変わり、ギターがその後ろへ応答する箇所を聴きたい。同じリフレインをコピーせず、呼吸によって感情の温度を変えている。</li>
<li>大衆的人気を得た歌い手を「純粋ではない」と退ける見方もある。一方で、古い節回しを保った声が新しい制作を通じて家庭へ届けば、若い聴き手がペーニャや古い録音へ戻る入口にもなる。伝統と市場は単純な敵同士ではない。</li>
</ul>
<h2>フラメンコギター工房だより</h2>
<ul>
<li>今日は既出の個人工房を再掲せず、<strong>スペイン・ギター製作者協会（AELAP）</strong>という職人団体を扱う。個々の名器より、製作者が展示、知識交換、顧客との接点を共有する仕組みに焦点を置く。</li>
<li>製作家の仕事は表板を薄くするだけではない。糸杉やローズウッドの乾燥、扇状力木の削り、ネック角度、弦高、フレンチポリッシュの厚みを、用途に合わせて組み合わせる。フラメンコ用は軽い応答と乾いた立ち上がりを求め、低い弦高によるわずかなビビりも音色の一部になりうる。</li>
<li>展示会で演奏家が複数の楽器を同じ部屋で弾けば、「一弦が足音に埋もれる」「低音がカンテの声域とぶつかる」といった現場の言葉を、表板、力木、弦高の調整へ翻訳できる。日本の産地組合と同じく、職人の個性を守りつつ共同の信用を作る基盤である。</li>
<li>参考: <a href="https://aelap.org/">AELAP公式サイト</a></li>
</ul>
<h2>フラメンコのパロ解説</h2>
<ul>
<li>今日のパロは<strong>マラゲーニャ</strong>（Malagueña）。マラガ地方のファンダンゴから派生し、19世紀にフラメンコの独唱形式として輪郭を整えた。成立を一人へ帰すことはできず、エンリケ・エル・メジソやアントニオ・チャコンらが個人様式を発展させた。</li>
<li>情感は荘重で、恋、故郷、喪失を歌う。固定した踊りのための拍より、カンタオールが一行をどこまで伸ばすかが時間を決める。レトラは短くても、一つの母音を伸ばし、途中で音程を細かく曲げるため、言葉の密度は薄くならない。</li>
<li>コンパスは原則としてカンテ・リブレ、自由リズム。パルマが周期を固定せず、ギターは歌の前にファルセータを置き、歌が始まると短い和音で呼吸を支える。踊りが中心のブレリアと違い、沈黙の長さも構成要素になる。</li>
<li>和声はEを主音とするフリジア系なら、台本でいうエー・マイナー、ジー、エフ、イーへ下るアンダルシア終止が骨格になる。歌の高さに合わせてカポタストを使い、ギターは固定テンポを押し付けず終止点を示す。</li>
<li>ホセ・メルセの伴奏者モライートが参加する<a href="https://www.youtube.com/watch?v=LVgXHfvQc9s">『Malagueña』の記録</a>では、長い第一声の間にギターが和音を急がない点を聴きたい。声が着地してから短い応答が入り、自由リズムが無秩序ではなく、二人の呼吸で組まれることが分かる。</li>
</ul>
<h2>まとめ</h2>
<ul>
<li>1937年のラ・バラッカ、三部門を束ねる現代の舞台、モライートとホセ・メルセの長い協働。今日のスペイン文化を貫くのは、主役一人ではなく、次の声や身体が入れる場所を作る技術である。</li>
</ul>
