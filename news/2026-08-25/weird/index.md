<h2>オープニング：2026年8月25日 — 世界の珍ニュース</h2>

<li>予約制でも混み合う中国の海水浴場、70室の色の迷路、ナンセンス詩の町祭り、私有島の交流会を紹介する。</li>
</ul>
<h2>ネタ1 1.8キロの砂浜に過去20万人、深圳の予約制ビーチ</h2>
<ul>
<li>中国・深圳の大梅沙海浜公園は全長約1.8キロの砂浜で、過去には一度に約20万人が集まったこともあると報じられた。</li>
<li>現在は5月から10月まで1日8万人を上限とし、入場には事前予約を求めている。</li>
<li>入場無料で、地下鉄駅が目の前という便利さも人気の理由だ。海へ行く気軽さと、巨大施設のような人数管理が同居している。</li>
<li>出典: <a href="https://www.odditycentral.com/travel/dameisha-the-worlds-most-crowded-beach.html">Oddity Central</a></li>
</ul>
<h2>ネタ2 英国の公園に70室、歩くたび色が変わる迷路</h2>
<ul>
<li>英国ワトフォード市は8月22日から31日まで、カシオベリー公園に約70の部屋をつないだ空気膜構造「カラー・スケープ」を設置した。</li>
<li>自然光が色付きの膜を通り、角を曲がるたび見える色が変わる。演奏家は固定舞台でなく迷路の各所に現れる。</li>
<li>23日には長さ4メートルのアルプホルン、室内ベル、電子音楽を組み合わせた公演が組まれた。</li>
<li>初日は生演奏を置かない静かな時間にし、強い刺激が苦手な来場者にも入口を用意した。</li>
<li>出典: <a href="https://www.watford.gov.uk/news/article/1019/step-into-a-world-of-colour-music-and-imagination-as-colourscape-returns-to-cassiobury-park-22-to-31-aug-2026-">Watford Borough Council</a></li>
</ul>
<h2>ネタ3 ナンセンス詩人の町で「真面目なナンセンス祭」</h2>
<ul>
<li>英国ノーズリー市のプレスコットで8月21、22日、「シリアス・ナンセンス・フェスティバル」が開かれた。</li>
<li>名称はナンセンス詩人エドワード・リアと地域の結びつきにちなみ、町中心部を演劇、サーカス、音楽の遊び場へ変える無料行事だ。</li>
<li>巨大ブロックを使う身体表現、ウクレレ、スカ、合唱、ダンスオーケストラを同じ番組に並べるのが狙いだった。</li>
<li>「真面目」と「ナンセンス」を一つの看板に載せ、文学史を現在の町おこしへ変えたところが珍しい。</li>
<li>出典: <a href="https://www.cultureknowsley.co.uk/one-week-to-go-until-serious-nonsense-festival-takes-over-prescot/">Culture Knowsley</a></li>
</ul>
<h2>ネタ4 独身者イベントなのに既婚者も歓迎、私有島の一日</h2>
<ul>
<li>米バージニア州リッチモンドの交流団体Pair Clubは8月23日、ジェームズ川のシャープス島で設立1周年の交流会を開いた。</li>
<li>Axiosの週末案内は私有島でのパーティーを39.19ドルと紹介し、独身者向け団体ながら「独身でない人も招待」と明記した。</li>
<li>屋上、バー、公園ではなく島へ渡る移動そのものを交流の仕掛けにした企画である。</li>
<li>恋人探しの境界を緩めた結果、看板より参加資格の方が自由という少し不思議な催しになった。</li>
<li>出典: <a href="https://www.axios.com/local/richmond/2026/08/20/richmond-weekend-events-things-to-do-august-20-23">Axios Richmond</a></li>
</ul>
