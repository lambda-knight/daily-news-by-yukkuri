<h1>世界から見た日本（2026年8月27日）</h1>
<h2>オープニング：2026年8月27日 — 世界から見た日本</h2>
<ul>
<li>中東発の国際通信社、米国のCNN、日本の英字紙、そして韓国メディアの4つの視点から、靖国参拝、温泉の作法、猛暑の甲子園、コンビニで働く外国人という4つの現場を比べる。</li>
<li>政治の緊張だけでなく、日本人が当たり前と思う生活習慣に海外がどこで驚き、どこを評価しているかを追う。</li>
</ul>
<h2>小泉防衛相の靖国参拝と、高市首相の供物で割れる中韓の反応</h2>
<ul>
<li>アルジャジーラ（AFP・ロイター配信、2026年8月15日）は、日本の敗戦81年に当たる8月15日、小泉進次郎防衛相が靖国神社を参拝したと報じた。小泉氏は記者の質問に答えず参拝し、インスタグラムで「祖国のために尊い命を捧げた英霊に、心からの哀悼をささげるため」参拝したと説明し、日本が平和国家であり続ける決意も併せて述べた。</li>
<li>高市早苗首相は就任前は靖国神社を定期的に参拝していたが、首相就任後の今回は本人は参拝せず、地元報道によると供物を奉納するにとどめた。</li>
<li>中国外交部は、高市氏の供物と小泉氏の参拝の両方を「強く非難する」と表明し、外交ルートを通じて「厳重に抗議した」とした。韓国外交部は「時代錯誤」な行為に「深い遺憾」を示し、日本の指導者に「謙虚な反省と真摯な謝罪」を求めた。</li>
<li>記事は、靖国神社が第二次大戦の戦没者約250万人を祀り、連合国側の裁判で戦争犯罪人とされた東条英機ら14人の指導者を含む1,000人以上が合祀されていることを歴史的背景として示した。</li>
<li>中東発の国際通信社が防衛相個人の参拝と首相の供物を区別して報じたことは、日本国内の政治的立場の違いを、参拝という行為の形式差から海外が読み取っていることを示す。</li>
</ul>
<h2>「全裸が基本」——CNNが伝える外国人観光客の温泉での失敗</h2>
<ul>
<li>CNN（記者モーリーン・オヘア、2026年7月11日）は、日本の温泉で外国人観光客が犯しがちな失敗を、入浴文化の専門家の助言とともに紹介した。記事は「日本の温泉では全裸が基本だが、イタリア・コモ湖畔のヴァレンナでは事情が違う」と対比し、日本の慣習が世界的には特殊であることを読者へ示した。</li>
<li>記事が挙げる主な注意点は、体を洗い場で洗ってから湯に入ること、時間に厳格であること、タトゥーを防水シールで隠す必要がある場合があることの3点。</li>
<li>入浴文化の専門家は、温度差による体調不良で救急搬送される観光客がいることにも触れ、慣れない高温の湯に長時間浸からないよう助言した。</li>
<li>CNNが「郷に入っては郷に従え」という助言を旅行記事として発信したことは、全裸入浴という日本人には日常的な習慣が、海外の一般読者にとって依然として説明が要る文化差であることを示している。</li>
</ul>
<h2>猛暑の甲子園、伝統と安全のはざまを韓国メディアも注視</h2>
<ul>
<li>日本の英字紙（2026年8月18日）は、全国高校野球選手権大会3日目の午後1時30分に気温36度、直射日光下のプラスチック製外野席上では45度に達したと報じ、猛暑が大会の前提を揺るがしていると伝えた。</li>
<li>大会は2023年から5回終了後に「クーリングタイム」を設け、空調の効いた室内で選手が体を冷やし水分を取れるようにしたほか、試合を午前・夕方の2部制に分けて直射日光の時間帯を避ける対応を続けている。</li>
<li>8月18日から21日にかけて福岡県では最高気温35度超えが4日続き、21日には全国126地点で35度以上を観測した。大会は22日、智弁和歌山が健大高崎を4対3で下し、2021年以来となる優勝を果たして幕を閉じた。</li>
<li>韓国の聯合ニュースや朝鮮日報など複数メディア（8月5日）は、大会が猛暑の中でも予定通り開幕したと報じ、伝統や球場の制約から日程変更が難しい事情を伝えるとともに、根本的な見直しを求める声が強まっていると紹介した。</li>
<li>隣国メディアが猛暑下の開催継続を「日程を変えられない理由」として詳しく取り上げたことは、日本の高校野球の日程の硬直性そのものを、海外の視点では珍しい制度として見ていることを示す。</li>
</ul>
<h2>コンビニを支える外国人スタッフ、日本語力と接客の評価</h2>
<ul>
<li>日本の英字紙（2026年7月26日）は、セブン-イレブン、ローソン、ファミリーマートの大手3社が2025年、合計で約80万人のパート従業員のうち11万人以上を外国人が占めたと報じた。内訳はセブン-イレブンが約5万2千人、ローソンが約3万1千人、ファミリーマートが約2万7千人。</li>
<li>ローソンでは外国人スタッフが全体の17%超と大手で最も高く、2023年の2倍以上に増えた。その約7割は南アジア出身で、うち約8割は日本語学校や専門学校に通う留学生だという。</li>
<li>記事は、採用担当者が「応募者数の多さだけでなく、仕事の質の高さが際立つ」と評価し、外国人スタッフの接客技術と日本語力の高さを繰り返し指摘していると伝えた。</li>
<li>日本人の担い手が減る中、外国出身の留学生が接客の質を支える主体として海外報道でも取り上げられている点は、労働力不足の穴埋めという扱いを超え、サービスの担い手としての評価に焦点が移っていることを示す。</li>
</ul>
<h2>まとめ</h2>
<ul>
<li>靖国参拝は歴史認識をめぐる中韓との溝を、温泉の作法は生活文化の特殊性を、猛暑の甲子園は伝統と安全のせめぎ合いを、コンビニの外国人スタッフは労働力を超えた評価を、それぞれ異なる国・媒体が別の角度から報じた。</li>
<li>政治の対立だけでなく、日常の習慣や制度のこわばり、外国出身者への評価まで、海外の視線は日本の複数の顔を同時に映している。</li>
</ul>
