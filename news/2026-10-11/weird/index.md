<li>共通するのは「すぐそばにあったのに、見方を変えるまで価値が分からなかったもの」。庭の置物、口の中の細胞、子どもの机、駅のホームの数秒の音が主役です。</li>

<h2>庭の置物だった教皇像、トレビの泉の彫刻家ブラッチのひな型が資材置き場から</h2>
<ul>
<li>イングランド南西部ウィルトシャーの建築資材の再生置き場で、目利きの収集家が汚れた大理石像を300ポンドで購入しました。表面には染みや傷があり、地衣類に覆われていました。</li>
<li>英国の競売会社ウーリー・アンド・ウォリスの調査で、18世紀ローマの彫刻家ピエトロ・ブラッチ（1700〜1773年）による、教皇クレメンス12世の像のひな型（マケット）と判断されました。右側面に「P. Bracci, Rom. F.」の署名があります。</li>
<li>ブラッチはトレビの泉の中央に立つ海神オケアノス像で知られる彫刻家です。像は高さ68センチ、1730年代の作で、玉座に座り教皇冠をかぶった姿です。</li>
<li>元になったのは、教皇がカピトリーノ美術館へ収蔵品を寄贈したことを記念し、ローマの元老院が資金を出した等身大のブロンズ像。パラッツォ・ヌオーヴォの大広間に置かれましたが、1798年、フランス占領下のローマ共和国の時代に溶かされました。</li>
<li>これまでブロンズ像の姿を伝えるのは版画だけでした。競売会社は今回の像を「現存する唯一のひな型」としています。ただし独立した専門家による鑑定結果は公表されていません。</li>
<li>競売会社の担当者マーク・ユアン・リチャーズさんによると、像はハンプシャー州アンドーバー近くの邸宅から出たもので、屋外に50年ほど置かれていた可能性があります。どうやってイングランドに渡ったかは分かっていません。</li>
<li>10月8日の競売にロット470として出品され、予想落札価格は5000〜1万ポンド。購入額の約17〜33倍です。落札結果はまだ報じられていません。</li>

</ul>
<h2>194歳のゾウガメ「ジョナサン」、5歳の若者並みに保たれた遺伝子のスイッチ</h2>
<ul>
<li>南大西洋の英国領セントヘレナ島に住むアルダブラゾウガメのジョナサンは、推定194歳で、知られている中で世界最高齢の陸上動物です。1882年に成体の状態で島へ贈られ、総督公邸プランテーション・ハウスの囲いで暮らしています。</li>
<li>10月7日、長寿研究の非営利団体カレルを中心とする研究チームが、ジョナサンのゲノム（全遺伝情報）とエピゲノムの解析結果を科学誌「サイエンス・アドバンシズ」に発表しました。ケンブリッジ大学のジャスティン・ガーラック博士も共著者です。</li>
<li>島の当局は感染の危険を避けるため採血を認めていません。チームはジョナサンが空中をかむ瞬間を待ち、手袋をした手で口を開けて、舌の下を専用キットでこすって試料を取りました。</li>
<li>エピゲノムは、遺伝子のどれを働かせるかを決める「スイッチ」の状態で、ふつうは年齢とともに乱れていきます。比較した4頭（幼体から高齢の成体まで）の中で、ジョナサンのスイッチの乱れは5歳の幼体を除く全頭より小さいという結果でした。</li>
<li>ジョナサンだけが持つ変異のある遺伝子は287個。がんの抑制やDNA修復に関わるものが含まれ、老化した細胞やがん化した細胞を標的にするたんぱく質の遺伝子を余分に持っていました。</li>
<li>共同筆頭著者のベンジャミン・ベイスビルさんは「長寿に関わる経路で変化が見つかった」としつつ、「これが長寿の理由だとは言い切れない」と述べています。調べたのは1頭だけで、熱帯の島の環境や獣医師が管理する食事も影響しうるとしています。</li>
<li>ジョナサンは白内障でほぼ目が見えませんが、食欲は旺盛です。2026年4月1日には、主治医を名乗る詐欺師の投稿で「死亡」が誤って報じられ、暗号資産の寄付を募る手口に使われました。</li>
<li>出典: <a href="https://www.cp24.com/news/world/2026/10/07/a-194-year-old-tortoise-worlds-oldest-land-animal-may-hold-clues-to-longer-life/">CP24（ロイター）</a> / <a href="https://gizmodo.com/jonathan-the-tortoise-survived-2-centuries-and-a-fake-death-now-scientists-are-unraveling-his-anti-aging-secrets-2000822921">Gizmodo</a> / <a href="https://www.goodnewsnetwork.org/nearly-200-year-old-tortoise-becomes-first-to-contribute-extraordinary-epigenome-to-aging-research/">Good News Network</a> / <a href="https://www.science.org/doi/10.1126/sciadv.adw8887">Science Advances（論文）</a></li>
</ul>
<h2>10年後にほどいた折り鶴、名前も知らない恩人が内側に書いた言葉</h2>
<ul>
<li>米公共ラジオ局KUOW（NPR系）が10月7日、高校生リカ・マツダさんの体験を伝えました。マツダさんは日本語で取材に答えています。</li>
<li>7歳のとき、新しい自転車のブレーキが利かず壁に衝突。足を痛めて座り込んでいると、スーツ姿の20代とみられる男性が声をかけてきました。</li>
<li>男性は水飲み場で傷を洗うのを手伝い、電話を貸して祖父に連絡させ、迎えを待つ間にかばんから紙を出して折り鶴の折り方を教えました。祖父が来ると、本人と自転車を家まで送るのを手伝いました。</li>
<li>別れ際、男性は何も言わずにほほ笑んで鶴を手渡しました。マツダさんは鶴を机の中にしまい、見るたびに親切を思い出していたといいます。</li>
<li>約10年後の17歳のとき、英語の授業でベンジャミン・ジョンソン先生が、身近な恩人を語るNPRの企画「マイ・アンサング・ヒーロー」を紹介し、生徒に自分の話を書かせました。</li>
<li>当時を思い返すうち、祖父と電話している間に男性が何か書いていたのではと思い当たり、急いで帰宅して鶴をほどくと、内側に言葉がありました。</li>
<li>書かれていたのは、人との出会いは二度とないかもしれないから大切にせよ、という意味のよく知られた日本語の言葉でした。マツダさんは「彼がどれほど親切な人だったか、さらに分かった」と語っています。男性の名前は分かっていません。</li>
<li>出典: <a href="https://www.kuow.org/npr-news/2026-10-07/a-childhood-bike-crash-led-to-a-strangers-gift-and-a-hidden-message">KUOW</a> / <a href="https://www.goodnewsnetwork.org/npr-inspired-homework-leads-teen-to-find-hidden-message-a-decade-after-a-strangers-kindness/">Good News Network</a></li>
</ul>
<h2>日比谷駅の発車メロディが「ゴジラのテーマ」に、東京メトロが広告商品として売り出す</h2>
<ul>
<li>東京メトロは10月6日、日比谷線と千代田線の日比谷駅の発車メロディを、11月3日の始発から「ゴジラのテーマ」に変えると発表しました。</li>
<li>日比谷には、70年以上「ゴジラ」シリーズを製作してきた東宝の本社があり、日比谷ゴジラスクエアとTOHOシネマズ日比谷の2か所にゴジラ像が立つ「ゴジラの聖地」です。東宝の協力で採用しました。</li>
<li>狙いは駅への愛着だけではありません。東京メトロは、自社が持つ「鉄道アセット」の一つである発車メロディを、新しい広告商品として展開すると説明しています。曲は本社所在地や発祥の地など、沿線との関係を考えて選ぶとしています。</li>
<li>1番線（日比谷線・中目黒方面）と3番線（千代田線・代々木上原方面）、2番線（日比谷線・北千住方面）と4番線（千代田線・綾瀬方面）で、それぞれ別のメロディを使います。</li>
<li>11月3日は、1954年に第1作「ゴジラ」が公開された日で、記念日協会に登録された「ゴジラの日」です。テーマ曲は第1作のために伊福部昭が作曲しました。</li>
<li>注意事項として、ホームに長時間とどまることや、放送スピーカーに録音機器を近づけることを控えるよう求め、駅係員や乗務員への問い合わせも遠慮するよう呼びかけています。音源についての問い合わせには答えないとしています。</li>
<li>出典: <a href="https://www.tokyometro.jp/news/2026/225476.html">東京メトロ ニュースリリース</a> / <a href="https://www.tokyometro.jp/news/images_h/metroNews261006_77.pdf">同 別紙PDF</a> / <a href="https://soranews24.com/2026/10/08/tokyo-train-station-will-play-godzilla-theme-song-as-new-departure-melody/">SoraNews24</a></li>
</ul>
<h2>まとめ</h2>
<ul>
<li>300ポンドの庭の置物、口の中の細胞、机の中の折り鶴、ホームに流れる数秒の音。今日の4題は、身近にあったものが見方を変えた瞬間に価値を現した話でした。</li>
<li>目利きの収集家、研究チーム、英語の授業、鉄道会社の営業。それぞれ「別の目」が入ったことで、置物は美術品に、鶴は手紙に、メロディは商品になりました。</li>
</ul>
