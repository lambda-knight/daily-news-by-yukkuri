<li>今日のスペイン語は「オイガ」。人へ丁寧に声を掛ける「すみません」「ちょっと聞いてください」で、親しい相手への「オジェ」より距離を保つ。</li>
<li>今日の軸は「一人の名人芸を、舞台と教育へどう残すか」。映画、自治体の祭典、トマティート、アントニオ・ガデス、ラ・ニーニャ・デ・ロス・ペイネス、ヤマハの量産設計、ソレアを結ぶ。</li>

<h2>国際情勢（スペイン視点）</h2>
<ul>
<li>当日取得分の国際欄には、スペインが直接の当事者となる新しい重要案件が乏しい。ウクライナやガザを「スペイン紙が報じた」という理由だけで件数合わせせず、文化へ時間を渡す。</li>
</ul>
<h2>スペイン国内ニュース</h2>
<ul>
<li>総選挙を前に、亡命者の子孫の投票権を最高裁が直前に判断する。国外居住者の投票は、内戦と独裁で離散した家族を現在の民主主義へどう結び直すかという問題でもある。</li>
<li>政党間の応酬より、投票日までの時間と手続きの公平性が争点。日本の在外投票にも似るが、スペインでは亡命の家族史が制度論へ直接重なる。</li>
</ul>
<h2>文化・芸能ニュース</h2>
<ul>
<li>映画監督カルロタ・ペレダは、女性がホラーを「より身体的に経験する」と語った。新作では恐怖を怪物の姿だけでなく、被害者の身体感覚と選択で描く。スペイン人女性監督としてシッチェス映画祭の開幕作を初めて任された節目でもある。</li>
<li>俳優ジョルディ・モリャには、ウディ・アレンから新作出演を誘う手紙が届いた。「断るなら将来でも。私はまだ90歳」というユーモアが話題だ。モリャは俳優だけでなく画家・監督でもあり、仕事を一つの肩書に閉じないスペイン芸術家の姿が見える。</li>
<li>マドリードのコンデドゥケでは「トリロヒア・フラメンカ」が上演される。短い企画名の中で、カンテ、ギター、身体を別作品で提示し、フラメンコを一枚岩の見世物にしない構成である。</li>
</ul>
<h2>フラメンコニュース</h2>
<ul>
<li>パンプローナ市は「フラメンコ・オン・ファイア」と連携し、市庁舎のバルコニーでエル・ペレが歌う企画、コンデスタブレ宮での二公演、未成年向けのギターと舞踊の教室を続ける。無料で目に入る広場と、学ぶ教室を同じ祭典に置く点が重要だ。</li>
<li>マラガ県アロサイナの「アルメナ・フラメンカ」は8月15日にカンテ、ギター、バイレを一夜へ集める。観光客向けの舞台だけでなく、小さな町が三者の共同作業を保つ地域行事である。</li>
<li>コルドバの第45回ギターフェスティバルは、国立フラメンコ芸術コンクール70周年を祝う。演奏会だけでなく、コンクールが地方の若手を全国の舞台へ送ってきた制度史にも光を当てる。</li>
<li>アンダルシア発の芸をパンプローナ、マドリード、コルドバが別の形で受け取る。首都が「国の顔」として提示する一方、地方都市は教室とコンクールで担い手を作る。</li>
</ul>
<h2>フラメンコギタリスト列伝</h2>
<ul>
<li>今日の一人はトマティート、本名ホセ・フェルナンデス・トーレス（1958年アルメリア生）。祖父ミゲル、父トマテ、叔父ニーニョ・ミゲルもギタリストという家に育ち、「小さなトマテ」が芸名になった。</li>
<li>少年期から地元のタブラオで弾き、十代でカマロン・デ・ラ・イスラと出会った。1970年代末からカマロン最晩年まで伴奏し、『ラ・レジェンダ・デル・ティエンポ』以後の革新的な編成でも、声が戻る場所をコンパスの中へ作った。</li>
<li>伴奏の核心は、歌の語尾を音で埋めないこと。歌い手が息を吸う場所では低音を一つ置き、次のレトラへ入る直前に短いファルセータで調性と拍を示す。独奏でもこの「待つ技術」が旋律の呼吸になる。</li>
<li>右手は粒のそろったピカード、親指で低音弦を押し出すアルサプーア、低音を保ちながら高音を歌わせるアルペジオが柱。速さを見せる局面でも、12拍の重心をぼかさない。</li>
<li>1992年のカマロン没後は独奏を本格化し、『ロサス・デル・アモール』『パセオ・デ・ロス・カスターニョス』などを発表。ジャズ・ピアニストのミシェル・カミロとの共演では、和声を広げてもラスゲアードとコンパスの輪郭を失わなかった。</li>
<li>カナル・スール公式の<a href="https://www.youtube.com/watch?v=f1C39M3T-QA">『トマティートが弾くロンデーニャ』</a>では、自由拍に聞こえる導入でも低音が次の句の着地点を予告する。速い高音のあとに音量を落とす間を聴くと、カンテ伴奏で得た呼吸が独奏へ移ったことが分かる。</li>
<li>パコ・デ・ルシアが編成と和声を大きく広げた世代なら、トマティートはカマロンの声のそばで革新を日常の伴奏へ定着させた。後進に残したのは速弾きの型だけでなく、歌を主役へ戻す判断である。</li>
</ul>
<h2>フラメンコバイレ列伝</h2>
<ul>
<li>今日の一人はアントニオ・ガデス、本名アントニオ・エステベ・ロデナス（1936–2004）。アリカンテ県エルダに生まれ、家族とマドリードへ移り、若くしてピラール・ロペス舞踊団で舞台の規律を学んだ。</li>
<li>民俗舞踊の語彙を集め、腰を過度に揺らさず、上体を垂直に保つ直線的な姿勢を作った。サパテアードを音量競争にせず、歩幅、視線、静止で人物の葛藤を示す。</li>
<li>カルロス・サウラ監督との映画『血の婚礼』『カルメン』『恋は魔術師』は、稽古場や簡素な舞台を映し、踊りが物語を組み立てる過程を世界へ伝えた。鏡や舞台袖まで画面に残すため、完成した幻想だけでなく集団の仕事が見える。</li>
<li>アントニオ・ガデス財団公式の<a href="https://www.youtube.com/watch?v=Mf1vsPYyZD0">『血の婚礼とフラメンコ組曲』</a>では、腕を大きく回す場面より、群舞が一斉に止まり、二人の距離だけが変わる瞬間に注目したい。静止が台詞の代わりになる。</li>
<li>自身の舞踊団とスペイン国立バレエ団で作品を残し、個人の即興性が強いフラメンコを再演可能な舞台作品へした。ただし固定化ではなく、カンテとギターの生演奏が毎夜の呼吸を変える余地も残した。</li>
</ul>
<h2>フラメンコカンテ列伝</h2>
<ul>
<li>今日の一人はラ・ニーニャ・デ・ロス・ペイネス、本名パストーラ・パボン・クルス（1890–1969）。セビリアの音楽一家に生まれ、幼い頃から酒場で歌い、兄トマス・パボン、夫ペペ・ピントとともに20世紀前半のカンテを形づくった。</li>
<li>芸名は初期に歌ったタンゴの歌詞に出る「くし」に由来する。ソレア、シギリージャ、タンゴ、ペテネーラ、カンティーニャまで録音し、一人の声の中に地域ごとの型を保存した。</li>
<li>声は低く金属的で、語頭を強く押す一方、語尾では細かなメリスマを使う。装飾は美声を飾るためでなく、短いレトラの痛みや皮肉を一語ずつ際立たせる。</li>
<li>カナル・スール公式の<a href="https://www.youtube.com/watch?v=GXnHYYcNLlE">『文化財となった声』</a>では、古い録音の狭い音域でも子音が前へ出る点を聴きたい。伸ばす母音より、言葉を切る位置がコンパスを作る。</li>
<li>彼女の録音群は2009年にアンダルシア州の文化財に指定された。歌い手本人だけでなく「声」という無形の表現を保護対象にした点で、録音保存と教育をつなぐ先例である。</li>
</ul>
<h2>フラメンコギター工房だより</h2>
<ul>
<li>国内個人工房の重複を避け、国外編として日本のヤマハを扱う。ヤマハはクラシックギターの量産技術を基に、フラメンコ用のCG182SFを展開する。</li>
<li>公式仕様では表板に単板スプルース、側・裏板にシープレス、指板にエボニーを用いる。シープレスの軽い胴と明るい立ち上がりは、歌や足音の隙間へ短い音を入れるフラメンコの要求に合う。</li>
<li><a href="https://usa.yamaha.com/products/musical_instruments/guitars_basses/cl_guitars/cg_cgx/models.html">ヤマハ公式のCG182SF製品ページ</a>で、一般クラシックと同じシリーズ内にフラメンコ仕様を置く設計思想が分かる。個人工房の一対一調整とは違い、各国で同じ仕様を入手できることが教育現場の利点になる。</li>
<li>量産品は名工の代用品ではない。最初の一本を安定した寸法で供給し、学習者が弦高や音の立ち上がりの違いを知る入口を広げる役割がある。</li>
</ul>
<h2>フラメンコのパロ解説</h2>
<ul>
<li>今日のパロはソレア。19世紀にカディス、ヘレス、セビリアの三角地帯で形を整えたとされ、「フラメンコの母」と呼ばれる。成立を一人へ帰すことはできず、地域と歌い手ごとの型がある。</li>
<li>レトラは孤独、喪失、誇りを短い三行または四行で歌う。遅いから悲しいのではなく、一句のあとに空白を置き、次の言葉が逃げられない構造が重さを作る。</li>
<li>12拍を一巡とし、3、6、8、10、12付近に重心を感じる数え方が一般的。ギターはレトラの間にファルセータを置き、バイレはエスコビージャで足技を細分化してから締めへ向かう。</li>
<li>Eフリジアン系なら、Aマイナー、G、F、Eへ下るアンダルシア終止が骨格になる。台本ではエーマイナー、ジー、エフ、イーと読み、歌い手の音域にカポタストで合わせる。</li>
<li>カナル・スール公式の<a href="https://www.youtube.com/watch?v=QQAqBt5vDDs">『ガスパール・デ・ウトレーラのソレア』</a>では、歌い出す前にギターが12拍を全部埋めず、10から12の締めだけを強く示す箇所を聴きたい。歌の一行後の沈黙もコンパスの一部である。</li>
</ul>
<h2>まとめ</h2>
<ul>
<li>名人芸を残す方法は一つではない。トマティートは伴奏の判断を、ガデスは再演できる舞台を、パストーラ・パボンは録音された声を残した。</li>
<li>別れの言葉は「ケ・テンガ・ブエン・ディア」。相手へ「よい一日を」と丁寧に願う表現で締める。</li>
</ul>
