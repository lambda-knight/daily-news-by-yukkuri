<h1>世界の珍ニュース（2026年10月1日）</h1>
<h2>オープニング：2026年10月1日 — 世界の珍ニュース</h2>
<p>アメリカ東海岸を襲った低気圧で水につかったニュージャージー州の住宅街を、小さなサメが泳いでいった。同じ9月26日の土曜日、干ばつが続くコロラド州の高級リゾート地アスペンでは、朝市の準備中にクロクマがパンの屋台へ現れた。スロベニアのスタント担当者は全身に火をまとったまま47秒の逆立ちでギネス世界記録を取り、カリフォルニアでは友人2人が1万1695ピースのレゴの世界地図を5時間足らずで組み上げた。メリーランド州では、昔住んでいた家の郵便番号を宝くじに書いた男性が5万ドルを当てた。今回は、海と道路、森と街、炎と体操、遊びと記録、過去の住所と現在の幸運――ふだんは交わらない境目を越えてきた5つの話をたどる。</p>
<h2>冠水した住宅街をサメが泳ぐ、ニュージャージーの「週末の訪問者」</h2>
<ul>
<li>9月26日（土）の正午ごろ、米ニュージャージー州のロングビーチ島にあるサーフシティで、住民のドリュー・プロカチーノさんが、冠水した自宅前の道路を泳ぐ小さなサメを撮影した。サメは家の私道へ入り込んだあと、西側のバーネガット湾の方向へ泳いでいった。</li>
<li>東海岸を北東の強風と高潮で襲った低気圧「ノーイースター」により、バーネガット湾の水が低い土地の道路へ押し寄せていた。動画には「あれ、小さいサメ？」「こっちに来る！」という住民の声が残る。</li>
<li>米マサチューセッツ州海洋漁業局のサメ研究者グレッグ・スコマル氏は映像から種類を「スムース・ドッグフィッシュ（ホシザメの仲間）」と特定。この海域の沿岸にごく普通にいる小型のサメで、歯は平らでカニなどをすりつぶして食べるため人には危険がない。成体はふつう約90センチ、大きくて約1.5メートル。</li>
<li>プロカチーノさんは「最初はただの魚だと思った。それでもすごかったけど、赤ちゃんザメだったのはもっとよかった」と話した。</li>

</ul>
<h2>朝市の開店前にクロクマが焼きたてパンを試食、コロラド州アスペン</h2>
<ul>
<li>9月26日（土）の朝、米コロラド州アスペンの中心街で「アスペン・サタデー・マーケット」の出店者が準備をしていたところへクロクマが現れ、地元のパン店「ルイス・スイス」の屋台で後ろ足で立ち上がり、並べてあった焼きたてのパンを食べた。</li>
<li>アスペン警察がクマを追い払い、クマは近くの木に登ったあと自分で立ち去った。撮影された動画は交流サイトで広がり、数十万回の再生と反応を集めた（デンバー・ポスト紙の報道として米フードライン）。</li>
<li>ルイス・スイスはコロラド州西部の山あい一帯で最大級の卸売・小売のパン店で、アスペンからグレンウッドスプリングスなどにかけて120以上の取引先に卸している。</li>
<li>コロラド州公園野生生物局の広報ジョーイ・リビングストン氏は、極端な干ばつで自然の食べ物が不足し、今年はクマとの遭遇が記録的な件数になっていると説明した。冬眠前のクマは「過食期」に入り、1日に最大2万キロカロリーを、1日最大22時間かけて食べ続ける。</li>
<li>コロラド州ではクマに餌を与えることは違法。人に慣れたクマは住民の安全を脅かすため、アスペンでは餌やりを見かけたら専用番号へ通報するよう呼びかけている。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/09/30/bear-Aspen-colorado-farmers-market-bread/5211790782350/">UPI</a> / <a href="https://hoodline.com/2026/09/hungry-bear-crashes-aspen-farmers-market-devours-bakery-s-fresh-bread/">Hoodline</a></li>
</ul>
<h2>全身に火をまとって47秒の逆立ち、スロベニアのスタント担当者がギネス世界記録</h2>
<ul>
<li>スロベニアの体操経験者で映画のスタントコーディネーター、フィリップ・クルジシュニクさん（35歳）が、3月4日にオーストリアのウィーンで全身を炎に包んだまま47秒間の逆立ちを続け、ギネス世界記録「全身燃焼状態での最長の逆立ち」に認定された。この項目の初代記録保持者で、米UPI通信が9月30日に伝えた。</li>
<li>動機を問われると「体を温めるのに、これよりいい方法が見つからなかった」と冗談で答えた。「45秒でも満足だったけど、60秒ならもっと満たされたと思う」とも語り、記録にはまだ伸びしろがあるとみている。</li>
<li>本業はスロベニアの首都リュブリャナを拠点とするスタントチーム「スタントマン」のスタントコーディネーター兼ワイヤー操作の責任者。チームは映画・テレビ・広告で18年以上の実績があり、30人を超える専門家を抱え、ワイヤーアクション、車両スタント、格闘の振り付け、水中スタントのほか、全身燃焼などの火のスタントを請け負っている。</li>
<li>全身燃焼はチームが映画やテレビの撮影で請け負う業務の一つで、今回の記録は本業の技術と体操の逆立ちを組み合わせたもの。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/09/30/austria-guinness-world-records-handstand-full-body-burn/2261790782974/">UPI</a> / <a href="https://www.yahoo.com/entertainment/celebrity/articles/professional-stuntman-performs-47-second-154659812.html">Yahoo!（UPI転載）</a> / <a href="https://stuntman.si/">Stuntman.si</a></li>
</ul>
<h2>1万1695ピースのレゴ世界地図を4時間59分51秒、友人2人の「色ごと作戦」</h2>
<ul>
<li>シンガポール出身のアテナ・レオンさんと米国出身のセビー・スウィフトさんが、4月12日に米カリフォルニア州ヘイワードの玩具店「ブリック・バイ・ブリック・トイズ」で「レゴ・ワールドマップ」を4時間59分51秒で完成させ、2人組での最速記録としてギネス世界記録に認定された。ギネスが9月に発表し、UPIが9月28日に伝えた。</li>
<li>ワールドマップは1万1695ピースで、市販のレゴの平面セットとしては史上最大。ギネスは2人組の新設項目に5時間30分の目標を設けていた。</li>
<li>1人での最速記録は、2023年からオーストラリアのクラリー・ファーカシュさんが持つ7時間9分41秒。2人組とはいえ、それより2時間以上速い。</li>
<li>作戦は、国を色ごとに分け、1色ずつまとめて組むこと。台紙はパズルのようにはめ込める区画に分けて分担した。スウィフトさんは「1色ずつ組むと、その色がもう手元にそろっているから、ぐっと速くなると気づいた」と話す。約1か月練習し、挑戦前の1週間は練習量を増やした。</li>
<li>2人は挑戦の1年前に知り合った。レオンさんは「小さいころ、レゴは、まだ技術も材料もないうちに想像を形にする道具をくれた」「この挑戦は私たちの友情を祝うすてきな方法」と語り、スウィフトさんは「レゴはずっと1人で遊ぶものだった。これを分かち合う方法だと思った」と話した。</li>
<li>出典: <a href="https://www.guinnessworldrecords.com/news/2026/9/two-friends-in-california-unite-their-inner-kids-to-conquer-lego-world-map-speed-record">Guinness World Records</a> / <a href="https://www.upi.com/Odd_News/2026/09/28/Guinness-World-Records-Lego-World-Map-duo/5361790618362/">UPI</a> / <a href="https://www.guinnessworldrecords.com/world-records/703839-fastest-time-to-build-the-lego%C2%AE-world-map">Guinness World Records（1人の記録）</a></li>
</ul>
<h2>昔の家の郵便番号で5万ドル、メリーランド州の宝くじ</h2>
<ul>
<li>米メリーランド州コロンビアに住む男性（名前は非公表）が、5桁の数字を当てる宝くじ「ピック5」で、以前住んでいたニューヨーク市クイーンズ区の郵便番号「11694」を選び、8月30日夜の抽選で5万ドルを当てた。メリーランド州宝くじ局が9月30日に発表した。</li>
<li>券を買ったのは、コロンビアのリトル・パタクセント・パークウェイ沿いにある自動車整備・洗車店「コロンビア・オート・ケア・アンド・ウォッシュ」。5桁の並びは10万通りある。</li>
<li>男性は「本当にすごかった。妻に見せたら、念のためにもう一度確かめてくれた」と話した。賞金の使い道は、妻の車の新しいタイヤと来年の旅行。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/09/30/lotto-Maryland-Lottery-zip-code-digits/4861790788995/">UPI</a></li>
</ul>
<h2>まとめ</h2>
<ul>
<li>洪水が海のサメを住宅街へ運び、干ばつが山のクマを朝市へ連れてきた。同じ9月26日の土曜日、東海岸は水が多すぎ、西部の山は食べ物が少なすぎた。</li>
<li>クルジシュニクさんの47秒の逆立ちは、体操と映画のスタントという2つの職業技術が交わった結果。レゴの世界地図は、1人の趣味を2人の友情に変えた色分けの工夫で、1人の記録を2時間以上縮めた。</li>
<li>宝くじの5万ドルは、10万通りの中から「昔の住所」という個人的な数字が選ばれた一回きりの偶然。</li>
</ul>
