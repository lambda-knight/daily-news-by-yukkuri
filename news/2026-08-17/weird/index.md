<h2>ネタ1 3年間逃げ切った灰色トラ猫「ナインライブズ」、最後は絶滅危惧カモの楽園で御用</h2>
<ul>
<li>ニュージーランド・プレリア半島。保全団体「ペストフリー・プレリア・プロジェクト」が3年前、希少なカモ「パテケ」20羽を放鳥したが、1週間後に1羽が殺害された</li>
<li>2024年にはさらに20羽を放鳥したが、うち15羽が短期間で殺害された。被害はパテケ個体数の1%規模、加えてキウイの雛や在来トカゲにも及んだ</li>
<li>犯人は灰色トラ猫「ナインライブズ」。プロジェクトマネージャーのアンディ・メンター氏らが3年間追跡したが捕獲を逃れ続けた</li>
<li>同じ場所に3夜連続で現れたところをついにわなで捕獲し、直後に「人道的に」銃殺処分。保全活動家は歓迎したが、愛猫家からは「動物園で保護できたはずだ」との批判がネット上で起きた</li>
<li>出典: <a href="https://www.odditycentral.com/animals/nine-lives-the-legendary-feral-cat-that-feasted-on-endangered-birds-and-eluded-capture-for-3-years.html">Oddity Central</a></li>
</ul>
<h2>ネタ2 資金を出して自ら主演、60回超のキスシーンを押し通した女性投資家</h2>
<ul>
<li>中国。50話の短編ドラマ制作にあたり、女性投資家が資金提供の条件として自ら主演女優の座と脚本の最終決定権を要求した</li>
<li>23歳の男優チョン・ユイフェイ演じる相手役と、60回以上のキスシーンを盛り込んだ脚本を自ら承認。監督や制作スタッフの反対意見は退けられた</li>
<li>プロデューサーのモン・シン氏らが制作を進めたが、完成後に配信プラットフォームがキスシーンの多さを理由に作品を却下し、商業的に失敗した</li>
<li>事件は中国のSNSで拡散し、「資本が撮影現場を狩り場に変えている」との批判が広がった</li>
<li>出典: <a href="https://www.odditycentral.com/news/wealthy-woman-bankrolls-drama-series-so-she-can-star-in-it-and-kiss-male-lead-more-than-60-times.html">Oddity Central</a></li>
</ul>
<h2>ネタ3 30日間洗わなくていいTシャツ、銅と火山灰で挑む野望</h2>
<ul>
<li>米国の衣料品企業ハークレオンが2026年8月3日、Tシャツ「ハークシャツ V5.0」を発表。2026年11月初旬に出荷予定</li>
<li>価格帯は3段階で、30日以上無洗濯をうたうプレミアム版が79ドル、14日間対応の標準版と3日間対応の廉価版がそれぞれ39ドル</li>
<li>生地には銅・銀・亜鉛・金・火山灰と非公開の2成分を織り込み、銅で臭いの原因菌を抑え、亜鉛で汗の硫黄化合物を中和し、火山灰で湿気と外部臭を吸うと説明する</li>
<li>通常のTシャツ7枚分以上の寿命があると謳うが、現時点では第三者によるテスト結果や専門家の検証は示されていない。色展開は当初黒のみで、のちに紺・エンジ・濃緑を追加予定</li>
<li>出典: <a href="https://www.odditycentral.com/news/clothing-brand-sells-t-shirt-that-doesnt-require-wasing-for-up-to-a-month-of-daily-wear.html">Oddity Central</a></li>
</ul>
<h2>ネタ4 深夜の「足音」苦情、犯人は隣人の寝室の壁の中のパイプだった</h2>
<ul>
<li>賃貸住宅で、下階の隣人から約1か月間「深夜に足音や家具を引きずる音がする」と苦情を受け続けた住人がいた</li>
<li>住人は週3日の夜勤シフトで、苦情のあった日のうち2日は実際には建物内にいなかった。勤務表を管理会社に提出しても隣人は納得しなかった</li>
<li>午前1時ごろ隣人が「1時間の騒音」を訴えてきた際、住人は勤務先の休憩室で撮った時刻表示付きの写真を送って反論した</li>
<li>翌朝、保守担当者が調べたところ、音の正体は隣人自身の寝室の壁の裏を通るパイプだったと判明。隣人は謝罪しなかったが、ドアに貼っていた苦情メモは静かに外された</li>
