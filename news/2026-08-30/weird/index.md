<h2>オープニング：2026年8月30日 — 世界の珍ニュース</h2>

<li>幻覚剤サイロシビンでむしろ「今ここ」に脳が集中したというオーストラリア・モナッシュ大学の研究、長さ52センチのトウガラシで3度目のギネス世界記録を取ったスイスの男性、アンティーク市で約50ポンドで買った「キツネのはく製」が絶滅動物フクロオオカミで6万ポンドになった話、心停止で搬送された女性に5時間駐車の反則切符が出たニュージーランドの一件を紹介する。</li>

<h2>ネタ1 サイロシビンで脳が「今ここ」に集中する、モナッシュ大学の研究</h2>
<ul>
<li>オーストラリアのモナッシュ大学心理科学部が、幻覚作用のある化合物サイロシビンを摂取した人の脳活動を詳細に撮影した研究をまとめ、2026年8月にワイアードなどが紹介した。</li>
<li>対象は幻覚剤の使用経験がない62人。19ミリグラムのサイロシビンをカプセルで経口摂取し、その後に瞑想する、音楽を聴く、映画を観るなどをしてもらった。</li>
<li>研究チームは脳の332の領域の動きを、機能的MRIと脳波で刻一刻と記録した。</li>
<li>一般に幻覚剤は現実から乖離するイメージがあるが、結果は逆で、体験が強い人ほど、聴いている音楽や観ている映像が脳により鮮明に刻まれていた。</li>
<li>筆頭著者のデヴォン・ストーリカー氏は「内的世界と外的世界を処理する脳のネットワークの境界が薄れ、その人が体験している内容を反映する形に再編成された」と説明している。</li>
<li>検証状況: 記事では、この研究が1施設で収集したセロトニン系幻覚剤の脳画像データとして世界最大とされる。参加者は全員が未経験者で、実験室環境という条件付き。査読論文の掲載誌・掲載日は本稿では特定していない。</li>
<li>出典: <a href="https://www.wired.com/story/psilocybin-might-make-your-brain-live-in-the-moment/">WIRED</a></li>
</ul>
<h2>ネタ2 長さ52センチ、自己記録を3度塗り替えたスイスのトウガラシ名人</h2>
<ul>
<li>スイスの園芸家ユルク・ヴィースリさんが育てたトウガラシが、2026年8月11日に長さ52センチと測定され、「最も長いトウガラシ」のギネス世界記録に認定されたと、8月27日に報じられた。</li>
<li>ヴィースリさんがこの記録を取るのは3度目。最初は2017年10月、ザンクト・ガレン州ヨナの野菜品評会で約43.7センチ。翌2018年に自分の記録を約48.8センチへ更新し、今回さらに塗り替えた。</li>
<li>育て方は、3月に室内で種をまき、育成ライトの下、気温28度で発芽させる。霜の心配がなくなる4月末に庭へ植え替えるという。</li>
<li>記録の対象は辛さではなく「長さ」で、細長く伸びる品種を使っている。</li>
<li>検証状況: 数値はギネス・ワールド・レコーズとUPIの報道による。品種名は本稿では特定していない。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/08/27/switzerland-Guinness-World-Records-longest-chili/6771787849466/">UPI</a></li>
</ul>
<h2>ネタ3 50ポンドの「キツネのはく製」、正体は絶滅したフクロオオカミで6万ポンド</h2>
<ul>
<li>イギリスの収集家ジェームズ・クランフィールドさんが、アンティーク市でおよそ50ポンド（約1万円）で買った「キツネのはく製の頭」が、絶滅した有袋類フクロオオカミ（タスマニアタイガー）だったと分かり、2026年8月にブリストルのオークショニウムで競売にかけられた。</li>
<li>クランフィールドさんは歯を見て気づいた。キツネやイヌは犬歯の間の上あごの前歯が6本だが、フクロオオカミなど有袋類は8本ある。この頭は8本だった。</li>
<li>フクロオオカミは1936年に最後の1頭が死んだとされ、はく製として現存が確認されているのは世界で101体ほど。</li>
<li>エックス線でも頭骨が確認され、競売の開始価格は28ポンドだったが、最終的に6万ポンド（およそ1200万円）で落札された。落札者はクランフィールドさん自身で、エセックスで珍品店を営み、生涯かけてはく製を集めてきた人物。「一生に一度の掘り出し物」と話している。</li>
<li>この個体は国際フクロオオカミ標本データベースに登録され、絶滅動物の復活計画を進める企業コロッサル・バイオサイエンシズなどがDNAを採取する予定という。</li>
<li>検証状況: 報道はABC（オーストラリア）などによる。取引額の円換算は本稿による概算。最初にアンティーク市で購入した時期は明示されていない。</li>
<li>出典: <a href="https://www.abc.net.au/news/2026-08-24/xray-confirms-thylacine-skull-uk-collector-james-cranfield/107069932">ABC News</a></li>
</ul>
<h2>ネタ4 心停止から生き返った女性に、5時間駐車の反則切符</h2>
<ul>
<li>2026年7月26日、ニュージーランドのオークランド近郊オレワにあるスーパー「ニューワールド」の駐車場で、54歳の女性が倒れた。</li>
<li>通りかかった人が脈のないことに気づき、居合わせた女性が救急隊の到着まで胸骨圧迫を続けて脈を取り戻した。女性は病院へ搬送され、その後回復している。</li>
<li>ところが、治療を受けていた5時間あまりのあいだ車が停まったままだったため、駐車場を管理するスマート・コンプライアンス・マネジメントが80ニュージーランドドルの反則切符を出した。</li>
<li>この駐車場は90分の上限があり、5時間超は「駐車違反」に当たるという理屈だった。会社は当初「違反は違反」として、事務手数料30ドルへの減額にとどめた。</li>
<li>最終的にニューワールドの本部が管理会社に連絡し、切符の取り下げと返金を求めて決着した。</li>
<li>検証状況: 報道はニュージーランドのスタッフ（Stuff）などによる。女性の氏名は公表されていない。</li>
<li>出典: <a href="https://www.stuff.co.nz/nz-news/361021333/woman-dies-comes-back-life-gets-parking-ticket">Stuff</a></li>
</ul>
