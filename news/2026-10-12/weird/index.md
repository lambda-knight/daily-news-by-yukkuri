<h2>35トンの大綱が雨で動かず、那覇大綱挽はクレーンで綱をつないで引き分け</h2>
<ul>
<li>10月11日、那覇市の国道58号・久茂地交差点で第56回那覇大綱挽が行われました。綱は全長約160メートル、重さ約35トンで、ギネス世界記録に認定された大綱です。</li>
<li>大雨で開始が予定より45分遅れました。稲わらの綱が水を吸って重く滑りやすくなり、東西の男綱と女綱を寄せられず、クレーン付きトラックで綱をつり上げてから、2本をつなぐ木の棒「カヌチ棒」を差し込みました。琉球新報はこれを「異例の事態」と伝えています。</li>
<li>雨が上がった午後4時ごろに引き合いが始まり、約10分で引き分けが決まりました。主催者発表の観衆は約7万人。通算成績は東19勝、西14勝、引き分け18となりました。</li>
<li>参加者からは「全力で引かせていただきました」「また来年リベンジします」という声が聞かれました。</li>
<li>綱引きは琉球王国時代から那覇の町々で続いてきた行事で、戦前は1935年を最後に途絶えました。1971年、那覇市の市制50周年に合わせ、10月10日に復活しました。10月10日は、1944年に那覇が大きな被害を受けた「十・十空襲」の日でもあります。</li>
<li>綱は毎年新しく稲わらで作られます。綱引きの後には手綱が切り分けられ、縁起物として持ち帰る習わしがあります。</li>

</ul>
<h2>双子の兄弟が引退した年に、一人で1295.8キロ、英国のカボチャ名人が自分の世界記録を更新</h2>
<ul>
<li>英国ハンプシャー州で園芸店を営むイアン・パトンさん（65）のカボチャ「バギーラ」が、10月3日、バークシャー州ウォーグレイブの計量大会で1295.8キロ（2856ポンド12.8オンス）を記録しました。審査団体グレート・パンプキン・コモンウェルスが確認し、ギネス世界記録が10月7日に発表しました。</li>
<li>それまでの世界記録は、イアンさんと双子の兄弟スチュアートさんが2025年に出した1278.8キロの「マグル」。約17キロ上回りました。</li>
<li>兄弟は50年以上いっしょに巨大カボチャを育ててきましたが、スチュアートさんは2025年に引退。2026年はイアンさんが初めて一人で育てた年でした。本人は「一人だった分、仕事がずっと多かった」と話しています。</li>
<li>温室の気温は猛暑で40度に達し、葉を守るため窓の一部を白く塗って日よけにしました。水やりは1日最大590リットル。2か月間、1日最大6時間を畑で過ごしました。</li>
<li>カボチャはゴルフボール大から約120日で育ち、最盛期には1日最大32キロ増えます。名前は息子の提案で、小説「ジャングル・ブック」の黒ヒョウから取りました。</li>
<li>同じ年の別の1個「バルー」も、9月のモルバーン秋季品評会で1258キロを記録して優勝しています。バギーラからは2600粒以上の種を採り、次の目標は3000ポンド（約1361キロ）です。</li>
<li>バギーラは10月末までサウサンプトン近くのサニーフィールズ農場で展示され、その後は牛の飼料になる予定です。</li>
<li>出典: <a href="https://www.guinnessworldrecords.com/news/2026/10/all-hail-pumpking-paton-british-grower-beats-his-own-record-with-giant-gourd">Guinness World Records</a> / <a href="https://www.upi.com/Odd_News/2026/10/07/Guinness-World-Records-heaviest-pumpkin/5121791389821/">UPI</a></li>
</ul>
<h2>176時間踊り続けたナイジェリアの「ベン・ダンサー」、ギネスの審査待ち</h2>
<ul>
<li>ナイジェリアのダンサー、ベンジャミン・ダニエルさん（通称ベン・ダンサー）が、9月22日から29日まで最大都市ラゴスのフリーダム・パークで踊り続けました。AFP通信の集計で176時間52分59秒です。</li>
<li>個人のダンス・マラソンの現在の世界記録は、2023年にインドのスルシュティ・スディール・ジャグタプさんが出した127時間。約50時間上回りますが、ギネスはまだ認定しておらず、提出された証拠を規定どおりか審査しています。</li>
<li>ダニエルさんはギネスに3回申請し、2026年2月に挑戦の承認を得ました。準備は2022年からで、ジムでの鍛錬、痛みと持久力の訓練、睡眠を削る練習を重ねました。挑戦の3週間前にはひざを痛めていました。</li>
<li>曲はアフロビーツを中心に、ナイジェリアの大衆音楽フジ、ジャズ、ズークなど。ときどきナイジェリアの伝統衣装に着替えました。</li>
<li>立ち会った医師は、7日間で大きな体調不良はなかったと説明しています。北部バウチ州の故郷からは親族や村の人々が駆けつけ、「初日からずっとここにいる」と話しました。</li>
<li>本人は記録そのものは本当の目的ではなく、アフリカの土着の踊りに世界の目を向けさせたかったと語り、「小さな場所からでも大きなことを成し遂げられる」と述べました。</li>
<li>出典: <a href="https://www.africanews.com/2026/09/30/nigerian-dancer-eyes-world-record-after-seven-day-marathon/">Africanews</a> / <a href="https://www.euronews.com/2026/10/01/nigerian-dancer-completes-168-hour-dance-marathon-in-guinness-bid">Euronews</a> / <a href="https://beninwebtv.bj/en/nigeria-ben-dancer-completes-over-176-hours-of-dancing-and-awaits-guinness-decision/">Benin Web TV</a></li>
</ul>
<h2>13年通った州立公園で6.03カラット、黄色いダイヤモンドを掘り当てた男性</h2>
<ul>
<li>米アーカンソー州のクレーター・オブ・ダイヤモンズ州立公園で、ジャック・ペアラディンさんが6.03カラットの黄色いダイヤモンドを掘り当てました。2026年にこの公園で見つかった石では最大で、10月2日に報じられました。</li>
<li>公園は元の露天掘りのダイヤモンド鉱山で、1972年に州立公園になりました。入園料を払えば誰でも掘ることができ、見つけた石は持ち帰れます。開園以来3万7000個以上が見つかり、毎年400〜800個が出ますが、ほとんどは約0.25カラットです。</li>
<li>ペアラディンさんはミズーリ州出身の海軍予備役で、2013年から公園で採掘を続け、近くのマーフリーズボロへ移り住みました。これまでに300個以上の石を見つけています。</li>
<li>発見の瞬間はTikTokで生配信しており、「すごいのが出た！」と叫ぶ様子が残っています。石は「アメリカン・ドリーム」と呼ばれています。</li>
<li>同様の黄色い6カラット級は約25万ドルで売れるとされ、本人は収集家から最大100万ドルと言われたと話しています。土砂を掘るのを手伝ったウィスコンシン州のマイケル・シューマッハーさんと利益を分け、自分の鉱物の採掘場を開く計画です。</li>
<li>公園では2020年に9カラット、2024年にフランス人男性が7カラットを発見しています。史上最大は1924年の40.23カラット「アンクル・サム」です。</li>
<li>出典: <a href="https://www.fox5atlanta.com/news/man-finds-6-carat-diamond-famed-arkansas-state-park-we-got-big-one">FOX 5 Atlanta（AP配信）</a></li>
</ul>
