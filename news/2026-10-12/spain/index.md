<h1>スペイン文化・フラメンコ便り（2026年10月12日）</h1>
<h2>オープニング：2026年10月12日 — スペイン文化・フラメンコ便り</h2>
<ul>
<li>今日のスペイン語は「デ・アクエルド（De acuerdo）」。提案に「了解」「賛成」と応じる表現で、単なる相づちより合意の意思が強い。</li>
<li>今日の軸は「身体と素材に刻まれる記憶」。マノロ・ミジャレスの麻布、アナ・クーラのパンク、ダニ・デ・モロンの伴奏、パトリシア・ゲレーロの身体、エストレージャ・モレンテの声を結ぶ。</li>
</ul>
<h2>国際情勢（スペイン視点）</h2>
<ul>
<li>当日取得分にはスペインが直接当事者となる重要案件が乏しい。第三国の戦争をスペイン紙掲載という理由だけで並べず、文化・音楽へ時間を振り向ける。</li>
</ul>
<h2>スペイン国内ニュース</h2>
<ul>
<li>総選挙を前に住宅問題が有権者の主要関心へ上昇した。エル・パイスは購買力低下や政治不信と結びつけ、エル・ムンドは国営郵便コレオスが2019年の半分未満の取扱量となり、累積損失11億6千万ユーロ、バレンシア―マドリード間の手紙に13日を要した例を伝えた。</li>
<li>日本も空き家と都市部の家賃上昇を同時に抱えるが、スペインでは住宅デモや広場の占拠が選挙運動そのものへ入り込む。生活費への怒りを街頭で可視化する政治文化が表れている。</li>
</ul>
<h2>文化・芸能ニュース</h2>
<ul>
<li><strong>マノロ・ミジャレス生誕100年</strong>：クエンカのアントニオ・ペレス財団が回顧展を開き、詩の復刊と映像作品の修復も進む。カナリア諸島出身のミジャレスは、裂いた麻布や縫い目を用い、支持体の傷そのものを戦後スペインの暴力と記憶へ変えた。</li>
<li><strong>アナ・クーラ、レイナ・ソフィア美術館へ</strong>：スペイン・パンクの担い手が「ビシオス・モデルノス」公演を始める。本人は「アイコン」と呼ばれる位置を他者が与えたものとしつつ、拒まないと語った。地下文化が国立美術館へ入ることは、反体制の身振りを無害な記念品にせず、当時の音量で聞き直せるかを問う。</li>
<li><strong>スルバランからイスラエル・ガルバンまでパリへ</strong>：ルーヴルのスルバラン展と並行し、ブニュエル、ティルソ・デ・モリーナ、ロッシ・デ・パルマ、イスラエル・ガルバンを紹介する企画が組まれた。黄金世紀の静物画と現代の異端的バイレを、一つの「スペインらしさ」へ閉じない構成である。</li>
</ul>
<h2>フラメンコニュース</h2>
<ul>
<li>パンプローナ市とフラメンコ・オン・ファイアは、エル・ペレの市庁舎バルコニー公演、二つのコンサート、未成年向けギター・舞踊講座を組み合わせた。鑑賞と実技を同じ祭典へ置くことで、観客を次の担い手へつなぐ。</li>
<li>マラガ県アロサイナの「アルメナ・フラメンカ」は、カンテ、ギター、バイレを一夜へ集める。小都市の祭りでは三者が別ジャンルでなく、互いの合図で成立する共同作業として見える。</li>
<li>ラ・ウニオンの第65回カンテ・デ・ラス・ミナス国際祭は最終候補を発表した。鉱山歌の保存とコンクールを結ぶ制度は、地域の記憶を観光だけでなく演者の職業機会へ変える。</li>
<li>フラメンコを「スペインの顔」として首都や国外が提示する一方、担い手の言葉、コンパス、教授法はセビリア、ヘレス、グラナダ、コルドバなどアンダルシアの地域社会で育つ。この二重性を消すと、文化の発信と所有の違いが見えなくなる。</li>
</ul>
<h2>フラメンコギタリスト列伝</h2>
<ul>
<li>今日の一人はダニ・デ・モロン（1981年セビリア生）。モロン・デ・ラ・フロンテーラで育ち、ディエゴ・デル・ガストール以来の、親指で太い低音を置き、ブレリアを乾いた音で刻む系譜を受け継ぐ。</li>
<li>セビリアのマティルデ・コラル舞踊学院で足音と決めを読む伴奏を学び、アントニオ・カナレスやマヌエラ・カラスコの舞踊団へ参加した。転機はパコ・デ・ルシアの『コシータス・ブエナス』ツアーで第二ギターを務めたこと。主旋律を奪わず、和音とコンパスの厚みを足す役割だった。</li>
<li>2018年の『21』では、エル・ペレ、ミゲル・ポベダ、ドゥケンデ、ロシオ・マルケスら11人の歌い手へ異なるパロを割り当て、伴奏そのものをアルバムの主題にした。独奏家の自己表現ではなく、相手によって音の置き方を変える能力を作品化した点が重要である。</li>
<li>公式映像の<a href="https://www.youtube.com/watch?v=ySZagd2n9Xo">『ラ・マサロカ』</a>では、パルマが加わった瞬間に右手の刻みが打楽器のように締まり、手拍子の裏へアクセントをずらす。低音を一つ置いて空間を作る箇所には、踊りの足を待ってきた伴奏者の判断が聞こえる。</li>
<li>2024年の『エンパティア』では歌の少ない編成でも、レトラが入り得る空白を残した。速弾きで埋め尽くさず、親指の低音、和音の省略、沈黙で架空の歌い手と対話する。モロンの土着的なタッチを現代和声へつないだ奏者である。</li>
</ul>
<h2>フラメンコバイレ列伝</h2>
<ul>
<li>今日の一人はパトリシア・ゲレーロ（1990年グラナダ生）。母の舞踊学院で3歳から踊り、15歳でマリオ・マジャのフラメンコ研究センターへ入り、17歳でラ・ウニオンのデスプランテ賞を得た。</li>
<li>代表作『カテドラル』は、宗教的な声の長い線と細かなサパテアードを衝突させ、慣習に縛られた女性の身体を描く。公式映像の<a href="https://www.youtube.com/watch?v=JAhClAr5rlI">『カテドラル』</a>では、上体とブラソを静かに保ったまま足だけが細分化する場面を見ると、祈りと抵抗が同時に置かれる構造が分かる。</li>
<li>2021年のスペイン国民舞踊賞を受け、2023年からアンダルシア・フラメンコ・バレエの芸術監督を務める。伝統的なコンパスを壊すのではなく、照明、群舞、異なる声の配置によって、身体へかかる社会的圧力を舞台化する。</li>
</ul>
<h2>フラメンコカンテ列伝</h2>
<ul>
<li>今日の一人はエストレージャ・モレンテ（1980年グラナダ県生）。父は革新的な歌い手エンリケ・モレンテ、母は踊り手アウロラ・カルボネル。7歳から父の舞台へ出て、サビーカスとも共演した。</li>
<li>初アルバム『ミ・カンテ・イ・ウン・ポエマ』は父が構成し、古いカンテと詩を若い声へ渡した。映画『ボルベール』ではペネロペ・クルスの歌声を担当し、カンテを映画の物語へ溶け込ませた。</li>
<li>公式配信の<a href="https://www.youtube.com/watch?v=X6tmIGhoakM">『エン・ロ・アルト・デル・セロ』</a>では、タンゴの4拍に乗りながら語尾を短く切り、細かなメリスマを次の拍へ食い込ませる。明るい声色の内側で、子音を前へ出してレトラの輪郭を保つ点が聴きどころである。</li>
<li>ファリャとロルカを扱う舞台では、幼少期に父と訪れた二人の家の記憶が創作へ戻る。家名を模倣するのでなく、クラシック、映画、ポップスとの接点を広げつつ、グラナダの歌の発音を残している。</li>
</ul>
<h2>フラメンコギター工房だより</h2>
<ul>
<li>今日の国外編は米国カリフォルニア発のコルドバ・ギターズ。GK Studioは表板に単板ヨーロピアン・スプルース、側・裏板にシープレス、透明なゴルペ板を採用し、標準的なクラシックギターより薄いネックと低めの弦高を掲げる。</li>
<li><a href="https://cordobaguitars.com/product/gk-studio/">公式製品ページ</a>が示す設計は、足音、パルマ、カンテの間へ短い音を入れる反応を、量産仕様で各国へ届ける試みである。個人工房の微調整とは役割が違い、学習者や巡演者が同じ寸法を得やすい。</li>
<li>シープレスの軽い胴とゴルペ板はフラメンコの使用法を最初から想定する。ブランド名がスペインの都市コルドバを借りる以上、産地のイメージだけでなく、アンダルシアの奏法へ設計で応答できるかが評価軸になる。</li>
</ul>
<h2>フラメンコのパロ解説</h2>
<ul>
<li>今日のパロはミネラ。19世紀半ば、ムルシア州カルタヘナからラ・ウニオンの鉱山地帯で、アルメリアなどから移った鉱夫の歌と土地のファンダンゴが交わって形づくられたカンテス・デ・レバンテの一つである。起源を一人へ固定する説には異論もある。</li>
<li>レトラは鉱山、危険、家族、労働を扱い、定型拍を持たない。歌い手は一息の長さで旋律を伸縮させ、ギターは句末を待って和音を置く。拍のある舞踊形タラントとはここが異なる。</li>
<li>ミネラ調の中心はG♯で、典型的な下降はC♯m→B→A→G♯。台本ではシーシャープマイナー、ビー、エー、ジーシャープと読む。最後の半音下降が、地面へ沈み込むような終止を作る。</li>
<li>祭典公式の<a href="https://www.youtube.com/watch?v=3t8nY2FKjvc">『グレゴリオ・モヤのミネラ』</a>では、伴奏ギターが拍を刻まず、長い歌の句が終わるまで和音を待つ箇所に注目したい。中ほどで声が高く持ち上がる山場と、その後の沈黙までが一つのフレーズである。</li>
</ul>
<h2>まとめ</h2>
<ul>
<li>麻布の傷、踊り手の足、歌い手の子音、ギターの低音は、歴史を説明するだけでなく素材と身体へ刻む。今日のスペイン文化は、記憶を保存する器そのものを問い直している。</li>
<li>別れの言葉は「ノス・ベモス（Nos vemos）」。直訳は「また会いましょう」で、次の再会を自然に約束する日常表現である。</li>
</ul>
