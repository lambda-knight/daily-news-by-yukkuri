<h2>オープニング：2026年9月1日 — スペインニュース</h2>
<ul>
<li>アイスランドのEU拒否がブリュッセルに残した「逸機」、セウタ危機でモロッコを免責したサンチェス、9月2日の街頭抗議に造反するPSOE市長、セビリアのフラメンコ・ビエンナーレ開幕、グラナダ近郊の製作講座を追う。</li>
</ul>
<h2>今日のスペイン語ひとこと</h2>
<ul>
<li>「A palabras necias, oídos sordos（ア・パラブラス・ネシアス、オイドス・ソルドス）」＝「愚かな言葉には、聞こえないふりを」。necias は「愚かな」を意味する形容詞 necio の女性複数形で、女性名詞 palabras（言葉）に一致している。oídos sordos は「聞こえない耳」で、動詞と組み合わせた「hacer oídos sordos（オイドス・ソルドスをする）」で「聞き流す・相手にしない」という慣用句になる。中傷合戦やデマが飛び交う今日の政治ニュースにそのまま当てはまる。</li>
</ul>
<h2>国際情勢（スペイン視点）</h2>
<ul>
<li><strong>アイスランドのEU拒否、エル・パイス社説「レイキャビクの門前払い、ブリュッセルの逸機」（8月31日）</strong>: 8月30日の僅差の国民投票で、アイスランドはEU加盟交渉の再開を否決した。エル・パイスの社説は、アイスランドが安全保障の傘と物価危機の出口を自ら手放した一方で、EUの側も「弱っている計画への手軽な補強」という一度きりの機会を逃した、と評価した。スペインは結束基金と共通農業政策の主要な受益国で、EUの拡大と結束を歓迎する立場にある。フランコ独裁後の民主化をEU加盟とともに歩んだスペインでは「欧州＝自由と繁栄の土台」という肌感覚が強く、豊かな国が加盟を自分から断る感覚は理解されにくい。</li>
<li><strong>サンチェス、セウタ危機でモロッコを免責、「極右インターナショナル」「ロシア」「イスラエル」が大量入国を招くデマを広めたと主張（8月31日、エル・パイス／エル・ムンド）</strong>: 7月末の7万人規模の越境について、サンチェス首相は記者会見でモロッコの責任に触れず、外国勢力の偽情報が大量入国を誘発したと述べた。「協力がなければ危機は悪化する」とモロッコを擁護し、大量越境の翌日に使った「スペインの領土保全への攻撃」という表現は繰り返さなかった。あわせて国王フェリペ6世が現政権下で初めてセウタを訪問すると明らかにしたが、日程は示していない。エル・ムンドはこれを「モロッコの全面擁護」と報じた。地中海とアフリカ側で起きることは「自分たちの問題」で、対モロッコ関係は主権（セウタ・メリリャ）とガス・移民協力が絡み合い、左右で評価が割れる。</li>
<li><strong>ニカラグアの作家セルヒオ・ラミレスがルーラ大統領に公開書簡（8月25日、エル・パイス）</strong>: セルバンテス賞作家でニカラグアを追われたセルヒオ・ラミレスが、エル・パイスに大統領ルーラ宛ての公開書簡を寄せた。「オルテガは選挙を廃止した。あなたを4選させうるのと同じ権利を、ニカラグア国民から奪わないでほしい」と訴える内容である。スペイン語圏の論壇はエル・パイスのような紙面を共有しており、旧植民地ラテンアメリカの民主主義の後退は、スペインの読者にとって「他人事ではない」出来事として届く。</li>
</ul>
<h2>スペイン国内ニュース</h2>
<ul>
<li><strong>PP対サンチェス、「フランコのせいにするのも忘れている」、9月2日の抗議にPSOE市長も参加表明（8月31日、エル・パイス／エル・ムンド）</strong>: サンチェスがセウタ危機でモロッコ以外のあらゆる主体（ロシア、イスラエル、極右）を名指ししたことに、野党PPは「フランコを非難し忘れている」と皮肉った。9月2日にPPが各地で呼びかける抗議集会には、レオン、メリダ、モゲール、チクラナなどのPSOE所属の市長・議員が、党本部（フェラス）の不参加指示に反して参加を表明した。フェラスは「自由律の詩人（versos libres）はいるものだ」と火消しに追われている。党議拘束と「和」を重んじる日本の政治では、地方首長が公然と党方針に背く光景は珍しい。街頭で意思表示するのがスペイン、静かな同調圧力で足並みをそろえるのが日本、という違いが出ている。</li>
<li><strong>エル・ムンド世論調査、「セウタの失政でサンチェス陣営は220万票を失った」</strong>: エル・ムンド（8月30日）の調査によれば、回答者の62.9%が政権の対応を「悪い」「非常に悪い」と評価し、その中にはサンチェス支持層の4分の1が含まれる。PPとVoxを合わせると204議席に達するという試算で、不満の受け皿が右派に向かっている。右派紙の調査である点は割り引く必要があるが、セウタが政権の体力を確実に削っている。</li>
<li><strong>美術館強盗の波に文化省が対応、自治州へ金・銀・宝石の所蔵目録を要請（8月31日、エル・パイス）</strong>: 相次ぐ考古遺物の強盗を受け、文化省は国家警察と協力し、盗まれやすい金・銀・宝石類の所在を把握するため自治州にデータ提出を求め、追加の会合を設定した。バレンシア州など一部の自治州は求められた情報を出さなかった。前週に扱った「どう盗まれたか」という手口の話とは別の、中央と自治州の足並みという論点である。地方分権への強い執着が、文化財のセキュリティ対策でも表面化した。</li>
<li><strong>アルカラス、4か月の負傷離脱から全米オープンで復帰、サフィウリンを撃破（8月31日、エル・ムンド）</strong>: 4か月ぶりの実戦で、カルロス・アルカラスは痛みの兆候を見せずに1回戦を突破し、2回戦でポルトガルのファリアと対戦する。スペインではスポーツが一面を占め、選手個人の不調と復帰が国民的な関心事として扱われる。ケガ明けの若い選手を国を挙げて後押しする空気がある。</li>
</ul>
<h2>文化・芸能ニュース</h2>
<ul>
<li><strong>サン・セバスティアン映画祭2026、ドノスティア賞にナオミ・ワッツ（8月31日、エル・パイス／エル・ムンド）</strong>: 『マルホランド・ドライブ』の女優ナオミ・ワッツに、生涯功労賞にあたるドノスティア賞が9月19日に贈られる。授与式のあと、ベン・シリニアン監督『ザ・ハウスワイフ（完璧な妻）』が上映される。9月18日から26日の映画祭は、スペイン映画界が国際的なスターを迎えて秋の賞レースの起点になる場である。</li>
<li><strong>第87回キンセナ・ムシカル（サン・セバスティアン）閉幕、リッカルド・シャイーが締め、地元合唱団オルフェオン・ドノスティアラが共演（8月31日、エル・パイス）</strong>: スカラ座の首席指揮者としての最後のツアーで、シャイーがドヴォルザーク、ヴェルディ、チャイコフスキーのプログラムを指揮した。1897年創設の地元合唱団オルフェオン・ドノスティアラと、チェロのユリア・ハーゲンが加わった。アンダルシアから遠いバスクの古参音楽祭で、地元の合唱団が世界的な指揮者と並ぶことが街の誇りになっている。</li>
<li><strong>日本の美術家・草間彌生が97歳で死去、エル・パイスが大きく報じる（8月27日）</strong>: 水玉模様で知られ、精神的な不調を抱えながら制作を続けた作家だとエル・パイスは伝えた。スペインでも回顧展が繰り返し開かれ、人気が高い。高齢まで現役を貫く作家像は日本とスペインに共通する。スペインの新聞が日本の作家の死をこれだけ大きく扱うのは、草間の作品が「国境を越える現代美術」の代表格だからである。</li>
</ul>
<h2>フラメンコニュース</h2>
<ul>
<li><strong>第24回セビリア・フラメンコ・ビエンナーレ、9月9日開幕〜10月3日</strong>: サラ・バラスの『インフィニタ』で幕を開ける。テアトロ・デ・ラ・マエストランサでは、フアン・マヌエル・カニサレスがセビリア王立交響楽団と『カニサレス・シンフォニコ』を、9月26日にはイスラエル・ガルバンが新作『白と黒のボレロ』を初演する。ホセ・メルセ、ファルキート、マヌエル・リニャン、マリナ・エレディアらが並ぶ。隔年開催のフラメンコ最大の見本市で、発祥地セビリアが世界に向けて発信する場である。</li>
<li><strong>第21回オスナ・フラメンコ祭（セビリア県、8月30日）</strong>: ペーニャ・フラメンカ・ラ・シギリージャが主催し、市の文化事業「ラ・クルトゥーラ・アル・フレスコ」の一環として、カサ・デ・ラ・クルトゥーラの中庭で開かれた。カンテはペドロ・エル・グラナイーノ、モンセ・コルテス、アンヘル・ベルドゥーゴ、バイレはマリア・タボラ、ギターはパトロシニオ・イホ、フアン・マヌエル・カデナス「エル・チノ」、ダビ・カロが務めた。20年以上続く夏の定番である。</li>
<li><strong>スマ・フラメンカ・ホベン第6回、9月にマドリードで開催</strong>: 名門スマ・フラメンカの前哨として、4日間、毎日ギタリスト1人に歌い手と踊り手を組み合わせ、若手を中心に立てる。首都マドリードが若手育成の器を用意する形である。</li>
<li><strong>フラメンコとアンダルシア地域性</strong>: 同じ9月に、セビリアのビエンナーレとオスナ祭という発祥地の大小の催しと、マドリードのスマ・フラメンカ・ホベンが並ぶ。フラメンコが首都で「スペインの顔」として使われることに、アンダルシアには複雑な思いが根強い。</li>
</ul>
<h2>フラメンコギター工房だより</h2>
<ul>
<li><strong>グラナダ近郊ウエトル・ベガの製作家オスカル・ムニョスと、その製作講座</strong>: ムニョスは2014年から本格的にギターを製作し、スティーブン・ヒルとパブロ・レケナに師事した。2017年のアントニオ・マリン・モンテロ国際ギター製作コンクールで銀賞を得ている。工房はグラナダから約2キロのウエトル・ベガにある。</li>
<li><strong>講座の中身</strong>: 1対1で160時間かけ、受講者がクラシックまたはフラメンコのスペインギターを1本、最初から最後まで組み上げる。集中コースは1か月、分割なら最大5か月。木材の選定・性質・品質・保存・下準備、工具の扱い、製作図面の読み方、表板・側板・裏板・ネック・ブリッジの全組み立てを、グラナダ様式（granadina）の構造を軸に教える。完成したギターと図面・技術データ一式を持ち帰る。</li>
<li><strong>継承と演奏現場とのつながり</strong>: グラナダはスペイン随一の製作家の集積地で、アントニオ・マリン・モンテロ（1933〜2019年）を頂点とする系譜に、英国出身でグラナダに根を張ったスティーブン・ヒルのような外国人製作家も連なる。フラメンコギターは糸杉の軽い胴で立ち上がりが速く、カンテ、バイレ、パルマに音を食いつかせる伴奏楽器である。工房は「弾く人」だけでなく「作る人」を育てる場にもなっている。</li>
</ul>
