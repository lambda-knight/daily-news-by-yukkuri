</ul>

<h2>国際情勢（スペイン視点）</h2>
<ul>
<li><strong>セウタで受け入れ場所がさらに4,000床不足</strong>（El Mundo、9月1日）: 自治市は移民1万人分の場所を準備しているが、政府の当初見積もりを上回り、なお4,000床必要とされた。モロッコに接するスペイン領の住宅、学校、警察が直接負担を受ける問題である。</li>
<li><strong>未成年25人のモロッコ送還手続きが始動、職員は署名に慎重</strong>（El Mundo、8月31日）: 最初の通常送還案件25件を週内に送る一方、担当者は法的責任を懸念している。国境管理だけでなく、未成年保護と適正手続きが衝突する。</li>
<li><strong>最初の機動隊18人はサンチェス首相警護へ</strong>（El Mundo、8月31日）: 7月31日以降、中央政府の要人26人がセウタを訪問し、街頭警戒より要人警護が優先されたとの警察側の不満が報じられた。</li>
<li><strong>サンチェス首相はモロッコとの協力を擁護</strong>（El País、8月31日）: 首相は大量越境をあおった偽情報として極右、ロシア、イスラエルを挙げ、国王フェリペ6世のセウタ訪問も予告した。協力を重視する左派紙の枠組みと、現場負担を前面に出す右派紙の差が鮮明になった。</li>
</ul>
<h2>スペイン国内ニュース</h2>
<ul>
<li><strong>9月2日の抗議へ社会労働党の地方首長も参加表明</strong>（El País／El Mundo、8月31日）: レオン、メリダ、モゲール、チクラナなどの首長・議員が、党本部の不参加方針に反して参加を表明。党本部は造反者を「自由律の詩人」と呼んだ。中央より地元住民への説明を優先する地方政治の強さが表れた。</li>
<li><strong>文化省が自治州へ金・銀・宝石の所蔵情報を要請</strong>（El País、8月31日）: 博物館強盗を受け、国家警察と危険度の高い所蔵品を把握する計画だが、バレンシア州などは必要情報を提出しなかった。地方自治と全国的な盗難対策の接合が課題になった。</li>
<li><strong>カタルーニャのPISA試験、7件の誤り警告を無視した理由を非開示</strong>（El Mundo、8月31日）: 教育行政トップ交代の背後で、州政府が警告への対応理由を示さないと報じられた。独自教育を誇る自治州だけに、データの信頼性は地域の自尊心にも響く。</li>
<li><strong>カルロス・アルカラスが4か月ぶりに復帰勝利</strong>（El Mundo、8月31日）: 全米オープン1回戦でロマン・サフィウリンを破り、痛みを見せず復帰。2回戦はポルトガルのジャイメ・ファリアと対戦する。</li>
</ul>
<h2>文化・芸能ニュース</h2>
<ul>
<li><strong>クリスティナ・リャノス、10年の沈黙を破る回想録</strong>（El País／El Mundo、8月29〜31日）: スペインのロックバンド、ドーバーの元ボーカルが『夜が落ち、もう誰も私を救えなかった』を刊行。うつ、性暴力被害、線維筋痛症、摂食や家族の問題と、バンド解散までを本人の言葉で振り返った。華やかな舞台と、声を失った後の長い生活を同時に伝える作品である。</li>
<li><strong>ロス・ハビスの『ラ・ボラ・ネグラ』にアカデミー賞5部門候補の予測</strong>（El Mundo、8月30日）: ハビエル・アンブロッシとハビエル・カルボによる新作をVarietyが有力作に挙げた。二人はスペインの舞台・テレビ・映画を横断して制作するコンビで、国内の物語を国際賞レースへ運ぶ。</li>
<li><strong>キケ・マイーリョ監督が「9・11被害者」を装ったスペイン人女性を映画化</strong>（El Mundo、8月28日）: 『ラ・スーペルビビエンテ』は、タニア・ヘッドを名乗ったアリシア・エステベの虚偽を再構成する。事件そのものより、なぜ共同体が物語を信じたかをスペイン人監督が問う。</li>
</ul>
<h2>フラメンコニュース</h2>
<ul>
<li><strong>第24回セビリア・フラメンコ・ビエンナーレ</strong>は9月9日から10月3日まで。サラ・バラス『インフィニタ』で開幕し、カニサレスとセビリア王立交響楽団、イスラエル・ガルバン新作、ホセ・メルセらが出演する。</li>
<li><strong>第21回オスナ・フラメンコ祭</strong>は8月30日、文化会館中庭で開催。ペドロ・エル・グラナイーノとモンセ・コルテスのカンテ、マリア・タボラのバイレ、3人のギターが一晩に集った。</li>
<li><strong>パンプローナのフラメンコ・オン・ファイア連携企画</strong>では、市庁舎バルコニーからエル・ペレが歌い、未成年向けギター・舞踊講座も実施。アンダルシア発祥の芸能が北部ナバラで教育へつながった。</li>
<li><strong>アンダルシアと首都・地方の距離</strong>: セビリアは世界最大級の舞台で発祥地の主導権を示し、オスナは中庭とペーニャの共同体を守る。マドリードや北部が「スペインの顔」として広げるほど、発祥地の固有性をどう残すかが問われる。</li>
</ul>
<h2>フラメンコギター工房だより</h2>
<ul>
<li><strong>オスカル・ムニョス工房、ウエトル・ベガ（グラナダ近郊）</strong>: ムニョスは2014年から製作を始め、スティーブン・ヒルとパブロ・レケナに師事。2017年アントニオ・マリン・モンテロ国際製作コンクール銀賞。</li>
<li><strong>1対1、160時間の製作講座</strong>: 集中1か月または最大5か月で、木材の選定・保存、図面、表板、側板、裏板、ネック、ブリッジを学び、グラナダ式のクラシックまたはフラメンコギターを完成させる。</li>
<li>フラメンコ用は軽快な応答でカンテ、バイレ、パルマへ音を食い込ませる。演奏家だけでなく製作家を育て、グラナダの系譜を次世代へ渡す講座である。</li>
</ul>

</ul>
