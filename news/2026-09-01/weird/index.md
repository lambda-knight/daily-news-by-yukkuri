<li>アメリカ国内のグーグルマップで、五大湖の「レイク・オンタリオ」の表示が「レイク・アメリカ」に切り替わった件。</li>

<h2>ネタ1 ドラマ50話に出資し、自分を主役にしてキス60回超を要求した中国の資産家</h2>
<ul>
<li>中国で、名前を公表していない資産家の女性が、全50話のショートドラマシリーズに出資した。出資の条件として、彼女は「主役の女性を自分が演じること」と「最終的な脚本の承認権」を求めたと報じられている。</li>
<li>完成した作品には、相手役の男優・鍾宇飛（ジョン・ユーフェイ、23）とのキスシーンが60回以上入っていた。</li>
<li>配信プラットフォームは、キスシーンが多すぎて内容規制に触れるとして、この完成済みシリーズの配信を拒否。商業的には失敗に終わった。</li>
<li>プロデューサーの孟星（モン・シン）が制作の内情を公に説明した。中国のSNSでは「資本が撮影現場を私的な狩り場に変え、俳優がモノのように扱われている」といった批判が出て、俳優へのハラスメントをめぐる議論になった。</li>
<li>出典: <a href="https://www.odditycentral.com/news/wealthy-woman-bankrolls-drama-series-so-she-can-star-in-it-and-kiss-male-lead-more-than-60-times.html">Oddity Central</a>（2026年8月12日）</li>
</ul>
<h2>ネタ2 グーグルマップの「オンタリオ湖」がアメリカ国内で「アメリカ湖」に</h2>
<ul>
<li>アメリカ国内のグーグルマップで、五大湖のひとつ「レイク・オンタリオ」の表示が「レイク・アメリカ」に変わった。</li>
<li>きっかけはトランプ大統領の大統領令で、カナダとの通商上の対立が背景にある。アメリカの公式な地名データベースが、国内向けの呼称をこの名前に改めた。</li>
<li>表示は場所によって分かれる。アメリカ国内の利用者には「レイク・アメリカ」、カナダの利用者には従来どおり「レイク・オンタリオ」、それ以外の国では両方の名前が併記される。</li>
<li>昨年、「メキシコ湾」の表示がアメリカ国内向けに「アメリカ湾」へ変わったのと同じやり方。</li>
<li>オンタリオ州の当局者やカナダ政府からは強い反発が出ている。オンタリオ湖は五大湖で最も面積が小さく、湖岸はアメリカとカナダの両国にまたがっている。</li>
<li>出典: <a href="https://www.cnn.com/2026/08/30/politics/google-maps-changes-lake-ontario-to-lake-america">CNN</a>（2026年8月30日） / <a href="https://time.com/article/2026/08/31/lake-ontario-america-us-canada-trump-google-maps/">TIME</a>（2026年8月31日）</li>
</ul>
<h2>ネタ3 買った土地のフェンスを外したら、隣人が40年頼っていた</h2>
<ul>
<li>アメリカで、ある人が土地を購入した。境界沿いには幅1.7メートルほどの細い通路と、自分の敷地側に立つ錆びた金網のフェンスがあった。</li>
<li>隣家の門扉はこの金網フェンスに取り付けられていて、フェンスがないと門として機能しない状態だった。</li>
<li>購入から2か月後、この人は歩くスペースを確保するため、劣化したフェンスを撤去した。防犯と礼儀のために新しい門を2つ付け、自分の裏庭はきちんと囲ったままにした。</li>
<li>すると隣人が弁護士を立て、「まったく同じ金網フェンスを建て直せ」と要求してきた。隣人はこのフェンスに40年間頼ってきたが、フェンス自体に法的な権利はない。投稿者いわく「引っ越してきたときからフェンスがあった、だから絶対にそこになければならない、と隣人は考えている」。</li>
<li>掲示板の相談板に投稿され、コメントの多くは「隣人に法的な立場はない」との見方。一方で、長年の使用から生じる「取得時効」を心配する声もあった。</li>
<li>出典: <a href="https://twistedsifter.com/2026/08/one-man-removed-a-fence-from-land-he-had-just-purchased-but-decades-of-neighbor-dependence-turned-the-decision-into-a-bigger-conflict/">TwistedSifter</a>（2026年8月31日）</li>
</ul>
<h2>ネタ4 ルールが厳しすぎて家を売れない、あるアメリカの住宅組合</h2>
<ul>
<li>アメリカで、ある住宅所有者が相談板に投稿した。住んでいる地区の住宅組合（HOA、住民でつくる自治組織）が、運営陣の交代のあと急速に細かくなり、違反と罰金が絶えないという。</li>
<li>挙がっているルールは、飼い猫を外で放し飼いにしない、犬を鳴かせない、子どもを前庭で遊ばせない、など。歩道にチョークで絵を描いたことにも警告が来た。来客の車が家の前に1時間を超えて停まると「20ドルの料金」がかかる。</li>
<li>家を売りに出したが、内見に来た人が厳しい組合ルールの話を聞くと、すぐに興味を失う。「組合の担当者がいつも外にいて、住民の細かな違反をめぐって騒ぎを起こしている」ことも、買い手を遠ざけているという。</li>
<li>投稿者は地区を「近所というより、暇を持て余した人たちが仕切る郊外の独裁国家」と表現し、相場より安くてもいいから抜け出したい、と書いている。</li>
<li>相談板の助言は「投げ出さず、自分が組合の理事会に入って中から変えろ」というもの。</li>
<li>出典: <a href="https://twistedsifter.com/2026/08/awful-hoa-creates-rules-that-restrict-how-pets-children-and-visitors-live-their-lives-but-the-rules-are-so-strict-that-one-homeowner-cant-even-sell-her-home/">TwistedSifter</a>（2026年8月31日）</li>
</ul>
