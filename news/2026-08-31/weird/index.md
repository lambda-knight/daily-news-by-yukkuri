<h2>ネタ1 「肌が燃える」と5年間ため池で暮らすインドの16歳</h2>
<ul>
<li>インド西ベンガル州ムルシダバードのイクバル・シェイクさん（16）が、原因不明の皮膚の痛みを抑えるため、この5年近くを小さなため池の中で昼夜過ごしていると訴えている。</li>
<li>本人によると、水から長く出ると肌が焼けるような激痛に襲われる。家族も同じ説明をしている。</li>
<li>複数の病院を受診したが診断はつかず、自称の治療者にもかかったが改善しなかった。</li>
<li>本人は原因を「ジン（精霊）や妖精など超自然的な何か」のせいだと語っている。ネット上では、皮膚が赤く灼熱感を伴う希少疾患「紅痛症（こうつうしょう）」ではないかとの推測も出ているが、公式な診断ではない。</li>
<li>動画が拡散して議論になり、実業家アナント・アンバニ氏がムンバイの専門医のもとへ約1,300マイル（約2,100キロ）の移送を手配した。</li>
<li>出典: <a href="https://www.odditycentral.com/news/indian-teen-allegedly-spent-the-last-five-years-in-a-pond-to-soothe-painful-skin-condition.html">Oddity Central</a>（2026年8月24日）</li>
</ul>
<h2>ネタ2 見知らぬ住所に300枚のピザ、ポーランドの23歳に最大8年</h2>
<ul>
<li>ポーランド北西部シュチェチンの23歳の男が、他人の名前と個人情報を使い、見知らぬ住所へ大量のピザを不正注文したとして捜査を受けている。</li>
<li>注文には、拉致・放火・事故を示唆する脅迫めいた文言も添えられていた。</li>
<li>一度の注文で300枚、3万7千ズウォティ（約1万ドル）に上る例もあった。注文先はシュチェチンのほか、ヴロツワフ、クラクフ、ワルシャワにも及んだ。あまりに数が多く店に断られた注文もあった。</li>
<li>ポーランドのサイバー犯罪対策中央局が家宅捜索を行い、電子機器やデータ記録媒体を押収した。</li>
<li>容疑はストーキング、なりすまし、多額の損害を与えたことなど。有罪なら最大8年の禁錮。動機はまだ捜査中とされる。</li>
<li>複数の飲食店が損失を被り、脅迫を受け取った人々も精神的な苦痛を訴えている。</li>
<li>出典: <a href="https://www.odditycentral.com/foods/man-faces-up-to-8-years-in-prison-for-ordering-hundreds-of-pizzas-to-random-addresses.html">Oddity Central</a>（2026年8月24日）</li>
</ul>
<h2>ネタ3 4か月かけた500キロの結婚式ケーキ、中身はほぼ砂糖</h2>
<ul>
<li>スペイン・カタルーニャの製菓職人マルク・スアレスさんが、重さ500キロ、高さ3.5メートル、幅1.8メートルの結婚式ケーキを制作し、パリのオペラ座（ガルニエ宮）で披露した。</li>
<li>表面には手作業で成形した砂糖のペタル（花びら）が3万3千枚。実際に食べられるスポンジは全体のわずか0.1%で、残りは砂糖細工とホワイトチョコレート。</li>
<li>構想に約1か月半、制作に4か月、延べ1,800時間。規模が大きすぎて、製菓職人仲間やその家族にも手伝ってもらった。</li>
<li>依頼主は名前を伏せたサウジアラビアの王族カップル。「ケーキに見えない、記念碑のようなもの」を求められたという。</li>
<li>実用的なデザートというより装飾用の「モニュメント」として作られた。</li>
<li>出典: <a href="https://www.odditycentral.com/art/pastry-chef-spends-four-months-creating-awe-inspiring-500-kilogram-wedding-cake.html">Oddity Central</a>（2026年8月10日）</li>
</ul>
<h2>ネタ4 芝の刈りかすを毎日花壇へ、ゴルフ場ともめる住民</h2>
<ul>
<li>アメリカ・オハイオ州でゴルフコースに隣接して暮らす住民が、掲示板の「近所トラブル」板に投稿した。</li>
<li>以前、コースは刈りかすを細かく砕くタイプの芝刈り機を使っており実害はなかった。ところがある夏、特定の作業員が機械を替え、刈りかすを住民の花壇へ吹き飛ばす向きでばかり刈るようになった。</li>
<li>投稿者いわく「彼はカート道の側を向いて刈ることは絶対にせず、うちの庭へ飛ぶ向きでしか刈らない」。同じ作業班は他の隣家では穏やかなやり方を続けているという。</li>
<li>住民はコース支配人に何度も留守番電話を残したが、折り返しはなかった。</li>
<li>ネットの助言は「日時入りの動画で、刈りかすが花壇へ吹き込まれる様子を記録せよ」。投稿時点で解決はしていない。</li>
<li>出典: <a href="https://twistedsifter.com/2026/08/golf-course-employee-kept-blowing-grass-clippings-into-his-flowerbeds-all-summer-so-he-finally-had-enough/">TwistedSifter</a>（2026年8月）</li>
</ul>
