<h2>ネタ1 91歳「グレービアード」、転倒71回を乗り越えAT縦走最高齢記録を奪還</h2>
<ul>
<li>アメリカ人デール・サンダースさん（91、トレイルネーム「グレービアード」）が、ジョージア州スプリンガー山からメイン州カタディン山までの約3,530キロ、アパラチアン・トレイル（AT）を踏破し、最高齢完走記録を奪還した（2026年9月1日前後、CNN・ABCニュースなど各紙報道）</li>
<li>サンダースさんは2017年に82歳で最高齢記録を樹立したが、2021年に友人のM・J・エバーハートさん（トレイルネーム「ニンブルウィル・ノマド」、当時83歳）に記録を譲っていた</li>
<li>今回の踏破では計71回転倒し、うち7回は「ひどい転倒」で1回は病院搬送、ゴールのわずか200ヤード手前でも転倒したという</li>
<li>出典: <a href="https://edition.cnn.com/2026/09/01/travel/dale-sanders-grey-beard-oldest-appalachian-trail-hiker">CNN</a></li>
</ul>
<h2>ネタ2 145年目のナグプール「マルバット祭り」、悪を燃やす黒と黄の巨大人形に新たに「銀」が加わる</h2>
<ul>
<li>インド・マハラシュトラ州ナグプールで9月11日、145回目となる「マルバット・ウトサブ」が開催される（地元紙The Live Nagpur、9月3〜5日報道）</li>
<li>藁と粘土と布で作る等身大より大きい人形「カリ・マルバット（黒）」は英国に服従したボンスレー家の王妃バンカーバーイーへの怒りを象徴し、「ピリ・マルバット（黄）」は英国統治や疫病への抗議を象徴するとされ、街を練り歩いた後に焼却・水に流される</li>
<li>2026年は新たに「シルバー・マルバット」が加わり、主催団体は「白は平和の象徴」として、平和・団結・調和という現代的なメッセージを毎年テーマを変えて発信していく方針という</li>
<li>入場は無料で、ガンジー像広場を中心に約3時間の行事になる予定</li>
<li>出典: <a href="https://thelivenagpur.com/2026/09/03/silver-marbat-marks-a-new-chapter-in-nagpurs-150-year-old-tradition/">The Live Nagpur</a></li>
</ul>
<h2>ネタ3 悪名高き激苦リキュールを1,969人が一斉乾杯、シカゴがギネス記録に挑戦</h2>
<ul>
<li>シカゴ・ウェストループのバー「Recess」で8月31日、地元産の激苦リキュール「イェプソンズ・マロート」を参加者が一斉に飲み干す世界記録イベントが開かれ、公式カウントは1,969人だった（Block Club Chicago、UPI報道）</li>
<li>イベントには州知事JBプリツカー氏も駆けつけ、自ら参加者に一杯ずつ注いだという</li>
<li>「良い目的のための悪い決断」と銘打たれ、収益はシカゴの地域団体レイブンズウッド・コミュニティ・サービシズに寄付された。カリフォルニアからメリーランドまで各地のバーも同時に乾杯に参加し、ギネス世界記録への正式認定を待っている</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/09/02/Guinness-World-Records-Jeppsons-Malort/9561788278812/">UPI</a></li>
</ul>
<h2>ネタ4 オーストラリアン・シェパードが人間56人の背中をわずか16秒で駆け抜けギネス記録</h2>
<ul>
<li>カナダ・アルバータ州の独立リーグ野球チーム「エドモントン・リバーホークス」の試合で、トレーナーのジェニファー・フレイザーさんの愛犬で4歳のオーストラリアン・シェパード「シャルドネ」が、外野に一列に並んだファン56人の背中を跳んで渡る「1分間で最も多く人間を跳び越えた犬」のギネス世界記録に挑戦し成功した（試合は6月14日、9月1日にワシントン・ポストなどが報道）</li>
<li>制限時間1分のところ、シャルドネはわずか16秒で56人を渡りきった</li>
<li>出典: <a href="https://www.washingtonpost.com/lifestyle/2026/09/01/australian-shepherd-raced-across-backs-56-people-set-world-record/">Washington Post</a></li>
</ul>
