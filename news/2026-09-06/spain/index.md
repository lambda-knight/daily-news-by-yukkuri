<h2>今日のスペイン語ひとこと</h2>
<ul>
<li><strong>Estar entre la espada y la pared（エスタール・エントレ・ラ・エスパダ・イ・ラ・パレー）</strong>＝「剣と壁の間にいる」＝進退窮まる、板挟みになるという表現。中世の決闘で背後の壁に追い詰められ、前は剣という状況から生まれた言い回し。EUとモロッコ、中央政府と自治州、双方から突き上げられる今日のサンチェス政権にそのまま当てはまる。</li>
</ul>
<h2>国際情勢（スペイン視点）</h2>
<ul>
<li><strong>欧州委員会コスタ委員、モロッコが移民をEUへの「道具」にしていると名指し</strong>（El Mundo、9月5日）: 「不法移民を抑える鍵は、出身国と良好な合意を持つことだ」と述べ、セウタへの流入をモロッコ側の政治利用と位置づけた。EU加盟を国の誇りとしてきたスペインにとって、頼みの綱であるブリュッセルが問題の相手国名を公式に挙げたことは、外交の後ろ盾を得た安堵と、自国だけでは抑えられない現実の両方を映す。</li>
<li>地中海とアフリカを「自分たちの問題」とみるスペインの感覚は、モロッコが名指しされたことで一段と強まった。国境の外の判断ひとつが、セウタという街の日常を直接動かしている。</li>
</ul>
<h2>スペイン国内ニュース</h2>
<ul>
<li><strong>政府がセウタ港を接収、港湾管理委員会と業界の反対押し切る</strong>（El Mundo、9月5日）: 運輸省は1,000人超を収容できるテントの設置を許可し、セウタ港湾局は正式に反対を表明した。同日、青年家族相レゴ氏は「政府の調整はもっと効率的か迅速であるべきだった」と初めて非を認め、ロブレス国防相に続く政権内の自己批判となった。</li>
<li><strong>少女500人の本土移送、PPの圧力で難航</strong>（El País、9月5日）: 青年・子ども省は、自治州政府の拒否権を回避する方法をセウタ市長ビバス氏が受け入れるかどうかの返答待ちだと明かした。フェイホー党首は「政府は自国の王には距離を置き、モロッコの王には敬意を払う、方向を間違えた王党派だ」と皮肉り、アユソ氏は「モロッコ諜報機関による組織的行動」と断じて政治責任を追及した。左派紙エル・パイスは子どもの脆弱性を、右派紙エル・ムンドは政府批判の応酬を前面に出し、同じ移送問題でも紙面の切り取り方が対照的だった。</li>
<li><strong>財政モデルを政府が90%の自治州へ強制、ケウタ州担当者は会議で激高</strong>（El Mundo、9月4日）: サンチェス首相はカタルーニャの独立派エスケラと合意した財政モデルを、民主化後初めて多数の自治州が反対する中で承認した。会議ではセウタ州担当者が「ケウタにはすべてをケチる」と激高したと報じられ、大型自治州への配慮とセウタへの手薄さが同じ日に並んだ。</li>
<li>遠慮なく言い切るフェイホー、アユソ、セウタ担当者の物言いは、意見を胸にしまう日本の「空気を読む」政治文化とは対照的である。一方でカタルーニャの財政的発言力の強さは、大阪が東京に張り合う地域自負心とどこか重なる。</li>
</ul>
<h2>文化・芸能ニュース</h2>
<ul>
<li><strong>カルロス・サイス監督『リオネル』、国内外の映画祭を席巻</strong>（El Mundo、9月4日）: セビリャ国際映画祭（セミンシ）からアトランティダ映画祭、ルーマニアのティミショアラ、北京の映画祭まで巡り、「今年のスペイン映画の隠れた宝石」と評された。サイス監督は「何かを物語ることが目的ではなく、いつも画面の外に置かれてきた人たちを中心に据えることが目的だ」と語り、周縁化された人々を主役に据える一貫した制作姿勢を明かした。</li>
<li>大都市の大作ではなく、地方発の映画祭を一つずつ歩いて評価を積み上げるサイス監督のような歩みは、地域の劇場や自主上映を大切にする日本のインディーズ映画文化とも重なる部分がある。</li>
</ul>
<h2>フラメンコニュース</h2>
<ul>
<li><strong>パンプローナ、フラメンコ・オン・ファイア13回目でエル・ペレが市庁舎バルコニーから熱唱</strong>（Ayuntamiento de Pamplona）: コンデスタブレでの2公演に加え、市庁舎のバルコニーからカンタオール、エル・ペレが歌声を届け、子ども向けのギター・舞踊ワークショップも同時開催された。市が主催に加わることで、観客席の外にも音を届ける工夫が続いている。</li>
<li><strong>セビリャ県オスーナ、第21回フラメンコ祭が開幕</strong>（Diario Avanza）: カンテ、トケ（ギター）、バイレの大物が一堂に会する構成で、地方都市が長年フェスティバルを育ててきた実績を21回という数字が示す。</li>
<li><strong>バダホスのプラサ・アルタでヘスス・オルテガによる「フラメンコ・エストレメーニョ」の夜</strong>（La Crónica de Badajoz）: 発祥地アンダルシアの外、エストレマドゥーラ地方独自のフラメンコの夜が広場で開かれた。地域ごとに異なる訛りと節回しが残っていることを示す催しである。</li>
<li><strong>第65回国際カンテ・デ・ラス・ミナス、コンクール第2次準決勝で沸く</strong>（Festival Internacional del Cante de las Minas）: 鉱山の町ラ・ウニオンで、新しい歌い手・奏者・踊り手を選ぶ大会が準決勝に進み、次世代の「伝説候補」たちの真剣勝負が続く。</li>
<li>市庁舎のバルコニー、地方都市の広場、鉱山町の劇場と、フラメンコは大劇場に限らず街のあらゆる場所に居場所を持つ。地域の祭りに老若男女が繰り出す様子は、日本の盆踊りや夏祭りの光景とも響き合う。</li>
</ul>
<h2>フラメンコギタリスト列伝</h2>
<ul>
<li><strong>第2回はパコ・デ・ルシア</strong>。本名フランシスコ・サンチェス・ゴメス。1947年12月21日、カディス県アルヘシラスに生まれ、2014年2月25日にメキシコのプラヤ・デル・カルメンで没した。父アントニオ・サンチェスの手ほどきで弾き始め、ニーニョ・リカルド、サビーカスからも学んだ。</li>
<li>1967年、ペドロ・イトゥラルデとの共作『La fabulosa guitarra de Paco de Lucía』でソロデビュー。1972年『El duende flamenco』、1973年『Fuente y Caudal』には代表曲のルンバ「Entre dos aguas」を収め、1976年『Almoraima』へと続いた。</li>
<li>1981年に兄弟ラモン・デ・アルヘシラス、ペペ・デ・ルシアに加え、ホルヘ・パルド、カルレス・ベナベント、ルベン・ダンタスとセクステートを結成。アルバム『Sólo quiero caminar』で、ペルーで出会った打楽器カホンをルベン・ダンタスとともにフラメンコへ導入し、以後の伴奏編成を一変させた。1987年『Siroco』、1990年『Zyryab』を経て、ジョン・マクラフリン、アル・ディ・メオラとの共演でも知られる。</li>
<li>右手の速いピカードと親指のゴルペ、ジャズやクラシックの和声を取り込んだ作曲、コンパスを保ったまま旋律を歌わせる構成力が持ち味で、ビセンテ・アミーゴやトマティートら後続の奏者たちの技術と作曲観の土台になった。</li>
</ul>
<h2>フラメンコギター工房だより</h2>
<ul>
<li><strong>アントニオ・マリン・モンテーロ工房（グラナダ、クエスタ・デル・カルデーロ）</strong>。1933年グラナダ生まれの製作家マリン・モンテーロは、1957年に師ペレスの工房に入り、1959年には父の勧めでクエスタ・デ・ゴメレス通りのエドゥアルド・フェレール工房に移った。</li>
<li>その後、甥のホセ・マリン・プラスエロとホセ・ゴンサレス・ロペスとともに自らの工房を構え、ヨーロッパ、米国、日本を含む世界中の演奏家・教師が訪れる工房として知られるようになった。2007年にはグラナダ大学から芸術功労賞を贈られている。</li>
<li>工房の楽器は「豊かな音色とグラナダ伝統に連なるスペインらしい性格」で知られる。クエスタ・デ・ゴメレス周辺は歴史的にギター工房が並ぶ通りで、師弟が軒を連ねて技を受け渡す点は、日本の職人町の徒弟制度とも通じるものづくりの気質が見える。</li>
</ul>
<h2>まとめ</h2>
<ul>
<li>セウタの港も財政の分配も、板挟みの一日だった。それでも市庁舎のバルコニーからは歌声が流れ、パコ・デ・ルシアが切り拓いた道の上でギタリストたちが弾き続け、グラナダの工房は世界中から弟子を集めている。</li>
</ul>
