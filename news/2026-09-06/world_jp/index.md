<h1>世界から見た日本（2026年9月6日）</h1>
<h2>オープニング：2026年9月6日 — 世界から見た日本</h2>
<ul>
<li>今日は、ウクライナ出身力士アオニシキとパリ・ロンドン公演が押し上げる大相撲の国際化、日本外務省がトランプ政権へ繰り返す「ポケモン・ナルト」無断使用への抗議、屋久島を襲った記録的豪雨を伝えるアゼルバイジャン・ウクライナ・エジプトの海外メディア、そして英国IT専門紙が読む「1000万台ロボット」構想を比べる。</li>
<li>相撲、外交とポップカルチャー、防災、高齢化と技術という4つの窓から、日本国内では別々の話題として流れる出来事が、海外でどうつながって読まれているかを見る。</li>
</ul>
<h2>ウクライナ出身アオニシキが押し上げる大相撲のヨーロッパ展開</h2>
<ul>
<li>ウクライナ出身の大相撲力士アオニシキは、2025年のデビューからわずか14場所で大関昇進を果たす史上最速の出世を記録した。5月場所を休場した影響で大関から陥落した後も、6月13〜14日にパリのアコー・アリーナで開かれた大相撲パリ公演に出場し、横綱大の里・豊昇龍と共に土俵に上がった。</li>
<li>大相撲の海外公演は、2025年10月に25年ぶりとなるロンドン公演が開かれ、2026年6月のパリ公演へと続いた。相撲の世界大会取材を続けるNippon.comは、モンゴル出身力士が1992年の民主化後に相次いで来日し、2010年11月場所では幕内42人中20人が外国出身、横綱・大関5人中4人が外国出身だった時期を経て、現在はウクライナ出身力士のような新しい出身国の力士が加わっていると位置づける。</li>
<li>東京・両国国技館では9月13日から27日まで秋場所が開かれ、全15日分の切符が発売から1か月足らずで完売した。国内では番付や優勝争いとして語られる場所だが、海外の取材は「どの国から来た誰が土俵に立つか」という選手の出身と経歴の物語を通じて相撲を紹介する。</li>
<li>力士の個性と出身国の物語を前面に出す海外の伝え方は、国技という枠組みより先に、アオニシキという一人の力士の急成長を入り口にしている点で、国内の番付中心の報道と焦点が異なる。</li>
</ul>
<h2>ポケモン・ナルトの無断使用、日本外務省がトランプ政権へ抗議を重ねる</h2>
<ul>
<li>米国土安全保障省は2025年9月、移民税関捜査局の摘発映像にポケモンのテーマ曲を重ねた動画を公開した。ポケモン社は後に「関与しておらず、権利者への許諾も求められていない」と説明した。</li>
<li>2026年3月にはホワイトハウスの公式X（旧ツイッター）アカウントが、イランへのミサイル攻撃の映像に任天堂「Wii Sports」の映像を組み合わせた動画を投稿した。ホワイトハウスはこのほか、ファン製作の「ポコピア」テキストジェネレーターを使い、ナルトの絵柄で「メイク・アメリカ・グレート・アゲイン」を掲げる投稿も行った。</li>
<li>日本の外務省は、少なくとも2026年6月までに複数回、在日米国大使館を通じてトランプ政権へ、ポケモン・ナルト・マリオなどの著作物を無許可で使わないよう申し入れたと複数の海外メディア（Kotaku、IBTimes UK、Screen Rant等）が8月6日前後に報じた。</li>
<li>米国のゲーム・IT系メディアは、この問題を著作権侵害というより、権力側が若者向けの人気キャラクターを政治的メッセージへ流用する構図として扱う。日本国内で語られがちな「クールジャパンの輸出」という誇らしい文脈とは逆に、海外メディアはキャラクターが政権の思惑に取り込まれる側面を問題視している。</li>
</ul>
<h2>屋久島の記録的豪雨、アゼルバイジャン・ウクライナ・エジプトの海外メディアが伝える</h2>
<ul>
<li>気象庁は9月4日夜から5日朝にかけて、台風24号（クロヴァン）と秋雨前線の影響で発達した線状降水帯が鹿児島県屋久島町を襲ったと発表した。屋久島町尾之間地区では24時間雨量が午前5時30分までに490.5ミリへ達し、観測史上最多を更新した。この量は同地点の平年9月ひと月分の雨量の約2倍にあたる。</li>
<li>気象庁は屋久島町に大雨特別警報級にあたる警戒レベル5相当の「土砂災害警戒情報」を出し、午前11時30分にレベル4へ引き下げた。</li>
<li>この屋久島の豪雨は、アゼルバイジャンのニュースサイト「News.az」、ウクライナの「UA.NEWS」、エジプトの「See.news」など、日本と直接の経済・外交関係が特に深いわけではない国々のニュースサイトでも取り上げられた。台風進路にあった沖縄・奄美では、9月1日午前9時時点で中心気圧996ヘクトパスカル、最大瞬間風速25メートルの熱帯低気圧として気象庁が発表し、韓国・済州島でも9月4日に84便の遅延と最大瞬間風速26.9メートルの強風が観測され、済州地方気象台は「8日にかけて強風・波浪注意報が続く可能性がある」と呼びかけた。</li>
<li>国内では地域の防災情報として扱われる屋久島の記録更新が、共同・AFPなど通信社配信を経て、日本との往来が少ない国のニュースサイトにまで届く点に、海外報道の広がり方の特徴が表れている。</li>
</ul>
<h2>「1000万台ロボット」構想、英IT専門紙が読む高齢化対策の内実</h2>
<ul>
<li>経済産業省の赤沢亮正経済産業大臣は7月1日、2040年までに国内で稼働するロボットを1000万台へ増やす改定版ロボット戦略を発表した。用途には高齢者向けの医療・介護、食品・飲料製造、災害対応が含まれる。</li>
<li>英国のIT専門紙ザ・レジスターは、ソフトバンク、NEC、ソニーグループ、ホンダが主要株主となる新組織「Noetra」を戦略の中核と紹介した。富士通と楽天も参加を検討しているという。赤沢氏は、日本のロボット技術が「高齢者向け医療、災害対応、製造業、福島第一原発の廃炉」で培われてきた経験に基づくと説明した。</li>
<li>ザ・レジスターは、日本が移民受け入れに慎重な政策を続けながら高齢化が進み、介護分野の有効求人倍率が全体平均の1.22倍を大きく上回る4.25倍に達している労働力不足を、ロボット投資の背景として位置づけた。同じ週に韓国も同様のロボット産業振興策を発表したとも伝えている。</li>
<li>国内では産業政策や企業連合の話として報じられがちな構想を、英国の専門紙は「移民を増やさずに高齢化を乗り切る日本独自の選択」という角度から読み、労働力不足という社会的な制約が技術投資の形を決めている点を強調した。</li>
</ul>
<h2>まとめ</h2>
<ul>
<li>今日の海外報道が拾ったのは、ウクライナ出身力士、トランプ政権のSNS投稿、屋久島の観測史上最多雨量、そして経済産業大臣が発表したロボット戦略という、日本国内では相撲・外交・防災・産業政策と別々の欄に分かれる出来事だった。</li>
<li>14場所での大関昇進、複数回の外務省申し入れ、490.5ミリ、1000万台。数字と当事者まで見ると、海外の視線は日本を「礼儀正しい国」「技術大国」という一語にまとめず、誰が土俵に立ち、誰が抗議し、誰が雨に警戒し、誰が労働力不足を補うかという具体的な現場を映している。</li>
</ul>
