<h1>世界の珍ニュース（2026年9月20日）</h1>
<h2>オープニング：2026年9月20日 — 世界の珍ニュース</h2>
<p>10年かけて塩コショウの小袋を754組集めた67歳の女性、同じ誕生日を5世代でつないだアイオワの一家、全長130メートルの巨大ソーセージ、そしてパレードから逃げ出して街を12分間走り回った馬。今回は「こだわり」と「偶然」が生んだ四題を追う。</p>
<h2>塩コショウの小袋、754組集めた67歳の"世界一"コレクター</h2>
<ul>
<li>米ウィスコンシン州ブルックフィールド在住のリンダ・シュルツさん（67歳）は、ファストフード店「アービーズ」でもらった1組の塩コショウの小袋をきっかけに、10年前から収集を始めた。</li>
<li>収集品は航空会社別・レストラン別・製造元別にバインダーへ整理して保管し、ブランドの入っていない無地の小袋専用のコーナーも設けている。塩コショウ収集の前は、バナナに貼られたシールを集めていたという。</li>
<li>2024年に494組でギネス世界記録「最大の塩コショウ小袋コレクション」の認定を受けたが、翌2025年にサラシニブ・"ソニー"・モリーナ氏の594組に記録を奪われた。今回754組まで増やし、2026年2月19日付で記録を奪還した。</li>
<li>お気に入りは、ハワイアン航空のハワイアンシャツ柄の小袋。シュルツさんはギネス側に「集めることはとても興味深くて楽しい。ギネス世界記録という目標があると、この趣味がさらに面白くなる」と語っている。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/09/16/Guinness-World-Records-salt-and-pepper-packets/9321789579951">UPI</a>、<a href="https://www.guinnessworldrecords.com/world-records/largest-collection-of-salt-and-pepper-sachets">Guinness World Records</a></li>
</ul>
<h2>5世代そろって9月14日生まれ、アイオワの一家がギネス記録に</h2>
<ul>
<li>米アイオワ州シルバーシティーのハーロウ家では、曾祖父ウィルバーさん（1907年生まれ）、母アディさん、フレッド・ハーロウさん、娘のエマ・ベルさん、孫のアーサーくんの5世代が、全員9月14日生まれという偶然が続いている。</li>
<li>一家は長年これを「面白い一致」として冗談交じりに話すだけだったが、アディさんが亡くなった後、エマさんが第2子の出産予定日がちょうど9月14日だと分かったことをきっかけに、正式なギネス認定を申請することにした。</li>
<li>エマさんは予定日に合わせて出産に臨み、息子アーサーくんは狙いどおり9月14日に誕生。5世代は男・女・男・女・男と交互に続いており、ギネス世界記録として認定された。</li>
<li>父フレッドさんは「子どもは誰にとっても贈り物だが、これは本当に特別な贈り物だ」と語り、エマさんは「祖母にはずっと『9月14日に男の子を産まなきゃ』と言われて育った」と振り返っている。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/09/17/Guinness-World-Records-five-generations-same-birthday/5611789656758">UPI</a>、<a href="https://www.cp24.com/news/world/2026/09/15/a-family-just-set-a-guinness-world-record-for-5-generations-sharing-the-same-birthday/">CP24</a></li>
</ul>
<h2>全長130メートル、重さ32キロの巨大「スリムジム」が世界記録</h2>
<ul>
<li>米食品大手コナグラ・ブランズは9月9日、ネブラスカ州オマハの自社キャンパスで、長さ429フィート5.4インチ（約130.9メートル）、重さ約70ポンド（約32キロ）に及ぶ巨大な「スリムジム」（ビーフジャーキー状の細長いスナック菓子）を披露し、ギネス世界記録「最長のミートスナック」を更新した。</li>
<li>これは2023年に樹立された旧記録（314フィート、約95.7メートル）を116フィート（約35メートル）以上も上回る長さで、サッカーコートの長さより長い143ヤードに達する。</li>
<li>制作は2025年6月、社内の11人からなるチーム「ブレイズ・クルー」が担当し、通常サイズのスリムジムと同じレシピ・同じ「パキッ」という食感を保つことにこだわりながら、巨大版の製法を開発した。製造時は大きな回転式ラックに巻き取った生地を、駐車場に並べたテーブルの上で一気に伸ばして全長を測定した。</li>
<li>チームは「味も食感も、ふだんのスリムジムと変わらないことに徹底してこだわった」と説明しており、認定員はギネス世界記録の公式ルールに沿って現地で長さを計測した。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/09/17/guinness-world-records-slim-jim/1191789667547/">UPI</a>、<a href="https://theshelbyreport.com/2026/09/10/slim-jim-sets-guinness-world-record-with-429-foot-meat-stick/">The Shelby Report</a></li>
</ul>
<h2>パレード直前に脱走した馬、警官と本物のカウボーイが12分間の追跡劇</h2>
<ul>
<li>米ニューメキシコ州サンタフェで9月14日（日）、地元恒例の「デスフィレ・デ・ラ・ヘンテ」パレードの開始を待っていた1頭の馬が、突然手綱を振り切って逃げ出した。</li>
<li>サンタフェ市警はSNSで、この馬を確保するためバイク隊、自転車隊、動物管理官、さらにドローン操縦員まで出動させたと発表した。白いまだら模様のある茶色の馬は、12分以上にわたって警官たちの追跡をかわし続けた。</li>
<li>最終的にバイク警官がキャニオン・ロード沿いで馬を追い込むことに成功し、駆けつけた飼い主が手綱を取り戻した。馬は水を一口飲んだだけで、パレードの開始時刻にはスタート地点へ無事に戻された。</li>
<li>けが人・けがをした馬はおらず、警察はパレード観客やSNS向けに追跡の様子を撮影した映像を公開し、「脱走劇」は地元で話題になった。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/09/17/santa-fe-parade-horse-chase/8301789655823">UPI</a>、<a href="https://www.kvoa.com/video/santa-fe-cops-and-cowboys-team-up-to-wrangle-rogue-parade-horse/video_565c1262-b986-59f7-b7bf-9506cf4c26ac.html">KVOA</a></li>
</ul>
