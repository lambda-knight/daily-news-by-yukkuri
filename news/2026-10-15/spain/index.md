<h2>オープニング：2026年10月15日 — スペイン文化・フラメンコ便り</h2>
<ul>
<li>今日のスペイン語は「ポコ・ア・ポコ（Poco a poco）」。「少しずつ」という意味で、速さより積み重ねを大切にするときに使う。</li>
<li>今日の軸は、保存と更新の両立である。ソローリャ美術館の増築、若者向け舞台芸術、現役三人の列伝、そしてロンデーニャの構造をたどる。</li>
</ul>

<ul>
<li>取得記事の国際面にはスペインが直接の当事者となる新規案件がなかったため、一般的なウクライナ、米国、ブラジルの記事は採用しない。番組の中心を文化へ置く。</li>
</ul>
<h2>スペイン国内ニュース</h2>
<ul>
<li>10月14日公表のCIS調査ではPSOEがPPを11.8ポイント上回った。一方、エル・ムンドは調査機関トップの名を見出しに置き、数字の政治性を強調した。左右両紙の差は結果そのものより、誰が測った数字かという信頼の置き方に現れる。</li>
<li>強制退去では57.1%が契約より弱い立場の保護を優先すると回答した。住宅を私有財産と見る軸と生活基盤と見る軸の衝突であり、日本の借地借家をめぐる議論にも通じる。</li>
</ul>
<h2>文化・芸能ニュース</h2>
<ul>
<li>マドリードのソローリャ美術館が大規模改修後に再開した。画家が暮らした邸宅に時間軸を導入し、光の作品だけでなく生活と制作の場を一緒に見せる。エル・ムンドは人員不足なら「フェラーリに600のエンジン」となるという運営面の警告も伝えた。</li>
<li>ホセ・アントニオ・ポルティージョが2026年児童・青少年舞台芸術国家賞を受けた。子どもを縮小した大人として扱わず、観客が触れ、考え、物語へ参加する舞台を作ってきた点が評価された。</li>
<li>マドリード最古の書店の閉店をめぐる記事は、文化施設が不動産価格と消費習慣の変化に押される現実を描く。日本の町の書店と同じく、在庫だけでなく店主の選書と会話が失われる問題である。</li>
</ul>

<ul>
<li>パンプローナ市はフラメンコ・オン・ファイアと連携し、市庁舎バルコニーからエル・ペレが歌う企画、ギターと舞踊の児童向け講座、コンデスタブレ宮での公演を組んだ。劇場外へ歌を開く設計である。</li>
<li>ラ・ウニオンの第65回カンテ・デ・ラス・ミナス国際祭は各部門の決勝進出者を発表した。歌、ギター、舞踊を別々に競いながら、最後は伴奏と身体が同じコンパスを共有する総合芸術として評価される。</li>
<li>コルドバの第45回ギター祭は国立フラメンコ芸術コンクール70周年を祝う。都市が音楽祭、教育、コンクールを結ぶ構図は、アンダルシアの文化をマドリード発の「国の顔」だけにしない地域主導の発信である。</li>
</ul>
<h2>フラメンコギタリスト列伝</h2>
<ul>
<li>今日の一人はセビリア生まれの現役ギタリスト、リカルド・モレノ。フラメンコの伴奏語法を土台に、ジャズの和声、ラテン音楽、歌との共同制作へ領域を広げてきた。</li>
<li>幼いころの事故で右腕に制約を負いながら、身体に合わせた右手の配置を組み立てた。速さを競うのではなく、親指の低音、和音の余韻、休符を一つの語彙にした点が特色である。</li>
<li>2013年の独奏作『Varekai』、2017年の『Agaleano』、2023年の『Miesencia』は転機を示す。独奏から、文学や大西洋両岸の記憶を含む共同制作へ重心が移った。</li>
<li><a href="https://www.youtube.com/watch?v=SWMiwzqvfWQ">『Miesencia』公式演奏</a>では、冒頭の低音を長く残し、その余白へ高音の短い句を置く箇所を聴きたい。連続するラスゲアードより、音を止める判断が旋律を立たせる。</li>
<li><a href="https://www.youtube.com/watch?v=VzovyoHYI-g">『Agaleano』ライブ映像</a>では、歌とパルマが入った後もギターが音数を増やしすぎない。カンテの子音が聞こえる場所を空け、句末だけを和音で受け止める伴奏の感覚が分かる。</li>
<li>パコ・デ・ルシア以後の技巧をそのままなぞるのでなく、身体条件と異文化の共演から独自の運指を作った。初めて聴くなら『Miesencia』で音の間を追い、次に『Agaleano』で歌との距離を比べるとよい。</li>
</ul>
<h2>フラメンコバイレ列伝</h2>
<ul>
<li>今日の一人はセビリア生まれのダビ・コリア。スペイン国立バレエや舞踊家ロシオ・モリーナとの仕事を経て、自作では群舞、歌、舞台空間の関係を組み替えている。</li>
<li>2010年の振付コンクール受賞、2014年のソロ作品『El encuentro』、近年の『¡Fandango!』が転機となった。伝統的な足技を見せ場として切り離さず、複数の身体が同じ拍を奪い合う劇へ変える。</li>
<li><a href="https://www.youtube.com/watch?v=oWd3uZUbteU">『¡Fandango!』公式舞台映像</a>では、群舞が横一列にそろう場面より、列が崩れて個々の足音がずれ始める箇所に注目したい。ブラソの大きな弧と、床を細かく刻むサパテアードが別々の時間を作る。</li>
<li><a href="https://www.youtube.com/watch?v=n1EwYi6M4tw">『El encuentro』舞台映像</a>では、ジャマーダを強い一打だけで示さず、視線と肩の向きから歌とギターへ合図を送る。群舞を背景にせず、踊り手同士の応答として扱う点が同時代の舞台らしい。</li>
<li>サラ・バラスの輪郭の明快さに比べ、コリアは重心の移動と沈黙を長く見せる。フラメンコを一人のスターの技巧から、複数者が交渉する劇へ広げた位置にいる。</li>
</ul>
<h2>フラメンコカンテ列伝</h2>
<ul>
<li>今日の一人はハエン県ビジャヌエバ・デ・ラ・レイナ出身の若手歌手カロリーナ・フェルナンデス「ラ・チスパ」。幼少期から地域のペーニャとコンクールで歌い、舞台伴唱と独唱の両方を続ける現役世代である。</li>
<li>ペーニャで古いレトラを学び、舞踊伴唱では踊り手の呼吸へ句の長さを合わせた。独唱では声を均一に磨かず、低音のざらつきから高音の細い伸びへ移る落差を残す。</li>
<li><a href="https://www.youtube.com/watch?v=1TPp4ounRuc">『Soleá』公演映像</a>では、ギターが閉じた後も母音を少し残し、次の12拍へ急いで入らない箇所を聴きたい。レトラの痛みを声量でなく、語尾の沈みで伝える。</li>
<li><a href="https://www.youtube.com/watch?v=JPcNdtGg4Gw">『Tangos』舞台映像</a>では、4拍の前へ子音を置き、パルマの後ろへ母音を引く。明るいタンゴでも声のざらつきを消さず、祝祭と翳りを同居させる。</li>
<li>エストレージャ・モレンテの磨かれた長い線に対し、ラ・チスパは短い句の切断と再開を武器にする。ペーニャの伝承を若い声の身体感覚へ移す過程そのものが聴きどころである。</li>
</ul>
<h2>フラメンコギター工房だより</h2>
<ul>
<li>今日の工房は国外編として、英国の製作家スティーブン・ヒルを扱う。スペインで製作技法を学び、演奏家向けの製作と国際的な製作講座を結びつけてきた。</li>
<li>フラメンコ用では軽い胴、低めの弦高、速い立ち上がりを重視する。クラシック用の長い余韻とは違い、パルマや足音の間で一音がすぐ立ち、すぐ消えることが伴奏では強みになる。</li>
<li><a href="https://www.youtube.com/watch?v=U0uPiY5QlvA">工房による製作紹介</a>では、表板を薄く整え、力木を削りながら反応を確かめる工程に注目したい。国外工房でも、設計を固定せず奏者との往復で調整するスペインの職人気質が継承される。</li>
</ul>
<h2>フラメンコのパロ解説</h2>
<ul>
<li>今日のパロはロンデーニャ。名称はマラガ県ロンダとの関係を想起させるが、地名起源には異説がある。ファンダンゴ系の歌から発展し、20世紀にはラモン・モントーヤが独奏ギターの形式を確立した。</li>
<li>歌のロンデーニャは自由リズムで語られることが多い。拍を均等に刻まず、カンテの長い句にギターが応答する。独奏版では変則調弦を用い、低音と開放弦の共鳴から遠景のような響きを作る。</li>
<li>典型的な独奏調弦では6弦をD、3弦をFシャープへ変える型が知られる。コードはD系の開放弦を軸にし、C、Bフラット、Aへ下る色彩を使う。カポは歌い手の音域に合わせるため、固定位置ではない。</li>
<li>コンパスを数える踊りのパロと違い、「1、2、3、4」を均等に回さない。歌の息が一つの単位で、ギターは句末の着地を聞いてからファルセータへ入る。パルマを常時重ねない静けさが重要である。</li>
<li>レトラは山、旅、別れ、土地への郷愁を扱うことが多い。踊りにする場合も、ジャマーダ、ファルセータ、エスコビージャを固定順で並べるより、自由な歌から拍のある終結へ移る構成が採られる。</li>
<li><a href="https://www.youtube.com/watch?v=UYlQL-DUFwc">『Rondeña』公式演奏</a>では、低い開放弦が残る上へ高音の旋律を重ねる冒頭を聴きたい。低音を消さない左手の運指が、通常調弦と違う広がりを作る。</li>
<li><a href="https://www.youtube.com/watch?v=pButgV-1Jv8">『Rondeña de concierto』</a>では、中盤の速いピカードより、その前後で開放弦へ戻る瞬間に注目したい。マラゲーニャの歌中心の自由さに対し、ロンデーニャは独奏ギターの調弦と構成が前景に出る点で聴き分けられる。</li>
</ul>

<li>別れは「アスタ・プロント（Hasta pronto）」。「また近いうちに」という再会への温かい言葉である。</li>
