<h2>1431キロ、初の3000ポンド超え、ロードアイランドの巨大カボチャが1週間で世界記録を塗り替える</h2>
<ul>
<li>米国ロードアイランド州のロン・ウォレスさんのカボチャが、10月10日（土）にウォーレンのフレリックス農場で開かれた「南ニューイングランド巨大カボチャ計量大会」で3156ポンド（約1431キロ）を記録しました。公式計量係のジョン・ルッソさんが発表しています。3000ポンドを超えたカボチャは記録上初めてです。</li>
<li>現在のギネス世界記録は、英国のイアン・パトンさんが10月3日にバークシャー州ウォーグレイブで出した2856.8ポンド（約1296キロ）。ウォレスさんのカボチャはこれを約300ポンド（約136キロ）上回ります。ギネスの認定はまだで、ウォレスさんは「認定に向けて順調だと伝えられた」と話しています。</li>
<li>パトンさんは自分の記録を更新した時点で「次の目標は3000ポンド」と語っていました。その壁は、記録の発表からわずか数日後に大西洋の向こうで越えられました。</li>
<li>ウォレスさんは2012年、初めて1トン（2000ポンド）を超えるカボチャを育てた人物です。2019年にも2114ポンドで記録を出しています。</li>
<li>今年は初めて温室で育て、「それが大きな違いを生んだ」と話します。きっかけはオンラインで園芸資材の店を始めたことで、いまでは農業関連企業から土や栽培法の助言を求められています。</li>
<li>賞金は地元大会の3500ドル。最高7万ドルを出す大会もありましたが、記録は地元で出したかったといいます。計量の瞬間について「会場が爆発したようだった」、栽培について「3000ポンドのカボチャは、仲間が協力し合ってこそ生まれる」と語りました。</li>
<li>同じ10月12日、カリフォルニア州ハーフムーンベイの第53回世界選手権では、ミネソタ州の園芸教師トラビス・ギエンガーさんの「ロッキー」が2389ポンドで5年連続優勝しました。1ポンド9ドルで賞金は2万1501ドル。世界記録なら上乗せされた3万ドルには届かず、氷点下の冷え込みと闘ったギエンガーさんは、ウォレスさんのような温度管理の設備に移ることも考えています。</li>

</ul>
<h2>一度も遊んだことのない女性が優勝、59回目のトチの実世界選手権</h2>
<ul>
<li>英国ノーサンプトンシャー州サウスウィックのパブ「シャクバラ・アームズ」で10月11日（日）、第59回ワールド・コンカー・チャンピオンシップが開かれました。コンカーはセイヨウトチノキ（マロニエ）の実にひもを通し、相手の実に振り下ろして割る英国の子どもの遊びです。</li>
<li>10か国から256人が出場し、日本やドイツからの参加者もいました。観客は2000人を超えました。</li>
<li>総合優勝はトラの着ぐるみで出場したフランキー・フーパーさん。コンカーで遊んだことも大会に出たことも一度もなく、決勝で男子優勝者のサイモン・グリフィスさんを破りました。優勝を「素晴らしい」と喜んでいます。</li>
<li>女子決勝の相手フィオナ・エイルモアさんは、2022年に約30年の挑戦の末に女子の部を制した人物です。父のデビッド・ジェイキンスさんは2024年、ポケットから茶色に塗った鋼鉄製の偽コンカーが見つかって不正を疑われましたが、映像の確認で潔白とされました。今年、名誉職「キング・コンカー」を退いています。</li>
<li>実と靴ひもは主催者が用意します。専門の担当者が大きさや形のそろった約2500個を選び、穴を開けて革の靴ひもに通します。選手は袋から見ずに引き、3個まで交換できます。交互に3回ずつ打ち、ひもを絡ませる「スナッグ」を3回やると失格です。</li>
<li>遊びの手引きは、酢や塩水に漬ける、軽く焼く、透明なマニキュアを塗る、接着剤を詰めるといった「実を硬くする細工」を不正として列挙しています。</li>
<li>始まりは1965年。隣村アシュトンの釣り仲間が、天気が悪くて釣りに行けず、パブ「チェッカード・スキッパー」でコンカー大会を開きました。仲間に目の不自由な親類のいる人がいたことから募金を集め、以来、視覚障害者を支える慈善団体へ50万ポンド以上を寄付しています。会場は2009年に今のパブへ移りました。</li>
<li>実が足りない年もありました。1976年は英領ジャージー島から実を空輸し、暑く乾いた夏で不作だった2025年はウィンザー城などからの寄贈で開催できました。2017年には85歳の退役軍人ジョン・ライリーさんが最高齢で優勝しています。第60回は2027年10月10日の予定です。</li>
<li>出典: <a href="https://www.lincsonline.co.uk/stamford/news/they-came-they-saw-they-conkered-9486667/">Stamford Mercury（LincsOnline）</a> / <a href="https://worldconkerchampionships.com/">World Conker Championships</a> / <a href="https://worldconkerchampionships.com/compete/how-to-play/">遊び方（公式）</a> / <a href="https://dullmensclub.com/the-59th-world-conker-championships-2026/">Dull Men's Club</a> / <a href="https://en.wikipedia.org/wiki/World_Conker_Championships">Wikipedia</a></li>
</ul>
<h2>「小麦は、二度おいしい。」水沢うどんの切れ端で造ったビール</h2>
<ul>
<li>群馬県渋川市の水沢うどん街道で、うどん店の製造工程で出る切れ端を原料に使ったクラフトビール「水沢15 UDON ALE」が10月10日に発売されました。英語圏の日本情報サイトSoraNews24も10月13日に紹介しています。</li>
<li>企画は東京・中野区の株式会社ODORIJI、醸造は足立区のさかづきブルーイング。担当は元アサヒビールの醸造家です。きっかけは、渋川伊香保温泉観光協会の理事で、こけし工房「卯三郎こけし」の副社長を務める3代目卯三郎の岡本義弘さんからの「水沢や伊香保の文化を体現する、持続可能なビールを造れないか」という相談でした。</li>
<li>うどんは長さをそろえて切るため、端が出ます。うどんのでんぷんはそのままではビール酵母が食べられないので、切れ端を砕いて温度を管理した湯に入れ、麦芽の酵素ででんぷんを糖に変えてから発酵させます。</li>
<li>スタイルはセゾン、アルコール分5%、350ml缶。酒税法上は麦芽使用率50%以上の発泡酒です。想定小売価格は1000円（税別）で、初回は480本限定のテスト販売。好評なら定番化を目指します。</li>
<li>名前の「15」は、うどん店が並ぶ県道15号線から。缶には、道とうどんを重ねた曲線と、伊香保の石段の模様が描かれています。岡本さんの試飲の感想は「思った以上に飲みやすく、フルーティー」でした。</li>
<li>水沢うどんは、坂東三十三観音の第16番札所、水澤寺（水沢観音）の門前で参拝客にうどんを振る舞ったのが始まりとされ、農林水産省の特集では400年以上の歴史があると紹介されています。天正10年（1582年）創業を名乗る店もあります。</li>
<li>ODORIJIの通販のほか、水沢観音門前のうどん茶屋、伊香保の石段街のカフェ、宝永年間創業の旅館などでもテスト販売されます。</li>
<li>出典: <a href="https://prtimes.jp/main/html/rd/p/000000009.000174494.html">PR TIMES（ODORIJI）</a> / <a href="https://soranews24.com/2026/10/13/new-craft-beer-made-from-japanese-udon-noodles-celebrates-centuries-of-mizusawa-food-culture/">SoraNews24</a> / <a href="https://www.maff.go.jp/j/pr/aff/1610/n_search.html">農林水産省「ニッポン麺探訪」</a> / <a href="https://tabi-mag.jp/gu0123/">たびまがじん</a></li>
</ul>
<h2>隣の猫が犬の夕食を完食、ロンドンの防犯カメラが捉えた一部始終</h2>
<ul>
<li>防犯カメラのRing UK &amp; Irelandが公開した映像に、ロンドン南東部の住宅へ猫が入り込み、犬の皿のえさを食べる様子が映っていました。UPIが10月13日に伝えました。</li>
<li>気づいた飼い犬のロージーは「番犬モード」になってほえ、驚いた猫を一気に追い出しました。</li>
<li>住人のマイロン・ウォレスさん（40）によると、家族は2階にいて、ロージーのほえ声を聞いて映像を確認するまで何が起きたのか分かりませんでした。</li>
<li>この猫は近所ではおなじみですが、家の中に入ってきたのは初めてでした。</li>
<li>実はこの家では以前、改装工事の最中に別の茶トラ猫が家の中にいたことがあります。作業員はその家の猫だと思い込んでいましたが、ウォレスさんとロージーが帰ってくると逃げていきました。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/10/13/London-cat-steals-dog-food-Ring-camera/1301791914101/">UPI</a></li>
</ul>
<h2>まとめ</h2>
<ul>
<li>ロン・ウォレスさんは、パトンさんが「次の目標」と語った3000ポンドを1週間で越えました。本人は記録を「仲間が協力し合ってこそ」と言い、7万ドルより地元の3500ドルを選んでいます。</li>
<li>コンカー世界選手権は、釣りに行けなかった雨の日の遊びが59年続き、50万ポンド以上の寄付になりました。今年は初めて遊んだ女性が世界一になっています。</li>
<li>水沢では、捨てていたうどんの端を麦芽の酵素で糖に変え、480本のビールにしました。「小麦は、二度おいしい」は、門前町の400年の食文化を別の形で分ける試みです。</li>
<li>ロンドンの猫は、他人の家の犬の取り分を勝手に分けてもらい、ロージーに追い出されました。</li>
</ul>
