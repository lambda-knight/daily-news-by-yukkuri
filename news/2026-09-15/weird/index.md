<h1>世界の珍ニュース（2026年9月15日）</h1>
<h2>オープニング：2026年9月15日 — 世界の珍ニュース</h2>
<ul>
<li>日本ではハンドルもペダルもない二人乗りタクシー車両が初公開された。</li>
<li>中国の峡谷では、通学路の一部を高さ288メートルの屋外エレベーターが担う。</li>
<li>ベルリンでは、監視カメラの人物検出を惑わせる柄のシャツをデザイナーが制作した。</li>
</ul>
<h2>東京に来た「運転席のない車」</h2>
<ul>
<li>テスラジャパンは9月11日、無人タクシー専用の二人乗り車両「サイバーキャブ」を東京・青山で日本初公開した。青山での展示は14日までで、17日から大阪、22日から名古屋、26日から東京・新宿へ巡回する。</li>
<li>ハンドルもペダルもなく、20.5型画面、上方へ開く扉、周囲を見る8個のカメラを備える。展示は静態で、来場者の乗車や試乗はできなかった。</li>
<li>日本での販売・運行時期は未定。ハンドルがないため現行の保安基準では公道走行できず、華やかな日本初公開と制度上の距離が同居する。</li>
<li>出典: <a href="https://www.tesla.com/ja_jp/event/2026sep_cc_tour_getupdate">テスラ公式</a> / <a href="https://www.itmedia.co.jp/news/article/2609/11/2000001424/">ITmedia NEWS</a></li>
</ul>
<h2>通学路が高さ288メートルのエレベーター</h2>
<ul>
<li>中国・雲南省の尼珠河村は峡谷の底にあり、子どもたちは約3時間かけて山道を登り、寄宿学校へ通っていた。</li>
<li>2022年に高さ268メートルの青雲梯が稼働したが、観光客の増加で長い列ができた。そこで隣に、より大きい81人乗りの扶揺梯が建設され、2026年7月31日に運転を始めた。</li>
<li>新しいエレベーターは高さ288メートルを約50秒で上る。送迎車とロープウェーも乗り継ぐが、通学は約30分へ短縮され、児童は無料で利用できる。</li>
<li>出典: <a href="https://www.odditycentral.com/architecture/china-builds-288-meter-outdoor-elevator-to-help-children-reach-school-easier.html">Oddity Central</a> / <a href="https://tvrinfo.ro/autobuzul-scolar-care-urca-pe-verticala-china-a-construit-un-lift-de-288-de-metri-pe-peretele-unui-canion-pentru-copiii-care-mergeau-trei-ore-la-scoala/">TVR Info</a></li>
</ul>
<h2>人には派手、カメラには「人ではない」シャツ</h2>
<ul>
<li>ベルリンのデザイナー、ジモン・ヴェッカートは、桃色、橙色、緑色の抽象柄を配した「デジタル・カモフラージュ」を制作した。</li>
<li>人物検出器へ候補柄を見せ、検出の確信度を測って柄を調整する「敵対的ループ」を反復。人の輪郭や頭・肩の統計的特徴を崩し、試した特定の検出システムでは着用者を人物として囲めなくした。</li>
<li>2026年6月、ベルリンのコットブッサー・トーアにある実働カメラの前でも試した。すべての監視装置に通じる万能な透明マントではなく、機械の見方を服で可視化する作品である。</li>
<li>出典: <a href="https://www.odditycentral.com/news/worlds-ugliest-hawaiian-shirt-was-designed-to-make-you-invisible-to-ai-surveillance-cameras.html">Oddity Central</a> / <a href="https://petapixel.com/2026/08/27/this-hawaiian-shirt-tricks-ai-surveillance-cameras-into-thinking-youre-not-human/">PetaPixel</a></li>
</ul>
<h2>まとめ</h2>
<ul>
<li>東京の車は運転席を消したが、日本の道路ではまだ走れない。</li>
<li>雲南のエレベーターは、観光施設と通学インフラを同じ崖で両立させた。</li>
<li>ベルリンのシャツは人から隠れるのでなく、特定の機械の「人らしさ」から外れる発想だった。</li>
</ul>
