<h2>ネタ1 121年ぶりの夕暮れショー — スペインを横断した皆既日食</h2>
<ul>
<li>8月12日の皆既日食は北極海からグリーンランド、アイスランドを通り、スペイン北西部からバレアレス諸島まで夕暮れ時に横断した</li>
<li>スペインで皆既日食が見られたのは1905年以来。皆既帯の外でも、フランスや英国など広い範囲で部分日食となった</li>
<li>日没に近いため太陽の高度が低く、建物や山に遮られない観察場所の確保が必要だった。雲で見えなかった地域もあった</li>

<h2>ネタ2 カメラが腕を伸ばして踊る — HonorのRobot Phone</h2>
<ul>
<li>Honorが中国向けに発表したRobot Phoneは、本体からモーター式ジンバルカメラが飛び出し、被写体を追跡するスマートフォン</li>
<li>200メガピクセル級のカメラを3軸ジンバルへ載せ、手ぶれを機械的に抑える。音楽に合わせて首を振るような動作も披露された</li>
<li>単体ジンバルを持ち歩かず撮影できる一方、可動部の耐久性、防水、厚さ、電池消費は実機評価が必要</li>
<li>出典: <a href="https://www.wired.com/story/honor-robot-phone/">Wired</a> / <a href="https://techcrunch.com/2026/03/01/honor-says-its-robot-phone-with-moving-camera-can-dance-to-music/">TechCrunch</a></li>

<h2>ネタ3 針で彫らずにパッチを押す — CipherXの永久タトゥー</h2>
<ul>
<li>英国のCipherXは、1ミリ未満の微細構造を使い、皮膚の上層へ色素を届けるMicrodot Tattoo Patchを展開</li>
<li>購入者はQRコードを受け取り、同社のポップアップ会場で訓練を受けたスタッフに貼付してもらう仕組み</li>
<li>同社は痛みを抑えた永久タトゥーとうたうが、長期的な色持ち、安全性、除去の難しさは第三者の確認が必要</li>
<li>出典: <a href="https://www.odditycentral.com/news/uk-based-startup-launches-worlds-first-painless-permanent-tattoo-system.html">Oddity Central</a> / <a href="https://www.cipherx.tech/our-technology">CipherX</a></li>
</ul>
<h2>ネタ4 居間にサラダ売り場 — 縦型タワーでレタスを自給</h2>
