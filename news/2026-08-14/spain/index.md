<h1>スペインニュース（2026年8月14日）</h1>
<h2>オープニング：国境の緊張と、夏の舞台を支える人々</h2>
<p>8月14日のスペインでは、北アフリカの自治都市セウタに到着した移民の処遇が最大の政治課題になっている。一方、各地の夏祭りではフラメンコの歌・踊り・ギターが土地ごとの形で受け継がれ、芸術家の生活と労働環境にも光が当たった。</p>
<h2>国際情勢：セウタで交差するスペイン、モロッコ、EU</h2>
<ul>
<li>スペイン政府は、セウタにいる移民を最大5,000人と推計した。内訳は未成年約2,500人、庇護申請の可能性がある成人約2,500人。内相フェルナンド・グランデ＝マルラスカは8月13日、送還手続きを担う外国人局の専門警官約20人を追加し、当初派遣済みの6人を補強した。街頭警備にも50人を増員する。</li>
<li>8月14日には、未成年者を各自治州へ移す「オペラシオン1,898」が焦点となった。全国の通常受け入れ枠17,081床に対し、短期に1,898人を配分するため、自治州間の負担と連帯が問われる。</li>
<li>モロッコ側は、8月15日に呼びかけられた新たな越境を阻止するため、タラハル周辺に有刺鉄線と放水砲を配備し、接続道路も警戒した。人の流れを外交圧力として扱ってきた両国関係が、国境にいる個人の安全を再び左右している。</li>
<li>モロッコが犯罪人引渡協定の停止を示唆すると、国民党（PP）は「セウタとメリリャはスペインであり、交渉せず守る」とサンチェス政権を追及した。国境管理、未成年者保護、庇護審査は別の法的責任だが、政治討論では一つの危機として束ねられやすい。</li>
</ul>
<h2>国内政治・社会：議会の多言語化、空港障害、音楽家の健康</h2>
<ul>
<li>下院でカタルーニャ語などを聞くための同時通訳イヤホン導入から3年となり、議長フランシナ・アルメンゴルの下で関連支出は400万ユーロを超えた。少数言語を国家機関で保障する費用なのか、政権協力を得るための高価な譲歩なのかが争点である。</li>
<li>バルセロナのエル・プラット空港では管制塔の障害が1時間以上長引き、管制官が紙と鉛筆で運用した。現場は空港運営会社Aenaに設備更新を要求し、同種の停電が管制網全体で起こり得ると警告した。観光客が集中する8月に、デジタル設備の冗長性不足が露呈した格好だ。</li>
<li>スペインのオーケストラ奏者では40%が耳鳴りを経験するとのデータが示された。大音量に継続してさらされる職業上の危険なのに、出演機会を失う恐れから症状を語りにくい。舞台の完成度を守るには、耳栓、音響配置、診療へのアクセスを個人の自己責任にしない制度が必要だ。</li>
<li>作家スサナ・フォルテスは、1975年夏にフランコ体制へ異議を唱えた軍民主同盟の将校たちと、逮捕された自身の父を音声作品で再構成した。独裁末期から51年後、家族の記憶を公共史へ戻す仕事になっている。</li>
</ul>
<h2>文化・芸能：ビクトル・コヨーテとラス・ケチャップの生活</h2>
<ul>
<li>ガリシア出身の音楽家・美術家ビクトル・コヨーテが8月13日、自転車事故で急逝した。ロス・コヨーテスを率いてラテン色のあるロックをスペインの1980年代へ持ち込み、俳優、イラストレーター、作家としても活動した。年齢は媒体により67歳と68歳に分かれた。</li>
<li>コヨーテはマドリードの自宅を制作の拠点にし、音楽、グラフィックデザイン、映像、文章を同じ生活の中で往復していた。2026年には回顧盤『El propio』と著書『Cruce de perras』を並行して発表。名声を保存するだけでなく、六十代後半まで複数の表現を日課として動かしていた点に、その人物像がある。</li>
<li>コルドバ出身のムニョス姉妹によるラス・ケチャップは、2002年の「アセレヘ」で世界的成功を収めた後、休みのない移動で全身が痛むほど消耗したと振り返った。当時は周囲が体調より日程を優先したが、現在は活動を自分たちで管理し、2026年夏も国内外の舞台を回る。ヒット曲を歌い続ける喜びは、働き方を自分で決められるようになって初めて戻った。</li>
<li>作家フアン・タジョンは、作家一人に100万ユーロを払って権威を買うような文学賞を「粗雑だ」と批判した。大賞金が読者を本へ導く効果はある一方、作品の評価より主催者の威信が前へ出れば、文化支援は広告購入に近づく。</li>
</ul>
<h2>フラメンコ1：アロサイナのアルメナ・フラメンカ</h2>
<ul>
<li>マラガ県アロサイナでは8月15日、「アルメナ・フラメンカ」を開催する。カンテ、ギター、バイレを一晩に組み、県と町が支える地域密着型の催しだ。</li>
<li>大都市の劇場ではなく山あいの町で三要素を同時に見せることに意味がある。歌だけ、踊りだけを商品化せず、互いの呼吸で成立する芸能として住民へ返している。</li>
</ul>
<h2>フラメンコ2：ラ・ウニオン、第65回カンテ・デ・ラス・ミナス</h2>
<ul>
<li>ムルシア州ラ・ウニオンでは、第65回フェスティバル・インテルナシオナル・デル・カンテ・デ・ラス・ミナスの決勝進出者が発表された。鉱山労働の土地から生まれた大会で、予選と準決勝を通った歌、ギター、踊りの担い手が最高賞を争う。</li>
<li>65回という継続は、観光用の夏祭り以上の重みを持つ。労働歌の記憶を競技形式へ移すことで技術は磨かれるが、順位だけが目的になれば、鉱山共同体の痛みという根が薄くなる。その両立が大会の課題でもある。</li>
</ul>
<h2>フラメンコ3：マルチェナ、ギター祭の三世代</h2>
<ul>
<li>セビリア県マルチェナの第52回「フィエスタ・デ・ラ・ギター」には、グラナダ生まれの舞踊家エバ・ジェルバブエナ、ヘレス出身の歌手ヘスス・メンデス、カディス出身のダビ・パロマールが集う。</li>
<li>名前にギターを掲げながら、踊りと二人の異なるカンテを並べる構成がよい。伴奏楽器としてギターだけを切り離さず、踊り手の足音と歌い手の間を結ぶ役割まで客席に伝えられる。</li>
</ul>
<h2>フラメンコ4：マラセナとマドリードへ広がる舞台</h2>
<ul>
<li>グラナダ県マラセナは第25回フラメンコ祭で、カンテ、バイレ、ギターの出演者を一堂に集める。25回目は、自治体の支援と地元客の蓄積が四半世紀続いた節目だ。</li>
<li>マドリードでは「スマ・フラメンカ2026」が10月に戻る。アンダルシアの町祭りと首都圏の大型企画が同時に存在することで、地域の生活文化と全国市場をつなげる回路ができる。ただし有名人中心の編成だけでは、若手や小さなペーニャへ収益が戻らない。</li>
</ul>
<h2>工房だより：グラナダのアントニオ・マリン・モンテロ工房</h2>
<ul>
<li>アントニオ・マリン・モンテロは1933年グラナダ生まれ。家族に楽器職人はいなかったが木工房で技能を磨き、1957年にペレスの工房、1959年にクエスタ・デ・ゴメレスのエドゥアルド・フェレル工房へ入った。</li>
<li>のちにクエスタ・デル・カルデロへ自身の工房を構え、甥のホセ・マリン・プラスエロ、ホセ・ゴンサレス・ロペスと製作を続けた。家族継承は単なる姓の継承ではなく、板の厚み、力木、奏者の注文を手触りで伝える長い教育である。</li>
<li>フランスの名工ロベール・ブーシェのもとで数か月を過ごし、共同で3本を製作した経験も持つ。グラナダの軽快な反応と、フランスの構造的な精密さが出会い、世界の製作家が訪れる基準点となった。</li>
<li>フラメンコ用の楽器には、歌、手拍子、足音の中でも輪郭が立つ速い発音が要る。音量競争ではなく、演奏者の一撃に木がすぐ応える設計こそ、この工房が舞台文化を裏側から支える価値だ。</li>
</ul>
<h2>まとめ：制度を動かす数字と、文化を生かす手仕事</h2>
<p>セウタの5,000人、未成年移送1,898人、受け入れ枠17,081床は、国境問題を抽象論ではなく行政と人権の仕事に戻す数字だ。文化面では、コヨーテやラス・ケチャップの暮らしが、創作の自由と身体を守る労働環境の重要性を示した。フラメンコは少なくとも四つの土地で、町祭り、歴史あるコンクール、世代をつなぐ舞台、首都の大型企画という別々の姿を見せる。その音を成立させる最後の土台が、グラナダの工房に蓄積された手仕事である。</p>
