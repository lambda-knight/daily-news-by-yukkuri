<h2>オープニング：2026年9月29日 — 世界の珍ニュース</h2>
<p>400を超えるギネス世界記録を破ってきた父親と、「自分の記録がほしい」と言い出した3歳の娘。体重45キロ近いリクガメが庭を抜け出し、道の真ん中で帰宅を拒んだコロラドの午後。日本の古書店に8月ごろから相次ぐ、哲学から江戸文化まで脈絡のない謎の大量注文。そして、寝たきりの人がロボット越しにカウンターに立つ京都のスナック。今回は、「誰が、どこから、何のために動いているのか」が一見しただけでは分からない四つの話をたどる。</p>
<h2>父と3歳の娘でギネス世界記録、「記録破りの達人」デビッド・ラッシュ家の30秒</h2>
<ul>
<li>米アイダホ州ボイシのデビッド・ラッシュ氏と3歳の娘フェリシティさんが、2人1組の部門でギネス世界記録「逆回転をかけたフラフープを30秒間にくぐった最多回数」を達成した。9月28日に米UPI通信が報じた。</li>
<li>従来の記録は8回。フェリシティさんは10回くぐったが、うち1回はフープが規定の距離を転がらなかったため無効となり、公式記録は9回。</li>
<li>きっかけは娘本人の「自分の記録がほしい」という願い。父や兄姉の練習を何年もそばで見てきた彼女を、ラッシュ氏は「練習中はずっと私の影だった」と表現する。これまでにもリフティング、鉛筆のバウンド、カップ投げなどを試していた。</li>
<li>練習方針は「本人がやりたい時にやり、やめたい時にやめる」。認定証が届いた日に、3人の子ども全員が初めての公式世界記録の認定証をそろえた。</li>
<li>ラッシュ氏はマサチューセッツ工科大学で電気工学を学んだ元スタートアップの製品責任者で、現在は講演者・作家。記録挑戦は子どもたちに科学・技術・工学・数学への関心を持ってもらうために始めたとギネス側は紹介しており、これまでに破った記録は350を超える（本人のサイトでは400超）。9月21日にも、紙コップ10個を投げて全部伏せて着地させる記録を6.63秒で更新したばかり（従来7.57秒）。この挑戦には5か月の練習を費やし、「確率の厳しさを思い知った」と語っている。1個が伏せて着地する確率が5割なら、10個すべてがそろうのは約1000回に1回という計算になるという。本人は「やってみて」と挑発している。</li>

<h2>体重45キロ近いリクガメ「ラード」、急がない脱走劇でコロラドの保安官事務所が出動</h2>
<ul>
<li>米コロラド州リトルトンで8月31日、柵に囲まれた庭からケヅメリクガメの「ラード」が抜け出した。体重は100ポンド（約45キロ）弱。ジェファーソン郡保安官事務所の動物管理官が「大きなカメが歩き回っている」との通報で出動した。</li>
<li>管理官が着いたとき、ラードは道路の真ん中にいて、女性が一人で連れ戻そうと苦戦していた。飼い主もいたが、保安官事務所によると「自発的な帰宅に向けた交渉は不調に終わった」。ラードは家と反対方向へ進みたがり、到着してからずっと道端の草を食べ続けていた。</li>
<li>最終的に管理官と居合わせた住民が2人がかりで持ち上げ、家まで運んだ。保安官事務所は9月下旬、胸に付けたカメラの映像を公開し、ラードを「大きな旅行計画があり、急ぐ気はまったくない」と紹介。事件を「解決」として締め、容疑者欄に"シェレブリティ"（甲羅＝シェルとセレブを掛けた造語）と書いた。</li>
<li>ケヅメリクガメはアフリカのサハラ砂漠の南縁に分布し、暑さを避けるために長い巣穴を掘る。成体は体長75センチを超え、体重45〜100キロにもなるため、庭の柵の下を掘って抜け出すことがある。寿命が長く成長も速いため、飼育しきれずに保護施設へ引き取られる例もある。秋に冷え込むコロラドでは屋内の暖かい場所も必要になる。</li>

<h2>古書店に謎の大量注文、送り先は岡山の物流センター</h2>
<ul>
<li>日本各地のオンライン古書店に、2026年8月ごろから書籍の大量注文が相次いでいる。日本テレビが9月22日に報じた。古書店からは「1日100冊売れる」「売上が5倍になった日もある」との声が出ている。</li>
<li>関東の古書店の50代店主は、1000冊以上を一つの送り先に売ったといい、「一つの送り先にこんなに多くの本を売ったことはない。業界の仲間にも同じ現象が起きている」と話す。西日本の古書店には、海外の会社から「数万冊を注文できるか」という問い合わせもあった。</li>
<li>売れているのは哲学、歴史、医学、法律のほか、「江戸時代の生活・文化」「30年前の政界の話」など脈絡のない専門書。都内の古書店は「普通は小説やコミックが売れるが、専門書がこんなに一気に売れたことはない」と語る。</li>
<li>注文は複数のアカウントから機械的な間隔で入り、送り先はいずれも岡山県内の同じ物流センター。センターの運営会社は「個別の取引については回答を控える」とし、注文主は明かされていない。日本から米国へ本が50トン以上輸出された記録も確認されている。</li>
<li>東京都古書籍商業協同組合は、こうした動きを把握しており、業界内では生成AIの学習データ集めが目的ではないかとの見方が広がっていると説明する。ただし注文主も用途も確認されていない。米国では2025年、AI企業のアンソロピックが紙の本を買って裁断・スキャンし、学習に使っていたことが著作権訴訟で明らかになっている。</li>
<li>古書店側には「売上が上がるのはうれしいが、本の価値は今後どうなるのか。複雑な気持ちもある」との声があり、著作権者への対価が見えにくいとの指摘も出ている。</li>
<li>出典: <a href="https://news.yahoo.co.jp/articles/b5bf35aac135601dde27ef7d43cbf5d7fe95e671">日テレNEWS NNN（Yahoo!ニュース）</a> / <a href="https://soranews24.com/2026/09/28/tons-of-used-books-in-japan-being-bought-up-by-someone-or-something/">SoraNews24</a></li>
</ul>
<h2>寝たきりでもバーテンダーに、京都に分身ロボットのスナック</h2>
<ul>
<li>東京のオリィ研究所は、分身ロボット「オリヒメ」を遠隔操作する「パイロット」が接客するスナック＆バー「OrySNACK Kyoto」を、12月4日に京都・四条烏丸で開業すると9月9日に発表した。同社にとって関西初の常設店。大垣書店が開く書店「BOOKHOME」内に入り、席数は9席と立ち飲み、営業は午後5時から11時。</li>
<li>カウンターに立つのは人工知能ではない。病気や障害などで外出や通勤が難しい人が、全国各地の自宅や病院から、身長約120センチの接客用ロボット「オリヒメD」を操作して酒を出し、客と会話する。寝たまま操作できるため、脊髄損傷、筋ジストロフィー、筋萎縮性側索硬化症などの人も働ける。</li>
<li>酒は1657年創業の京都・伏見の蔵元、北川本家が協賛し、京都を中心とした日本酒4種の飲み比べ（予約制）と、予約なしで立ち寄れる通常のスナック営業を用意する。</li>
<li>開業資金の一部を募るクラウドファンディングは目標500万円に対し約780万円、達成率156％、支援者348人に達した（9月下旬時点）。</li>
<li>同社は2021年に東京・日本橋で「分身ロボットカフェDAWN ver.β」を開き、現在は100人を超えるパイロットが働く。週2時間しか働けなかったパイロットが、声を出して接客することで週20時間働けるようになった例もあるという。代表の吉藤オリィ氏は「たとえベッドの上から動けなくなったとしても、仲間と一緒に接客の仕事を担い、自分自身でお客様との関係を築いていける」と語り、将来はパイロット自身が店を持つことを目標に掲げる。</li>

<h2>まとめ</h2>
<ul>
<li>3歳の娘の世界記録は、父が何年も続けてきた記録挑戦の日常から生まれた。リクガメのラードは急がないまま保安官事務所を動かし、古書店の謎の注文は送り先だけが分かって注文主が見えない。京都のスナックでは、カウンターのロボットの向こうに、ベッドの上から働く人がいる。</li>
<li>四つの話はどれも、見えている姿と、その後ろで実際に動いている主体が違う。記録の主役は3歳児でも、支えたのは父の習慣。本を集めているのは人かAIか分からず、ロボットのバーテンダーを動かしているのは人の声だった。</li>
</ul>
