<h2>ネタ1 全額出資の裕福な女性、自ら主演しキスシーン60回以上を強行し配信中止に</h2>
<ul>
<li>中国で、名前非公表の裕福な女性が全50話のショートドラマシリーズに全額出資し、自ら主演女優を務める条件と脚本への最終決定権を設定した</li>
<li>女性は監督・スタッフの反対を押し切り、23歳の主演男優・鍾宇飛（ショウ・ウヒ）さんとのキスシーンを60回以上脚本に盛り込むことを強行した</li>
<li>完成後、配信プラットフォームは規制違反の懸念から作品の配信を却下した</li>
<li>中国のソーシャルメディアでは、若手俳優へのハラスメントと、出資者に最終決定権が集中する力関係への批判が拡散した</li>
<li>出典: <a href="https://www.odditycentral.com/news/wealthy-woman-bankrolls-drama-series-so-she-can-star-in-it-and-kiss-male-lead-more-than-60-times.html">Oddity Central</a>（2026年8月12日公開）</li>
</ul>
<h2>ネタ2 絶滅危惧種の鳥を狩り続け3年間逃げ切った伝説の野良猫「ナインライブズ」、ついに捕獲</h2>
<ul>
<li>ニュージーランド・プレルア半島で、保全団体「ペストフリー・プレルア」が放獣した絶滅危惧種の褐色ハジロ（キーウィ近縁の飛べない鳥）が、2023年から野良猫に襲われ続けていた</li>
<li>猫は初回放獣20羽のうち1羽、2024年の追加放獣20羽のうち15羽を捕食したとみられ、褐色ハジロ全個体群の約1%を減らした計算になる</li>
<li>プロジェクトマネージャーのアンディ・メンター氏によると、この猫は「非常に不規則で、ある場所に現れては2〜3か月姿を見せない」ため3年間罠にかからなかった</li>
<li>同じ場所に3晩連続で現れたことを確認し、サーモン・揚げ鶏・ウサギの肉を使った罠でようやく捕獲。捕獲後は人道的な方法で駆除され、追跡された個体の記録として剥製保存が予定されている</li>
<li>出典: <a href="https://www.odditycentral.com/animals/nine-lives-the-legendary-feral-cat-that-feasted-on-endangered-birds-and-eluded-capture-for-3-years.html">Oddity Central</a></li>
</ul>
<h2>ネタ3 パリ・オペラ座で披露、パティシエが5.5ヶ月かけた500キロの結婚式ケーキ</h2>
<ul>
<li>カタルーニャ出身のパティシエ、マルク・スアレスさんが、サウジアラビアの王族から依頼を受け、パリのオペラ・ガルニエで披露する結婚式ケーキを制作した</li>
<li>完成品は500キログラム（1,100ポンド）で、構想に約1.5か月、実制作に4か月、合計約5.5か月・1,800時間を費やした</li>
<li>3万3,000枚の砂糖ペースト製の花びらを手作りし、ケーキ全体のうち実際の生地部分は0.1%のみで、残りは砂糖ペーストとホワイトチョコレートで構成されている</li>
<li>スアレスさんは両親や友人たちの協力を得て制作し、本人は「ケーキというより、会場そのものへのオマージュとなるモニュメント」だったと語っている</li>
<li>出典: <a href="https://www.odditycentral.com/art/pastry-chef-spends-four-months-creating-awe-inspiring-500-kilogram-wedding-cake.html">Oddity Central</a></li>
</ul>
<h2>ネタ4 セミの大合唱を4時間聞き続けた18歳、一時的な難聴に</h2>
<ul>
<li>中国・浙江省寧波市で、18歳の王さんが森でキャンプ中、正午ごろからセミの鳴き声が一段と大きくなるのに気づいた</li>
<li>夜になると耳鳴りと違和感を覚え、鳥の声やスマートフォンの通知音が聞こえなくなり、両耳の腫れも確認された</li>
<li>単体のセミの鳴き声は約70デシベルだが、数百匹が合唱すると85デシベルを超え、聴覚障害が起こりうる音量域に達するという</li>
<li>病院で腫れを抑える薬を処方され14日間の安静を指示された結果、2週間後に聴力は完全に回復した</li>
<li>出典: <a href="https://www.odditycentral.com/news/teenage-boy-suffers-temporary-hearing-loss-after-listening-to-cicadas-for-four-hours.html">Oddity Central</a>（2026年8月7日公開）</li>
</ul>
