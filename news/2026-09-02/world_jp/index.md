<h1>世界から見た日本（2026年9月2日）</h1>
<h2>オープニング：2026年9月2日 — 世界から見た日本</h2>
<ul>
<li>今日は、終戦の日をめぐる高市政権への海外の割れた評価、その議論に重なる映画「開戦前夜」の英語圏批評、年約500トンという着物廃棄を追う海外メディア、記録的な訪日客を前に「京都を避けよ」と書き始めた海外の旅行報道を比べる。歴史認識、文化、生活、観光の4面で、日本人には見慣れた場面が海外でどう別の意味に読まれているかを示す。</li>
</ul>
<h2>靖国参拝と式辞をめぐり、海外は高市政権に異なる評価を並べる</h2>
<ul>
<li>8月16日の戦後81年の終戦の日に、高市早苗首相の式辞には加害への謝罪、アジアの近隣国に与えた被害への言及、「反省」の語がなかったと海外メディアは整理した。同じ日に小泉防衛相が靖国神社（A級戦犯14人を合祀）を参拝したことも報じられた。朝日新聞は参拝が平和主義の原則と憲法秩序を損ないかねないと批判し、東京新聞は高市政権の政策に戦前回帰の傾向がはっきり出ていると社説で書き、毎日新聞は戦争の教訓に向き合わなければ平和国家としての信頼が揺らぐと論じた。</li>
<li>中国国営放送CGTNは8月17日、これら日本の社説を束ねて「戦前への回帰」の見出しで大きく報じ、殺傷兵器の輸出解禁、防衛費の増額、情報機関の拡充を並べた。日本国内の一部紙の懸念を、中国の国営メディアが対外発信で増幅した構図になる。</li>
<li>一方、東京の政治コンサルティング会社ラングレー・エスクァイアは、高市首相をほとんど外遊しない「在宅型の首相」と評し、トランプ大統領を含む主要国首脳と約2か月、対面も電話もない点を指摘する。同時に、通常国会の政府提出法案65本が全て成立したことを珍しい行政上の成果と評価し、内閣支持の弱さ、円安での日米協調介入、9月中旬〜下旬に見込まれる内閣改造と麻生派依存の見直しを焦点に挙げる。国内政治の再編が終わるまでロシアや北朝鮮への反応を意図的に抑えているという読みも示す。</li>
<li>歴史認識を軸に見る中国国営メディア・国内リベラル各紙と、統治能力と外交の空白を軸に見る西側の政治リスク分析とで、同じ首相の評価が割れている。いずれも日本国内の式典報道とは角度が異なる。</li>
</ul>
<h2>映画「開戦前夜」、英語圏の批評は「いまに響く警告」と読む</h2>
<ul>
<li>石井裕也監督、池松壮亮主演の2026年公開作「開戦前夜」（英語題 The Secret Battlefield）は、1941年4月に官僚・将校・民間人の若い精鋭が総力戦研究所に秘密裏に集められ、対米戦争を机上演習する史実を描く。演習の結論は「長期戦になれば日本の敗北で終わる」だったが、指導部は数か月後に真珠湾攻撃へ進んだ。</li>
<li>The Japan Times の8月1日の批評は、テレビ映画的な作りは抜けきらないとしつつ、1940年代初頭の空気をよく再現し、主題は「いまに強く響く」と評した。英語で日本の外の読者に向けて書く批評家は、この作品を時代劇ではなく、専門家の分析が政治の勢いに押し流される過程を描いた話として受け取っている。</li>
<li>同じ週の再軍備・靖国をめぐる議論と並べると、海外の関心は戦争そのものより「正しい試算を組織がどう握りつぶすか」に向かう。日本国内の戦争映画の受け取り方とは力点がずれる。</li>
</ul>
<h2>使われない着物、年約500トンの廃棄を海外メディアが追う</h2>
<ul>
<li>複数の海外報道が、日本でほとんど袖を通さない着物が年におよそ500トン捨てられているという推計を引く。着物が普段着でなくなり、特別な日のために買って、しまい込み、箪笥の奥で役目を終える流れが背景にある。</li>
<li>CNN の文化面は、捨てられる着物をスニーカー・シャツ・帽子へ作り替える東京の新興企業「Tokyo Kimono Shoes」を取り上げた。浅草で1950年代から手作業で靴を作る工房と組み、2024年に4500足を販売、690着の着物を再生したと伝え、再生品が海外の環境意識の高い買い手やデザイン愛好家に届いていると紹介した。</li>
<li>環境系媒体は繊維ごみの問題として、ファッション・工芸系媒体は古い意匠を現代の服へ生かす話として書く。日本国内で呉服業界の縮小として語られる話題が、海外では「国を代表する衣装がいまはほぼ箪笥の中にある」という違和感から入る。ただし動いているのは一部の起業家と職人で、規模はまだ小さい。</li>
</ul>
<h2>記録的な訪日客、海外の旅行報道は「京都を避けよ」と助言し始めた</h2>
<ul>
<li>2025年の訪日外国人はおよそ4270万人で過去最多。2023年比で約2割増、2024年の約3700万人も上回り、2026年も4千万人規模が続く見通しとされる。政府は数の拡大から「価値重視」へ軸を移し、2030年に年6千万人、100地域で混雑対策という目標を掲げる。</li>
<li>2026年の富士山登山シーズンは主要4ルート全てで4000円の通行料と、吉田ルートで1日4000人の上限が導入され、2023〜24年の混乱はかなり収まったと評価される。以前は象徴的な少額の任意協力金だったため、大幅な引き上げにあたる。京都は高級宿の宿泊税が1泊1万円に達し、2027年度からの市民向け割引バス運賃を検討。2月には富士山を望む桜まつりが、住民が「一線を越えた」として中止になった。</li>
<li>海外の旅行メディアは、京都を季節を問わない構造的混雑と位置づけ、金沢・広島・高山・東北・九州へ回ることを勧める記事を増やしている。旅行者自身のガイドが絵はがきの名所から人を遠ざける形で、2010年代の「ぜひ来て」という誘致キャンペーンからの反転にあたる。海外から見ると、日本は名所への入場を静かに絞り始めたように映る。</li>
</ul>
<h2>まとめ</h2>
<ul>
<li>9月2日前後の海外報道で、日本は戦争の記憶をめぐり評価が割れる国、専門家の警告を描く映画を作る国、国を象徴する衣装を捨てている国、名所を絞り始めた観光大国として別々に映った。評価主体を中国国営メディア、政治リスク分析家、環境・ファッションの記者、旅行ガイドと分けて見ると、「平和国家」「観光立国」という短い呼び名の内側にある具体的な緊張が見える。</li>
</ul>
