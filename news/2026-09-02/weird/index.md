<h1>世界の珍ニュース（2026年9月2日）</h1>
<h2>オープニング：2026年9月2日 — 世界の珍ニュース</h2>
<ul>
<li>2026年9月2日放送。今日は4本。</li>
<li>中国・雲南省の峡谷の村で、子どもの通学のために崖の壁面へ高さ288メートルの屋外エレベーターを建設。片道3時間の山道が約30分に短縮された。</li>
<li>ドイツのデザイナーが作った、人を検出するAIカメラに「何もない」と判定される派手な柄の夏用シャツ。</li>
<li>中国のユニトリーが公開した人型ロボット「スーパーマン」が、最高秒速12.66メートルでウサイン・ボルトの記録を上回ったと発表。ただし第三者による検証はまだない。</li>
<li>ニュージーランド北島で在来のカモなどを襲い、3年間捕獲を逃れ続けた野良猫「ナインライブス」がついに捕まった。</li>
</ul>
<h2>ネタ1 通学のために崖へ建てた高さ288メートルの屋外エレベーター</h2>
<ul>
<li>中国・雲南省の深い峡谷にある村と、子どもたちが通う小学校のあいだには標高差の大きい崖がある。従来は片道約3時間、往復約6時間の山道を歩いて通学していた。ある児童は「荷物を背負って3時間歩く。うっかりすると滑って落ちる」と話している。</li>
<li>崖の壁面に高さ288メートルの鉄骨エレベーターを設置。シャトルバス、エレベーター、ロープウェイを乗り継ぎ、通学時間は約30分に短縮された。子どもは無料。</li>
<li>2022年に近くの別の崖へ設置された高さ268メートルのエレベーターに続く2基目。1基目は観光客に人気が出て順番待ちが数時間に及び、児童が乗れなくなったため、通学用にシャフトが約20メートル長い2基目を増設した。</li>
<li>出典: <a href="https://www.odditycentral.com/architecture/china-builds-288-meter-outdoor-elevator-to-help-children-reach-school-easier.html">Oddity Central</a></li>
</ul>
<h2>ネタ2 AI監視カメラに映らない「世界一ダサいアロハシャツ」</h2>
<ul>
<li>ドイツのデザイナー、サイモン・ヴェッカートが、カラフルで渦を巻いたような派手な柄の夏用シャツを制作。人間の目にはよく見えるが、人を検出するAIカメラには「そこに何もない」と判定されるように設計されている。</li>
<li>AIは膨大な学習画像から人の輪郭・コントラスト・シルエットの特徴を学ぶ。ヴェッカートは候補の柄を検出システムに繰り返しかけ、認識の確信度が下がるよう調整を重ねた。「見張る側のAIが、隠れ方をシャツに教えた」と説明している。</li>
<li>効果は本人が試した検出システムに対するもので、カメラの種類や設定によって結果は変わりうる。実用の防犯用品というより、人物検出技術の脆さを示す作品としての性格が強い。</li>
<li>出典: <a href="https://www.odditycentral.com/news/worlds-ugliest-hawaiian-shirt-was-designed-to-make-you-invisible-to-ai-surveillance-cameras.html">Oddity Central</a>（2026年8月31日）</li>
</ul>
<h2>ネタ3 人型ロボットがウサイン・ボルトより速く走った</h2>
<ul>
<li>中国のロボット企業ユニトリーが、2026年8月17日に人型ロボット「スーパーマン」を公開した。</li>
<li>最高速度は秒速12.66メートル（時速45.6キロ）で、ウサイン・ボルトの記録である秒速12.27メートル（時速44.17キロ）を上回ったとしている。垂直跳びも2メートルを記録し、2021年の記録1.70メートルを超えたと主張。</li>
<li>走行フォームはぎこちなく、記事は「まぬけな走り方で本来の性能が伝わらない」と評している。</li>
<li>これらの数値は第三者による検証がなく、通常の地面かトレッドミル上かをユニトリーは明らかにしていない。記録の妥当性を判断するうえで重要な差である。</li>
<li>同社は以前、複数ロボットによる武術の一斉演武でも話題になったが、一部が誤作動して人に接触する騒ぎもあった。</li>
<li>出典: <a href="https://www.odditycentral.com/technology/worlds-fastest-humanoid-robot-can-already-run-faster-than-usain-bolt.html">Oddity Central</a></li>
</ul>
<h2>ネタ4 3年つかまらなかった伝説の野良猫「ナインライブス」</h2>
<ul>
<li>ニュージーランド北島のプレルア半島では、在来のカモ「パテケ」の再導入活動が行われている。1匹の灰色のトラ猫がこの鳥などを襲い続けていた。</li>
<li>被害は数十羽におよび、2024年に新たに放した20羽のうち15羽がこの猫にやられた。キーウィのひなや在来のヤモリも捕食していた。</li>
<li>プロジェクト責任者のアンディ・メンターによると、この猫は夕方・真夜中・明け方・日中と出現時間に規則性がなく、追い詰めても背の高い草に逃げ込むため、3年間捕獲できなかった。「ナインライブス（9つの命）」と呼ばれるようになった。</li>
<li>3晩連続で同じ場所に現れたのを機に、活動チーム「ペストフリー・プレルア」がサーモン、フライドチキン、ウサギの肉を仕掛けたわなで捕獲した。</li>
<li>捕獲後、猫は人道的な方法で処分された。「動物園などで生かせたのでは」との批判も出ている。研究者は胃の内容物を分析し、遺体をはく製として保存する予定。</li>
<li>出典: <a href="https://www.odditycentral.com/animals/nine-lives-the-legendary-feral-cat-that-feasted-on-endangered-birds-and-eluded-capture-for-3-years.html">Oddity Central</a></li>
</ul>
<h2>まとめ</h2>
<ul>
<li>崖に貼り付けた通学エレベーター、監視AIに消される派手なアロハシャツ、ボルト超えを名乗る人型ロボット、そして3年逃げ切った野良猫。</li>
<li>4本に共通するのは「本気の出しどころが少し極端」であること。</li>
<li>便利にした施設は観光地化し、ロボットの記録は測定条件が示されるまで保留、逃げ切った猫の物語には重い後日談がついた。派手な見出しの裏側まで見ると印象が変わる。</li>
</ul>
