<h1>世界の珍ニュース（2026年9月18日）</h1>
<h2>オープニング：2026年9月18日 — 世界の珍ニュース</h2>
<p>自由の女神が屋上に2体立つ銀行ビル、144本の映画のセリフだけで名曲を再現する動画、頭が外れても戦い続けるロボット格闘リーグ、そして北極オオカミと同じ屋根の下で眠れる宿。今回は「本気の作り込み」が生んだ四題を追う。</p>
<h2>銀行が名前を変えたら、屋上に自由の女神が2体立った</h2>
<ul>
<li>米国ニューヨーク州バッファローの「リバティビル」は1925年築のネオクラシカル様式のオフィスビル。</li>
<li>前身は「ジャーマン・アメリカン銀行」という名だったが、第一次世界大戦中の反ドイツ感情の高まりを受け、1918年に「リバティ銀行」へ改称した。</li>
<li>新しい名前に合わせ、彫刻家レオ・レンテッリに依頼して自由の女神像を製作させ、完成した2体を屋上に、もう1体をメイン入口に設置した。屋上の2体は高さ約11メートル（36フィート）で、1925年から街を見下ろし続けている。</li>
<li>出典: <a href="https://laughingsquid.com/buffalo-liberty-building-statues-of-liberty/">Laughing Squid</a></li>
</ul>
<h2>144本の映画のセリフだけで「ミスター・ブライトサイド」を歌わせる</h2>
<ul>
<li>動画クリエイターのロス・ファーンリー氏が、ザ・キラーズの2004年のヒット曲「Mr. Brightside」を、144本の映画のセリフを切り貼りしてそのまま歌詞代わりに再現した動画を公開した。</li>
<li>手法は同氏が「CinemaSings」と呼ぶシリーズで、既存の映画音声から歌詞と同じ発音・意味の台詞を探し出し、メロディに合わせて継ぎ合わせる。</li>
<li>1曲のために144本という物量を投じる執念が、単なる空耳動画と一線を画す。</li>
<li>出典: <a href="https://laughingsquid.com/mr-brightside-144-movies/">Laughing Squid</a></li>
</ul>
<h2>頭が外れても試合続行、中国のロボット格闘リーグ</h2>
<ul>
<li>中国のロボット企業ENGINE AIが主催する人型ロボット格闘リーグ「URKL」が深圳市の南山文体中心で開幕し、同社製の人型ロボット「T800」（身長173センチ、重量75キロ)同士がリング上でキックボクシング形式の試合を行った。</li>
<li>「ホワイトイーグル」と「マタドール」という愛称の2体が対戦し、一方が回転蹴りを受けて首の接続部が外れ、頭部が配線でぶら下がったまま試合が続行される場面があった。</li>
<li>主催企業の狙いは見世物だけでなく、実戦に近い衝撃を与え続けて量産機の耐久性・安全性を検証することにある。</li>
<li>出典: <a href="https://note.com/zhenren63/n761fb27812bb">note（吉川真人）</a></li>
</ul>
<h2>北極オオカミと同じ屋根の下で一晩過ごせる宿</h2>
<ul>
<li>パリ近郊イヴリーヌ県トワリの動物園「ズー・サファリ・ド・トワリ」が、北極オオカミの群れの生活圏に面した専用ロッジ「ルージュ（Loudges）」を運営している。</li>
<li>寝室・簡易キッチン・浴室を備え、大きな窓越しにオオカミの群れをすぐそばから見られる設計で、星空の下、オオカミの遠吠えを聞きながら眠る体験ができる。</li>
<li>滞在中はレンジャーによる解説ワークショップや、群れへの給餌の様子を見る機会も用意されている。</li>
<li>出典: <a href="https://www.sortiraparis.com/hotel-restaurant/hotel/articles/313550-insolite-dormez-en-tete-a-tete-avec-les-loups-arctiques-dans-les-loudges-du-zoo-safari-de-thoiry">Sortir à Paris</a></li>
</ul>
