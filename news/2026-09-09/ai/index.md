<li>2026年9月9日、生成AIニュースをお届けする。</li>
<li>当日の柱は、AIコーディング企業コグニションの評価額急騰、メタの新エージェント「ミューズ」への信頼問題、メタ広告に実在の未成年の写真を使ったAI生成児童性的虐待コンテンツが数百件掲載されていた問題、フランスのミストラルAIの巨額調達、そしてコペンハーゲンの量子チップ工場計画。</li>
</ul>
<h2>コグニション、評価額480億ドルへ急騰しAIコーディング市場の見方を一変</h2>
<ul>
<li>AIコーディングエージェント「Devin」を開発するコグニションが、シリーズEで20億ドル超を調達し評価額480億ドルに達したと2026年9月8日に発表された。</li>
<li>直近ラウンドは2026年5月27日のシリーズDで、調達額10億ドル超・評価額260億ドルだった。約3カ月半で評価額は倍近くに伸びた計算になる。</li>
<li>主導したのはアンドリーセン・ホロウィッツとアクセルの新規投資家2社で、ファウンダーズファンド、ゼネラル・カタリスト、アヴェニアなど既存投資家に加え、NVIDIAなど数十社が参加した大型シンジケートとなった。</li>
<li>会社の年換算収益は前回ラウンド時点の4億9200万ドルから、今回はほぼ9億ドルへ伸びたとされる。</li>
<li>一部の海外テックメディアはこの調達を、AIコーディング市場が単独勝者総取りにはならないという投資家の見方を示すものと位置づけている。競合のカーサーがスペースXへの売却時点で持っていた評価倍率よりも、コグニションの今回の倍率の方が高い。</li>
</ul>
<h2>メタの新AIエージェント「ミューズ」、家計・医療情報までアクセス要求し信頼が焦点に</h2>
<ul>
<li>メタが2026年9月8日、消費者向けとしては同社最大規模のAIエージェント「ミューズ」を発表した。</li>
<li>ミューズはメール、カレンダー、決済、健康・フィットネスサービス、スマートホーム機器、ショッピング、音楽、イベントなど接続先アプリを横断して動作し、メール送信、旅行予約、請求額の見直し、フォーム入力、レシピ動画からの買い物リスト作成、招待状送付、Stripe連携での決済実行までこなすとされる。</li>
<li>提供はウェブ版muse.ai、iOS/Androidアプリ、WhatsApp内チャットから開始し、今後メタ製ARグラスにも展開予定。有料プランは月額20ドルの「Power」と月額100ドルの「Maximum」の2種類。</li>
<li>各ミューズはそれぞれ専用の仮想マシン上で動き、ユーザーが操作していない間もバックグラウンドで処理を継続できる設計になっている。</li>
<li>一方でメタ社内のテスト担当者からは、説明なく接続が切れる、許可なく機密情報がアップロードされるといった不具合の報告も出ている。メール・決済・医療情報という機微データへのアクセスを求める設計だけに、利用者の信頼を得られるかが焦点になっている。</li>
</ul>
<h2>メタ広告にAI生成の児童性的虐待コンテンツ、実在の未成年の写真が悪用</h2>
<ul>
<li>非営利団体テック・トランスペアレンシー・プロジェクト(TTP)の調査により、メタのインスタグラムとフェイスブックで、実在する未成年の写真を悪用したAI生成の児童性的虐待コンテンツ(CSAM)を含む広告が今年に入り300件超掲載され、合計2万9000人以上に配信されていたことが2026年9月8日までに報じられた。</li>
<li>広告の多くは、実在人物の写真から服を脱がせたように加工する「ヌーディファイ」アプリの宣伝目的だった。TTPは、欧州王室の若年メンバーの報道写真や、人気の未成年インフルエンサーのインスタグラムアカウントから取られた画像が悪用されていたことを突き止めた。</li>
<li>メタは2026年9月1日時点で該当広告の約半数を広告ライブラリから削除していたが、残りはTTPが調査結果を共有した後に削除したという。</li>
<li>広告審査という既存の仕組みが、AIによる合成コンテンツの生成・拡散の速さに追いついていない実態を示す事例で、プラットフォームの責任範囲が改めて問われている。</li>
</ul>
<h2>ミストラルAI、欧州最大級の30億ユーロ調達で「主権AI」路線を加速</h2>
<ul>
<li>フランスのAIスタートアップ、ミストラルAIが2026年9月8日、シリーズDで30億ユーロ(約34億9000万ドル)を調達し、調達後評価額が210億ユーロ(約244億ドル)超に達したと発表した。欧州テック企業の資金調達としては過去最大規模となる。</li>
<li>ラウンドはサムスン電子が主導し、EQTのスケールアップ・ヨーロッパ・ファンドとPSGエクイティが共同主導した。ASML、NVIDIA、BNPパリバCIBなど既存投資家も参加した。</li>
<li>創業から3年での調達で、資金はフロンティア研究とモデル開発の拡大、計算基盤・製品機能の強化、商用展開と国際展開の加速に充てるという。</li>
<li>ミストラルは、政府や企業がインフラ・データ・展開方法をより強く自分たちで制御できるAIシステムへの需要が高まっていると説明しており、各国が自国内でAI基盤を持とうとする「主権AI」路線が、技術面だけでなく大型資金調達を伴う一つの産業になりつつあることを示している。</li>
</ul>
<h2>量子コンピュータ: ノボノルディスク財団、コペンハーゲンに5300平方メートルの量子チップ工場</h2>
<ul>
<li>デンマークのノボ ノルディスク財団傘下のクオンタム・ファウンドリー・コペンハーゲンが2026年9月4日、量子チップ製造拠点として床面積5300平方メートルの新工場計画を発表した。投資額は約6200万ドルで、稼働開始は2027年を予定する。</li>
<li>施設は量子材料のナノ加工用ラボ、高度な特性評価、チップの組み立て・パッケージング、超高真空製造設備を一体で備え、世界の量子技術ベンダー向けにウエハー製造を商用ベースで受託する計画。</li>
<li>この投資は、ノボ ノルディスク財団による量子技術への総額29億デンマーククローネ(約390億ユーロ相当)のコミットメントの一部で、コペンハーゲン大学ニールス・ボーア研究所の量子コンピューティング・プログラムとも連携し、2034年までの誤り耐性型量子コンピュータ実現を目標に掲げている。</li>
<li>商用量子コンピュータの実用化競争は米中の大手ベンダーが目立つ中、欧州は自前の製造基盤への投資という形で存在感を確保しようとしている。</li>
</ul>
<h2>まとめ</h2>
<ul>
<li>コグニションの評価額急騰とミストラルの欧州最大級調達は、AIコーディングと主権AIという異なる切り口で、投資マネーが依然として生成AI領域に厚く流入していることを示した。</li>
<li>メタは消費者向けエージェント「ミューズ」で機微データへのアクセスを求める一方、広告面では実在の未成年の写真を悪用したAI生成CSAM広告への対応の遅れが表面化しており、同じ会社の中でAI活用の攻めと守りのギャップが目立った一日だった。</li>
<li>量子コンピュータでは欧州が製造基盤への投資で存在感を示し、実用化競争は装置メーカーの陣取り合戦の段階に入りつつある。</li>
</ul>
