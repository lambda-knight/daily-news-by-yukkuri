## 概要

36年の歴史で初めてアメリカ国外（スイス・チューリヒ）で開かれた2026年イグ・ノーベル賞、人類最速を上回る時速45.6キロを記録したとメーカーが発表した人型ロボット、マッチングアプリに従兄弟の写真を使って対面で見破られた男性、希望の名前を8か月無視されて約200ドルで正式に法的改名した社員の逆襲を紹介します。

<h2>ネタ1 ゴキブリのミルクから蚊の3Dプリンターまで、初の米国外開催となった2026年イグノーベル賞</h2>
<ul>
<li>「人を笑わせ、そして考えさせる」研究を表彰する2026年イグノーベル賞（第36回）が、2026年9月3日、スイス・チューリヒで発表された。36年の歴史で初めてアメリカ国外での開催となった</li>
<li>化学賞は、ゴキブリの「ミルク」（母乳のような分泌液）が牛乳の約3倍のエネルギーを持つことを突き止めた研究チームに贈られた</li>
<li>医学賞は「鼻のかみ方――鼻かみの空気力学的研究」という論文、経済学賞は「裕福な人ほど子ども向けの飴を盗んだり、他の不正行為をしたりしやすい」ことを示した研究に贈られた</li>
<li>技術賞は、カナダ・マギル大学のカオ・チャンホン氏とリー・ジエンユー氏らのチームが、メスの蚊の「口吻（こうふん）」を高解像度3Dプリンターのノズルとして使う技術に授与された。チームは牙・針・植物の導管などを比較した末、長さ2ミリで内径が極細の蚊の口吻に行き着き、幅20マイクロメートル（0.02ミリ）という極細の線を印刷することに成功した</li>
<li>このほか生体力学賞は「キスの進化的な意味」を再定義した研究に贈られた</li>
<li>出典: <a href="https://www.pbs.org/newshour/science/scientists-studying-cockroach-milk-nose-blowing-win-2026-ig-nobel-prizes-for-quirky-science">PBS NewsHour</a> / <a href="https://www.the-scientist.com/mosquito-blood-sucking-organ-turned-3d-printing-nozzle-wins-ig-nobel-74952">The Scientist</a></li>
</ul>
<h2>ネタ2 人類最速より速い？ 人型ロボット「スーパーマン」が時速45.6キロを記録</h2>
<ul>
<li>中国のロボット企業Unitreeは2026年8月17日、新型人型ロボット「Superman」の運動能力を示す動画を公開した</li>
<li>同社発表では最高速度は秒速12.66メートル、時速45.6キロ。ウサイン・ボルト選手が記録した最高速度の秒速12.27メートル、時速44.17キロを上回る</li>
<li>垂直跳びでは2メートルを記録したとされ、2021年にクリストファー・スペル氏が達成した1.70メートルの記録も超える数値になっている</li>
<li>ただし速度と跳躍の数値はメーカーの動画と発表に基づき、第三者機関による検証はまだない。人間との公平な比較には走路、計測方法、持続時間など同じ条件での測定が必要になる</li>
<li>出典: <a href="https://www.odditycentral.com/technology/worlds-fastest-humanoid-robot-can-already-run-faster-than-usain-bolt.html">Oddity Central</a></li>
</ul>
<h2>ネタ3 マッチングアプリに従兄弟の写真を使った男性、対面したその場で見破られる</h2>
<ul>
<li>アメリカのSNS「TwistedSifter」が2026年9月8日に紹介した投稿によると、28歳の男性が出会い系アプリのプロフィール写真に、27歳の従兄弟ジェイクさんの写真を使っていたことが明らかになった</li>
<li>男性は元交際相手と一緒に写った写真ばかりで自分単独の写りの良い写真がなく、自撮りもうまくいかなかったため、子どもの頃から「双子のよう」と言われていた従兄弟の写真を借りたという</li>
<li>マッチした34歳の女性ジュリーさんとは1週間ほどメッセージをやり取りしたのち初対面となったが、ジュリーさんは会った瞬間に「プロフィール写真の人と違う」と指摘した</li>
<li>男性が違うと言い張ったにもかかわらず、ジュリーさんは不快感を示してその場を去った。投稿を見た読者からは「キャットフィッシング（身元詐称)そのもの」と批判が相次いだ</li>
<li>出典: <a href="https://twistedsifter.com/2026/09/man-used-his-lookalike-cousins-photo-on-a-dating-profile-but-his-match-realized-the-truth-when-they-met/">TwistedSifter</a></li>
</ul>
<h2>ネタ4 希望の名前を8か月間無視された社員、約200ドルをかけて「正式改名」で会社に逆襲</h2>
<ul>
<li>「TwistedSifter」が2026年9月に紹介した投稿によると、ある社員は入社時から12年間、法律上の名前ではなく希望する名前を職場で使い続けていた</li>
<li>ところが新しく着任した人事責任者のもとで、名刺の再発行を複数回申請しても8か月間対応されず、最終的に「会社方針」を理由に法律上の名前だけを印刷した名刺300枚が届いた。同じ職場の他の管理職には希望名での名刺作成が認められていたにもかかわらず、この社員だけが対象にされたという</li>
<li>社員は約200ドルをかけて姓を含む名前を正式に法的改名し、運転免許証の更新や関係機関への届け出も済ませた</li>
<li>その結果、届いていた300枚の名刺はすべて使えなくなって返却され、人事担当者は全社員ファイルと契約書の名前を書き換え、本社への書類提出と新しい名刺の再発注に追われることになった。社員はその後まもなく退職した</li>
<li>出典: <a href="https://twistedsifter.com/2026/09/they-asked-to-be-known-by-their-preferred-name-at-work-but-after-management-ignored-it-they-decided-to-change-their-name-legally/">TwistedSifter</a></li>
</ul>
