<h1>スペインニュース（2026年9月9日）</h1>
<h2>オープニング：2026年9月9日 — スペインニュース</h2>
<ul>
<li>一般ニュースは二題だけ。主軸は、9月9日に始まるセビリア・フラメンコ・ビエンナーレ、各地の公演、マノロ・サンルーカルの音楽、ホセ・ラミレス工房の構造設計。</li>
<li>聞き終えると、舞台で鳴る一音を、演奏家・歌い手・踊り手・製作家がどう共同で作るかが分かる。</li>
</ul>
<h2>今日のスペイン語ひとこと</h2>
<ul>
<li><strong>Dar la nota（ダール・ラ・ノタ）</strong>。直訳は「音符を出す」だが、目立つ、場違いな振る舞いで注目を集める、という意味にもなる。</li>
<li>音楽家が正しい音を出す場合にも、誰かが悪目立ちする場合にも使える。今日の「音を支える」話と、政治家の激しい応酬をつなぐ表現。</li>
</ul>
<h2>国際情勢（スペイン視点）</h2>
<ul>
<li>サンチェス首相は9月9日、セウタへの大量越境のような「ハイブリッド攻撃」に備え、情報機関はさらに高度化すべきだと表明。北アフリカのスペイン領をめぐる国境管理が、移民行政だけでなく国家安全保障の問題として再定義された。</li>
<li>モロッコとの関係をめぐり、PPのフェイホーとVoxのアバスカルは首相がラバトに対して自由に判断できないと攻撃し、首相は「私に主人はいない」と反論。地中海の対岸を生活圏と感じる市民には、外交の失敗がセウタの日常へ直結する。</li>
</ul>
<h2>スペイン国内ニュース</h2>
<ul>
<li>最高裁は「孫法」でスペイン国籍を得た在外有権者の扱いを、選挙前に緊急判断する。対象として報じられた人数は230万人、在外票は有権者100人中12人に達する計算で、歴史的移民とのつながりと選挙の公平性が衝突する。</li>
<li>国籍回復を家族の歴史として受け止めるラテンアメリカ系住民と、居住実態の薄い有権者が結果を左右すると警戒する側が対立。地域の帰属を重く見る点は日本にも通じるが、海外に広がる家族を選挙制度へ組み込む規模は大きく異なる。</li>
</ul>
<h2>文化・芸能ニュース</h2>
<ul>
<li>マドリードで12公演を行うシャキーラのレジデンシーに、スペインの<strong>アマイア、ギタリカデルフエンテ、ジェライ・コルテス</strong>らが参加する。音楽だけでなく食・文学も含むラテン文化の催しで、欧州ツアー唯一の滞在地を一夜限りでなく都市型企画へ広げた。</li>
<li>カステリョン出身のギタリカデルフエンテは、アラゴンの祖母の村で覚えたギターと地中海の民謡感覚をポップへ接続してきた。ジェライ・コルテスが持ち込むフラメンコの切れ味と並び、同じ「スペインのギター」でも土地とリズムが違う。</li>
<li>映画監督・作家の<strong>ロドリゴ・コルテス</strong>は第三小説『Hija del cielo』を発表。崖に面した架空の土地ガバオンと61人の修道女を描き、長年「人工知能が作ったような製品」を見てきたと、創作の均質化を批評した。</li>
<li><strong>エレナ・デル・リベロ</strong>はニューヨークを去る。2001年9月11日、南棟近くの自宅兼スタジオが崩壊する様子をテレビで見て以来、25年にわたり傷と喪失を作品化してきた。移動は単なる転居ではなく、生活空間そのものを制作資料にしてきた期間の区切りになる。</li>
<li>ペネロペ・クルスとハビエル・バルデムはベネチアで映画『Búnker』を発表。クルスは私生活と仕事に「良い均衡」があると話した。夫婦役を演じる二人が、家庭と国際的な撮影現場を分けながら共同作業する具体例である。</li>
</ul>
<h2>フラメンコニュース</h2>
<ul>
<li><strong>第24回セビリア・フラメンコ・ビエンナーレ</strong>が9月9日開幕。サラ・バラス『インフィニタ』を皮切りに、カニサレスとセビリア王立交響楽団、イスラエル・ガルバン、ホセ・メルセらが10月3日まで出演する。踊り、ギター、歌を都市全体で見せる24日間となる。</li>
<li>パンプローナでは第13回フラメンコ・オン・ファイアの連携企画として、エル・ペレが市庁舎のバルコニーから歌い、コンデスタブレで二公演、未成年向けギター・舞踊教室も開かれた。完成した舞台だけでなく、子どもが拍と身体を覚える入口を公共事業にした点が重要だ。</li>
<li>ヘレスの「金曜フラメンコ」は、トマス・ルビチ、チェロ・パントーハ、バルージョのカンテとソラヤ・クラビホのバイレで今季を締めくくる。家系で受け継ぐ歌と、踊りの足音をギターが同じコンパスへ束ねる。</li>
<li>バダホスのプラサ・アルタではヘスス・オルテガが「エストレマドゥーラのフラメンコ」を掲げる。セビリア、コルドバ、ヘレス、グラナダで育った芸が各地へ渡る一方、土地名を冠することで受け手も自分たちの節回しを主張する。</li>
<li>マドリードがフラメンコを国の顔として発信すると、アンダルシアには誇りと中心を奪われる感覚が同居する。カタルーニャにも「スペイン全体」の記号へまとめられることへの距離があり、普及と出自の尊重は常に対である。</li>
</ul>
<h2>フラメンコギタリスト列伝</h2>
<ul>
<li>第5回は<strong>マノロ・サンルーカル（Manolo Sanlúcar, 1943–2022）</strong>。カディス県サンルーカル・デ・バラメダ生まれ。本名マヌエル・ムニョス・アルコン。父イシドロの指導を受け、若くして歌手ペペ・マルチェナの一座で伴奏した。</li>
<li>代表作『Tauromagia』（1988年）は闘牛の進行をアルバム全体で描き、『Medea』では管弦楽とフラメンコを接続した。伝統のパロを保ったまま、和声と構成を大きな物語へ拡張した点が核心である。</li>
<li>右手はラスゲアードの量より音の粒とアクセントの位置を重視し、左手の和音は低音を残して響きを広げる。速いパッセージでもコンパスの重心が消えず、歌の伴奏で学んだ「声を押しのけない間」が独奏にも残る。</li>
<li>聞きどころは『Tauromagia』の「Oración」。静かな低音から旋律が立ち上がり、音数を増やさず緊張を保つ。弟子ビセンテ・アミーゴへ、技巧だけでなくアルバムを一つの作品として設計する発想を渡した。</li>
</ul>
<h2>フラメンコギター工房だより</h2>
<ul>
<li><strong>ホセ・ラミレス工房</strong>は1882年にマドリードで創業した家族工房。初代ホセ・ラミレスから世代を重ね、現在もラミレス家が製作と監修を続ける。クラシックとフラメンコを別用途の楽器として展開してきた。</li>
<li>フラメンコモデルでは、一般にシープレスの横・裏板とスプルース表板を組み合わせ、薄く軽い構造、低い弦高、ゴルペ板を採る。音の立ち上がりと減衰が速く、歌、パルマ、踊りの足音が重なる現場でも輪郭を作りやすい。</li>
<li>クラシックモデルが持続する響きと音色の幅を求めるのに対し、伴奏用フラメンコは弾いた瞬間の応答が優先される。ただ軽くすればよいのではなく、表板の厚みと力木で強度、低音、反応の均衡を取るのが製作家の仕事である。</li>
<li>量産品も用意しつつ上位器は工房で調整する仕組みは、舞台の要求を広い価格帯へ届ける方法でもある。奏者が弦高やゴルペの当たり方を相談し、作り手が演奏姿勢へ合わせる点は、日本の職人と演奏家の関係にも近い。</li>
</ul>
