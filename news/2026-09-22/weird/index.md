<h1>世界の珍ニュース（2026年9月22日）</h1>
<h2>オープニング：2026年9月22日 — 世界の珍ニュース</h2>
<p>3時間かけて崖をよじ登っていた通学路を30分に変えた雲南省の288メートルエレベーター、AI監視カメラの目をハワイアン柄の一枚のシャツで欺くドイツ人アーティスト、ギタリストの相方として歌ではなく口笛で伴奏するオウムのティコ、そしてテイラー・スウィフトの新曲を28人のディズニーキャラクターの声で一気に歌い分ける声優。今回は「技術」「発想」「才能」がそれぞれ主役の四題を追う。</p>
<h2>崖の村に288メートルの通学エレベーター、雲南省で稼働開始</h2>
<ul>
<li>中国雲南省宣威市の{尼珠河|にじゅか}大峡谷にある尼珠河村では、谷底の集落から崖の上にある{官寨|かんさい}小学校まで、児童がこれまで片道約3時間、往復6時間以上かけて岩場を手足で登って通学していた。転倒によるけがも起きていたという。</li>
<li>現地当局は2022年、まず高さ268メートルの「{青雲梯|せいうんてい}」エレベーターを稼働させ、2026年7月31日には2基目となる高さ288メートルの「{扶揺梯|ふようてい}」を追加で稼働させた。2基体制のエレベーターとロープウェイを組み合わせた「空の通学バス」が完成した形になる。</li>
<li>扶揺梯は360度の全面ガラス張りで、速度は秒速5メートル、1時間あたり最大1200人を運べる設計になっている。尼珠河村と官寨村の住民・児童は無料で利用でき、通学の児童には優先レーンも用意されている。</li>
<li>この結果、通学時間は往復6時間以上から約30分にまで短縮された。中国国営メディアは地元児童の「以前は荷物を持って崖を登り、転ぶこともあった」という声を伝えている。</li>
<li>出典: <a href="https://tech.chinadaily.com.cn/a/202608/04/WS6a71480ca310d709c2fc1474.html">中国日報（China Daily）</a>、<a href="https://english.news.cn/20260804/1eb9bbf2aae143c49837f9f778037ce9/c.html">新華社（Xinhua）</a>、<a href="https://www.odditycentral.com/architecture/china-builds-288-meter-outdoor-elevator-to-help-children-reach-school-easier.html">Oddity Central</a></li>
</ul>
<h2>AI監視カメラに「人として映らない」ハワイアンシャツ、ベルリンのアーティストが発表</h2>
<ul>
<li>ベルリン在住のアーティスト、{サイモン・ヴェッケルト|ウェッケルト}氏は2026年8月、Dezeenマガジンなどを通じて、派手な柄のハワイアンシャツ「デジタル・カモフラージュ」を発表した。人間の目には単なる奇抜な柄だが、AIの物体検出システムには着用者が「人間」と認識されにくいよう設計されている。</li>
<li>ヴェッケルト氏はデジタルインフラが公共空間に与える影響をテーマに活動してきたアーティストで、2020年には赤い手押し車に中古スマートフォン99台を積んで街を歩き、グーグルマップ上に偽の渋滞を発生させる作品で知られている。</li>
<li>今回のシャツの柄は、汎用の物体検出モデル「YOLO」を相手に、検出精度が崩れるまでパターンを調整し続ける「敵対的ループ」で作られた。エッジや輪郭のコントラスト、肩や頭のシルエットなど、AIが人間を認識する際に使う統計的な特徴を狂わせる設計だという。</li>
<li>ヴェッケルト氏自身は、このシャツが匿名性を保証するものではないと明言しており、あくまで「技術の価値を、実用性ではなく次世代の視点から問い直す」ための作品と位置づけている。</li>
<li>出典: <a href="https://www.odditycentral.com/news/worlds-ugliest-hawaiian-shirt-was-designed-to-make-you-invisible-to-ai-surveillance-cameras.html">Oddity Central</a>、<a href="https://www.pttl.gr/en/simon-weckert-digital-camouflage-ai-shirt/">Dezeen経由の報道（pttl.gr）</a></li>
</ul>
<h2>ギターの相方は歌わず口笛で伴奏、オウムのティコがレッド・ツェッペリンをカバー</h2>
<ul>
<li>米国のギタリスト、{フランク・マリオ|マグリオ}氏が飼っている{ダブルイエローヘッド・アマゾン|アマゾンオウムの一種}「ティコ」は、2026年9月21日に公開された動画で、マリオ氏がサンバースト色のレスポールで弾くレッド・ツェッペリン「ブラック・ドッグ」に合わせ、歌詞を歌う代わりに口笛と鳴き声で伴奏している。</li>
<li>マリオ氏は動画のコメントで「歌詞は口笛で表現するしかなかった。自分はロバート・プラントのようには歌えないから」と説明している。</li>
<li>ティコとマリオ氏の演奏動画はシリーズ化されており、これまでにAC/DCの「T・N・T」やレッド・ツェッペリンの「{階段|ステアウェイ・トゥ・ヘブン}」なども取り上げてきた。</li>
<li>出典: <a href="https://laughingsquid.com/parrot-sings-black-dog-with-human/">Laughing Squid</a></li>
</ul>
<h2>声優ブライアン・ハル、テイラー・スウィフトの新曲を28人のディズニーキャラクターで歌い分ける</h2>
<ul>
<li>米国の声優{ブライアン・ハル|ハル}氏は2026年9月21日に公開された動画で、テイラー・スウィフトが「トイ・ストーリー5」のために書き下ろした主題歌「{I Knew It, I Knew You|アイ・ニュー・イット、アイ・ニュー・ユー}」を、28人のディズニー・ピクサーキャラクターの声を次々に切り替えながら歌い上げた。</li>
<li>ハル氏はダラス・バプティスト大学で声楽を専攻し、2009年からYouTubeで声真似動画の投稿を始めた。2014年に投稿した「アナと雪の女王」の「{レット・イット・ゴー|Let It Go}」を複数のディズニーキャラクターの声で歌う動画が3300万回以上再生される反響を呼び、注目を集めた。</li>
<li>その後、映画「ホテル・トランシルバニア／トランスフォーマニア」（2022年）でドラキュラ役、「ラプンツェル/新しい世界」テレビシリーズ（2017年）でスタビントン兄弟役を演じるなど、プロの声優としても活動している。</li>
<li>テイラー・スウィフトの「I Knew It, I Knew You」は2026年6月5日に配信され、ビルボード・グローバル200で首位を獲得するヒット曲となった。ハル氏の動画は、その人気曲をディズニーキャラクターの声だけで再現する新しいカバーとして公開された。</li>
<li>出典: <a href="https://laughingsquid.com/taylor-swift-song-as-disney-characters/">Laughing Squid</a>、<a href="https://www.billboard.com/culture/tv-film/taylor-swift-toy-story-5-original-song-knew-it-knew-you-1236261432/">Billboard</a></li>
</ul>
<h2>まとめ</h2>
<ul>
<li>四題に共通するのは、「不便」や「制約」を逆手に取った工夫が思わぬ驚きを生んでいる点だ。</li>
<li>3時間の崖登りを解消する巨大エレベーター、AIの認識精度そのものを逆手に取ったシャツ、歌えないから口笛で応じたオウム、既存のヒット曲を28通りの声で再構成した声優。いずれも「できないこと」や「困っていること」への具体的な応答から生まれている。</li>
<li>技術が生活を変える話、技術を出し抜く話、そして人と動物それぞれの持ち味を生かした話として、聞き比べると面白い一日になった。</li>
</ul>
