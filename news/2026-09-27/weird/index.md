<p>18歳以上限定なのに幼児番組のように丸くて愛らしい人工知能、メールの「スヌーズ」をブラウザーのタブへ移したフクロウ、そして地球の一日を数ミリ秒ずつ伸び縮みさせる地下深くの綱引き。今回は、難しい仕組みを親しみやすく見せる三つの工夫と、その裏側をたどる。</p>
<h2>18歳以上限定なのに子どもの玩具そっくり、メタの人工知能「ミューズ」</h2>
<ul>
<li>メタの個人向け人工知能エージェント「ミューズ」は、メール整理や予約などを代行する一方、利用は18歳以上に限定されている。ところが案内役の「ジョリー」は丸くて毛むくじゃらの人形風。着せ替えもでき、マーク・ザッカーバーグ氏のジョリーはイベントでトーガと月桂冠を着けていた。</li>
<li>年末には、たまごっちのような専用端末「ミューズ・チャーム」も発売予定。メタは生年月日の入力、18歳未満と検知した人の登録阻止、年齢の追加確認を行うと説明する。</li>
<li>子ども向けメディアを監視する非営利団体フェアプレイのジョシュ・ゴリン氏は「テレタビーのようだ」と指摘。丸い形は幼児にも強く訴えると批判する。一方、メタは「自分だけの個性とスタイルを持つアバターを作ることが楽しいから」と説明する。</li>
<li>ハーバード大学のジュリアン・デフレイタス准教授は、かわいさが製品を暖かく脅威の少ないものに見せると分析する。ミューズとのやり取りは、利用者が拒否設定をしない限り人工知能の訓練に使われる。見た目が柔らかいほど、データ利用まで柔らかく感じてしまうのが、この設計の妙であり落とし穴だ。</li>
<li>出典: <a href="https://www.wired.com/story/meta-muse-is-adults-only-why-does-it-look-like-a-cute-kids-toy/">WIRED</a></li>
</ul>
<h2>タブを「週末まで寝かせる」、毛布にくるまったフクロウの拡張機能</h2>
<ul>
<li>無料のブラウザー拡張機能「タック」は、開いているタブをメールのようにスヌーズできる。アイコンは毛布にくるまったフクロウ。「今日の後」「明日」「週末」「来週」を選ぶとタブが閉じ、指定時刻に戻る。</li>
<li>「月曜の午後2時」のような自然な言葉でも時刻を指定できる。標準設定では24時間触らなかったタブを自動で閉じて一覧へ保存し、3時間、12時間、3日、7日にも変更できる。</li>
<li>クローム、サファリ、エッジ、ファイアフォックス、ブレイブなど主要ブラウザーに対応し、アカウント登録は不要。固定タブとタブグループは自動で閉じず、文書作成サイトなど特定のドメインも除外できる。</li>
<li>同期には各ブラウザーの既存機能を使い、独自に利用情報を集めないと開発側は説明する。ただし携帯版はなく、ある端末で寝かせたタブを別端末で時間どおり自動復活させることもできない。散らかった机を片づけるのではなく、書類に起床時刻を付けて戸棚へ入れる発想だ。</li>
<li>出典: <a href="https://www.wired.com/story/tuck-browser-extension-lets-you-snooze-open-tabs-until-later/">WIRED</a></li>
</ul>
<h2>地球の一日は固定ではない、地下2900キロの「重力の綱引き」</h2>
<ul>
<li>地球の一日の長さは完全には一定でなく、数ミリ秒ほど変化する。大気や海流、巨大地震、氷床融解による水の移動も自転速度を変えるが、数十年規模のゆっくりした変化には地球内部が関わる。</li>
<li>岩石質のマントルの下には、厚さ約2250キロの液体金属からなる外核があり、その流れが変わると地表側の回転もわずかに変わる。ただし核とマントルの摩擦は弱く、力をどう伝えるかが謎だった。</li>
<li>今週ネイチャーに掲載された研究は、内核の重力と核・マントル間の別の作用が互いに逆向きに働く「綱引き」を提案した。内核と地球のほかの部分は同じ速さで回らず、マントル内の質量の偏りとの位置が少しずれる。重力は両者を整列させようとする。</li>
<li>研究チームは1964年から2019年までの内核の回転推定と、外核の液体金属の流れのモデルを組み合わせた。モデルは実際に観測された緩やかな自転変化の時期と大きさをよく再現したが、未知の要因は残る。地上の時計が刻む一秒の下で、地球全体は何十年もかけて姿勢を直している。</li>
<li>出典: <a href="https://www.wired.com/story/gravitational-struggle-deep-in-earth-is-changing-length-of-days/">WIRED</a></li>
</ul>
<h2>まとめ</h2>
<ul>
<li>ミューズは複雑な人工知能をぬいぐるみの姿にし、タックはタブ管理を眠るフクロウにし、地球科学者は見えない重力作用を綱引きとして捉えた。</li>
<li>親しみやすい姿や比喩は、難しい仕組みへの入口になる。ただしミューズではデータ利用、タックでは端末間の制約、地球の自転では未知の力が、かわいい説明の外側に残っている。</li>
</ul>
