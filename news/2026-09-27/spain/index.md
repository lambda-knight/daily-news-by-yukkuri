<h1>スペイン文化・フラメンコ便り（2026年9月27日）</h1>
<h2>オープニング：2026年9月27日 — スペイン文化・フラメンコ便り</h2>
<ul>
<li>住宅をめぐる広場の抗議とサン・セバスティアン映画祭を短く押さえ、後半はマドリードの若手公演、ギター、踊り、歌、そして古いパロ「カーニャ」を掘り下げる。</li>
<li>今日の軸は「型を守ることと、型の内側で声を変えること」。列伝はマノロ・サンルーカル、エバ・ジェルバブエナ、カルメン・リナーレスを取り上げる。</li>
</ul>
<h2>国際情勢（スペイン視点）</h2>
<ul>
<li>9月26日付エル・パイスは欧州23の急進右派政党を調べた研究を紹介した。移民抑制では接近する一方、ロシアとの距離、女性の権利、気候政策では割れている。スペインのボックスを一枚岩の「欧州右派」へ単純化できないことが具体的に示された。</li>
<li>スペインにとって対ロシア政策は、北東欧の陸上国とは安全保障上の距離が違う。一方、移民はカナリア諸島、セウタ、メリリャの受け入れ能力へ直結する。同じ政党群でも争点ごとに連合の形が変わる点が、欧州議会の採決を左右する。</li>
</ul>
<h2>スペイン国内ニュース</h2>
<ul>
<li>9月26日から27日にかけ、住宅費への抗議がマドリード中心部プエルタ・デル・ソルの占拠へ発展した。エル・パイスとエル・ムンドはいずれも、参加者が広場へ残り、住居を投資商品ではなく生活基盤として扱うよう求めたと伝えた。</li>
<li>政府内ではスマールが住宅政令を閣議で承認しなければ再び欠席する構えを示した。家主側には供給増で資産価値が下がることへの抵抗もある。日本の大都市と同じく、借り手の家賃負担と既存所有者の資産防衛が正面から衝突する。</li>
<li>同じ26日の反政府デモではボックスと国民党の距離も露出した。参加規模は5月の同種集会のおよそ半分と報じられ、右派結集の看板と、主導権争いの現実が一致していない。</li>
</ul>
<h2>文化・芸能ニュース</h2>
<ul>
<li>サン・セバスティアン国際映画祭で、スペイン人俳優ハビエル・カマラが助演部門の銀の貝殻賞を受賞した。本人は現在の充実を「終わってしまうのが怖くて口にするのがためらわれる」と語った。成功の誇示より、長い職業生活の不安を言葉にした点が印象的である。</li>
<li>観客賞はロス・ハビスの映画『La bola negra』へ贈られた。ロルカの未完の題材を起点に、同性愛嫌悪と複数世代の生を結ぶ作品で、古典を記念碑にせず現在の身体へ戻す仕事になった。</li>
<li>バンド、トリアナの創設者でギタリストのエドゥアルド・ロドリゲス・ロドウェイが81歳で死去した。フラメンコの旋法とプログレッシブ・ロックを結んだ同バンドは、アンダルシアの音を地域色に閉じ込めず、1970年代の若者文化へ渡した。</li>
<li>日本の伝統芸能が現代劇やロックと交わる時にも似た緊張がある。原型を壊したかではなく、拍、旋律、言葉のどの部分を残して新しい聴衆へ渡したかが評価の分かれ目になる。</li>
</ul>
<h2>フラメンコニュース</h2>
<ul>
<li>マドリードのコンデドゥケ文化センターでは「Trilogía flamenca」が組まれ、踊り、歌、ギターを別々の余興でなく、一つの舞台言語として提示する。都市の公共劇場がアンダルシア発祥の芸能を扱う時、国民文化としての普及と、土地の来歴を薄めない説明の両方が必要になる。</li>
<li>「Suma Flamenca Joven 2026」は若手の歌、ギター、舞踊へ独立した舞台を与える。巨匠の再演だけでなく、若手が同じコンパスへどんな間、身体、和声を持ち込むかを観客が比較できる仕組みである。</li>
<li>エヘア・デ・ロス・カバジェロス市はリカルド・フェルナンデス・デル・モラルの『Nuestro Flamenco』を案内した。一人でカンテとギターを担いながら舞踊も交える構成は、三部門が互いの合図をどう聞くかを可視化する。</li>
<li>アンダルシアの家庭やペーニャで育った実践をマドリードが「スペインの顔」として上演することには両義性がある。全国へ届く一方、ヘレス、セビリア、コルドバ、グラナダごとの語彙を均質化しない配慮が欠かせない。</li>
</ul>
<h2>フラメンコギタリスト列伝</h2>
<ul>
<li>今日の主役はマノロ・サンルーカル、本名マヌエル・ムニョス・アルカンタラ（1943年サンルーカル・デ・バラメダ生、2022年没）。父イシドロ・ムニョスから学び、少年期からペペ・マルチェーナの一座で伴奏経験を積んだ。</li>
<li>右手は親指の低音を旋律として前へ出し、アルペジオとラスゲアードの音量差で大きな弧を作る。左手ではフリジア系の終止へ開放弦や転調を差し込み、カンテの重さを失わず管弦楽的な色彩を広げた。</li>
<li>独奏家でありながら、歌のレトラが伸びる余白とバイレのジャマーダへ応答する感覚を保った。『Medea』や『Tauromagia』では、短い技巧の連結ではなく、人物や儀式をアルバム全体で描いた。</li>
<li>アンダルシアの公共放送が1992年に収録した<a href="https://www.youtube.com/watch?v=rI0rYaIC7aw">『Cuando se asoma el aire』</a>では、ギターの旋律に声や他の楽器が重なっていく箇所を聴きたい。速い音より、和音が消えるまで次を待つ時間に作曲家としての耳が表れる。</li>
<li>後進への影響は、伝統的なパロをクラシックの語法へ溶かすのでなく、コンパスを骨格にしたまま大きな形式へ育てた点にある。</li>
</ul>
<h2>フラメンコバイレ列伝</h2>
<ul>
<li>今日の主役はエバ・ジェルバブエナ（1970年フランクフルト生、グラナダ育ち）。11歳から踊りを学び、マリオ・マジャらに師事し、1998年に自らの舞踊団を設立した。</li>
<li>サパテアードは高速の連打を均一に並べず、踵の低い音、つま先の鋭い音、沈黙を組み合わせる。ブラソは大きな曲線を描きながらも肩と視線を固定せず、上半身の揺れが足のフレーズへ先行する。</li>
<li>1992年、コルドバの全国フラメンコ芸術コンクール決勝で踊った<a href="https://www.youtube.com/watch?v=bcC1CiSv1J0">ソレア</a>では、腕をゆっくり開いた後、足の細かな打音へ移る場面に注目したい。静止が途切れではなく、カンテとギターへ次の入口を渡す合図になっている。</li>
<li>日本舞踊の「間」と似て見えるが、フラメンコでは足音が合奏の打楽器でもある。ジェルバブエナは沈黙から一打目へ移る重さによって、悲嘆を表情だけでなく時間として作る。</li>
</ul>
<h2>フラメンコカンテ列伝</h2>
<ul>
<li>今日の主役はカルメン・リナーレス、本名カルメン・パチェコ・ロドリゲス（1951年ハエン県リナーレス生）。マドリードのタブラオで経験を積み、女性歌手が限られた型だけを求められた時代に、広いパロと詩作品へ声を開いた。</li>
<li>声は明るい金属的な芯を持ち、子音を明瞭に置いた後、母音を細く長く伸ばす。ソレアやシギリージャの深さに加え、ファリャやロルカの作品でも、詩の言葉を旋律へ埋没させない。</li>
<li>スペイン公共放送の<a href="https://www.rtve.es/play/videos/caminos-del-flamenco/gran-carmen-linares-directo/6307936/">『Caminos del flamenco — Carmen Linares』</a>では、言葉を明瞭に立てた直後に声量を落とし、ギターへ余韻を渡す箇所を聴きたい。強声だけでなく、言葉が聞こえる弱音が個性である。</li>
<li>女性のカンテを装飾的な役割へ限定せず、詩、劇場、録音を横断するレパートリーへ広げたことが後進への大きな遺産になった。</li>
</ul>
<h2>フラメンコギター工房だより</h2>
<ul>
<li>全履歴の個人工房との重複を避け、今日は未紹介の周辺テーマとして、マドリードの王立音楽院などに残る歴史的ギターの保存・修復を見る。修復は新作製作と違い、割れや浮いた力木を直しながら、元の板厚、ニス、ラベルを必要以上に置き換えない判断が中心になる。</li>
<li>古いフラメンコギターは軽い表板、低い弦高、演奏による摩耗が音と来歴の両方を伝える。新品同様へ磨けば、ゴルペの跡や過去の調整まで消える。日本の古楽器修復と同じく、弾ける状態と資料性の均衡が問われる。</li>
<li>カンテやバイレを支えた楽器は、単なる木工品ではない。どの弦高でラスゲアードが分離し、どの修理が音の立ち上がりを変えたかを記録することが、演奏史を次世代へ渡す仕事になる。</li>
</ul>
<h2>フラメンコのパロ解説</h2>
<ul>
<li>今日のパロはカーニャ。19世紀初頭までに記録が見られる古いカンテで、ポロと近縁である。起源を一人へ帰す説は確定しておらず、アンダルシアで複数の歌唱伝統が交わったとみるのが安全である。</li>
<li>重厚で儀式的な性格を持ち、レトラの間に「アイ」という長い嘆声を挟む型が特徴である。現代ではバイレを伴うこともあり、ブラソの長い線とサパテアードが、歌の伸びた母音と十二拍の締めを結ぶ。</li>
<li>コンパスはソレア系の十二拍で、三、六、八、十、十二付近の重みを感じる。ギターはファルセータで歌の入口を示し、ラスゲアードを埋め尽くさず、嘆声が拍をまたぐ余白を残す。</li>
<li>和声はEを主音とするフリジア系なら、Aマイナー、G、F、Eへ下るアンダルシア終止が基本になる。カポタストで高さは変わっても、終止へ向かう引力とコンパスの配置は保たれる。</li>
<li>エンリケ・モレンテが1994年に歌った<a href="https://www.youtube.com/watch?v=BbhK0oZC9Yw">カーニャ「A mí me pueden mandar」</a>では、歌の嘆声をギターが急いで塞がない場面に注目したい。ポロとの近さは説明だけでなく、ソレア族の十二拍として聴き比べると分かりやすい。</li>
</ul>
<h2>まとめ</h2>
<ul>
<li>2026年9月27日は、広場では住まいを誰のために使うかが問われ、映画とフラメンコでは古い型を誰の現在へ渡すかが問われた。</li>
<li>サンルーカル、ジェルバブエナ、リナーレス、カーニャを結ぶのは、型を壊さず、沈黙、言葉、身体の置き方で新しい声を作る技術である。</li>
</ul>
