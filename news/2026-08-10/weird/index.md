<h2>ネタ1 97歳、脳卒中1年後にウイングウォーク世界記録を更新</h2>
<ul>
<li>英国チェルトナム在住のベティ・ブロメイジさん（97歳）が、複葉機の翼の上に立って飛ぶ「ウイングウォーク」に挑戦し、自身が持つ「最高齢の女性ウイングウォーカー」のギネス世界記録を更新した。</li>
<li>記録達成は2026年8月4日（火曜）、97歳127日での挑戦。前回の自己記録は2022年、93歳のときに樹立していた。</li>
<li>2025年8月に脳卒中を発症し、現在も言語に影響が残る中での挑戦。飛行はチェルトナム総合病院の脳卒中治療病棟への寄付を集めるチャリティーを兼ねる。</li>
<li>本人はBBCの取材に「そうしないと人生に飽きてしまう。運転もできないし、目もあまり見えなくて、もどかしくなる。だからできることをやりたいの」と語った。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/08/05/Guinness-World-Records-oldest-wing-walker-female/1651785946981/">UPI Odd News</a></li>
</ul>
<h2>ネタ2 9万個のアヒルがシカゴ川に「大量投入」チャリティー大会</h2>
<ul>
<li>米シカゴで木曜日、9万個の黄色いゴムアヒルを積んだトラックが半分持ち上がった橋の上からアヒルを川へ一斉に投入し、恒例の「シカゴ・ダッキー・ダービー」が開催された。</li>
<li>主催は「スペシャルオリンピックス・イリノイ」で、障害のある人向けの競技会を支援するチャリティーイベント。これまでの累計寄付額は48万ドルを超えている。</li>
<li>アヒルたちは高層ビルが立ち並ぶ川面を約15分間漂い、その後1位・2位のアヒルが引き上げられた。</li>
<li>1位のアヒルを購入していたスポンサーにはSUV1台、2位には現金2,500ドルが贈られる仕組み。</li>
<li>出典: <a href="https://www.irishnews.com/news/world/90000-rubber-ducks-splash-into-chicago-river-for-ducky-derby-fundraiser-3G62ZH2EBFJ4RIQ4ILWEFNNPT4/">Irish News</a></li>
</ul>
<h2>ネタ3 マヨネーズの瓶が頭から取れない浣熊「マヨネサ」救出</h2>
<ul>
<li>米テキサス州ダラスの住宅街で、頭にマヨネーズの空き瓶をすっぽりかぶったまま数日間さまよっていた浣熊が地元住民の間で目撃され続けた。</li>
<li>浣熊には「マヨネサ」という愛称がつけられたが、捕獲を何度も逃れ続けていた。</li>
<li>月曜朝、ダラス動物管理局の職員2人が空き家近くの木の上にいるマヨネサを発見し、木を下りてきたところを背後から確保した。</li>
<li>保護後は施設で鎮静・水分補給の処置を受けて瓶を外され、数日間の脱水以外は元気な状態だったという。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/08/07/raccoon-mayonaisse-jar-Dallas-texas/6681786113237/">UPI Odd News</a></li>
</ul>
<h2>ネタ4 スパイダーマン上映中に強烈な臭い、コロンビアの映画館が緊急避難</h2>
<ul>
<li>コロンビアの複合商業施設プラザ・ボカグランデ内「シネ・コロンビア」で8月2日、映画「スパイダーマン：ブランニュー・デイ」の上映が上映開始からほぼ半分を過ぎたところで中断された。</li>
<li>場内に強烈な、おなら臭に例えられる悪臭が充満し、観客が一斉にロビーへ避難する事態になった。</li>
<li>原因は特定されておらず、体調不良による大量のガスとも、いたずら用の「臭い玉」爆発とも噂されているが、犯人は今も分かっていない。</li>
<li>劇場側は上映自体は中止せず続行したが、避難した観客の多くは戻らなかった。避難の様子を映した映像には、スパイダーマンの仮装をした客も映り込んでいた。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/08/04/colombia-Spider-Man-cinema-evacuated-fart-smell/5831785867630/">UPI Odd News</a></li>
</ul>
<h2>ネタ5 10歳で大学、18歳で最年少教授 — 306年ぶりの記録更新</h2>
<ul>
<li>米フロリダ州のネイサン・トーマスさんは10歳でマイアミ・デイド・カレッジに入学、14歳でフロリダ国際大学に編入し、18歳で電気工学の修士号を取得した。</li>
<li>18歳346日でマイアミ・デイド・カレッジの教員となり、ギネス世界記録の「史上最年少の男性教授」に認定された。この記録は306年前に19歳で教授になったコリン・マクローリン氏が保持していたもの。</li>
<li>現在21歳になった同氏は、オンライン授業で教える傍ら、マイアミ大学ロースクールで法務博士号の取得を目指している。</li>
<li>出典: <a href="https://www.guinnessworldrecords.com/news/2026/7/18-year-old-becomes-youngest-professor-ever-teaches-engineering-to-students-his-own-age">Guinness World Records</a></li>
</ul>
