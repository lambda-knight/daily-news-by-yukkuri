<h1>世界の珍ニュース（2026年9月23日）</h1>
<h2>オープニング：2026年9月23日 — 世界の珍ニュース</h2>
<p>爪でそっと引っ掻かれるためだけに客が並ぶ中国シェンチェンのサロン、95歳のウィリアム・シャトナーが結成したメタルバンドのメタリカ・カバー、アヒルの鳴き声をそのまま五線譜に書き起こした作曲家、そして278時間かけて2000個のビー玉が鐘やドラムを叩き続ける巨大装置。今回は「くすぐったさ」「年齢」「音」「執念」がそれぞれ主役の四題を追う。</p>
<h2>「マッサージより癒やされる」、爪でそっと引っ掻く"スクラッチングサロン"が中国で拡大</h2>
<ul>
<li>中国{深圳|シェンチェン}市{宝安区|ホウアンく}で、32歳の起業家{張暁超|チャン・シャオチャオ}氏が2026年5月、客が仰向けに寝転び、先端の丸いプラスチック製の付け爪を着けたスタッフに全身をそっと引っ掻いてもらう「スクラッチングサロン」を開業した。</li>
<li>きっかけは、妻が夫の背中を引っ掻く動画をネットで見た際、「こういうサービスにお金を払ってもいい」というコメントが多数付いていたのを目にしたこと。張氏自身も子どものころ、父親に背中を引っ掻かれながら眠りにつくのが好きだったという。</li>
<li>料金は1時間300元（約41ドル）で、現在2店舗を運営し、月商は約10万元（約15000ドル）に達している。</li>
<li>張氏は「大都市の人々はストレスが強く、この種のサービスへの需要は強い」と述べており、全国で100店舗の新規出店を計画している。</li>
<li>出典: <a href="https://www.odditycentral.com/news/entrepreneur-opens-unique-salons-where-customers-relax-by-being-gently-scratched.html">Oddity Central</a></li>
</ul>
<h2>95歳ウィリアム・シャトナー、自身のメタルバンドでメタリカ「エンター・サンドマン」をカバー</h2>
<ul>
<li>米俳優{ウィリアム・シャトナー|シャトナー}氏（95）は2026年9月20日、シカゴで開催された音楽フェス「{ライオット・フェスト|ライオットフェスト}2026」に、自ら率いるヘビーメタルバンド「{ザ・アッカーズ|The *uckers}」で出演し、メタリカの「{エンター・サンドマン|Enter Sandman}」をカバーした。</li>
<li>バンドにはギター兼音楽監督の{マーカス・ナンド|ナンド}氏、女性ギタリストの{ブリット・ライトニング|ライトニング}氏、元オジー・オズボーンのベーシスト{フィル・スーサン|スーサン}氏など、ベテラン音楽家がそろう。</li>
<li>この日はメタリカのほか、オジー・オズボーンやモーターヘッドの楽曲もカバーし、90代の俳優がヘビーメタルのステージに立つという珍しい光景がフェスの話題を集めた。</li>
<li>出典: <a href="https://laughingsquid.com/william-shatner-enter-sandman-riot-fest/">Laughing Squid</a></li>
</ul>
<h2>アヒルの「クワッ」をそのまま五線譜に、作曲家が鳴き声を楽曲化</h2>
<ul>
<li>作曲家{ツーチン・シュー|シュー}氏は、オーストラリア東海岸の{バンジャルン・カントリー|バンジャルンカントリー}にある牧場「{マザー・ザ・マウンテン・ファーム|マザーザマウンテンファーム}」で飼われているアヒル「{ハッピー|Happy}」の鳴き声を採取し、そのまま音符に書き起こして五線譜に仕立てた。</li>
<li>シュー氏は「アヒルの鳴き声を聞いたら、書き起こさずにはいられなかった」と、プロジェクトの動機を率直に語っている。</li>
<li>野鳥の声を採譜して自作曲に取り込む作曲家{アレクサンダー・リーバーマン|リーバーマン}氏の活動から着想を得たといい、完成した楽譜と音声はInstagramのリール動画で公開された。</li>
<li>出典: <a href="https://laughingsquid.com/transcribing-duck-sounds/">Laughing Squid</a></li>
</ul>
<h2>ビー玉2000個、鐘128個、製作278時間の巨大からくり楽器「カコフォニー」</h2>
<ul>
<li>オランダのビー玉アーティスト{イェレ・バッカー|バッカー}氏は2026年9月、2000個のビー玉と128個の鐘・チャイム、複数のドラム、じょうご、バネ、釘、木の棒などを組み合わせた巨大な音響装置「{カコフォニー|Cacophony}」を発表した。</li>
<li>ビー玉は1000個用と200個用の2つのダンプスター型容器に収められており、木製のキャビネット全体が共鳴箱として音を増幅する構造になっている。</li>
<li>バッカー氏は「{ジェルズ・マーブル・ランズ|Jelle's Marble Runs}」の運営者で、砂の上でビー玉を走らせるイベント「マーブル・ラリー」の主催者としても知られる。今回の装置は主に端材と過去の作品の再利用パーツを使い、278時間かけて製作された。</li>
<li>出典: <a href="https://laughingsquid.com/cacophony-marble-machine/">Laughing Squid</a></li>
</ul>
