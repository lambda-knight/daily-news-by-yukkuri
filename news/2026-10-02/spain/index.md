<h1>スペイン文化・フラメンコ便り（2026年10月2日）</h1>
<h2>オープニング：2026年10月2日 — スペイン文化・フラメンコ便り</h2>
<ul>
<li>今日のスペイン語は「ブエン・プロベチョ（Buen provecho）」。食事を楽しんで、という意味で、食卓を囲む相手へ気軽に贈る言葉。</li>
<li>主役は、ギタリストのビセンテ・アミーゴ、舞踊家ロシオ・モリーナ、歌い手ドゥケンデ、そして鍛冶場の歌マルティネーテ。いずれも伝統を保存箱に入れず、身体と音の現在形へ変える人々である。</li>
</ul>
<h2>国際情勢（スペイン視点）</h2>
<ul>
<li>9月30日、ロシアがバルト海情勢をめぐり北大西洋条約機構諸国へ核兵器使用の可能性を示したと、エル・パイスとエル・ムンドが報じた。スペインは北大西洋条約機構加盟国で、ロタ海軍基地とモロン空軍基地を抱えるため、北東欧の威嚇も遠い地域ニュースではない。</li>
<li>左派紙が欧州の結束と抑止の危険な連鎖を前面に置く一方、右派紙は同盟国への直接的な脅迫という見出しを選んだ。フランコ独裁後の民主化を欧州統合と結びつけてきたスペインでは、欧州への攻撃は自由な政治秩序への圧力としても読まれる。</li>
</ul>
<h2>スペイン国内ニュース</h2>
<ul>
<li>住宅緊急政令をめぐる採決が10月2日に迫った。政府は脆弱な世帯の立ち退き保護を2030年まで延長し、一部賃貸契約の2年延長などを提案する。与党側は投資ファンドへの対抗策と説明し、人民党は家主の負担が供給を減らすと批判した。</li>
<li>発端の一つは87歳のマリカルメンさんの立ち退きである。個人の物語が広場の野営と議会日程を動かす点は、制度改正をまず当事者の顔から語るスペインらしい。日本の住宅政策が統計や制度名から語られがちなのに対し、スペインでは街頭の名前が政治の速度を変える。</li>
</ul>
<h2>文化・芸能ニュース</h2>
<ul>
<li>映画監督ペドロ・アルモドバルと作家ハビエル・セルカスがフランスのレジオン・ドヌール勲章を受ける。映画と文学という別の領域で、スペイン内戦、記憶、欲望を国外の観客へ翻訳してきた二人が同時に評価された。</li>
<li>彫刻家ジャウメ・プレンサは、詩人ジョアン・マルガリットを記念する「本の彫刻」を制作した。カタルーニャ語とスペイン語の二言語で書いた詩人を、読む物と見る物の境界に置く試みである。地方語を地域内へ閉じ込めず公共空間へ出す姿勢は、方言文学を地域文化として扱いがちな日本との違いを映す。</li>
<li>カルタヘナ出身のロックバンド、アルデ・ボゴタは、急速な成功を「ノーラン映画の脚本のよう」と語った。ツアーと創作の速度が上がるほど、地元のバンドとして築いた合奏をどう保つかが仕事になる。</li>
</ul>
<h2>フラメンコニュース</h2>
<ul>
<li>マドリードのコンデドゥケ文化センターには「フラメンコ三部作」が登場し、カンテ、ギター、バイレを別々の見世物でなく一つの舞台言語として組み直す。三本柱を同格に置く企画は、スター一人の公演とは違い、相互に合図を読む芸術だと示す。</li>
<li>パンプローナ市はフラメンコ・オン・ファイアとの協働で、エル・ペレの市庁舎バルコニー公演、二つのコンサート、未成年向けのギターと舞踊の講座を組んだ。劇場の切符だけでなく、広場と教室へ入口を増やす施策である。</li>
<li>マドリードのスマ・フラメンカ・ホベンは若手を主役に据える。フラメンコがアンダルシアの記憶に根を持つ一方、首都の公的舞台が次世代の職業経路を作る。その支援は全国化の利点であり、土地の名を消して「スペイン一般」の商品にしない配慮も必要になる。</li>
<li>アンダルシアの側から見れば、セビリア、ヘレス、グラナダ、コルドバの家族・地区・祭りが育てた様式である。マドリードが国の顔として提示するとき、出演者の出身、師、パロの土地を明記することが文化の中心と周縁を平らにしない最低条件になる。</li>
</ul>
<h2>フラメンコギタリスト列伝</h2>
<ul>
<li>ビセンテ・アミーゴは1967年、セビリア県グアダルカナルに生まれ、コルドバで育った。幼い頃からギターを学び、エル・トマテ、メレンゲ・デ・コルドバを経て、マノロ・サンルーカルのもとで長く演奏した。独奏以前に伴奏の呼吸を身につけ、カマロン・デ・ラ・イスラやホセ・メルセの録音にも関わった。</li>
<li>1991年の初アルバム『デ・ミ・コラソン・アル・アイレ』以後、旋律を長く歌わせる作曲と、速いピカードを音量の誇示にせずフレーズの頂点へ置く設計で独自の位置を得た。右手はラスゲアードの密度を急に変え、左手はポジション移動を滑らかにつないで、ギターがカンテの息を模倣するような線を作る。</li>
<li>マノロ・サンルーカルから受けたのは技巧だけではない。パロの語法を踏まえたうえで、管弦楽や異文化の楽器と組む構成法である。1997年の『ポエタ』ではラファエル・アルベルティの詩世界を管弦楽とギターで描き、2002年には『シウダ・デ・ラス・イデアス』でラテン・グラミーを受賞した。</li>
<li>伴奏では、歌い手の句末へ和音をかぶせず、息が落ちる場所を待って短い応答を置く。バイレには低音とゴルペで床の重心を示し、独奏では同じ伴奏感覚を内声へ移す。華やかな高音の背後で低音が別の旋律を保つため、独奏でも複数の演者がいるように聞こえる。</li>
<li>2013年のアルバムではスコットランドやアイルランドの音楽家と録音した。公式映像『<a href="https://www.youtube.com/watch?v=0JiWWNwh8Jc">Tierra</a>』では、冒頭の細いギターの旋律が歌へ受け渡され、低音楽器と打楽器が加わってもギターが音数で競わない点を聴きたい。フラメンコのアクセントを保ったまま、ケルト系の持続音が作る広い空間へ旋律を伸ばしている。</li>
<li>2024年の『アンデネス・デル・ティエンポ』まで、彼は「融合」を異質な音の展示にせず、旋律がどこへ帰るかという作曲の問題として扱ってきた。後進への影響は、速く弾くことより、伴奏の耳を持った独奏者という像にある。</li>
</ul>
<h2>フラメンコバイレ列伝</h2>
<ul>
<li>ロシオ・モリーナは1984年、マラガ生まれ。3歳で踊り始め、マドリード王立舞踊専門学校を2002年に卒業した。若くしてマリア・パヘス舞踊団に参加し、2010年に国家舞踊賞を受けた。</li>
<li>伝統的な女性像に収まらず、長い衣装、裸足、男性的とされた直線的な足技を作品ごとに組み替える。サパテアードは速さより音色の差が重要で、踵、つま先、足裏を使い分ける。ブラソは装飾として腕を流すのでなく、胴体の向きを遮る壁や、次の動きを切り開く線になる。</li>
<li>代表作『カイーダ・デル・シエロ』や『カウティバ』では、身体を美しい型へ回収せず、疲労、呼吸、床との摩擦まで舞台の材料にする。ギターやカンテを従属させるのでなく、演奏者の選択が踊りの予定を変える余白を残す。</li>
<li>セビリア市が公開した『<a href="https://www.youtube.com/watch?v=JoPzEBuEZ_A">ビエナルのリタ・カベユートとのパフォーマンス</a>』では、画家の身体とキャンバス、フアナ・ラ・デル・ピパの声へ踊りが反応する。足数を数えるより、静止した背中がカンテの一声でほどけ、腕が絵の線を横切る瞬間を見ると、即興が対話であることが分かる。</li>
<li>モリーナの革新は伝統の否定ではない。コンパスを身体の内側へ深く入れたからこそ、衣装や性別役割を外してもフラメンコとして緊張が残る。日本舞踊で型を身につけた踊り手が現代舞台へ進む場合と同じく、壊しているように見える部分ほど基礎の強さが問われる。</li>
</ul>
<h2>フラメンコカンテ列伝</h2>
<ul>
<li>ドゥケンデ、本名フアン・ラファエル・コルテス・サンティアゴは1965年、バルセロナ近郊サバデルのヒターノ家庭に生まれた。幼少期にカマロン・デ・ラ・イスラに見いだされた逸話で知られ、カタルーニャで育ちながらアンダルシアのカンテを家庭と共同体から学んだ。</li>
<li>声はざらついた高音と、句末で急に暗くなる母音が特徴である。ソレアでは旋律を急がず、レトラの最後を細く落とす。ブレリアでは子音を拍へ鋭く置き、ギターの合図に遅れて入ることで、後ろへ引っ張るような緊張を作る。</li>
<li>パコ・デ・ルシアのグループで長く歌い、トマティート、チクエロらとも共演した。器楽的に複雑な編成でも、カンテを音量で押し出さず、一声で調性と情感の中心を戻す役割を担った。</li>
<li>国立音楽普及センターの公演資料は、本人の言葉「フラメンコは生き方であり、肺であり、鼓動する心だ」を紹介する。アルバム『ミ・フォルマ・デ・ビビール』にはタンゴ、アレグリアス、ソレア、ブレリア、マルティネーテが並び、パロごとに発声の圧力を変える幅が分かる。</li>
<li>鑑賞には公的音楽機関の公演資料『<a href="https://cndm.inaem.gob.es/sites/default/files/events/hand_programs/duquende_chicuelo_cndm1516.pdf">ドゥケンデとチクエロ—歌の魔法</a>』を添える。掲載された演目と経歴を手掛かりに、ギターの短い合図のあと、ドゥケンデが息を多く含む声で入り、句末だけ金属的な芯を残す対照へ耳を向けたい。</li>
<li>カタルーニャ生まれの歌い手がパコの国際舞台で中心を担った事実は、フラメンコを出生地だけで区切れないことを示す。同時に、家庭で受け継いだヒターノの歌とアンダルシアのパロの名を消さないことが、その越境を薄い混合にしない。</li>
</ul>
<h2>フラメンコギター工房だより</h2>
<ul>
<li>今日のテーマはセビリア近郊ヘルベスにあるアンダルシア州立の弦楽器製作訓練。過去の工房履歴と照合し、特定の既出工房の再紹介ではなく、職人を育てる公的教育へ焦点を移した。</li>
<li>訓練では図面を読むだけでなく、木材の選別、表面板と裏板の厚み、ネックの接合、力木、塗装、弦高調整までを一つの工程として扱う。ギターは部品の規格品を組むだけでは完成せず、木の剛性に応じて削る量を変える判断が必要になる。</li>
<li>フラメンコ用では、舞踊の足音やパルマの中で立ち上がる速い反応、演奏者の右手を妨げない弦高が求められる。クラシック用より軽い構成や糸杉の側・裏板が典型とされるが、材料名だけで音は決まらず、表面板と力木、重量配分、奏者の調整が一体になる。</li>
<li>公式の『<a href="https://90aa749c-1d31-4441-9565-fc9d46792741.filesusr.com/ugd/dd0035_b2945632e8f74b58acc930f80d1e6cd8.pdf">2026年弦楽器製作講座資料</a>』には材料、工具、ギター部品を扱うカリキュラムが示される。完成品のブランドだけでなく、修理と調整を地域に残す教育基盤を見る資料である。</li>
<li>スペインのアルテサニアと日本のものづくりは、完成品より手の判断を重んじる点で近い。違いは、ヘルベスではカンテ、バイレ、パルマと同じ生活圏で楽器の反応を試せることだ。工房教育は雇用政策であると同時に、伴奏文化のインフラでもある。</li>
</ul>
<h2>フラメンコのパロ解説</h2>
<ul>
<li>今日のパロはマルティネーテ。アンダルシア・フラメンコ研究所は、カディスとセビリアに由来し、鍛冶場または鉄工所に起源を持つ可能性が高いと説明する。トナーの一種で、カルセレーラ、デブラと近縁だが、成立を単一の職人歌へ断定することはできない。</li>
<li>レトラは一般に8音節4行。悲しみ、迫害、牢獄、労働が題材になり、長くギターを伴わず歌われた。金床を槌で打つ音を添える上演はあるが、それは和音伴奏ではなく、声の時間を区切る金属音である。</li>
<li>自由リズムのカンテとして歌われ、ブレリアのような循環コンパスを常に刻まない。舞踊化するときはシギリージャ系の重い十二拍へ整理する場合があり、自由な歌と振付の拍を同一視しないことが重要である。</li>
<li>ギターを伴わないため、典型的なコード進行はない。歌手は一定の和音に拘束されず、旋律の終わりで長調側の響きへ着地する型がある。舞台でギターが加わる場合も、イー・フリジアンなどの和音は演出上の枠で、古い無伴奏形の必須条件ではない。</li>
<li>アンダルシア州のマルティネーテ解説では、無伴奏の声と金床の打音が要点になる。声が拍へ従うのでなく、長い母音の終わりを槌音が受けるため、沈黙も一つの音として働く。</li>
<li>舞踊の理解にはスペイン国営放送の『<a href="https://www.rtve.es/play/audios/a-compas/compas-aula-flamenco-martinete-211119/5450129/">フラメンコ教室—マルティネーテ</a>』が役立つ。ダニエル・ドーニャの説明では、自由なカンテを舞台の身体へ移すとき、足技が単なる打楽器でなく、鍛冶の記憶を引き受けることが聞き取れる。</li>
</ul>
<h2>まとめ</h2>
<ul>
<li>2026年10月2日のスペインは、住宅と欧州安全保障の緊張を短く押さえつつ、文化の中心を「受け継いだ型をどう現在の身体へ渡すか」に置いた。ビセンテ・アミーゴの旋律、ロシオ・モリーナの身体、ドゥケンデの声、マルティネーテの槌音は、変化と継承が反対語ではないことを示す。</li>
</ul>
