<h2>オープニング：2026年10月2日 — 世界の珍ニュース</h2>
<p>東京では、2階建てバスの2階に回転寿司のレーンを載せた「SUSHI BUS」が9月30日に予約受付を始め、10月10日から街を走る。米マサチューセッツ州では、頭が2つあるダイヤモンドガメの赤ちゃんが保護され、2つの頭がそろって餌を食べようとしている。英国カンブリアの「クラブ・フェア」では、馬の首輪から顔を出して変顔を競う世界大会で、41年前にジュニア部門で優勝した男性がついに大人の部門の頂点に立った。ローマでは、バチカンのそばの庭の下から、千年以上前にイングランドから来た人々の小銭20枚が見つかった。今回は、ひとつの体に2つの頭、走る車に厨房とレーン、千年前の外国人街に母国のお金――「ありえない組み合わせ」が実際に成り立っている4つの話をたどる。</p>
<h2>走る回転寿司「SUSHI BUS」、10月10日から東京駅前を発着</h2>
<ul>
<li>株式会社SUSHI BUS（東京都台東区、代表・矢野智之氏、2026年5月設立）は9月30日、2階建てオープントップバスの2階に回転寿司レーンを設けた「SUSHI BUS」を10月10日から運行すると発表し、同日15時に予約受付を始めた。2階建てレストランバスを持つWILLER ACROSS（ウィラー・アクロス）が車両を貸し出し、施工も担う。</li>
<li>発着は東京駅から徒歩3〜5分の鍛冶橋駐車場。1便約70分で、1日5便（11時、13時、15時、17時、19時発）。定員は2階席の20席だけで、年間の最大席数は「20席×5回転×365日」の3万6500席。</li>
<li>料金は1人1万6000円で、寿司は食べ放題、飲み物付き。車両は全長約12メートル、高さ約4メートルで、1号車の愛称は「マグロ号」。走行速度は時速約30キロ。</li>
<li>寿司は1階のキッチンで握り、車内のエレベーターで2階へ上げ、スタッフがレーンに流す。ネタは豊洲市場の仲卸業者と提携して10〜15種類を用意し、中トロは1貫12グラムと通常の回転寿司の約1.5倍にした。</li>
<li>急ブレーキで皿が落ちないかを100回以上試験したとしている。雨の日は透明な屋根が自動で閉まり、運行を続ける。</li>
<li>矢野代表は「この2年半もの間、大の大人たちが誰もやったことがない企画実現に向け、まるで童心に帰ったようにSUSHI BUSに熱中してきました」とコメントした。主な対象は訪日外国人観光客で、夜の観光の選択肢としても期待されている。</li>

</ul>
<h2>頭が2つあるダイヤモンドガメの赤ちゃん、ケープコッドで保護</h2>
<ul>
<li>米マサチューセッツ州ケープコッドのウェルフリートにある保護された産卵地で、頭が2つあるダイヤモンドガメ（キスイガメ）の赤ちゃんがふ化した。マサチューセッツ・オーデュボン協会のウェルフリート湾野生生物保護区が見つけ、バーンスタブルの「ケープ野生動物センター」へ運んだ。センターが9月下旬に公表し、UPIが10月1日に伝えた。</li>
<li>体重は5セント硬貨（約5グラム）ほど。性別はまだ分からない。</li>
<li>1つの体から、独立して機能する2つの頭が育つ「二頭体（にとうたい）」と呼ばれるまれな発生異常。2つの頭はどちらも反応がよく、周りを見回し、餌を出すとどちらも食べようとする。</li>
<li>運営団体ニューイングランド野生動物センターのザック・マーツ最高経営責任者は「双子になるように胚が分かれかけて、分かれきらなかったときに起きる。体の重なり方は1例ごとに少しずつ違う」と説明した。</li>
<li>センターがこうした二頭体の個体を扱うのは過去5〜6年で3例目。職員は食欲・成長・行動を見守り、2つの頭と体がどう連携しているかを調べるため、詳しい画像検査を予定している。野生へ戻すかどうかは検査結果を見て決める。</li>
<li>センターは「この珍しい状態は以前にも見てきたが、1例ごとに、この動物の体のつくりと働きを学ぶ機会になる」としている。</li>
<li>ダイヤモンドガメはマサチューセッツ州の絶滅危惧種法で「絶滅危惧（Threatened）」に指定され、連邦レベルでも保全上の位置付けが見直し中。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/10/01/diamondback-terrapin-two-heads-Cape-wildlife-center/4871790869105/">UPI</a> / <a href="https://www.popsci.com/environment/tiny-two-headed-turtle-found-in-cape-cod/">Popular Science</a> / <a href="https://www.wtap.com/2026/09/30/rare-two-headed-turtle-hatchling-found-cape-cod/">WTAP（CNN Newsource）</a></li>
</ul>
<h2>馬の首輪から変顔、41年越しの世界チャンピオン</h2>
<ul>
<li>英イングランド北西部カンブリア州エグレモントで9月19日に開かれた「エグレモント・クラブ・フェア」の「世界ガーニング選手権」で、地元のゲッド・エクルズさんが男子の部で優勝した。ガーニングは、馬の首輪（地元の言葉で「ブラフィン」）に頭を通して、いちばん醜い、グロテスクな顔を作った人が勝つ競技。</li>
<li>エクルズさんは1985年にジュニア部門で優勝して以来、大人の部門では2009年と2016年に3位、2023年に2位と、何十年も挑戦を続けてきた。今年は5月から毎日3〜4時間、鏡の前で練習し、首・頬骨・あごの筋肉をほぐして「下唇を鼻まで上げる」技で頂点に立った。</li>
<li>本人は「最高の気分。何年も何年も挑戦してきたから、ついに取れたのは信じられない」と話し、来年の防衛を目指すという。</li>
<li>2位は、地元でテレビドラマを撮影していた俳優ウィル・メラーさん（「ホリーオークス」「ミスター・ベイツ対郵便局」などに出演）で、共演者のラルフ・リトルさんとともに飛び入りで参加した。女子の部は9回目の優勝となるクレア・リスターさんが王座を奪還し、ジュニアの部はボビー・ドナルドさんが制した。出場は3部門で約50人、観客は約800人（BBC）。</li>
<li>フェアは1267年、ヘンリー3世が勅許状を与えた収穫祭が起源で、今年が759回目。領主が町の人へ酸っぱいクラブアップル（野生のリンゴ）を配った習慣が名前の由来で、今もメインストリートで荷車からリンゴを投げる。変顔の競技は1852年の地元紙に「タバコをかけたにらめっこ」として記録が残る。ほかに、ラードを塗った約9メートルの柱を登る「グリーシー・ポール」、粘土のパイプでのたばこ吸い、方言の歌、猟犬の追跡レースなども続く。</li>
<li>出典: <a href="https://ca.style.yahoo.com/actor-mellors-gurning-beaten-local-052042446.html">BBC（Yahoo転載）</a> / <a href="https://uk.news.yahoo.com/ged-eccles-crowned-world-gurning-040000233.html">News and Star（Yahoo News UK転載）</a> / <a href="https://www.egremontcrabfair.com/history.html">Egremont Crab Fair 公式（歴史）</a></li>
</ul>
<h2>バチカンの庭の下から千年前の「英国人街」の小銭、ローマで20枚</h2>
<ul>
<li>ローマのバチカン近く、パラッツォ・デッラ・ローヴェレの庭の下を2020年から発掘している調査で、10世紀のアングロ・サクソン（中世イングランド）の硬貨20枚が見つかった。内訳は銀のペニー19枚と半ペニー1枚。研究成果は論集『ローマと他者たち（300〜1000年）』に発表され、9月30日〜10月1日に各国の科学メディアが伝えた。同じ発掘地は、2023年に皇帝ネロの劇場跡が見つかった場所でもある。</li>
<li>硬貨は、アルフレッド大王の息子エドワード長兄王（在位899〜924年）と、その孫のエゼルスタン王（924〜939年）、エアドレッド王（946〜955年）の名で、約40年の間に鋳造された。造られた場所はイースト・アングリア、ケント、ロンドン、ウェスト・ミッドランズとイングランド各地にわたる。14枚はゴミ捨て穴の中で6枚と8枚の2つの塊に固着して見つかった。</li>
<li>この一帯には8世紀後半から、サン・ピエトロ大聖堂とテベレ川の間に「スコラ・サクソヌム」と呼ばれるイングランド人の居住区があった。文献に初めて現れるのは799年。教皇マリヌス1世は、アルフレッド大王の求めに応じてこの居住区を「あらゆる貢納と通行税から」免除した。</li>
<li>中世ローマでは外国の貨幣の使用は一般に制限されていたが、ケンブリッジ大学の歴史家ロリー・ネイスミス教授は「この時代の硬貨は、ローマでは教皇の硬貨より、アングロ・サクソンの硬貨の方がたくさん見つかっている」と指摘。母国のお金を使える特別な扱いを受けていた可能性を示す。</li>
<li>同じ場所からは革・骨・金属の加工の跡も見つかり、居住区は巡礼者が祈って泊まるだけの場所ではなく、働き、商う町だったことがうかがえる。ネイスミス教授は「教皇に会い教会を巡るために来ていても、食べていかなければならない」と話す。研究に加わったフランチェスカ・ティンティ教授は「この発見の前には、ローマのイングランド人街の物的な痕跡はまったくなかった」と述べた。</li>
<li>出典: <a href="https://www.medievalists.net/2026/10/anglo-saxon-coins-reveal-medieval-englands-little-england-in-rome/">Medievalists.net</a> / <a href="https://gizmodo.com/being-an-anglo-saxon-expat-in-medieval-rome-came-with-a-rare-papal-perk-2000820283">Gizmodo</a> / <a href="https://www.popsci.com/science/medieval-rome-coins-from-england/">Popular Science</a></li>
</ul>
<h2>まとめ</h2>
<ul>
<li>SUSHI BUSは、時速約30キロで走る車に厨房・エレベーター・レーンを詰め込み、1便20席・1日5便という小さな器で、食事そのものを東京観光にした。</li>
<li>ケープコッドのダイヤモンドガメは、分かれきらなかった1つの胚から2つの頭が生まれた。5グラムほどの体で、2つの頭がどちらも餌を取りに行く。</li>
<li>エグレモントの変顔大会は、759回続く収穫祭の中で、1人の男性が1985年のジュニア優勝から41年かけて大人の王座へたどり着いた。</li>
<li>ローマの20枚の小銭は、千年以上前のイングランド人が祈るだけでなく、働き、母国のお金で暮らしていた外国人街の姿を初めて形で示した。</li>
</ul>
