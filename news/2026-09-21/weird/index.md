<h1>世界の珍ニュース（2026年9月21日）</h1>
<h2>オープニング：2026年9月21日 — 世界の珍ニュース</h2>
<p>20年かけてバルサ材でニューヨークを丸ごと再現したトラック運転手、フリーマーケットで30ドルの絵が25万ドルの名画だと判明した話、ロンドンで934人が声を合わせた「バルカン式敬礼」の世界記録、そして同じ数字の宝くじを2枚買って10万ドルを手にした女性。今回は「執念」「幸運」「団結」がそれぞれ主役の四題を追う。</p>
<h2>トラック運転手が20年かけたニューヨークの模型、美術館の展示に</h2>
<ul>
<li>ニューヨーク・クイーンズ出身のジョー・マッケンさん（トラック運転手、週末はバス運転手も兼務）は、小学生の頃にクイーンズ美術館で見た1964〜65年ニューヨーク万国博覧会のパノラマ模型に魅了された。家族でニューヨークを離れて以来、無意識のうちに故郷を恋しく思ったことがきっかけで、自宅地下室で独自の模型作りを始めた。</li>
<li>制作は20年以上に及び、まずロックフェラーセンターから着手し、ミッドタウンだけで約10年を費やした。素材はバルサ材とフォームボードで、ニューヨーク5区に加えニュージャージー州の一部、ロングアイランド郊外まで再現している。模型全体は縦約15メートル、横約9メートル、1インチが約49メートルに相当する縮尺で、80万棟以上の建物を配置した。</li>
<li>最難関はエンパイア・ステート・ビルディングだったといい、マッケンさんは「完璧にしたかった。みんなが見るから」と語る。「寝る前でも4時間費やして、そのままテーブルで寝落ちすることもあった。これは執着だ」とも振り返っている。</li>
<li>完成後、娘に勧められてTikTokに投稿したところ、動画は1週間で1000万回以上再生される反響を呼んだ。これを見たニューヨーク市立博物館が本人に連絡を取り、「He Built This City（この街を彼が造った）」と題した展示が2026年2月に開幕し、10月12日まで開催されている。</li>
<li>出典: <a href="https://www.cp24.com/news/world/2026/09/18/a-truck-driver-built-a-model-of-nyc-with-over-800000-structures-for-fun-now-its-a-museum-exhibit/">CP24</a></li>
</ul>
<h2>フリーマーケットの30ドルの絵、実は25万ドルのシカゴ・シュルレアリスム作品</h2>
<ul>
<li>ミシガン州の遺品整理セールで、ある美術品収集家が1枚の絵を30ドルで購入した。絵の左下隅に「Abercrombie, '51」という署名を見つけ、ミルウォーキーの展覧会カタログで同じ構図の作品を発見したことから、ルーズベルト大学の美術史家スーザン・ワイニンガー氏に鑑定を依頼した。</li>
<li>鑑定の結果、1951年にシカゴ・シュルレアリスムの画家ガートルード・アバークロンビーが描いた本物と確認された。作品名は『Alderman Merriam's Shells（市議会議員メリアムの貝殻）』で、シカゴ市議会議員ロバート・メリアム氏の貝殻コレクションを描いたもの。</li>
<li>この絵は1952年、医療処置への謝礼としてカラマズーの医師ジョン・レイノルズ氏に贈られ、以来約75年にわたってレイノルズ家に保管されていたことも判明した。</li>
<li>現在はオークションハウス「フリーマンズ」への出品が決まっており、推定落札価格は15万〜25万ドルとされている。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/09/18/painting-estate-sale-Gertrude-Abercrombie/3931789753677/">UPI</a></li>
</ul>
<h2>ロンドンで934人が「バルカン式敬礼」、スタートレック・デーに世界記録</h2>
<ul>
<li>2026年9月10日の「スタートレック・デー」、ロンドンのサイエンス・ミュージアムに1188人のファンが集まり、シリーズでおなじみの「バルカン式敬礼」（指を二股に開く挨拶）を1分間そろって披露する世界記録に挑戦した。</li>
<li>ギネス世界記録の公式測定官パウリナ・サピンスカ氏が来場者のうち記録条件を満たした934人を実際にカウントし、新記録として認定した。</li>
<li>特別ゲストとして、ドラマ「スタートレック：ストレンジ・ニューワールド」でモンゴメリー・スコット役を演じるマーティン・クイン氏が参加した。</li>
<li>サピンスカ氏は「1分間という短い挑戦でしたが、非常に興奮した瞬間で、ファンにとって大きな一体感を生む時間になった」とコメントしている。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/09/15/Guinness-World-Records-Star-Trek-Vulcan-salute/3451789489055/">UPI</a></li>
</ul>
<h2>同じ数字を2枚、メリーランドの女性が宝くじで10万ドルを射止める</h2>
<ul>
<li>米メリーランド州プリンスジョージズ郡在住の女性は8月28日、姉妹と買い物に出かけた際、その日はまだ宝くじを買っていないことに気づき、ランドーバーの「アードウィック・リカーズ」に立ち寄った。</li>
<li>その場でその日の「ピック3」「ピック4」「ピック5」の抽選券をそれぞれ2枚ずつ購入したが、ピック5だけは同じ数字を選んだ券を2枚買っていた。</li>
<li>帰宅途中に当選番号を確認したところ、2枚のピック5券がどちらも1ドルのストレート・ベットで5万ドルずつ、合計10万ドルの当選となっていた。</li>
<li>女性は「自分の目が信じられなかった。落ち着いてから財布からチケットを取り出すと、本当に当たり券だった」と語っており、賞金は請求書の支払いと自宅の修繕に充てる予定だという。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/09/16/lotto-Maryland-Lottery-Pick-5-two-tickets/3551789579360">UPI</a></li>
</ul>

<ul>
<li>四題に共通するのは、小さな行動や偶然が、思いがけない大きな結果へつながっていく面白さだ。</li>
<li>20年間ひとりで模型を作り続けた執念、遺品セールの1枚の絵が持っていた75年分の来歴、1分間だけ声をそろえた934人の一体感、そして「もう1枚買っておこう」といういつもの判断が生んだ10万ドル。</li>
<li>どれも「積み重ねる」か「たまたま起きる」かの違いはあれど、聞き終えたあとに誰かへ話したくなる小さな驚きを持っている。</li>
</ul>
