<h1>スペインニュース 2026年8月4日</h1>
<h2>オープニング</h2>
<h2>国際情勢（スペイン視点）</h2>
<ul>
<li><strong>外相アルバレス、EU同僚に「連帯」を要求しメローニを名指し批判</strong>: セウタの越境危機をめぐり、アルバレス外相は「欧州の同僚たちの連帯」を公然と求め、対応の遅さを批判するイタリアのメローニ首相を名指しで批判した（El País）。自国だけが地理的に矢面に立たされているという不満が外交の表舞台に噴き出した形である。</li>
<li><strong>フォンデアライエン欧州委員長、初めてモロッコを名指し</strong>: これまで曖昧だった欧州委員会の立場が一転し、フォンデアライエン委員長は「移民を圧力の手段として利用しようとするいかなる試みも容認できない」とモロッコを名指しで批判した（El Mundo）。EUの重心がスペイン擁護に傾いたことは、孤立感を強めていたスペイン政府にとって外交的な得点になる。</li>
<li><strong>国家治安裁判所、セウタ越境の捜査権限の有無を検討</strong>: スペインの国家治安裁判所（アウディエンシア・ナシオナル）は、モロッコ側の密航組織が絡む今回の大量越境事件を自らが裁く権限を持つかどうかを判断するため、警察に報告書の提出を求めた（El País）。国境を越えた密航ネットワークの摘発は一国の警察力だけでは完結しない、という現実が司法手続きの入り口で早くも表面化している。</li>
<li><strong>死者「ほぼ90人」、欧州世論の目が離れない</strong>: El Paísの論説は死者数が「ほぼ90人」に達したと指摘し、地中海の悲劇がスペイン一国の統計にとどまらず欧州全体の良心を問う数字になっていると論じた。</li>
<li><strong>スペイン人の受け止め</strong>: 外交の場でモロッコとメローニ双方から名指しで批判され、フォンデアライエン委員長にようやく味方してもらえた今回の展開は、スペイン人にとって「なぜいつも自分たちだけが説明を求められるのか」という積年の不満が晴れる瞬間でもあった。EU加盟によって得た「連帯」への信頼が、危機のたびに試される構図が続いている。</li>
</ul>
<h2>スペイン国内ニュース</h2>
<ul>
<li><strong>外人部隊がセウタで移民集団を拘束、国境へ移送</strong>: セウタでスペイン外人部隊（ラ・レヒオン）が移民集団を拘束・集結させ、国境地帯へ移送する作戦を実施している。現場担当者は「本当のことを言えば、彼らを国境まで連れて行くだけだ」と率直に語った（El Mundo）。軍が国内の治安作戦に直接投入される場面は、平時の治安維持を警察が担う日本の感覚とは距離がある。</li>
<li><strong>モンクロア（首相官邸）、国家治安担当者を更迭</strong>: セウタへの越境者数が4万9000人に達していたとの情報を上げた国家治安担当の幹部が更迭された（El Mundo）。危機の規模そのものよりも、情報を扱った担当者の進退が先に動くという展開は、「誰が情報を止めたか」を巡る責任の押し付け合いがスペイン政治で繰り返されるパターンを示している。</li>
<li><strong>セウタ、移民の未成年者1000人超を2施設に再配置</strong>: セウタ市は現在862人の移民未成年者を保護しており、今後1000人を超える見通しから大規模施設2か所を急ぎ整備している（El País）。危機一辺倒の議論の陰で、子どもの保護という地道な行政実務が同時進行している。</li>
<li><strong>サパテロ元首相、自身の口座捜査の司法許可を不服申し立て</strong>: サパテロ元首相は、自身と周辺の銀行口座を調べる裁判官の許可に対して不服申し立てを行った（El Mundo）。ベゴーニャ・ゴメス氏（サンチェス首相夫人）周辺の疑惑をめぐり、Red.esの経理担当者が上司から情報削除の「直接命令」を受けたとして警察に告発するなど、与党周辺の疑惑報道が途切れずに続いている。</li>
<li><strong>日本人との比較</strong>: 軍が国境警備の前面に立ち、担当者更迭という「人」の問題が先に処理される今回のセウタ対応は、原因究明より先に組織内の誰かが責任を取らされる日本の不祥事対応と奇妙に重なる。一方でスペインでは野党とメディアが与党周辺の疑惑を連日、実名入りで追及し続ける点は、内輪の調整で収めがちな日本の政治文化との違いが際立つ。</li>
</ul>
<h2>文化・芸能ニュース</h2>
<ul>
<li><strong>俳優マノロ・ソロを悼む声、同僚の追悼文で続く</strong>: 62歳で急逝した俳優マノロ・ソロについて、El Paísは同僚による追悼文「アケジャ・タルデ・コン・マノロ（マノロとのあの午後）」を掲載した。声を荒げず沈黙と間で魅せる演技は、近年のスペイン映画の静かな潮流を象徴していたと改めて振り返られている。</li>
<li><strong>マドリード王宮、名もなき使用人たちの生活史が発掘される</strong>: El País文化面は、かつて王宮に住み込んでいた使用人たちの暮らしを一次史料から掘り起こした特集を組んだ。「亡くなった侍女アントニアの部屋を私にお与えください」という当時の嘆願の文言が紹介され、華やかな宮廷史の裏側にあった名もなき労働者たちの人生に光を当てている。</li>
<li><strong>『スパイダーマン』新作がスペインでも記録的興行、地元映画界は複雑な視線</strong>: ハリウッド超大作『スパイダーマン：ブランニュー・デイ』が世界興行収入8億ユーロを突破したとEl Paísが報じた。スペイン国内でも大ヒットとなる一方、地元紙の映画評は「燃え尽き症候群のヒーロー」という皮肉な視点で作品を評しており、超大作依存への複雑な業界の空気も透けて見える。</li>
</ul>
<h2>フラメンコニュース</h2>
<ul>
<li><strong>第45回コルドバ・ギター祭、CNAF創設70周年を祝う</strong>: コルドバで開催される第45回「フェスティバル・デ・ラ・ギターラ・デ・コルドバ」が、全国フラメンコ芸術コンクール（CNAF）創設70周年を記念する企画としてフラメンコ界の重鎮たちを集める。ギターを主役に据えた大型フェスティバルが、教育・コンクール・演奏の三位一体でアンダルシアの伝統を支えている好例である。</li>
<li><strong>第52回マルチェーナ・ギター祭、エバ・ジェルバブエナが舞う</strong>: セビージャ県マルチェーナで開かれた「フィエスタ・デ・ラ・ギターラ・デ・マルチェーナ」第52回で、著名舞踊家エバ・ジェルバブエナのバイレと、ヘスス・メンデス、ダビ・パロマールのカンテが披露された（Cadena SER）。半世紀を超えて続く、ギターを軸に据えた数少ないフェスティバルとして地域に根付いている。</li>
<li><strong>カンテ・デ・ラス・ミナス財団、2026年大会「新たな伝説を探せ」で公募開始</strong>: フラメンコの登竜門として知られる名門コンクール「カンテ・デ・ラス・ミナス」が2026年大会の参加者募集を始めた（ExpoFlamenco、Revista La Flamenca）。歌・踊り・ギターの若手発掘を担う仕組みが、毎年変わらず稼働し続けている。</li>
<li><strong>アンダルシアとカタルーニャの視線の違い</strong>: コルドバとマルチェーナという二つのフラメンコの聖地が同時に取り上げられる今日のニュースは、フラメンコがアンダルシアの土地に根差した芸能であることを改めて示している。カタルーニャの読者にとっては「スペイン全体の顔」として消費されるフラメンコに、地元アンダルシアの人々が抱く誇りと複雑な感情が今回も背景にある。</li>
</ul>
<h2>フラメンコギター工房だより</h2>
<ul>
<li><strong>コンデ・エルマーノス工房（マドリード）</strong>: マドリードの老舗フラメンコ・クラシックギター工房「コンデ・エルマーノス」は、名工ドミンゴ・エステソの弟子だったコンデ兄弟（マリアーノ、フェリペ、フアン）が師の工房を受け継ぐ形で興し、現在は三代目フェリペ・コンデ氏が中心となって稼働を続けている。</li>
<li>パコ・デ・ルシアが若手時代に弾いていたギターを手がけたことで知られるほか、サビーカスやニーニョ・リカルドといった歴代の巨匠たちにも愛用されてきた歴史を持つ。マドリードにありながらアンダルシアの奏者たちに信頼されてきたのは、木工技術と音づくりの両面で師匠エステソの流儀を丁寧に受け継いだためとされる。</li>
<li>表板には松、側板・裏板には糸杉を用いる伝統的な組み合わせを基本としつつ、一本ごとに演奏家の要望に応じて厚みや力木の配置を微調整する受注生産を続けている。量産品にはない「弾き手に合わせて仕上げる」姿勢が、パコ・デ・ルシアをはじめとする巨匠たちに選ばれ続けてきた理由である。</li>
<li>今日のフラメンコニュースで取り上げたコルドバ・ギター祭やマルチェーナ・ギター祭のような演奏の現場と、マドリードで受け継がれる工房の手仕事は、地理的には離れていても同じ楽器文化の両輪として結びついている。</li>
</ul>
<h2>まとめ</h2>
<p>セウタの死者が「ほぼ90人」に迫る中、外相アルバレスがメローニ首相を名指し批判する一方でフォンデアライエン委員長は初めてモロッコを名指しし、国家治安裁判所が捜査権限を検討し始めた2026年8月4日。国内では外人部隊の国境作戦と担当者更迭、サパテロ元首相の口座捜査不服申し立てが政治の混乱を映す一方、コルドバとマルチェーナのギター祭、そしてマドリードで三代続くコンデ・エルマーノス工房の手仕事が、変わらないスペインの文化の底力を静かに物語った。</p>
