<h2>オープニング：2026年9月4日 — スペインニュース</h2>
<ul>
<li>ブリュッセルが凍らせた1億ユーロ超の緊急支援、フォルクスワーゲンの大リストラとセアトの行方、選出漏れとなったアルモドバル、各地に散る秋のフラメンコ、アルメリアのゲルンディーノ工房を追う。</li>
</ul>
<h2>今日のスペイン語ひとこと</h2>
<ul>
<li><strong>Pasar la patata caliente（パサール・ラ・パタタ・カリエンテ）</strong>＝「熱いジャガイモを回す」＝厄介な問題や責任を、自分で処理せず次の人へ押し付けること。閣僚同士、司法と行政、与野党が互いに責任を回し合う今日のセウタ政局にそのまま当てはまる表現。</li>
</ul>
<h2>国際情勢（スペイン視点）</h2>
<ul>
<li><strong>サンチェス首相、モロッコ関与を条件付きで認める姿勢に転換</strong>（El Mundo、9月3日）: 国会答弁で「証拠が見つかれば行動する」としつつ、「現時点で情報機関はモロッコ関与を否定している」と述べた。8月21日にモロッコ大使を呼び出していたことも初めて明らかにし、なぜこれまで公表しなかったのかが新たな論点になった。EU加盟を誇りとする国だけに、隣国モロッコとの関係を対外的にどう説明するかが問われている。</li>
<li><strong>欧州委員会、セウタ向け緊急支援1億ユーロ超の拠出を遅延</strong>（El Mundo、9月3日）: ブリュッセルは「初日から」支援を申し出ていたが、スペイン政府の正式要請は8月24日と遅く、しかも「重要な説明」を欠いていたという。EUを強く支持してきたスペインが、肝心の実務でEU側を待たせた形になった。</li>
<li><strong>フォルクスワーゲン、追加5万人規模の人員調整に合意、セアトの将来が不透明に</strong>（El Mundo、9月3日）: 2024年末合意分と合わせ最大10万人規模の調整になり、ドイツ国内4工場とセアトブランドの扱いが宙に浮いた。スペインの主要自動車ブランドの命運が、ドイツ本社の経営判断ひとつで左右される構図である。</li>
<li>隣国モロッコとの摩擦、EUとの実務、ドイツ資本への依存。スペインが望むと望まざるとにかかわらず、国境の外の判断が国内の雇用と政治日程を直接動かしている。</li>
</ul>
<h2>スペイン国内ニュース</h2>
<ul>
<li><strong>フェイホー党首、サンチェス首相を「モロッコに脅されている」と非難</strong>（El País、9月3日）: 国民党（PP）党首は「モロッコが越境を主導した兆候がある」と繰り返し、「司法の場で責任を取らせる」と首相を追及した。左派紙エル・パイスは首相の慎重な物言いを、右派紙エル・ムンドは情報機関の警告そのものを前面に出し、同じ答弁でも紙面の切り取り方が対照的だった。</li>
<li><strong>マルラスカ内相、司法権評議会（CGPJ）へ苦情</strong>（El País、9月3日）: 国家警察情報部門（CENIF）が上司へ報告するのを担当判事が禁じたとして、内相が文書で不満を伝えた。最高裁長官はこれに対し、判事の独立性を守る立場を明確にし、行政と司法がセウタ問題を挟んで綱引きになっている。</li>
<li><strong>ロブレス国防相、首相への拍手の輪から外れる</strong>（El Mundo、9月3日）: 議場で他の閣僚が立って拍手する中、ロブレス氏だけは着席し拍手も控えめだったと報じられた。情報機関が事前に危険を警告していたと閣内で唯一言い続けているのが同氏だとされ、政権内部の足並みの乱れが視覚的に伝わった。</li>
<li><strong>セウタで女性を親族殺害容疑で逮捕</strong>（El Mundo、9月3日）: 自宅で口論の末、同居していたいとこにあたるモロッコ人男性を刃物で死亡させた疑いで女性が逮捕された。近隣住民は「ナイフ、ナイフという叫び声を聞いた」と証言しており、越境危機の陰で個々の家庭内の悲劇も起きている。</li>
<li><strong>アトレティコ・マドリードのマルコス・ジョレンテ、スペイン代表引退を表明</strong>（El Mundo、9月3日）: 「多くの人には理解されないと分かっている」と述べ、ワールドカップ出場の有無にかかわらず決めていた決断だと説明した。周囲の期待より自分の納得を優先して公言する態度は、空気を読んで理由を明かさないことも多い日本のスポーツ選手の身の引き方とは対照的である。</li>
<li>閣内も与野党も司法も、互いに「熱いジャガイモ」を投げ合う一日だった。中央の責任論が過熱するほど、現場のセウタでは支援の遅れと家庭内の事件が静かに積み上がっている。</li>
</ul>
<h2>文化・芸能ニュース</h2>
<ul>
<li><strong>スペイン、来年のアカデミー国際長編映画賞候補に3作を予備選出</strong>（El País／El Mundo、9月3日）: 『ラ・ボラ・ネグラ』（ロス・ハビス監督）、『ロス・ドミンゴス』（アラウダ・ルイス・デ・アスア監督）、『エル・セール・ケリード』（ロドリゴ・ソロゴジェン監督）の3本に絞られ、9月16日に最終候補が発表される。ペドロ・アルモドバル監督の新作は今回選に漏れ、映画界に驚きが広がった。</li>
<li><strong>アラウダ・ルイス・デ・アスア、広告業界20年を経て監督に</strong>（The Objective、2026年2月28日ほか複数報道）: ビルバオ近郊バラカルド出身で、デウスト大学で英語学、バスク大学で視聴覚コミュニケーションを学んだのち、ECAMで映画監督を修めた。長編デビュー作『シンコ・ロビートス』（2021年）でゴヤ賞新人監督賞を受賞し、2024年には結婚と性的同意を描くドラマシリーズ『ケレール』を発表。最新作『ロス・ドミンゴス』はビルバオを舞台に、修道女を志す少女と裕福な家庭を描き、2025年サンセバスチャン映画祭で最高賞パルマ・デ・オロを獲得、ゴヤ賞監督賞・脚本賞も受けた。広告の仕事を20年続けたのちに個人的な転機を経て映画に転じたという歩みが、作品の題材選びにも重なっている。</li>
<li><strong>選外となったアルモドバルの扱いを巡り評価が割れる</strong>（El Mundo、9月3日）: 「ロス・ハビス」「ソロゴジェン」「ルイス・デ・アスア」という顔ぶれは、いずれもスペイン映画界の実力派だが、常連候補だったアルモドバルの不在が話題を呼んだ。世代交代を歓迎する声と、国際的知名度を惜しむ声の両方が伝えられている。</li>
<li>ビルバオの家庭劇、バルセロナの犯罪劇、そして選に漏れた巨匠。スペインが世界へ送り出す物語は一つの型に収まらず、地域と作家性の広がりそのものが売りになっている。</li>
</ul>
<h2>フラメンコニュース</h2>
<ul>
<li><strong>コルドバ、第45回ギター祭が開幕</strong>: 国立フラメンコ研究センター（CNAF）創立70周年を記念する構成で、フラメンコ界の主要な奏者・歌い手が顔をそろえる。教育機関としてのCNAFの節目を、現役世代の公演で祝う企画である。</li>
<li><strong>マラガ県アロサイナ、アルメナ・フラメンカで歌・ギター・舞踊が集結</strong>: 城壁を意味する地名を冠した催しに、地元と近郊のアーティストが参加。大劇場ではなく、白い村の広場が舞台になった。</li>
<li><strong>カディス県ロタ、第43回アランケ・ロテーニョ</strong>: 歌・ギター・舞踊が一体となった伝統行事が43回目を重ね、地域の年中行事として定着している。</li>
<li><strong>カスティーリャ・ラ・マンチャ、プエルトジャノで第31回「鉱夫の日」フラメンコ祭</strong>: アンダルシア以外の鉱山地帯にもフラメンコが根づいていることを示す催しで、歌・ギター・舞踊を鉱山労働の記憶と結びつけて紹介する。</li>
<li><strong>ハエン大学、国際ダンスデーに合わせフラメンコ舞踊入門講座</strong>: 教育機関が一般向けの体験講座を開き、次世代への裾野を広げる取り組みを続けている。</li>
<li>発祥地アンダルシア（コルドバ、アロサイナ、ロタ）だけでなく、カスティーリャ・ラ・マンチャの鉱山町や大学の講座までフラメンコが広がる様子は、地方色の強い祭りを大切にする点で日本の郷土芸能とも重なるが、担い手の裾野を大学教育でまで広げる点はより組織的である。</li>
</ul>
<h2>フラメンコギター工房だより</h2>
<ul>
<li><strong>ゲルンディーノ・フェルナンデス・イーホ工房（アルメリア県、C/モンテ・ペルディード5番地）</strong>: 公式サイトによれば、父ゲルンディーノ・ミゲル・フェルナンデス・ガルシア（1931〜2006年）は1958年から専業で製作を始め、1960年にアルメリアで自らの工房を開いた。年産10〜12本程度の少量生産で、しわがれた力強い響きとバランスの取れた音程、パーカッシブな音色で知られた製作家である。</li>
<li><strong>息子が受け継ぐ手作業の全工程</strong>: 1974年アルメリア生まれの息子ゲルンディーノ・フェルナンデス・ジャマスは、幼少期から工房が自宅にある環境で育ち、父の手法をそのまま引き継いでいる。公式サイトは、工房で作るギターはすべて完全手作業で、1本あたり2〜3か月を要し、仕上げはセラック仕上げ（顧客の希望で変更可）と説明する。</li>
<li><strong>素材と演奏現場</strong>: 使用木材はローズウッドと糸杉が中心で、父の代はドイツ松またはウエスタン・レッド・シダーの表板に軽量な糸杉の側・裏板を組み合わせ、立ち上がりの速さを追求した。この軽快な応答性が、カンテの伴奏やパルマのリズムに瞬時に音を重ねるフラメンコギターの核心であり、二代にわたって受け継がれる家業がその条件を支えている。</li>
</ul>
<h2>まとめ</h2>
<ul>
<li>今日のスペインは、国境の外の判断が国内の雇用と政治日程を動かす一日だった。EUの支援は自国の遅れで止まり、ドイツの経営判断がセアトの将来を握り、映画界では常連の巨匠が選に漏れた。それでも各地のフラメンコ祭とアルメリアの手仕事は、変わらぬ日程で続いている。</li>
</ul>
