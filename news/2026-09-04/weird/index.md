<h2>ネタ1 靴下2000足超、元消防士のギネス記録挑戦は寄付つき</h2>
<ul>
<li>米サウスカロライナ州ノースオーガスタ在住のダリル・パーカー氏（元フィラデルフィア市消防局の救急救命士、30年勤務）は、靴下の収集数で2000足を突破したと2026年8月31日〜9月1日に地元局WRDW、UPI等が報じた。</li>
<li>きっかけは父の日の贈り物。以後、誕生日や昇進祝い、記念日のたびに靴下が増えていった。現在の公式記録は元CBSフィラデルフィアのアンカー、ジム・ドノヴァン氏が2025年に達成した1531足で、パーカー氏はすでにこれを上回っている。</li>
<li>パーカー氏は年末まで収集を続けたうえでギネス世界記録に正式申請する予定。挑戦中に集めた靴下はすべて地域のシェルターや困窮者へ寄付する方針で、「地域を一つにまとめて、少し元気を届けられたら本望だ」と語った。</li>
<li>一番のお気に入りは、心不全で入院した際に履いていたハート柄の靴下。妻と孫たちに背中を押されて記録挑戦を決めたという。現在は退職後にCPR（心肺蘇生法）講習を教える非営利団体を運営している。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/09/01/Guinness-World-Records-socks-collection/1621788280670/">UPI</a>（2026年9月1日）／<a href="https://www.wrdw.com/2026/08/31/finding-solutions-mans-record-breaking-sock-collection-will-soon-go-shelters/">WRDW</a>（2026年8月31日）</li>
</ul>
<h2>ネタ2 真水を飲まないブラジルの島のヤギ、250年生存の謎</h2>
<ul>
<li>ブラジル北東部バイーア州沖70キロ、アブロリョス群島の一つサンタバーバラ島で、真水源がないのに250年以上生息してきたヤギの群れが確認されている。植民地時代に家畜として持ち込まれ、入植失敗後に取り残されたのが起源とされる。</li>
<li>現地の生物多様性保全機関「チコ・メンデス研究所（ICMBio）」が管理するアブロリョス国立海洋公園の担当者エリスマー・ホシャ氏によると、調査中に一度も水を飲む様子が確認できなかったという。海水への適応や、水分の多い島の植物「ベルドロエガ」への依存が仮説として挙がっているが、確定していない。</li>
<li>出産のほとんどが双子で、栄養状態は良好とみられる。ホシャ氏は「厳しい環境で生き延びる独自の能力を身につけたのだろう」と話す。</li>
<li>2025年3月、島の生態系保護のため残っていた27頭は保護区外へ移送された。研究者らは、この生存メカニズムを乾燥地帯向けの家畜品種改良に応用できないか研究を進めている。</li>
<li>出典: <a href="https://www.odditycentral.com/news/mysterious-goats-survive-over-200-years-on-isolated-island-with-no-fresh-water.html">Oddity Central</a></li>
</ul>
<h2>ネタ3 ペンタゴンを80年ぶりに超えた「世界最大の建物」はダイヤモンド取引所</h2>
<ul>
<li>インド・グジャラート州スーラト郊外に完成した「スーラト・ダイヤモンド・ブルス」が、延べ床面積で米国防総省ペンタゴン（約62万平方メートル）を約5000平方メートル上回り、世界最大の建物としてペンタゴンの80年にわたる記録を塗り替えた。</li>
<li>設計はインドの建築事務所モルフォジェネシス。9棟の長方形棟を中央通路でつなぐ15階建てで、建設費は320億ルピー（約388億円）。用途は国際的なダイヤモンド・宝飾品取引の拠点で、世界のダイヤモンド研磨の9割を担うスーラトの産業を支える。</li>
<li>4700以上のオフィス・作業スペースを持ち、最大6万5000人を収容。スマート制御のエレベーター131基を備え、最上階まで平均6分で到達する設計。駐車場は自動車4500台、二輪車1万台分を用意した。</li>
<li>共同設計者のソナリ・ラストギ氏は「記録更新が目的ではなく、需要に応えた結果この規模になった」と説明している。</li>
<li>出典: <a href="https://www.odditycentral.com/architecture/new-worlds-largest-office-building-surpasses-the-pentagon.html">Oddity Central</a></li>
</ul>
<h2>ネタ4 1日250トンの燃料を飲む、世界最大のディーゼルエンジン</h2>
<ul>
<li>フィンランドのワルトシラ社が開発した「ワルトシラ・サルザーRTA96-C」は、14気筒2ストローク・ターボ過給ディーゼルエンジンで、コンテナ船向けとしては世界最大級。高さ13メートル、全長26メートル、総重量2300トンで、クランクシャフト単体だけでも300トン、ピストン1本が5トンに達する。</li>
<li>出力は10万8920馬力（8万80キロワット、毎分102回転）。燃料消費は重油換算で1日約250トン、時速換算ではおよそ1時間に1660ガロン(約6300リットル)を消費する。</li>
<li>2006年に初号機が大型コンテナ船「エマ・マースク」に搭載されて就航した。12気筒型では大型化する船体に出力が足りず、クランクシャフトの素材を見直して14気筒化を実現したという開発経緯がある。製造コストは1基25億円規模とされる。</li>
<li>出典: <a href="https://www.odditycentral.com/technology/the-worlds-largest-combustion-engine-uses-250-tons-of-fuel-a-day.html">Oddity Central</a></li>
</ul>
<h2>まとめ</h2>
<ul>
<li>靴下2000足の収集は寄付という形で地域に還元され、水を飲まないヤギは250年分の謎を研究者に残し、世界最大のオフィスビルは需要の結果としてペンタゴンを超え、最大のディーゼルエンジンは1日250トンの燃料で巨大コンテナ船を動かし続けている。</li>
<li>今日の4本に共通するのは、誰か一人の執念や一つの目的をとことん積み重ねた先に、思いがけない規模や謎が生まれるということだった。</li>
</ul>
