<h2>ボルト選手より速い？ 時速45.6キロの二足ロボット</h2>
<ul>
<li>中国のロボット企業ユニツリーは8月17日、人型ロボット「スーパーマン」の運動動画を公開した。同社発表では最高速度は秒速12.66メートル、時速45.6キロである。</li>
<li>ウサイン・ボルト選手の最高速度として記事が比較した秒速12.27メートル、時速44.17キロを約0.39メートル毎秒上回る。さらに垂直跳びは2メートルとされた。</li>
<li>ただし数値は企業動画に基づき、第三者の計測ではまだ確認されていない。100メートルの記録ではなく、瞬間的な最高速度同士の比較でもある。</li>
<li>不格好に見える走り方と、金属の脚が人類最速級という落差が見どころ。速さの記録以上に、同じ条件で再測定できるかが製品デモと競技記録の違いを示す。</li>
<li>出典: <a href="https://www.odditycentral.com/technology/worlds-fastest-humanoid-robot-can-already-run-faster-than-usain-bolt.html">Oddity Central</a></li>
</ul>
<h2>鳥の来店を通知する、顔認識つきスマート餌台</h2>
<ul>
<li>ワイアードが2026年9月に更新した比較記事では、透明な餌箱へカメラ、通信アプリ、太陽電池を組み合わせた「スマート鳥餌台」を2年以上、雨、雪、暑さの中で試している。</li>
<li>鳥が止まると写真や動画を保存し、エーアイが種類を推定してスマートフォンへ通知する。試験者はコーネル大学鳥類学研究所の資料などで判定を照合した。</li>
<li>推奨機のバードファイ・ライトは1080ピーのカメラ、155度の画角、約1.4リットルの餌入れを備える。識別機能は買い切り版のほか、月5ドルの契約でも提供される。</li>
<li>別製品では西海岸の普通種を東海岸の種と誤認する例もあり、鳥の名前は便利な仮説にとどまる。餌を食べる鳥だけでなく、リスとの攻防や契約料金まで観察対象になる機械である。</li>
<li>出典: <a href="https://www.wired.com/story/best-smart-bird-feeders/">WIRED</a></li>
</ul>
<h2>室内の壁でカリフラワー、助言役は年259ドル</h2>
<ul>
<li>ワイアードが2026年9月に更新した室内菜園比較では、縦型水耕栽培機「ガーディン・ホーム4.0」で花、タイム、コールラビ、丸ごとのカリフラワーまで育った。</li>
<li>本体価格は899ドルで、最大30株を植えられる。根は専用容器から栄養液へ伸び、ポンプは標準で一日3回、各5分動く。</li>
<li>カメラとセンサーを使い、水やり、照明、手入れを助言する契約サービス「ケルビー」は年259ドル。契約なしでも照明と給水を手動操作できる。</li>
<li>手放しの畑に見えても、約3週間ごとの根の整理と4週間ごとのタンク清掃が要る。屋外の土を省いた代わりに、壁際へ農作業とソフトウェア契約を持ち込む仕組みである。</li>
<li>出典: <a href="https://www.wired.com/gallery/best-indoor-gardening-systems/">WIRED</a></li>
</ul>
<h2>まとめ</h2>
<ul>
<li>二足ロボットは、人類最速級という派手な数字ほど測定条件が重要だった。</li>
<li>スマート餌台は、庭の鳥を通知する便利さと、誤認・リス・月額料金を一緒に運んでくる。</li>
<li>室内菜園は、壁でカリフラワーを育てられるが、根とタンクの手入れまでは自動化しない。</li>
</ul>
