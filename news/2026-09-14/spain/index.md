<h1>スペイン文化・フラメンコ便り — 2026年9月14日</h1>
<h2>オープニング：2026年9月14日 — スペイン文化・フラメンコ便り</h2>
<ul>
<li>今日の軸は、海外在住スペイン人の投票権、サンパウロ国際ブックビエンナーレ、各地のフラメンコ公演、ビセンテ・アミーゴ、マドリードのコンデ工房、そしてタンゴスの四拍子。</li>
</ul>
<h2>今日のスペイン語ひとこと</h2>
<ul>
<li><strong>tener duende（テネール・ドゥエンデ）</strong>は、直訳しにくい「人を引き込む霊感・魔力がある」。技巧だけでは説明できない舞台の切迫感を褒める言い方で、今日の演奏評にもつながる。</li>
</ul>
<h2>国際情勢（スペイン視点）</h2>
<ul>
<li>9月13日、スペイン最高裁をめぐり、いわゆる「孫法」で国籍を得た在外スペイン人の一部について投票停止が争点となった。『エル・パイス』社説は対象を約40万人とし、国籍を認めながら選挙権を狭めるのは過剰だと批判した。</li>
<li>これは外国の出来事を眺める話ではない。内戦と独裁で亡命した家族の子孫、ラテンアメリカに暮らすスペイン国民、国内の政党勢力図が直接結ばれる。日本の在外投票にも手続き上の壁はあるが、スペインでは亡命の記憶そのものが資格論争へ入る点が異なる。</li>
<li>権利保護を強調する見方と、急増した有権者名簿の適法性を厳密に問う見方が対立する。確定したのは国籍と投票をめぐる司法判断が政治参加へ直結したことで、個々の資格を一括して疑う論法には慎重さが要る。</li>
</ul>
<h2>スペイン国内ニュース</h2>
<ul>
<li>セウタでは8月から続く大規模越境後、放火や暴行など緊張が増したと9月13日に報じられた。政府周辺は正常化に最大3か月を見込み、野党党首アルベルト・ヌニェス・フェイホーはモロッコとサンチェス政権の責任を強く追及した。</li>
<li>左派系『エル・パイス』は市内の憎悪と共存の傷を、右派系『エル・ムンド』は情報機関資料と閣内混乱を前面に置く。同じ危機でも、市民社会の損傷を見るか政権の統治能力を見るかで焦点が違う。</li>
<li>海峡の向こうがすぐモロッコというセウタでは、移民政策は抽象論ではなく学校、商店、近隣関係へ届く。街頭で責任論を激しく戦わせるスペインと、合意形成を表に出しにくい日本の違いも見える。</li>
</ul>
<h2>文化・芸能ニュース</h2>
<ul>
<li>サンパウロ国際ブックビエンナーレのスペイン館は、作家マルタ・サンスの選書で、文学的な「カースト」に属さない書き手とスペイン内部の多様性をブラジルへ示した。スペイン語圏だけでなくポルトガル語圏と接続し、植民地史を一方向の輸出ではなく対話へ組み替える試みだ。</li>
<li>9月13日付『エル・ムンド』は、9月17日にマドリードで初演される舞踊作品『ラスト・アンド・ファースト・メン』を紹介した。遠い未来のディストピアを身体で描きながら、環境との協調による希望を置く構成で、言葉より身体の距離と群舞で未来像を示す。</li>
<li>ルシア・アレニャール・イグレシアス監督の長編デビュー作『フォラステラ』は、ゾエ・ステイン主演で喪失と記憶を扱う。怪談の形を借りながら「幽霊のいない幽霊譚」と評され、若いスペイン人監督が日常の沈黙を映画の余白へ変えた。</li>
<li>日本の文学祭や映画祭も地域性を掲げるが、スペインではカスティーリャ語だけで国を代表させないことが政治性を帯びる。多言語・多地域の作家を国外へどう見せるか自体が文化政策になる。</li>
</ul>
<h2>フラメンコニュース</h2>
<ul>
<li>パンプローナ市は第13回フラメンコ・オン・ファイアと連携し、コンデスタブレでの二公演、エル・ペレによる市庁舎バルコニーでのカンテ、未成年向けギター・舞踊講座を組んだ。スター公演と入口教育を同じ事業に置いた点が重要だ。</li>
<li>マラガ県アルチドーナでは9月12日、ラ・ポーラ・フラメンカがカンテ、バイレ、ギターを一つの夜へ集めた。大都市の専用劇場ではなく町の催しへ三者を戻し、歌の伸縮へギターと踊りが即応する総合芸術の形を見せる。</li>
<li>サラゴサ県エヘア・デ・ロス・カバジェロス市は、リカルド・フェルナンデス・デル・モラル一座の『ヌエストロ・フラメンコ』を開催する。カンテ、ギター、バイレの熟練をまとめて紹介し、アンダルシア外の観客へ舞台文法を手渡す企画だ。</li>
<li>フラメンコはセビリア、ヘレス、カディス、グラナダなどアンダルシアの土地で育った一方、パンプローナやアラゴンへ広がる。全国文化としての普及には価値があるが、マドリード発の「スペインの顔」だけに還元すると、アンダルシア固有の歴史と地域差が薄れる。</li>
</ul>
<h2>フラメンコギタリスト列伝</h2>
<ul>
<li>第10回は<strong>ビセンテ・アミーゴ（Vicente Amigo、1967年生）</strong>。セビリア近郊グアダルカナル生まれ、コルドバで育ち、マノロ・サンルーカルのもとで研鑽した。カマロン・デ・ラ・イスラ、エル・ペレらのカンテを支えた後、独奏家・作曲家として活動を広げた。</li>
<li>代表作『シウダ・デ・ラス・イデアス』では、フラメンコのコンパスを保ちながら、開放弦を含む和音と歌うような旋律を長くつなぐ。右手のピカードは速さだけでなく音量差を作り、アルペジオでは内声を残して和声の色を変える。</li>
<li>伴奏経験が独奏にも生き、旋律を言い切らず次の呼吸を空ける。カンテと共演した録音では、歌の語尾へ和音を被せず、短いファルセータで次のレトラへの橋を架けるところが聞きどころだ。</li>
<li>パコ・デ・ルシア以後の現代フラメンコを、ジャズ風の和声を借りるだけでなく、コルドバで培った音の余白と旋律美で更新した。まず表題曲を、低音が拍を守る層と高音が歌う層に分けて聴くと個性が見える。</li>
</ul>
<h2>フラメンコギター工房だより</h2>
<ul>
<li>今日の工房はマドリードの<strong>コンデ・エルマノス</strong>。起源はドミンゴ・エステソの系譜にあり、甥のファウスティーノ、マリアーノ、フリオ・コンデが仕事を継承した。複数の家系工房がコンデ名を受け継いでいるため、ラベル、所在地、製作年代の確認が個体評価に欠かせない。</li>
<li>フラメンコ器ではスプルース表板とシープレスの横・裏板を用いる伝統があり、軽い反応、短めの余韻、打音の輪郭が求められる。薄さや力木は一律ではなく、奏者の右手、弦高、舞台で必要な音量に合わせて調整される。</li>
<li>ゴルペアドールはラスゲアードや指先の打撃から表板を守る。クラシック器が長い余韻と音の混ざりを重視する場面に対し、フラメンコ器はカンテ、パルマ、サパテアードの隙間へ素早く立ち上がる必要がある。</li>
<li>名工の系譜をブランド名だけで買うのではなく、誰がいつどの工房で作ったかを確かめる姿勢は、日本の陶芸で窯と代を見分ける感覚に近い。職人名と実物の調整履歴までが音の来歴になる。</li>
</ul>
<h2>フラメンコのパロ解説</h2>
<ul>
<li>今日のパロは<strong>タンゴス（Tangos flamencos）</strong>。19世紀後半に形を整えたとされ、カディス、セビリア、グラナダ、マラガなど土地ごとの型がある。大西洋を往復した音楽との関係を含め起源には諸説あり、単一の街や民族だけへ還元できない。</li>
<li>雰囲気は親しみやすく祝祭的だが、レトラには恋、からかい、日常の苦みも入る。短い歌詞句を繰り返し、カンテの合間へジャマーダ、パルマ、バイレの足技を差し込めるため、舞台でも集いでも展開しやすい。</li>
<li>コンパスは四拍子で、基本の重心は2拍目と4拍目。パルマとカホンが裏拍を押し、ギターは音を詰めすぎず、歌と足が入る空間を残す。十二拍系のシギリージャやアレグリアスとは身体の数え方が明確に違う。</li>
<li>和声はフリジア系が多く、イ調の説明ならイ短調、ト長調、ヘ長調、ホ長調へ下るアンダルシア終止が典型となる。長調・短調の型もあり、カポタストで歌い手の音域へ合わせ、ファルセータは四拍の着地点を崩さず装飾する。</li>
<li>「四拍子だから簡単」ではない。二拍目と四拍目の粘り、歌の後ろへ置くギター、地域ごとのアクセントがそろって初めて、歩くように前へ進むタンゴスのグルーヴになる。</li>
</ul>
<h2>まとめ</h2>
<ul>
<li>2026年9月14日は、在外投票の境界から本の越境、公演の地方巡回、アミーゴの余白、コンデ工房の系譜、タンゴスの四拍まで、文化を運ぶには権利・土地・手仕事の来歴が必要だと見えた。</li>
</ul>
