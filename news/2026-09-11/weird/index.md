<h2>幅50センチに切り詰めた「世界一狭い車」、アンドレア・マラッツィさん</h2>
<ul>
<li>イタリア北部バニョーロ・クレマスコのアンドレア・マラッツィさん（31）は、廃車の解体とリサイクルを仕事にしている。1993年式のフィアット・パンダを改造し、幅50.3センチの1人乗り電気自動車に仕立てた</li>
<li>車体と車台の中央部分を丸ごと切り取り、残った左右を溶接でつなぎ直した。作業はおよそ1年。四輪を含め、元の部品の99パーセントを残したという</li>
<li>ギネス世界記録は2026年9月10日に「運転できる世界一狭い車」として認定し、ギネス世界記録2027年版に掲載した。公道での常用はせず、見本市やイベントでの実演に限って走らせる</li>
<li>本人は「切って、溶接して、板金やプラスチック、パッキンまで、周りのものを全部自分で作った」と話している</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/09/10/Guinness-World-Records-book-new-titles/8281789059748">UPI</a> / <a href="https://www.odditycentral.com/auto/italian-mechanic-turns-old-fiat-into-the-worlds-narrowest-drivable-car.html">Oddity Central</a> / <a href="https://www.designboom.com/technology/worlds-narrowest-fiat-panda-drives-fully-functional-single-seater-electric-car-06-27-2025/">designboom</a></li>
</ul>
<h2>カエルグッズ1万3201点、収納用に家をもう1軒買ったスーザン・バーゴスさん</h2>
<ul>
<li>アメリカ・カリフォルニア州カマリロのスーザン・バーゴスさんが、カエルにちなんだグッズ1万3201点を集め、ギネス世界記録の「カエル関連グッズの最大コレクション」に認定された。認定日は2026年1月12日で、従来記録の1万502点を上回った</li>
<li>きっかけは1983年、自宅の台所で小さなアマガエルを見つけたこと。最初に買ったのは、エメラルドの目が付いた金のカエルの指輪だった</li>
<li>収蔵品はぬいぐるみ、おもちゃ、クリスマスの飾り、食器、衣類、アンティークなど多岐にわたる。置き場所が足りず、大きな車庫のある家をもう1軒購入して一部を保管している</li>
<li>出典: <a href="https://www.guinnessworldrecords.com/world-records/largest-collection-of-frogs">ギネス世界記録</a> / <a href="https://www.upi.com/Odd_News/2026/09/10/Guinness-World-Records-book-new-titles/8281789059748">UPI</a></li>
</ul>
<h2>吸い殻20本でミニパンケーキと交換するオランダの屋台「ウェイストバー」</h2>
<ul>
<li>オランダで2022年、ノリーン・ファン・ホルステインさんとラリタ・ファン・ラムスウェールデさんが屋台「ウェイストバー」を始めた。路上に捨てられたたばこの吸い殻20本を、オランダのミニパンケーキ「ポファチェス」と交換する</li>
<li>飲み物や果物、菓子も、吸い殻やプラスチックごみの持ち込み量に応じて渡す。屋台は音楽祭や子ども向けイベント、企業の催しに出店する</li>
<li>オランダでは年間50億〜100億本の吸い殻が捨てられるとされる。フィルターはセルロースアセテートという樹脂で、分解に最長10年かかり、その間ニコチンや重金属が土や水に溶け出す</li>
<li>創業者は「地面から物を拾うのをためらわれるかと不安だったが、最初から反応は好意的だった」「一度見たら、もう見なかったことにはできない」と話している</li>

</ul>
<h2>約30センチの角で住民に突進、保安官と格闘したワシントン州の脱走ヤギ</h2>
<ul>
<li>アメリカ・ワシントン州スノホミッシュ郡の保安官事務所は2026年9月9日、脱走したヤギを住宅街で捕まえたと発表した。出動は8月28日で、囲いを抜け出したヤギは「近所の暴れ者という役目を真剣に受け止めていた」と投稿でからかい半分に説明された</li>
<li>長さ約30センチの角を持つヤギが住民に突進し、住民は保安官が来るまで屋内に避難した。ボディーカメラの映像には、2人の保安官が両側から角をつかんで囲いへ誘導し、「こいつ、本当に力が強いぞ」と話す声が記録されている</li>
<li>けが人はなく、ヤギも無事に囲いへ戻った。騒ぎは数分で収まった</li>
