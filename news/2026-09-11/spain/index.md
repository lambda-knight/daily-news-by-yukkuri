<h1>スペイン文化・フラメンコ便り（2026年9月11日）</h1>
<h2>オープニング：2026年9月11日 — スペイン文化・フラメンコ便り</h2>
<ul>
<li>今日の中心は、コルドバの第45回ギター祭とフラメンコ芸術大会70周年、モロンの伝説ディエゴ・デル・ガストール、コルドバに根を張ったカナダ生まれの製作家ジョン・レイ。</li>
<li>昨日のサビーカス（世界へ出て録音を残した人）と対にして、「土地に留まる生き方」からフラメンコを見る回。</li>
<li>本日9月11日はカタルーニャの「ラ・ディアーダ」。1714年のバルセロナ陥落を記念する日で、独立運動の分裂も取り上げる。</li>
</ul>
<h2>今日のスペイン語ひとこと</h2>
<ul>
<li><strong>Llevar la voz cantante（リェバル・ラ・ボス・カンタンテ）</strong>。直訳は「歌う声を運ぶ」。もとは合唱で主旋律を担う声部を指し、そこから「主導権を握る」「仕切る」という決まり文句になった。</li>
<li>文法メモ: <code>cantante</code> は動詞 <code>cantar</code> の現在分詞が形容詞化して固定した形。単独では「歌手」の名詞にもなるが、この慣用句では「歌っている声＝主導する声」の含意で使う。</li>
<li>用例: 「En esa negociación lleva la voz cantante el ministro（あの交渉は大臣が仕切っている）」。今日のフラメンコの「歌が主、ギターは伴奏」という話題にも通じる。</li>
</ul>
<h2>国際情勢（スペイン視点）</h2>
<ul>
<li>スペイン議会は、スペイン領サハラ時代にスペインの身分書類を持っていたサハラウイの人々へ国籍取得の道を開く案を可決した。審議は与野党の激しい非難の応酬になった。</li>
<li>左派は1975年に西サハラを放棄した植民地支配の責任を果たす一歩と位置づける。右派（PP・Vox）は野党を中心に、サンチェス政権の対モロッコ外交全体への不信と結びつけて反発した。</li>
<li>旧植民地への負い目と、ジブラルタル海峡の向こう側への警戒という、スペインの二つの対外感情が同じ採決に表れている。一般政治はこの一題に限定。</li>
</ul>
<h2>スペイン国内ニュース</h2>
<ul>
<li>ディアーダ前夜、リポイ市長シルビア・オリオルス（アリアンサ・カタラナ）の集会が、独立派内部の緊張を可視化した。「カタルーニャを救いに来た」と発言。</li>
<li>オリオルスは移民に厳しい主張で支持を伸ばしており、従来の独立派であるERC（エルカ）やJunts（ジュンツ）とは距離がある。独立運動が一枚岩でなくなり、内部で主導権を争っている。</li>
<li>地域の誇りが独自の政党の形まで取るのはスペインの特徴。日本の郷土愛は祭りや方言にとどまることが多く、街頭で毎年ぶつけ合うスペインとは強度が異なる（大阪対東京の対抗心が政党化したような構図）。</li>
</ul>
<h2>文化・芸能ニュース</h2>
<ul>
<li>マヨルカ出身のルシア・アレニャール・イグレシアス監督の長編デビュー作『フォラステーラ（Forastera）』が高評価。祖母を亡くした10代の少女が祖母の仕草や話し方を模倣しはじめる、喪失と島の閉塞を描く静かな作品。セルジ・ロペス、アイナ・クロテットが共演。批評は四つ星。</li>
<li>短編から発展させた題材で、時間をかけて撮る作家性。スペイン映画が大作でなく小さな声を丁寧にすくう系譜に連なる。</li>
<li>マラガの「コミック見本市」が会場を拡張し、来場者の行列短縮を最優先課題に掲げた。ピカソの故郷であり映画祭も持つマラガが、観光都市から創作・見本市の集積地へ変化しつつある。</li>
</ul>
<h2>フラメンコニュース</h2>
<ul>
<li><strong>第45回コルドバ・ギター祭</strong>。1956年創設のコルドバ全国フラメンコ芸術大会（CNAF）の70周年に重ね、フラメンコの主要な演奏家を集める編成。無名の歌い手・弾き手を世に出してきた大会の記憶を軸にする。</li>
<li><strong>カンテ・デ・ラス・ミナス（ラ・ウニオン、ムルシア州）</strong>が「2026年の新しい伝説」を探すと発表。19世紀にアンダルシアからレバンテの鉱山へ移った労働者が残したタランタ、カルタヘネーラなど「鉱山の歌」を継ぐ。フラメンコがアンダルシアだけの芸ではないことを示す地理。</li>
<li><strong>ヘレスの金曜フラメンコ</strong>の締めに、トマス・ルビチ、チェロ・パントーハ、バルージョの歌と、ソラヤ・クラビホの踊り。サンティアゴ地区・サンミゲル地区という家庭内継承の街で、舞台と生活の距離が近い。</li>
<li><strong>パンプローナ「フラメンコ・オン・ファイアー」</strong>でエル・ペレが市庁舎バルコニーから歌い、子ども向けギター・舞踊教室も。エル・ペレはコルドバの歌い手で、ラ・ウニオンの大会でも評価された経歴。コルドバ・ラ・ウニオン・パンプローナが同じ週につながる。</li>
<li>マドリードがフラメンコを「国の顔」として輸出するとき、カタルーニャは距離を置き、アンダルシアは出自が薄まることを惜しむ。両方の視点を保つ。</li>
</ul>
<h2>フラメンコギタリスト列伝</h2>
<ul>
<li>第7回は<strong>ディエゴ・デル・ガストール（Diego del Gastor、本名 Diego Amaya Flores、1908–1973）</strong>。マラガ県アリアテ生まれ、一家はカディス県エル・ガストール出身（名の由来）。セビリア県モロン・デ・ラ・フロンテーラで育ち、同地で没した。</li>
<li>昨日のサビーカスと対照的に、生涯ほとんど町を離れず、商業スタジオ録音を残さなかった。現存音源はモロンでの私的な酒宴を外国人愛好家が録音したものが中心。「芸は仲間内の宴のためのもの」という姿勢だったと評伝は伝える。</li>
<li>奏法は親指（プルガール）の打ち込みが強く、短いトレモロに独特の粘り。速度より、コンパスの重さと沈黙の置き方で聴かせる。ファルセータは短いが、ブレリア・ソレアの拍が明瞭。歌と踊りを前に出し、ギターは土台に徹する伴奏観。</li>
<li>フェルナンダ／ベルナルダ・デ・ウトレラ、アントニオ・マイレナらの歌に付け、「モロンの流派」を育てた。甥のパコ・デル・ガストール、ディエゴ・デ・モロン、フアン・デル・ガストールが継承。</li>
<li>聞きどころ: モロンの酒宴を録った音源のブレリア。拍の隙間と親指の重みが、録音の粗さの向こうから立ち上がる。</li>
</ul>
<h2>フラメンコギター工房だより</h2>
<ul>
<li>今日は<strong>ジョン・レイ（John Ray）工房、コルドバ</strong>。公表情報によれば、1963年カナダ生まれ。1990年代にコルドバへ移住し製作家として定着した。</li>
<li>コルドバの名工マヌエル・レイエスに師事し、ミゲル・ロドリゲスら地元の系譜に連なる仕事をする。昨日のサビーカス（スペインから海外へ）とは逆に、外国から来てギターの都に根を張った例。</li>
<li>コルドバのギターは、ミゲル・ロドリゲス工房が築いた「明るく芯の強い音」が一つの基準。パコ・デ・ルシアも1969年製のコルドバ・ギターを長く使用した。</li>
<li>レイは新作製作に加え、サントス・エルナンデスやトーレスなど歴史的名器の調査・復元研究でも知られる。古い個体の力木の高さ、表板の厚みを実測し、現代の材で組み直す「歴史を手で読む」作業。</li>
<li>コルドバが大会70周年を祝う年に、その街で楽器を作り続ける人がいる。祭りと工房は同じ土地の根から伸びた枝。</li>
</ul>
