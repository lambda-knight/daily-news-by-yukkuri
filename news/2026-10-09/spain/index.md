<ul>

<li>カディスでは、マニラ・ガレオンの交易を通じ中国から渡り、スペイン文化の象徴になったマニラ・ショール27点を展示。フラメンコ衣装も、海を越えた交易史の産物である。</li>
<li>歌手ソラジャ・アルネラスはテレビ番組「オペラシオン・トリウンフォ」から25年を振り返り、「もうマドンナになろうとは思わない」「私は商品だった」と語った。</li>

<h2>フラメンコニュース</h2>
<ul>
<li>パンプローナ市と第13回フラメンコ・オン・ファイアは、エル・ペレの市庁舎バルコニー公演、二つのコンサート、未成年向けギター・舞踊教室を組み合わせた。</li>
<li>マドリードのコンデドゥケには「フラメンコ三部作」が到着。劇場で複数作品を連ね、単発の見せ場より作品構成でフラメンコを見せる。</li>
<li>マラガ県アロサイナのアルメナ・フラメンカは、カンテ、ギター、バイレを一つの催しに集める。フラメンコがアンダルシアの地域文化である一方、マドリードや北部都市が国の顔として紹介する二重性が見える。</li>
</ul>
<h2>フラメンコギタリスト列伝</h2>
<ul>
<li>今日の一人はパコ・ペーニャ、本名フランシスコ・ペーニャ・ペレス。1942年コルドバ生まれで、六歳から家族にギターを学び、十二歳でプロの舞台へ進んだ。1960年代に英国へ移り、独奏、舞踊団、教育を通じてアンダルシアの音楽を海外へ伝えた。</li>
<li>彼の重要性は、速弾きを前面に出すより、パロごとのコンパス、歌の輪郭、右手の音色を明瞭に示したことにある。親指は低音を太く置き、ラスゲアードは音量より拍の輪郭を作る。独奏でも歌のレトラが入る余白を思わせる句読点がある。</li>
<li>1981年には故郷コルドバにフラメンコ・センターを設立し、コルドバ・ギター祭の発展にも関わった。舞台作品では、独奏家が主役を独占せず、カンテ、バイレ、パルマが互いに合図を渡す構成を守る。</li>
<li>ウィグモア・ホールで2006年に録音したリサイタルは、各パロを一曲ずつ提示する教材のような構成である。<a href="https://wigmore-hall.bandcamp.com/track/pe-a-soleares-mi-sole">『Mi Sole』</a>では、低音を置いた後に高音を急がず、ソレアの十二拍を「埋める」のではなく支える間を聴きたい。</li>
<li>『Rosarillo』ではティエントスからタンゴスへ重心が変わり、同じ四拍系でも右手の密度が変化する。『Arroyo Pedroche』のブレリアでは、強拍を大声で示すのでなく、短いファルセータを拍の後ろへ置いて推進力を作る。</li>
<li>パコ・デ・ルシアが編成と和声を拡張した同時代に、ペーニャは伝統的なパロの文法を海外の聴衆へ翻訳した。二人は方向が違っても、ギターを伴奏の匿名性から独立した芸術へ押し上げた。</li>
<li>教える際にも型を固定するのでなく、コンパスを身体へ入れ、歌を聴いてから技法を置く順序を重視する。日本の稽古で形を正確に覚える方法と似るが、最後は共演者の呼吸へ応じて形を崩す点がフラメンコらしい。</li>
</ul>
<h2>フラメンコバイレ列伝</h2>
<ul>
<li>今日の一人はマノレテ、本名マヌエル・サンティアゴ・マジャ（1945–2022）。グラナダのサクロモンテに連なるマジャ一族の踊り手で、洞窟のザンブラから舞台へ進み、十五歳でマドリードへ移った。</li>
<li>マヌエラ・バルガスらの舞踊団、国立バレエ団への客演、1980年代の作品『マカマ・ホンダ』などで活動し、日本公演でも評価された。長身を生かした直立姿勢と、腕を大きく振り回さず空間を区切る造形が特徴である。</li>
<li>サパテアードは速さだけで押さず、足音の前後に静止を置く。ブラソは曲線を飾るより、胴体の垂直線と対照を作り、観客にコンパスの区切りを見せる。</li>
<li>Canal Surの公式アーカイブ<a href="https://www.youtube.com/watch?v=Z3hWQraKLBc">『マノレテ、グラナダでアレグリアスを踊る』</a>では、1991年の舞台で、カンカニージャとトニ・マジャの歌へ足を詰め込み過ぎない。歌の終わりで姿勢を止め、次のジャマーダへ入る瞬間を見ると、静止が合図になることが分かる。</li>
<li>教師としても後進へ影響し、男性舞踊を力強さだけに閉じず、姿勢、沈黙、線の美学として伝えた。故郷のザンブラを観光的な型に固定せず、劇場の構成へ移した橋渡し役でもある。</li>
</ul>
<h2>フラメンコカンテ列伝</h2>
<ul>
<li>今日の一人はフリアン・エストラーダ。コルドバ県プエンテ・ヘニル出身の歌い手で、地元の歌とアンダルシア各地のパロを土台に、明るく前へ飛ぶ声を持つ。</li>
<li>アレグリアスでは子音を強く切るより母音を伸ばし、十二拍の後半へ声を乗せる。ギターとパルマが密になっても、声の輪郭が埋もれないのが強みである。</li>
<li>Canal Surの公式アーカイブ<a href="https://www.youtube.com/watch?v=hnwvO8WhDVw">『フリアン・エストラーダのアレグリアス』</a>では、レトラの語尾を拍の手前で閉じず、次のコンパスへ橋を架ける。歌の途中でパルマが押し返す箇所に耳を向けたい。</li>
<li>カンテは独唱でありながら共同作業である。歌い手が句を伸ばせばギターは終止を待ち、短く閉じればレマーテを返す。エストラーダの歌は、その会話を明るい音域で聞き取りやすくする。</li>
<li>地域の祭典や放送アーカイブに演奏が残ることは、スターの録音だけでなく、現場でパロを継ぐ歌い手の技法を次代へ渡す意味を持つ。</li>
</ul>
<h2>フラメンコギター工房だより</h2>
<ul>
<li>スペイン国内の紹介済み工房が増えたため、切替規則の国外編として米国企業コルドバ・ギターズの「F7 Paco」を扱う。公式ページは<a href="https://cordobaguitars.com/iberia/f7-paco/">「F7 Paco Flamenco」</a>で、パコ・デ・ルシアの愛器群から着想した量産モデルである。</li>
<li>一般的な白フラメンコのスプルース表板とシープレス側板ではなく、カナディアン・シダー単板とインディアン・ローズウッドを採用する。そのため標準F7より暗く厚い音を狙いながら、薄めの胴と軽量設計、透明なゴルペ板でフラメンコの応答を残す。</li>
<li>650ミリ弦長、52ミリのナット幅、十二フレット接合という仕様は伝統的なスペイン式に沿う。手工品の一本ごとの調整ではなく、同じ設計を各国の学習者が入手できることが国外メーカーの役割である。</li>
<li>ローズウッドの持続音は独奏に厚みを与える一方、カンテや足音を支える場面では音を伸ばし過ぎない右手が必要になる。材料名だけで「本場の音」を保証せず、演奏現場での立ち上がりを確かめるべきモデルである。</li>
</ul>
<h2>フラメンコのパロ解説</h2>
<ul>
<li>今日のパロはアレグリアス。カディスに結びつくカンティーニャ群の代表で、19世紀にアラゴン地方のホタなど複数の歌が港町で交わり、現在の形へ発展したと説明される。起源を単一の作者へ帰すことはできない。</li>
<li>名は「喜び」を意味し、明るく祝祭的だが、速いだけの曲ではない。レトラ、ギターのファルセータ、踊りのエスコビージャ、沈黙を作る場面が連なり、舞台では緊張と解放を設計する。</li>
<li>コンパスは十二拍系。数え方は一から十二までだが、三、六、八、十、十二付近の重みを感じる型が基本になる。パルマと足は全拍を均等に強くせず、アクセントの間に軽い拍を置く。</li>
<li>調性はAメジャー系が典型で、ギターではEメジャー、B7、Aメジャーなどを使い、カポで歌い手の高さへ合わせる。台本ではエー・メジャー、イー・メジャー、ビー・セブンと読む。</li>
<li><a href="https://www.youtube.com/watch?v=Z3hWQraKLBc">『マノレテ、グラナダでアレグリアスを踊る』</a>では、歌のレトラの間は足数を抑え、歌が閉じた後にサパテアードを密にする。カンテを覆わず、踊りが前へ出る場所を選ぶ構成が見どころである。</li>
<li>カディスの地域文化を「スペイン全体の陽気さ」へ単純化すると、土地の歴史が消える。国の舞台で広く演じられても、港町カディスの言葉、風、歌の系譜を残すパロである。</li>
</ul>
<h2>まとめ</h2>
<ul>
<li>今日の鍵は、海外へ渡っても土地の文法を失わないこと。パコ・ペーニャの教育、マノレテの舞台、国外製ギター、アレグリアスがその違う答えを示した。</li>
<li>別れの言葉は「ケ・テ・バジャ・ビエン」。相手のこれからがうまく行くよう願う、温かい挨拶で締める。</li>
</ul>
