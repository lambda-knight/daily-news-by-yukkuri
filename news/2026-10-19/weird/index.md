<h2>4万6128人が同時に踊る、インド・バドーダラーのガルバが世界記録</h2>
<ul>
<li>ギネス世界記録は10月16日、インド西部グジャラート州バドーダラー市で開かれた「ヴィクシット・バーラト・サンカルプ・ガルバ」（おおむね「発展したインドへの誓いのガルバ」）を、「最大のガルバ・ダンス」として認定したと発表しました。認定人数は4万6128人です。</li>
<li>催しは10月7日、市内のM M パテル農場（ユナイテッド・ウェイ・ガルバ会場）で開かれました。主催はバドーダラー市当局と慈善団体ユナイテッド・ウェイ・オブ・バローダ。ギネスの審査員リシ・ナート氏が現地で見届け、認定証を市に手渡しました。インドの報道では参加者数を4万6818人と伝えたものもありますが、ギネスの公表値は4万6128人です。</li>
<li>認定の条件は3万人以上でした。地元の民謡歌手アトゥル・プローヒト氏（愛称アトゥル・ダダ）が歌い、約3000人の学生が、市の遺産、清潔さ、女性の力、発展したインドという4つのテーマを表す大きな輪を作りました。</li>
<li>ガルバは、女神ドゥルガーと女性的な神の力シャクティをたたえる9夜のヒンドゥー教の祭り、ナヴァラートリを中心に踊られる民俗舞踊です。伝統的には、明かりをともした素焼きの壺か女神の像を囲み、足さばき、手拍子、回転をそろえて輪になって回ります。壺は命と創造を表します。</li>
<li>ユネスコは2023年12月、「グジャラートのガルバ」を無形文化遺産に登録しています。審査員のナート氏は「ガルバは、見事な振り付け以上のものだ」と述べ、市の長官は「この達成はバドーダラーのすべての市民のものだ」としました。</li>
<li>出典: <a href="https://www.guinnessworldrecords.com/news/2026/10/more-than-46000-dancers-celebrate-the-indian-tradition-of-gabra">Guinness World Records</a> / <a href="https://www.businesstoday.in/india/story/viksit-bharat-sankalp-garba-vadodara-creates-guinness-world-record-with-46818-participants-560463-2026-10-08">Business Today</a></li>
</ul>
<h2>45.22キロ、火星の探査車パーシビアランスが「別の天体で最も長く走った車」に</h2>
<ul>
<li>NASAの探査車パーシビアランスは2026年10月11日、ジェゼロ・クレーターの縁にある「ラック・ド・シャルム」から「イドゥビ」へ向けて91.31メートル走り、通算走行距離が45.13キロから45.22キロになりました。ギネス世界記録が10月13日に伝えています。</li>
<li>これで、2018年に運用を終えた先輩の探査車オポチュニティーが約14年かけて走った45.16キロを抜き、地球以外の天体での最長走行距離の記録保持者になりました。</li>
<li>記録の系譜は月から始まります。旧ソ連の月面車ルノホート1号（1970年11月17日着陸）が10.54キロ、ルノホート2号が1973年に37キロを走り、この記録は40年以上破られませんでした。2014年7月27日にオポチュニティーが更新しています。</li>
<li>オポチュニティーの直線での最高速度は秒速3.7センチ、時速にして0.13キロ。2012年8月から活動するキュリオシティーは、1回に30〜50メートル、1時間に約140メートル進むペースで、これまで約38キロを走っています。</li>
<li>パーシビアランスの重さは1026.4キロ。1回の最長走行は411.7メートルです。地球との通信は片道約13分。位置推定の仕組み「マーズ・グローバル・ローカリゼーション」は、現在地を約25センチの精度で特定します。車輪のモーターは当初20キロ分の設計でしたが、今では少なくとも100キロは走れる見込みです。</li>
<li>NASAのスティーブ・リー氏は「パーシビアランスの距離記録は、火星の1日ごとに伸びていく」と話しています。</li>
<li>出典: <a href="https://www.guinnessworldrecords.com/news/2026/10/nasas-perseverance-rover-breaks-the-record-for-longest-road-trip-on-mars">Guinness World Records</a></li>
</ul>
<h2>3.16秒、オレンジソーダ500ミリリットルを飲み干したフィンランドの料理人</h2>
<ul>
<li>フィンランドの料理人トミ・コティライネンさん（26）が、「500ミリリットルの炭酸飲料を最も速く飲む」ギネス世界記録に認定されました。記録は3.16秒。ギネスが10月14日に発表しました。</li>
<li>挑戦したのは6月13日、ウーシマー県のヤルヴェンパーで、観客の前でした。この種目の記録保持者は彼が初めてで、ギネスが設けた基準の5秒を大きく下回りました。</li>
<li>飲んだのは、フィンランドで人気のオレンジソーダ「ヤッファ」。本人は「世界でいちばんの飲み物」と呼んでいます。</li>
<li>挑戦の理由は「ずっと、何かで一番になりたかった」。どう準備したのかと聞かれると「飲むことで」と冗談で答えました。</li>
<li>飲み終えた直後には大きなげっぷをし、もう一度やればもっと速くできると話しています。今後も飲み物の記録に挑むつもりです。</li>
<li>出典: <a href="https://www.guinnessworldrecords.com/news/2026/10/chef-chugs-500-ml-of-his-favourite-orange-soda-in-just-a-few-seconds-to-claim-record">Guinness World Records</a> / <a href="https://www.upi.com/Odd_News/2026/10/14/finland-Guinness-world-records-orange-soda/7121791997375/">UPI</a></li>
</ul>
<h2>神社が酒を造り、参拝者に振る舞う、白川郷のどぶろく祭が今日まで</h2>
<ul>
<li>岐阜県白川村の白川郷で、10月14日から「どぶろく祭」が開かれ、19日が最終日です。山の神に五穀豊穣、家内安全、里の平和を願う秋の祭礼で、約1300年前から祭礼にどぶろくが使われてきたとされます。</li>
<li>会場は2日ごとに移ります。14〜15日が荻町の合掌造り集落の南にある白川八幡神社、16〜17日が鳩谷八幡神社、18〜19日が道の駅白川郷の正面にある飯島八幡神社です。CBCテレビによると、白川村では9月下旬から10月中旬にかけて、5つの集落がそれぞれの神社で祭りを開いています。</li>
<li>どぶろくは、雪に埋もれる1月に、地域の酒米を使って神社の酒蔵で仕込みます。酒税法では自家醸造が禁じられているため、各神社は祭りで振る舞うための製造免許を取っています。仕込み量の多い神社では約5000リットルにのぼります。</li>
<li>1日の流れは、朝8時の神事、9時から獅子舞や五色の旗を連ねた御神幸の行列が笛や太鼓とともに集落を巡り、午後3時に神前へどぶろくを供える「どぶろくの儀」。3時半から5時ごろまで、大きな酒樽から「きったて」と呼ばれる容器に移して振る舞います。夜7時からは境内で獅子舞が奉納され、郷土芸能も披露されます。</li>
<li>飲むには、境内の志納所で神社指定の盃を受け取ります。盃のどぶろくを別の容器に移して持ち帰ることは禁じられ、違反すると退場です。車を運転する人は飲めません。</li>
<li>東海テレビは15日、秋晴れのもと、みこしと獅子舞が荻町地区の家々を巡ったと伝え、CBCテレビは17日の鳩谷八幡神社で、振る舞いが始まると会場が芳醇な香りに包まれ、「おいしい」「どぶろく祭り最高」という声が上がったと伝えています。</li>
<li>出典: <a href="https://news.web.nhk/newsweb/na/nd-20261015de59940">NHK</a> / <a href="https://www.chunichi.co.jp/article/1325165">中日新聞</a> / <a href="https://www.tokai-tv.com/tokainews/feature/article_20261015_48827">東海テレビ</a> / <a href="https://news.yahoo.co.jp/articles/2d8ac413773aff3250a5ea751ed8b0f822e0d67b">CBCテレビ（Yahoo!ニュース）</a> / <a href="https://www.nippon.com/ja/guide-to-japan/gu019021/">nippon.com</a> / <a href="https://tabi-mag.jp/shirakawago-doburoku/">ニッポン旅マガジン</a></li>
</ul>
<h2>パンも野菜もない肉だけ、バーガーキングの「オン ザ ビーフ」が1週間だけ復活</h2>
<ul>
<li>バーガーキングを運営するビーケー・ジャパンは、ハンバーガーのパティだけを売る「オン ザ ビーフ」シリーズを、10月16日から22日までの1週間限定で復活させました。前回は2025年9月26日から10月9日まで販売していました。</li>
<li>商品は4種類。塩コショウだけの「オン ザ ビーフ」が450円、パティ2枚の「ビーフ オン ザ ビーフ」が900円、ソース付きの「ソース オン ザ ビーフ」が550円、2枚にソースの「ソース オン ザ ダブルビーフ」が1000円です。</li>
<li>パティは100％ビーフで、専用のブロイラーで直火焼きします。ソースは、トマトとハラペーニョのスパイシー、焦がしねぎと赤味噌を隠し味にしたテリヤキ、スモーキーなバーベキューの3種類から選べます。</li>
<li>英語圏の日本情報サイト、ソラニュース24によると、パティはワッパーと同じものとみられ、ワッパー（690円から）より240円安い一方、メニューで最も安い360円のチーズバーガーよりは高くなります。</li>
<li>同サイトは、日本ではハンバーグが家庭料理や弁当、カレーの具として定着している一方、バーガーキングはご飯もカレーも売っていないので、付け合わせは自分で用意することになると指摘しています。</li>
<li>4商品のどれかを買うと、なくなり次第終了のオリジナルステッカーが1枚もらえます。</li>
<li>出典: <a href="https://gourmet.watch.impress.co.jp/docs/news/2148498.html">グルメ Watch</a> / <a href="https://soranews24.com/2026/10/18/burger-king-japan-now-selling-hamburgers-minus-everything-but-the-meat/">SoraNews24</a> / <a href="https://gigazine.net/news/20251001-burgerking-on-the-beef">GIGAZINE（2025年の販売）</a></li>
</ul>
