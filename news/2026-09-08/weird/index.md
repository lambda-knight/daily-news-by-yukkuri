<h2>ネタ1 ゲーム由来の対決遊び「アウラ・ファーミング」、ブラジル発でラテンアメリカとスペインの街頭へ</h2>
<ul>
<li>ブラジルで生まれた「アウラ・ファーミング（aura farming、日本語では「オーラ集め」に近い）」と呼ばれる路上の対決遊びが、2026年6月ごろからSNSを通じてラテンアメリカ各地へ広がり、AP通信が2026年9月1日に特集した</li>
<li>二人が向かい合い、ダンスやポーズ、キメ顔で「どちらのオーラが強いか」を competition 形式で見せ合う。相手に触れたり悪口を言ったりはせず、観客の歓声が大きかった方が勝ち。テレビゲームで経験値やアイテムを「farming（周回して稼ぐ）」する感覚から名前が付いた</li>
<li>よく使われる動きは、サッカー選手クリスティアーノ・ロナウドのゴール後のジャンプや、両手を動かしながら「シックス、セブン」と繰り返すネットミーム。参加者は漫画や映画のキャラクターの仮装で登場することも多く、映画専攻の学生リアム・ゴンサレスさん（20）はシュレックの姿で「恥ずかしさのない場所で自分のエッセンスを出すこと」と説明した</li>
<li>ブラジルの歩道から始まり、ペルー・リマの浜辺、アルゼンチン・ブエノスアイレスのオベリスク前、メキシコシティ、エクアドル・キト、スペインのマドリード・ブルゴス・サラゴサの広場にも登場した</li>
<li>コスタリカの教育省は「生徒同士の対立や授業の妨げになりうる」として公立学校での実施を禁止。一方でメキシコの教育相は自ら参加する動画を投稿し「良い教育をファーミングしている」と述べた。リマでは許可の問題で予定されたイベントが中止された</li>
<li>出典: <a href="https://ny1.com/nyc/all-boroughs/ap-top-news/2026/09/02/aura-farming-the-video-game-inspired-youth-trend-sweeping-latin-america">AP通信（Spectrum News NY1 配信）</a> / <a href="https://www.washingtonpost.com/world/2026/09/01/farming-aura-trend-latin-america-farmeando-aura/">The Washington Post</a></li>
</ul>
<h2>ネタ2 66年継ぎ足しの揚げ油、日本の唐揚げ店「wakatori」三代目・土屋佳宏さんが金賞</h2>
<ul>
<li>日本の唐揚げ店「wakatori（ワカドリ）」が、日本唐揚協会の「からあげグランプリ」で金賞を受賞し、三代目店主の土屋佳宏さんが「1960年代の開店当時から使い続けている揚げ油」が味の決め手だと明かした（オディティ・セントラル、ヴィジョン・タイムズなどが2026年6月中旬から下旬に報道）</li>
<li>土屋さんによると、古い油には新しい油では出せない複雑な香りとうまみがあり、66年間、一度も全部を捨てていないという。この話がSNSで広がると「客の健康を危険にさらしている」という批判が相次いだ</li>
<li>店側は「毎晩、油を清掃してろ過し、風味のベースとして少量の古い油だけを残して、新しい油を大量に継ぎ足している」と説明した。油の大部分は毎日入れ替わり、創業時の油はごくわずかに混ざっているだけだという</li>
<li>うなぎ店の「秘伝のたれ」や、老舗の「ぬか床」と同じ「継ぎ足し」の考え方を、揚げ油に当てはめた形になる</li>
<li>出典: <a href="https://www.odditycentral.com/foods/award-winning-fried-chicken-restaurant-hasnt-replaced-its-cooking-oil-in-66-years.html">Oddity Central</a> / <a href="https://www.visiontimes.com/2026/06/24/award-winning-japanese-fried-chicken-shop-stands-by-its-66-year-old-frying-oil.html">Vision Times</a></li>
</ul>
<h2>ネタ3 カナダ・オタワの新しい案内看板、l が1文字抜けて「公共の小広場」が別の意味に</h2>
<ul>
<li>カナダの首都オタワの中心部センタータウンで、地区の活性化事業「Uncommon Spaces（アンコモン・スペーシズ）」のために設置されたフランス語の案内看板に翻訳ミスが見つかった（ニュース・オブ・ザ・ウィアード2026年9月号などが紹介）</li>
<li>「公共の小広場」を意味する «Placettes Publiques» から l が1文字抜け、«Placettes Pubiques»、つまり「陰部の小広場」と読める表記で印刷・掲示されてしまった</li>
<li>事業を担当するセンタータウン商業改善地区のサブリナ・ルメイ事務局長は「これは意図しない翻訳ミスで、そのまま制作に回ってしまった」と釈明した。市議のステファニー・プラント氏も経緯を説明した</li>
<li>フランス語では公用語政策の関係で英仏併記の看板が多く、校正の網の目をすり抜けた一文字が、狙っていない意味を生んだ形になる</li>
<li>出典: <a href="https://funnytimes.com/news-of-the-weird-september-2026/">News of the Weird（Funny Times, 2026年9月号）</a></li>
</ul>
<h2>ネタ4 宇宙飛行士の食事から生まれた食品安全ルール「ハサップ」、始まりはピルズベリー社</h2>
<ul>
<li>スーパーの弁当や缶詰、給食の管理で世界的に使われている食品衛生の手法「ハサップ（HACCP）」は、もともとNASAの宇宙開発と製粉大手ピルズベリー社が1960年代に宇宙食を作る中で生まれたと、ワイアードが解説した</li>
<li>1961年のアラン・シェパードの弾道飛行のあと、宇宙船内では「くずが出て機器の間に浮かない食べ物」と「絶対に食中毒を起こさない食べ物」が必要になった。NASAはミネアポリスのピルズベリー社の微生物学者ハワード・バウマン博士に協力を求めた</li>
<li>アポロ計画の担当部署は、ロケット製造の品質管理にならい、完成品を検査するのではなく「工程のどこで危険が生まれうるか」をあらかじめ洗い出し、温度や時間などの「重要管理点」と、そこで守るべき数値の限界を決める方式を設計した</li>
<li>ピルズベリー社は1971年の全米食品保護会議でこの考え方を初めて公表。その後、アメリカの食品医薬品局が低酸性の缶詰の規制に採り入れ、いまでは各国の食品工場や飲食店に広がっている</li>
<li>出典: <a href="https://www.wired.com/story/how-nasa-testing-changed-us-food-inspection-forever/">WIRED「How NASA Testing Changed US Food Inspection Forever」</a> / <a href="https://spinoff.nasa.gov/moon-landing-food-safety">NASA Spinoff</a></li>
</ul>
