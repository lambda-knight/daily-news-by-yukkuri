<h1>世界から見た日本（2026年9月8日）</h1>
<h2>オープニング：2026年9月8日 — 世界から見た日本</h2>
<ul>
<li>今日は、ヴェネチア国際映画祭のコンペティション部門に入った是枝裕和監督の実写映画「ルック・バック」、同映画祭スポットライト部門で公開された海外制作の相撲ドキュメンタリー、京都市観光協会が7月に公表したオーバーツーリズムの分析、平和憲法9条をめぐる世代間の受け止めの変化を取り上げる。</li>
<li>参照するのはイタリアで開かれる映画祭の場、イギリスの映画専門誌スクリーン・デイリー、アメリカのAP通信とバラエティ、香港のサウスチャイナ・モーニング・ポスト、フランスのフランス24、日本研究誌アジア太平洋ジャーナル・ジャパンフォーカス。映画・スポーツ・観光・政治という日本国内では別々に語られる場面から、海外が日本のどこを見て何に引っかかっているかを当事者の言葉で追う。</li>
</ul>
<h2>是枝裕和「ルック・バック」、ヴェネチアが見た「漫画を作る手つき」</h2>
<ul>
<li>第83回ヴェネチア国際映画祭（9月2〜12日）のコンペティション部門で、是枝裕和監督の「ルック・バック」が9月7日にプレミア上映された。是枝監督にとって初めての漫画の実写化で、金獅子賞を争う21作品の1つに選ばれた。原作は藤本タツキが2021年に発表した読み切り漫画で、漫画を描く2人の少女の物語。</li>
<li>AP通信（9月7日）によると、是枝監督は原作をコロナ下で偶然読み、「監督である自分が感謝を形にする自然な次の一歩は、映画にすることだった」と語った。監督が中心に置いたのは「ペン先の音の変化」で、ためらいがちな線から自信のある線、デジタルのペンのタップ音までを描いたという。</li>
<li>出演のナツキ・デグチ、アジュ・マキタ、フリ・ナナセ、ロッカ・オカダは撮影前に数か月漫画を練習した。若いころの藤野を演じたナナセは「漫画を描くことがどれだけ大変か、分かっていなかった」と話した。是枝監督は、漫画がいまや「古典文学のように読まれる」ようになったとも述べた。</li>
<li>イギリスの映画専門誌スクリーン・デイリー（9月7日、評者ティム・グリアソン）は、穏やかなトーンと若い俳優の自然な演技を評価しつつ、「是枝の抑制がここでは過剰で操作的に感じられる」「物語が軽すぎる」と批判した。同じ日本の漫画文化を、海外の映画界はまず普遍的な創作の物語として受け止め、その上で演出の是非を論じている。</li>
</ul>
<h2>海外制作の相撲ドキュメンタリー、称賛と「描かなかったもの」への異論</h2>
<ul>
<li>ヴェネチア国際映画祭のスポットライト部門は、開幕作にドキュメンタリー「Sumo: Spirit Weighs Nothing」を選んだ。監督はアメリカの撮影監督エリック・シライで、「アンソニー・ボーディン」や「トーキョー・バイス」の撮影を手がけてきた。制作に約6年かかり、力士の信頼を得るのに時間を要したという。日本・アメリカ・イギリス・デンマークの共同制作。</li>
<li>アメリカの業界誌バラエティやデッドラインは、セピア調の光で撮られた映像美と、体を作り維持する痛みと労働を静かに見つめる姿勢を高く評価した。異なる時期の力士を追い、相撲という職業の幅を描いたとする。</li>
<li>一方でアジア系メディア「ジョイソース」の評者シッダント・アドラカ（9月4日）は、この作品が「八百長、しごき、暴力団との関係」に触れず、1993年以降の横綱の多くがアメリカかモンゴル出身である点や、力士が1990年代の約1000人から現在の約500人へ減った理由も掘り下げないと指摘した。主人公格の横綱・照ノ富士にある暴行疑惑にも触れていないという。</li>
<li>アドラカは、公式の関与がないのに結果として「プロパガンダ」になっていると評した。海外の作り手が相撲を美しく撮るとき、何を選び、何を外すか。同じ被写体でも、映像美を評価する業界誌と、誰を代表として映すかを問うアジア系媒体では読み方が分かれている。</li>
</ul>
<h2>京都のオーバーツーリズム、「中国人観光客のせい」を地元組織が数字で否定</h2>
<ul>
<li>京都市観光協会で観光地経営を担う組織は7月、市内の混雑や宿泊料の高騰を「本土からの中国人団体客が原因」とみる市民の受け止めが、実際の数字と食い違っていると報告した。香港のサウスチャイナ・モーニング・ポスト（7月21日）が伝えた。</li>
<li>報告によると、ここ数年、京都を訪れた中国本土からの観光客はむしろ少なかった。日中関係の悪化を背景に、北京が自国民に日本以外への旅行を促してきたためで、中国本土からの宿泊は大きく減っていた。同協会の企画・マーケティング担当タクヤ・ホリエ氏は、中国人客の数についての思い込みが強いと述べた。</li>
<li>分析側は、海洋をめぐる対立、拘束、ミサイル発射など中国関連の報道が連日続いたことが、市民の思い込みと不満を増幅し、敵意にもつながったとみている。</li>
<li>京都市は3月から宿泊税を引き上げ、高級室では1泊1万円の税を課す。市は税収が2024年の約61億円から約126億円へ倍増すると見込み、混雑対策と文化財保全に充てる。海外メディアは、混雑の主因を特定の国籍に帰す語りを、地元の数字で問い直している。</li>
</ul>
<h2>平和憲法をめぐる世代間の再交渉、被爆国の記憶と9条</h2>
<ul>
<li>日本研究誌アジア太平洋ジャーナル・ジャパンフォーカスは5月、政治学者シバタ氏による論考「抗議と3分の2 — 日本の平和主義、世代間の再交渉、来たる憲法上の総決算」を載せた。2月の選挙で改憲勢力が3分の2を確保した一方、国会前では大規模な抗議が続いた状況を分析している。</li>
<li>論考は、若い有権者の一定層が「平和」を道具的にとらえ直し、憲法上の制約ではなく抑止と安全保障を同一視するようになったとする。他方で抗議側の一部は抑止の論理そのものを退け、9条を同盟の枠組みに組み込めば防御と海外派遣の境界が保てなくなると主張する。シバタ氏は、若い世代は平和主義を捨てたのではなく、性別や経験によってばらつきながら作り直していると結論づけた。</li>
<li>香港のサウスチャイナ・モーニング・ポスト（4月27日）は、この抗議が女性主導である点に注目した。事業を営むレイナ・タシロ氏は「憲法は権力を縛るために存在する。高市早苗首相はそれを理解していない」と語った。抗議は2月末の数千人から、国会前の数万人へ膨らんだ。</li>
<li>フランスのフランス24（8月9日）は、長崎の被爆81年の式典を取り上げた。90か国以上が参列し、認定被爆者は3月時点で9万1000人、平均年齢は86.7歳。鈴木史朗市長は核兵器を「絶対悪」と呼び、抑止論を退けた。高市首相は非核三原則について「わが国は現在、堅持している」と述べるにとどめ、広島の82歳の被爆者サトシ・タナカ氏は「現状の説明だけで、将来には触れていない」と話した。</li>
</ul>
<h2>まとめ</h2>
<ul>
<li>今日の4件は、ヴェネチアの是枝映画、海外制作の相撲ドキュメンタリー、京都の観光分析、平和憲法をめぐる世代間の受け止め。国内では映画・スポーツ・観光・政治と別々に扱われる。</li>
<li>金獅子賞候補21作の1つ、相撲映画は4か国の共同制作、京都の宿泊税は倍増、被爆者は9万1000人で平均86.7歳。海外は、漫画を古典のように読み、相撲の何を映すかで割れ、混雑の原因を国籍で語る癖を数字で問い直し、日本の平和主義が世代でどう作り直されているかを見ている。いずれも日本の中では当たり前すぎて見えにくい場面で、評価主体と観察された場面までたどると輪郭がはっきりする。</li>
</ul>
