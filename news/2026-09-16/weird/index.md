<h2>円周190センチ、3人がかりで測ったジェシカさんのアフロ</h2>
<ul>
<li>ギネス世界記録は9月15日の世界アフロデーに、米国のジェシカ・マルティネスさんが2025年10月23日に樹立した女性最大のアフロ記録を紹介しました。</li>
<li>高さ29センチ、幅31センチ、円周190センチ。円周測定には3人が必要でした。</li>
<li>前保持者のエイヴィン・デュガスさんは2010年に初記録を取り、2021年と2023年に奪還。髪の手入れと文化的誇りを発信しています。</li>
<li>ジェシカさんへの「王冠」引き継ぎにもエイヴィンさんが立ち会い、競争だけでなく自然な髪を肯定する共同体の物語になりました。</li>
<li>出典: <a href="https://www.guinnessworldrecords.com/news/2026/9/world-afro-day-2026-these-incredible-afros-made-history-could-yours-be-next">Guinness World Records</a></li>
</ul>
<h2>934人が同時にバルカン式あいさつ</h2>
<ul>
<li>ロンドン科学博物館で9月8日、934人が中指と薬指を開く「バルカン式あいさつ」を同時に行い、初のギネス世界記録を樹立しました。</li>
<li>1966年9月8日に米国で初放送された『スター・トレック』の60周年行事です。</li>
<li>博物館の科学展示とファン文化を組み合わせ、架空の宇宙人の所作を、人間が一斉に再現する記録になりました。</li>
<li>出典: <a href="https://www.upi.com/amp/Odd_News/2026/09/15/Guinness-World-Records-Star-Trek-Vulcan-salute/3451789489055/">UPI</a> / <a href="https://www.euronews.com/culture/2026/09/10/star-trek-fans-successfully-set-new-guinness-world-record-at-london-museum">Euronews</a></li>
</ul>
<h2>カメラ眼鏡が近くに来ると知らせる「ZuckOff」</h2>
<ul>
<li>独立開発アプリZuckOffは、カメラ付き眼鏡が発するブルートゥースのメーカー識別信号をスマートフォンで検出します。</li>
<li>レイバン・メタ、オークリー・メタ、スナップ・スペクタクルズなどを対象とし、アカウントや外部サーバーを使わず端末内で処理します。</li>
<li>検出は録画の証拠ではなく、無反応でも眼鏡がない証明にはなりません。信号強度から分かる距離も概算で、方向は分かりません。</li>
<li>出典: <a href="https://zuckoff.app/">ZuckOff公式</a> / <a href="https://www.wired.com/story/zuckoff-app-sees-meta-glasses-before-they-see-you/">WIRED</a></li>
</ul>
<h2>「男らしく見える」とまつ毛を短くする流行</h2>
<ul>
<li>まつ毛を短くすると男性的に見えるとして、理髪店などで切る動画が各国のSNSに広がっています。</li>
<li>まつ毛の長さと密度は性別ではなく遺伝要因に左右され、上まぶたには平均約90〜160本、下まぶたには約75〜80本あります。</li>
<li>まつ毛はほこりや汗を遮り、目への接近物を感知してまばたきを促します。刃物を目元へ近づけること自体にもけがの危険があります。</li>
<li>出典: <a href="https://www.odditycentral.com/news/bizarre-beauty-trend-sees-men-trimming-their-eyelashes-to-look-more-masculine.html">Oddity Central</a> / <a href="https://www.sciencefocus.com/qanda/trim-eyelashes-dangers">BBC Science Focus</a></li>
</ul>
<h2>朝の散歩仲間が運河のエミューを救出</h2>
<ul>
<li>アリゾナ州ギルバートで9月13日午前8時45分ごろ、運河を泳ぐ大型の飛べない鳥エミューの通報が警察へ入りました。</li>
<li>警察が着く前に、朝の散歩をしていた近隣住民の一団が鳥を水から引き上げました。</li>
<li>エミューの名はタイニー。けがはなく、保護施設クリスタルズ・クリッター・ヘイブンを経て飼い主へ戻りました。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/09/15/emu-canal-Gilbert-Arizona/4331789484354/">UPI</a></li>
</ul>
