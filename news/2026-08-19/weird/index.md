<h2>オープニング：2026年8月19日 — 世界の珍ニュース</h2>
<h2>ネタ1 針を使わない「痛くない永久タトゥー」、英スタートアップが開発</h2>
<ul>
<li>英国のスタートアップ「Cipher X」が、世界初をうたう「痛みのない永久タトゥー」システムを発表した</li>
<li>仕組みはマイクロニードル技術で、色素を含む微小構造の付いたパッチを専用装置で肌に当て、約15分間保持することで色素を放出する。針の穿刺はなく、施術直後は薄いが24〜48時間かけて発色が濃くなる</li>
<li>創業者でCEOのフェルディナンド・コール氏は、自身が血や針を強く怖がることが起業のきっかけだったと語り、「現代の工学とデザインを通じてタトゥーを再構想する探求」だと説明している</li>
<li>現時点ではデザイン領域が直径15ミリ以内、色は黒のみに限定され、提供地域もロンドンに限られる。既存の永久タトゥーと同様に消すにはレーザー除去が必要で、「痛くない」以外は通常のタトゥーと同じ制約が残る</li>
<li>出典: <a href="https://www.odditycentral.com/news/uk-based-startup-launches-worlds-first-painless-permanent-tattoo-system.html">Oddity Central</a></li>
</ul>
<h2>ネタ2 捨てられたエミューの卵を6個引き取り、割れた殻を金継ぎで直した男性</h2>
<ul>
<li>オーストラリアの動物保護活動を行うAlwyn Wils氏（YouTubeチャンネル「A Chick Called Albert」運営）が、産まれてから3週間以上放置されていた捨てエミューの卵6個を引き取った</li>
<li>検査の結果、生存可能だったのは6個のうち2個のみ。1個目の孵化は比較的順調だったが、2個目は卵膜が乾燥していて難航したという</li>
<li>Wils氏は「この卵たちに可能性を与えるしかなかった」と振り返っており、孵化を見届けたあと、割れた殻の一部を日本の伝統技法「金継ぎ」の精神にならい、金箔で修復した</li>
<li>割れた場所を隠さず金で縁取って可視化する金継ぎの発想を、卵の殻という壊れやすい対象に応用した点が、SNSで「発想が美しい」と話題になっている</li>
<li>出典: <a href="https://laughingsquid.com/abandoned-emu-eggs-gold-leaf/">Laughing Squid</a></li>
</ul>
<h2>ネタ3 「ハトが好きすぎて」始まった、フィラデルフィアの鳩ウォーキングツアー</h2>
<ul>
<li>米フィラデルフィア・サウスフィリー地区で、Hannah Michelle Brower氏とAspen Simone氏が「Philly Pigeon Tours」というハト専門の街歩きツアーを始めた</li>
<li>きっかけは、Brower氏が体調を崩したハト「プリムローズ」の保護を手伝ったこと。その後この個体を引き取って飼うようになり、ハトへの関心が地域住民と共有したいほど強くなったという</li>
<li>ツアーではハトの行動・生態・歴史に加え、移民や都市化、生態系、持続可能性といった現代的な話題をハトというレンズを通じて解説し、「ハトは汚い迷惑な鳥」という一般的な誤解を解くことを目的にしている</li>
<li>一羽の保護がきっかけで地域ツアー事業が生まれた点が、単なる動物好きの域を超えた継続的な活動として注目されている</li>
<li>出典: <a href="https://laughingsquid.com/philly-pigeon-tours/">Laughing Squid</a></li>
</ul>
<h2>ネタ4 保護猫ゾーイ、シェルターから4週間でカヤックデビュー</h2>
<ul>
<li>米ニューハンプシャー州で、保護されたオレンジ色の猫「ゾーイ」が飼い主とのカヤック遊びを楽しむ様子が話題になっている</li>
<li>ゾーイはシェルターから引き取られてわずか4週間後にカヤックを始めた。飼い主はまず陸の砂の上でカヤックに慣れさせ、次に膝の上に乗せたまま水上で静止させ、最後にゆっくり桟橋から押し出すという段階を踏んで慣らしたという</li>
<li>最初は不安定だったが、すぐにバランスの取り方を覚え、今では自分から船首まで歩いて座るようになった。2艘のカヤックの間を行き来することもあり、まれに水に落ちても動じないという</li>
<li>飼い主はInstagramアカウント「@zoeyzestyclaws」で日々の活動を発信しており、慎重な段階づけが猫の新しい遊びへの適応を後押しした例として紹介されている</li>
<li>出典: <a href="https://laughingsquid.com/orange-cat-loves-kayaking/">Laughing Squid</a></li>
</ul>
