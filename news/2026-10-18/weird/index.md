## 概要

近くの白色矮星151個を調べたら、ほとんどは本当に白く、ナトリウムがオレンジ色を吸う1つだけが緑色だった。トルコ沖では、船体が消えても壺の形から約4700年前と推定された沈没船と、ヤギの乳でチーズを作ったかもしれない穴あきの壺。さらに、1996年から破られない63.98メートルの長靴投げの世界記録と、噴水やピアノを弾くワニを経て7代目へ向かう道頓堀のグリコサイン。世界と日本の無害で不思議な4題です。

<h2>白色矮星は白かった、そして1つだけ緑だった、ウォーリック大学の色の調査</h2>
<ul>
<li>英ウォーリック大学のマーク・ホランズ博士らが、白色矮星が人の目にどんな色に見えるかを調べた論文を、英王立天文学会の学術誌「RASTI（RAS Techniques and Instruments）」に発表しました。大学の発表は10月15日、CNNが17日に伝えています。</li>
<li>白色矮星は、太陽のような星が燃え尽きた後に残る、とても高密度の芯です。どの白色矮星も、近くで直接見られるほど地球に近くはありません。チームは既存のスペクトル（光を波長ごとに分けたデータ）を、人の色覚のモデルに通して「見え方」を計算しました。</li>
<li>対象は地球から20パーセク（約65光年）以内にある151個。146個の色温度の中央値は約6800Kで、見た目はまさに白でした。「白色矮星は青っぽい」という通説は、明るい青い星ほど観測で拾われやすいための思い込みだったとしています。共著者のボリス・ゲンジケ教授は「平均的な白色矮星は、本当に白い」と話しています。</li>
<li>残る5個は、黄色が2個、ピンクが3個。冷えた白色矮星の大気は水と同じ1立方センチあたり約1グラムまで密度が上がり、炭素・カルシウム・ナトリウムなどの微量元素が、幅広い色の光を吸うためです。</li>
<li>緑色だったのは、この範囲の外にある「WD J1330+6435」。表面温度は約4000度で、かつての惑星系から岩石の破片を取り込み、大気にカルシウム、リチウム、ナトリウムを含みます。ナトリウムがオレンジ色の光を吸うため、黄緑色に見えると計算されました。チームは「銀河で初めて知られた、本当に緑色の星」としています。</li>
<li>ほかに、約48光年先の「WD J1011+2845」は、炭素の分子が600ナノメートルより短い光をほぼ吸い取り、サーモンピンクに光る、記録上もっとも赤い星の候補です。おおいぬ座のシリウスの伴星、シリウスBは淡い青でした。</li>
<li>チームは、宇宙の白色矮星の約30個に1個が変わった色をしていると見積もっています。ホランズ博士は「この極端に密度の高い星が、だれも予想しなかった色を出せることが分かった」と述べました。</li>
<li>出典: <a href="https://warwick.ac.uk/news/pressreleases/astronomers-reveal-true-colours-of-white-dwarf-stars/">University of Warwick</a> / <a href="https://www.cnn.co.jp/fringe/35253665.html">CNN.co.jp</a> / <a href="https://www.space.com/astronomy/stars/astronomers-discover-the-1st-ever-green-star-a-cosmic-zombie-just-in-time-for-halloween">Space.com</a></li>
</ul>
<h2>船にヤギを乗せてチーズを作った？　トルコ沖で約4700年前の沈没船</h2>
<ul>
<li>トルコ文化観光省は10月14日、南部アンタルヤ県のケコバ島沖で、世界最古とみられる沈没船を確認したと発表しました。積み荷のアンフォラ（取っ手の付いた運搬用の壺）は約4400〜4700年前のもので、青銅器時代の前期にあたります。</li>
<li>現場は水深約30メートル。木造の船体は朽ちて残っておらず、放射性炭素による年代測定はできていません。年代は積み荷の壺の様式から割り出したもので、「最古」は暫定的な評価です。</li>
<li>発掘を指揮するのはアクデニズ大学のハカン・オニズ准教授。最初の調査では新しい時代の船だと考えられていましたが、エジプトのギザのピラミッド付近で出土したアンフォラの論文を読んだオニズ氏が、形の類似に気づきました。再び潜って調べ直し、オーストラリアの考古学者カリン・ソワダ氏とも年代の見方が一致しました。</li>
<li>粘土の分析では、壺はヨルダン渓谷の工房で作られた可能性が高いとされます。同じ型の壺はギザ、サッカラ、アブシールのピラミッド周辺のほか、トロイやクレタ島でも見つかっています。船はレバント沿岸の港を出て、トロイかクレタ島へ向かう途中で沈んだとみられます。</li>
<li>中身はオリーブ油かワインと考えられています。ただ、1つの壺だけは胴に2つの穴と9つの刻み目があり、バターやチーズを作る攪拌用の壺だった可能性があります。そうだとすれば、船乗りがヤギを乗せて航海し、航海中に乳を搾って乳製品を作っていたことになります。これは研究者の推測の段階です。</li>
<li>発掘は2026年、アンタルヤ博物館の管轄で始まりました。錨などほかの遺物も同じ時代のものと確認されています。</li>
<li>出典: <a href="https://www.euronews.com/2026/10/14/worlds-oldest-shipwreck-off-turkey-4700-year-old-amphorae-discovered">Euronews</a> / <a href="https://www.cnn.co.jp/fringe/35253565.html">CNN.co.jp</a> / <a href="https://www.aljazeera.com/news/2026/10/14/worlds-oldest-shipwreck-found-off-coast-of-turkiye">Al Jazeera</a></li>
</ul>
<h2>63.98メートル、30年破られない長靴投げの世界記録</h2>
<ul>
<li>英国発祥の競技「ウェリー・ワンギング（長靴投げ）」の男子世界記録が、10月12日で樹立から30年を迎えました。ギネス世界記録が同日、記事で紹介しています。</li>
<li>記録保持者はフィンランドのテッポ・ルオマさん。1996年10月12日、フィンランドのハメーンリンナで、長靴を63.98メートル投げました。女子記録も同じ1996年で、4月19日にトゥルクでサリ・ティルッコネンさんがサイズ8のダンロップ製長靴を40.87メートル投げています。どちらも破られていません。</li>
<li>63.98メートルは、ギネスによると乗用車およそ15台分、ロンドンの2階建てバス6台を縦に並べた長さ、ジャンボジェットの翼の幅にあたります。</li>
<li>競技は1970年代にイングランド南西部で始まったとみられ、村の祭りや募金行事の定番になりました。ギネスが最初に認めた世界最高は、1978年にイングランドのウィルトシャーでトニー・ロジャースさんが記録した52.73メートルです。</li>
<li>「聖地」とされるのは、ウェスト・ヨークシャーのホルムファース近くの村アッパーソング。世界選手権が開かれ、地元の言い伝えでは、パブで農夫が別の農夫の長靴にビールをこぼし、怒った農夫が長靴を脱いで逃げる相手に投げつけたのが始まりとされます。</li>
<li>アッパーソングの規則では、改造していない緑色のサイズ9のダンロップ製長靴を使い、助走は42歩まで。追い風は歓迎ですが、風を待てるのは1分だけで、人工の風は禁止です。投げ方は自由で、片手でも両手でも、後ろ向きでも股の間からでも構いません。</li>
<li>地域によって規則は違い、立ったまま投げる大会、サマセットの一部では長靴に水を入れる大会、勢いを付けないようごみ箱の中に立って投げる大会もあります。ギネスには「同時に長靴を投げた最多人数」の記録もあり、ホルスワージーの農業ショーで792人が投げました。</li>
<li>出典: <a href="https://www.guinnessworldrecords.com/news/2026/10/how-far-can-you-wang-your-welly-enough-to-beat-this-30-year-old-record">Guinness World Records</a></li>
</ul>
<h2>噴水、ピアノを弾くワニ、14万個のLED、道頓堀のグリコサインが7代目へ</h2>
<ul>
<li>江崎グリコは10月14日、大阪・道頓堀の看板「グリコサイン」の6代目の掲出を2026年11月末で終え、12月から改修工事に入ると発表しました。7代目の掲出は2027年春の予定で、デザインは明かしていません。</li>
<li>6代目は2014年10月に点灯。縦20メートル、横10.38メートルで、LEDチップは14万3976個。日没後から午前0時まで、両手を上げて走るランナーの背景に国内外の名所を映してきました。</li>
<li>同社の担当者は、7代目でも「ランナーが主役であり続ける」と説明しています。英語圏の日本情報サイト、ソラニュース24は、看板の前に1日7万〜8万人が訪れると伝えています。</li>
<li>初代は1935年、創業者の江崎利一が人通りの多いこの場所に建てた高さ33メートルのネオン塔。ランナーと文字を6色に変え、花模様を毎分19回点滅させましたが、1943年に戦時の鉄材供出で撤去されました。</li>
<li>2代目（1955〜1963年）は高さ21.75メートルのネオン塔で、下に高さ5.26メートルの特設ステージがあり、ワニ君の人形がピアノを弾き、人形劇やロカビリー大会も開かれました。</li>
<li>3代目（1963〜1972年）は噴水ネオン塔。150本のノズルから12トンの水を噴き上げ、12色のランプ400個で虹模様を描きました。</li>
<li>4代目（1972〜1996年）は陸上競技場のトラックを点滅させてランナーに躍動感を出し、1996年1月21日に消灯。約2年半の空白を経て、1998年7月に5代目が点灯し、大阪城や通天閣を背景に時間帯で色が変わる仕掛けになりました。</li>
<li>今回の工事期間中、道頓堀は冬の間ランナー不在になります。</li>
<li>出典: <a href="https://www.watch.impress.co.jp/docs/news/2148018.html">Impress Watch</a> / <a href="https://soranews24.com/2026/10/17/osakas-famous-glico-running-man-will-be-removed-and-replaced-with-a-new-look-sign/">SoraNews24</a></li>
</ul>
<h2>まとめ</h2>
<ul>
<li>ウォーリック大学の調査では、近くの白色矮星151個のほとんどは本当に白く、ナトリウムがオレンジ色を吸う1つの星だけが緑色に見えました。</li>
<li>トルコ沖の沈没船は、船体が消えても壺の様式と粘土から約4700年前と推定され、穴の開いた1つの壺が、ヤギと航海した船乗りの姿を想像させます。</li>
<li>ルオマさんの63.98メートルは、10月12日で30年。パブのいさかいから生まれたとされる遊びに、42歩の助走と1分の風待ちという細かな規則が付いています。</li>
<li>グリコサインは11月末で6代目を終え、春に7代目へ。噴水やピアノを弾くワニを経ても、主役はずっと走る人です。</li>
</ul>
