<h1>スペイン文化・フラメンコ便り（2026年9月12日）</h1>
<h2>オープニング：2026年9月12日 — スペイン文化・フラメンコ便り</h2>
<ul>
<li>今日の柱は、アルバ・フローレスが率いる舞台『リブレス！！！』、三つの土地で続くフラメンコの実演、トリアナの作曲家ラファエル・リケーニ、グラナダのホセ・ロペス・ベジード工房、そしてカディス生まれのパロ「アレグリアス」。</li>
<li>公演、演奏家、製作家、曲種を一本の線で結び、「明るい音楽は、何を積み重ねて明るく聞こえるのか」を考える。</li>
</ul>
<h2>今日のスペイン語ひとこと</h2>
<ul>
<li><strong>Dar el cante（ダル・エル・カンテ）</strong>。直訳は「歌を差し出す」だが、日常では「悪目立ちする」「場違いで目立つ」の意味で使う。</li>
<li><code>cante</code> はフラメンコの歌そのものを指す語でもある。舞台では声を前へ出すことが芸になり、日常では出すぎると揶揄になる、スペイン語らしい二面性がある。</li>
<li>用例は <code>Con esa chaqueta vas a dar el cante</code>。「その上着だと目立つよ」。日本語の「浮く」より、周囲の視線を集める感じが強い。</li>
</ul>
<h2>国際情勢（スペイン視点）</h2>
<ul>
<li>今回は文化・音楽へ集中する。紅海や米国の9・11追悼など国際記事は多いが、スペインが直接の当事者ではないため採用しない。</li>
</ul>
<h2>スペイン国内ニュース</h2>
<ul>
<li>セウタでは移民が暮らす仮設小屋42棟が一夜に焼け、港の海上保安レベルが2へ引き上げられた。北アフリカにあるスペイン領の暮らしと地中海移動が直結する出来事として、この一点だけを押さえる。</li>
</ul>
<h2>文化・芸能ニュース</h2>
<ul>
<li>マドリードの舞台『リブレス！！！』では、マドリード生まれの俳優<strong>アルバ・フローレス</strong>が中心となり、独裁以前のスペインで活動した女性たちの系譜を、当時の刺激的なクプレとキャバレーで描く。「離婚万歳」という題句は、家族制度を笑いながら問い直した大衆歌謡の攻撃力を現在へ戻す。</li>
<li>フローレスは俳優一族に育ち、音楽家アントニオ・フローレスを父に持つ。歌を家業の飾りにせず、舞台上で政治的記憶を運ぶ道具へ変えている点が、この新作の聞きどころである。</li>
<li>小説家<strong>ハビエル・セルカス</strong>はセゴビアのヘイ・フェスティバルで、1981年2月23日のクーデター未遂時には恐怖から沈黙が広がったと振り返った。新著『民主主義の新聞』と結びつけ、民主化を英雄譚だけでなく「声を出せなかった時間」から語る。</li>
<li>故<strong>ハビエル・マリアス</strong>の、シェイクスピアを論じた未邦訳随筆がスペイン語で刊行される。文学、映画、サッカーを横断した小品を集める企画で、長編小説だけでは見えにくい日々の批評作業に光を当てる。</li>
<li>日本では社会運動を硬い記録として残しがちだが、『リブレス！！！』は歌と笑いで再演する。祭りや大衆歌謡を公共の記憶装置にする点に、スペインらしい表現の強さがある。</li>
</ul>
<h2>フラメンコニュース</h2>
<ul>
<li><strong>パンプローナ「フラメンコ・オン・ファイア」</strong>では、コルドバ出身の歌い手エル・ペレが市庁舎のバルコニーから歌い、コンデスタブレ館で二公演、未成年向けのギターと舞踊の教室も行われた。劇場券を持つ人だけでなく、広場の通行人と子どもへ入口を開いた催しである。</li>
<li><strong>マラガ県アルチドナの「ラ・ポラ・フラメンカ」</strong>は、カンテ、バイレ、ギターを一晩に並べる地域公演として再開した。完成された独奏より三者の呼吸を前面に出し、歌の伸縮をギターと足拍子が受け止める本来の座組を見せる。</li>
<li><strong>サラゴサ県エヘア・デ・ロス・カバジェロス</strong>では、リカルド・フェルナンデス・デル・モラルの一座が『ヌエストロ・フラメンコ』を上演する。本人は歌とギターを兼ね、舞踊を加えた小編成で、役割が固定される前の親密なフラメンコへ観客を案内する。</li>
<li>パンプローナとエヘアはアンダルシアの外にある。広がりは文化の強さだが、ヘレス、セビリア、コルドバ、グラナダの生活とヒターノを含む複数共同体が育てた由来まで「スペイン一般」に均してしまえば、発祥地の経験は薄くなる。</li>
<li>地域の祭りを土地の人が支える構図は日本にも似る。ただしスペインでは、客席と演者がパルマで同じコンパスへ入るため、鑑賞と参加の境目がいっそう近い。</li>
</ul>
<h2>フラメンコギタリスト列伝</h2>
<ul>
<li>第8回は<strong>ラファエル・リケーニ（Rafael Riqueni、1962年生）</strong>。セビリアのトリアナ地区に生まれ、11歳でニーニョ・リカルドの音に出会ってフラメンコギターへ進んだ。14歳でコルドバの全国フラメンコ芸術大会、17歳でヘレスのコンクールに入賞した。</li>
<li>初期作『フエゴ・デ・ニーニョス』『ミ・ティエンポ』では伝統的なパロを作曲家の視点で組み直し、『アルカサル・デ・クリスタル』では和声と音色の幅を広げた。のちの『パルケ・デ・マリア・ルイサ』は、セビリアの公園を歩く記憶をギター組曲へした作品である。</li>
<li>右手の速さを前面に出すタイプではない。分散和音の内声を残し、旋律の前後へ静かな間を置く。左手は開放弦を混ぜた和音で響きを重ね、コンパスを守りながらクラシック音楽に近い長い構成を作る。</li>
<li>カンテ伴奏では歌の語尾を音で埋めず、独奏では同じ「空け方」を旋律の呼吸へ変える。昨日のディエゴ・デル・ガストールが短いファルセータと重い親指でモロンの宴を支えたのに対し、リケーニは街の風景を長い組曲へ展開する。</li>
<li>まず『パルケ・デ・マリア・ルイサ』の表題曲を聴くとよい。冒頭の少ない音、開放弦の余韻、旋律が戻る位置に耳を置くと、技巧より記憶を語る奏者だと分かる。</li>
</ul>
<h2>フラメンコギター工房だより</h2>
<ul>
<li>今日は<strong>ホセ・ロペス・ベジード（José López Bellido）工房</strong>。グラナダのギター工房が集まるクエスタ・デ・ゴメレスで、1960年代末にエドゥアルド・フェレールのもとで製作を学び、1970年代から自らの名で製作を続けてきた実在の工房である。</li>
<li>工房はクラシックとフラメンコの両方を手掛ける。フラメンコ器では一般にスプルース表板とシープレスの横・裏板を選び、軽い胴、低めの弦高、速い立ち上がりを狙う。クラシック器の長い余韻より、歌、パルマ、靴音の間へ輪郭を差し込む用途が優先される。</li>
<li>肝は薄さだけではない。表板を支える扇状の力木、ネック角、サドル高を組み合わせ、強いラスゲアードやゴルペでも音が潰れない位置を探る。奏者の右手が強ければ、弦高を単純に下げるだけでは雑音が増えるため、調整は演奏姿勢との共同作業になる。</li>
<li>クエスタ・デ・ゴメレスはアルハンブラへ上る坂で、複数の工房が近接する。技術が一軒だけに囲い込まれず、師弟と隣人のあいだを移る環境は、日本の工芸産地に似た職住一体の強みを持つ。</li>
</ul>
<h2>フラメンコのパロ解説</h2>
<ul>
<li>今日のパロは<strong>アレグリアス（Alegrías）</strong>。カディスを代表する明るいカンテで、19世紀初めの半島戦争期にアラゴンのホタがカディスへ入り、港町の歌と混ざったという説明が有力だが、成立過程には諸説ある。カンティーニャス系の一種に位置づけられる。</li>
<li>名は「喜び」の複数形。海、カディスの街、美しさや恋を歌うことが多く、バイレでは歌のレトラ、ギターのファルセータ、足技を見せるエスコビージャ、テンポを上げるブレリア・デ・カディスへ展開する構成がよく使われる。</li>
<li>コンパスは12拍を一巡とし、数え方の一例では<strong>3、6、8、10、12</strong>に重みを置く。パルマはこの骨格を保ち、サパテアードは8・10・12付近の応答を際立たせる。明るく速くても、均等な12個の音にしてはいけない。</li>
<li>ギターは長調が基本で、ホ長調なら主和音のホ長調と属和音のロ長調、下属和音のイ長調を軸にする。伝統的なカディスの色として、ホ短調へ一時的に陰る変化も使われる。歌い手の音域に合わせてカポタストを置き、ファルセータの終わりを歌の入口へ正確に返す。</li>
<li>喜びは単なる速さではない。重い場所が決まった12拍、長調の開放感、一瞬の短調の陰りがそろって初めて「アレグリアスらしい明るさ」になる。</li>
</ul>
<h2>まとめ</h2>
<ul>
<li>2026年9月12日は、女性史を歌うアルバ・フローレス、広場へ出るエル・ペレ、街を組曲にするリケーニ、坂道で木を削るロペス・ベジード、12拍の重心で喜びを作るアレグリアスを通じ、スペイン文化の明るさが技術と記憶の積み重ねだと見た。</li>
</ul>
