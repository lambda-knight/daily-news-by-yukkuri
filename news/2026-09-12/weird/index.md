<h2>パスタ生涯無料、112回の食事を記録するブレイデン・シンクレアさん</h2>
<ul>
<li>アメリカのブレイデン・シンクレアさん（33）は、レストランチェーン「オリーブ・ガーデン」が2019年に50人だけへ販売した生涯パスタ・パスの保有者。通常の期間限定パスを最初に買った50人が、400ドル追加すると取得できた</li>
<li>パスは店内飲食に限り、パスタ、具、ブレッドスティック、スープまたはサラダを、生涯にわたり追加料金なしで注文できる。配達には使えない</li>
<li>シンクレアさんは2026年、自作サイトで2019年以降の利用を可視化。9月11日の報道時点で来店112回、パスタ152皿、推計15万4817キロカロリー、通常価格換算1878.87ドル、チップ607ドルを記録していた</li>
<li>最多はリガトーニ、ソースはアルフレード、具はクリスピー・チキン。サイトの投票で次の組み合わせを決めてもらうと、最初の投票には700票以上が集まった</li>
<li>一度に大量注文はせず、おかわりも避け、店員の負担を増やさない「低負荷の客」を心がける。妻とは高校時代から同店へ通い、4歳の長男もパスタ好きだが、子ども抜きの外食では別の店を選ぶという</li>
<li>出典: <a href="https://www.wired.com/story/this-man-has-a-cult-internet-following-over-his-olive-garden-lifetime-pasta-pass/">WIRED（2026年9月11日）</a> / <a href="https://lifetimepastapass.com/">Lifetime Pasta Pass</a></li>
</ul>
<h2>初心者は数分で修理、農家は使わないジョン・ディアの診断サービス</h2>
<ul>
<li>WIRED記者は2026年9月、カリフォルニア州サンタクララの実演で、ジョン・ディア製5130MLトラクターの「燃料への水混入を監視するセンサー」の外れた配線を、パソコン上の説明を見ながら数分でつなぎ直した</li>
<li>使ったのは2025年開始の自己修理サービス「オペレーションズ・センター・プロ・サービス」。電子制御機器の付いたほぼ全機種に対応し、機械1台あたり年195ドルから、全機種版は年4995ドルから、農業・芝管理向け全機種版は年5995ドル</li>
<li>シリアル番号に合う説明書や診断情報を示し、通信できない場所向けのオフライン機能もある。ジョン・ディアによれば開始1年後の利用者は1日約1000人だが、アメリカには約180万の農場がある</li>
<li>ミズーリ州でトウモロコシと大豆を3000エーカー栽培するジャレッド・ウィルソンさんは、単純な故障なら使えても、診断コードが3つ、4つと出た場合にどこから調べるか分からないと指摘。自分も周囲の農家も利用していないと話した</li>
<li>ジョン・ディアは4月に9900万ドルの和解、7月には連邦取引委員会が起こした別訴訟で、製品を修理しやすくする内容の和解に応じた。ただし、いずれも裁判官の最終承認前で、同社は不正を認めていない</li>
<li>出典: <a href="https://www.wired.com/story/i-fixed-a-tractor-john-deere-self-repair-service/">WIRED（2026年9月11日）</a></li>
</ul>
<h2>「残業は上司の承認制」、承認者が不在なので毎日定時退社</h2>
<ul>
<li>インターネット投稿を紹介したTwistedSifterの2026年9月11日記事によると、ある匿名の経理担当者は年俸3万7500ドルで、契約上は週40時間勤務だった。本人談に基づく逸話で、企業名や契約書は公開されていない</li>
<li>年俸4万ドル未満の労働者へ残業代を認める制度変更を見込み、週45〜55時間働くようになったところ、会社は「残業には上司の承認が必要」とする書面へ署名させた。書面には開始日も終了日もなかったという</li>
<li>担当者はただちに残業をやめ、昼休みを取り、毎日午後5時1分に退社。午後4時45分に重要な依頼が来ても承認を求めたが、承認権者は平日午後2時から8時まで法科大学院の授業で連絡がつかなかった</li>
<li>その後、想定された残業制度は裁判官に差し止められ、会社は承認制を不要と説明した。しかし担当者は日付のない合意書と、週40時間と書かれた元の雇用契約を示して定時勤務を続けたと投稿している</li>
<li>数カ月後に解雇されたが、学んでいた別分野へ転職し、4年後の現在は在宅で働いているという。会社の統制策が、承認権者の不在と契約文言によって、残業を断る根拠へ反転した話として読まれた</li>
<li>出典: <a href="https://twistedsifter.com/2026/09/accountant-is-told-not-to-work-overtime-unless-the-boss-approves-it-first-so-she-enjoys-working-40-hours-a-week-and-not-a-second-more/">TwistedSifter（2026年9月11日）</a></li>
</ul>
<h2>まとめ</h2>
<ul>
<li>パスタ・パスは食べ放題をデータ作品へ、修理サービスは簡単な実演を権利と信頼の論争へ、残業承認書は会社の防御策を定時退社の根拠へ変えた</li>
<li>制度の名前よりも、価格、利用条件、承認経路を具体的にたどると、人と仕組みの意外な関係が見えてくる</li>
</ul>
