</ul>
<h2>今日のスペイン語ひとこと</h2>
<ul>
<li><strong>tener duende（テネール・ドゥエンデ）</strong>は、直訳すれば「ドゥエンデを持つ」。技巧だけでは説明できない、聴き手をつかむ魔力や表現の深さを褒める言い方である。</li>
</ul>
<h2>国際情勢（スペイン視点）</h2>
<ul>
<li>セウタの越境危機をめぐり、現地政府代表部では情報機関の警告を中央政府へ伝えたかについて説明が対立し、官房長が辞任した。地中海とアフリカに接する国境はスペインにとって遠い国際問題ではなく、自治都市の住民生活と欧州連合の域外国境管理が重なる場所である。</li>
</ul>
<h2>スペイン国内ニュース</h2>
<ul>
<li>セウタではファティマ・ハメド氏が、自治都市を本土政争の道具にせず「国家政策」が必要だと訴えた。日本の離島政策と同じく、首都から見た安全保障と現地の暮らしにずれが生じるが、セウタでは言語、宗教、国境往来が日常に直結する。</li>
</ul>
<h2>文化・芸能ニュース</h2>
<ul>
<li>2017年に亡くなったマドリード出身の小説家<strong>ハビエル・マリアス</strong>の、シェイクスピアを論じる未刊スペイン語随筆「もう少し書く」が書籍『ここで立ち止まる』に収録される。文学だけでなく映画とサッカーについての小品も集め、長編の陰にあった日々の批評作業を見せる。</li>
<li>セゴビアの<strong>ヘイ・フェスティバル</strong>は20周年を迎え、作家ハビエル・シエラ、神経科学者ナサレ・カステジャノスらが参加する。歴史都市を会場に、文学だけでなくデザイン、科学、博物館運営を「知識の危機」への応答として並べる。</li>
<li>エル・パイスは、第二共和政最後の大統領ホセ・マルドナドが亡命先で外国人知識人に支えられながら、国内では忘却された生涯を紹介した。華やかな受賞より、独裁と亡命で切れた文化的記憶を誰が編み直すかという仕事である。</li>
<li>日本でも没後刊行や地方文学祭はあるが、スペインでは内戦・独裁・民主化の断絶が遺稿編集や人物再評価へ入り込む。作品を保存することが政治的記憶の修復にもなる。</li>
</ul>
<h2>フラメンコニュース</h2>
<ul>
<li>レオン県<strong>アストルガ</strong>ではサンタ・マルタ祭の最終日にカンテとバイレを上演する。アンダルシアから遠い巡礼路の町が祝祭の締めへフラメンコを置き、全国文化として受け入れた形である。</li>
<li>エストレマドゥーラ州<strong>バダホス</strong>のプラサ・アルタでは、踊り手ヘスス・オルテガが「エストレマドゥーラのフラメンコ」を掲げる。受け手の土地名を冠することで、アンダルシア由来の芸を単に借りず、地域の表現として引き受ける。</li>
<li>ムルシア州ラ・ウニオンの<strong>カンテ・デ・ラス・ミナス</strong>は2026年の新しい才能を募る。19世紀、アンダルシアから鉱山へ移った労働者の歌を背景に、タランタやカルタヘネーラなど鉱山系のカンテを競う場である。</li>
<li>北西部、エストレマドゥーラ、地中海岸へ広がっても、フラメンコの核にはセビリア、ヘレス、コルドバ、グラナダなどアンダルシアの生活と、ヒターノを含む複数共同体の歴史がある。マドリードが「国の顔」として輸出するとき、その出自を均さない配慮が要る。</li>
<li>日本の民謡大会や地域祭りと同じく、舞台は保存装置である。ただしフラメンコでは客席のパルマ、歌の伸縮、踊りの足音が同じコンパスを共同で作り、鑑賞者と演者の境が近い。</li>
</ul>
<h2>フラメンコギタリスト列伝</h2>
<ul>
<li>第9回は<strong>ニーニョ・リカルド（Niño Ricardo、本名 Manuel Serrapí Sánchez、1904–1972）</strong>。セビリア生まれ。父もギタリストで、若くから歌と踊りの伴奏を重ね、20世紀前半から中葉のフラメンコギターを代表する奏者・作曲家となった。</li>
<li>カンテ伴奏では歌い手の呼吸を追い、和音を先回りして押しつけず、短い応答句でレトラを支える。独奏では親指の低音、細かなアルペジオ、ラスゲアードを組み合わせ、旋律に装飾音を多く織り込む「リカルディスモ」と呼ばれる語法を築いた。</li>
<li>代表的な小品「シエラ・ネバダ」などでは、低音の歩みと高音の旋律が会話し、速さだけでなく歌うようなルバートが聞きどころになる。今日のパロ、シギリージャでは、12拍を均等に刻まず、重いアクセントの間へ沈黙を置く伴奏感覚が生きる。</li>
<li>セビリアの後輩ラファエル・リケーニは11歳でその音に出会い、パコ・デ・ルシアも影響源として挙げた。ニーニョ・リカルドの遺産は、古典伴奏の語彙を独奏曲へ移しても、カンテの呼吸を失わなかった点にある。</li>
</ul>
<h2>フラメンコギター工房だより</h2>
<ul>
<li><strong>アントニオ・ベルナル工房</strong>はセビリアの実在工房。製作家アントニオ・ベルナルは1950年代からギター製作に携わり、息子たちへ仕事を継承した。フラメンコの歌・踊り・ギターが日常的に交わる都市で、奏者の調整要求を受けてきた。</li>
<li>フラメンコ器ではスプルースの表板、シープレスの横・裏板を使う伝統的な組み合わせが中心。軽い胴、低めの弦高、薄い塗装によって、一音目が速く立ち、パルマやサパテアードに埋もれにくい輪郭を狙う。</li>
<li>クラシック器が長い余韻と音色の連続性を求める場面に対し、伴奏用フラメンコ器では低音の打点、ラスゲアードの乾いた分離、ゴルペを受け止める反応が重要になる。日本の手工芸と同じく、寸法表だけでなく演奏家との試奏が最終調整を決める。</li>
</ul>
<h2>フラメンコのパロ解説</h2>
<ul>
<li>今日のパロは<strong>シギリージャ（Seguiriya／Seguiriyas）</strong>。19世紀前半までにカディスやセビリア、ヘレス周辺で形を整えたとされる深い歌で、起源には諸説ある。死、喪失、苦悩を短いレトラへ凝縮し、カンテ・ホンドの中心に置かれる。</li>
<li>コンパスは12拍を一周と見る説明が一般的だが、均等な三拍子ではない。数え方の流儀は複数あり、アクセントは日本式に12から数えるなら1、3、5、8、11付近に重心を置く。長短の間隔が交互に現れ、パルマと足拍子は歌を追い越さない。</li>
<li>ギターはフリジア旋法とアンダルシア終止を基礎に、伝統的にはイ調系ならイ短調、ト長調、ヘ長調、ホ長調に相当する下降感を使う。カポタストで歌い手の音域へ合わせ、ファルセータはレトラの間へ置く。</li>
<li>アレグリアスの明るい12拍と同じ数字でも、アクセント配置と和声、歌詞、間の取り方が変われば身体感覚は別物になる。シギリージャの重さは遅さだけでなく、次の打点が来るまで耐える時間から生まれる。</li>
</ul>
