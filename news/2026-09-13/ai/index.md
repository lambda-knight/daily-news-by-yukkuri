<li>生成AIでは、開発企業自身が提案する能力向上の「ペース調整」、中国Moonshot AIの収益目標、架空証言を提出した弁護士への制裁を扱う。</li>
<li>量子は、スイス初のIBM Quantum System Twoが防衛調達のオフセット契約で整備される構図。セキュリティは、1億5300万件超の免許証画像をうたう闇市場と、遠隔管理ソフトScreenConnectの悪用確認済み脆弱性を取り上げる。</li>
<li>共通する論点は、高性能な技術の便益を保ちながら、速度・アクセス権・責任を誰が制御するかである。</li>
</ul>
<h2>生成AI政策：Anthropicが提案する「フロンティアのペース調整」</h2>
<ul>
<li>TechCrunchは9月12日、Anthropicのダリオ・アモデイ最高経営責任者が、高度なAIの能力向上を意図的に遅らせる制度案を示したと報じた。OpenAIのサム・アルトマン氏も7月、社会が新しい能力水準へ備える時間を得るため、開発速度の調整が必要になり得ると述べていた。</li>
<li>両社は、米政府に国際的な技術・統治手段の整備を求める「Pacing the Frontier」の請願を支持した。ただし、具体的な停止条件、対象能力、検証主体、違反時の措置は制度設計の途上にある。</li>
<li>最大の利害対立は、安全上の猶予と競争上の不利益である。一社だけが減速すれば、国内外の競合へ市場と人材を譲る。一方、主要企業が共同で速度を決めれば、談合や規制の囲い込みにも見え得る。</li>
<li>前日はAIの兵器・生物研究への悪用を扱った。本日の新しい角度は、個々の利用を遮断する運用から、モデル能力そのものの投入時期を調整する産業横断の仕組みへ議論が移った点にある。</li>
<li>実効性を左右するのは「危険な能力」を再現可能な試験で定義できるか、国外の開発者を含む共通基準を作れるか、そして小規模企業の参入を不当に妨げないかである。</li>
</ul>
<h2>生成AI市場：Moonshot AIが年商20億ドルを目標</h2>
<ul>
<li>TechCrunchは9月11日、中国のMoonshot AIが年換算売上高20億ドルを目指していると報じた。同社は長文処理やエージェント機能を備えるKimiシリーズを展開している。</li>
<li>OpenRouterの集計では、K3系モデルは最近やや利用が減ったものの、一日最大3000億トークンを生成している。利用量は大きいが、外部ルーター上のトークン数とMoonshotの有料売上は同じ指標ではない。</li>
<li>20億ドルという目標は、前日に扱った米国モデルの蒸留許諾論とは別の競争軸を示す。中国企業が低価格と大量利用を、継続課金や企業契約へどこまで変換できるかという事業モデルの問題である。</li>
<li>モデル市場では、性能順位だけでなく、推論原価、価格、利用者の定着、企業向けサポートが収益を決める。大量のトークンが動いても、値下げ競争が激しければ利益は残りにくい。</li>
<li>中国国内の競争と輸出規制の下で、Moonshotが計算資源を確保しながら20億ドルへ到達できるかは、オープン寄りのモデルが持続可能な事業になるかを測る材料になる。</li>
</ul>
<h2>AIと司法：架空の証言を提出した弁護士に制裁</h2>
<ul>
<li>Ars Technicaは9月、米ニューメキシコ州の刑事弁護人がChatGPTを使い、実在しない証人の架空証言を裁判書面へ引用したとして制裁を受けたと報じた。</li>
<li>弁護士は「AIが事実を幻覚するとは知らなかった」と説明した。生成AIの文章が流暢でも、証人、判例、記録が実在する保証にはならない。</li>
<li>問題は単なる誤字ではない。裁判所へ提出する弁護士には、引用した記録を原資料で照合する職業上の責任があり、道具へ委ねても責任は移らない。</li>
<li>AIは調査の入口や文章整理を速められる一方、存在確認を省けば、被告人、証人、司法制度の信頼へ直接損害を与える。効率化の便益と、専門職が負う検証義務は別勘定である。</li>
<li>AIと社会をめぐる本日の焦点は、利用禁止の是非ではなく、提出者本人が追跡可能な根拠を保持し、誤りが起きた際の責任主体を曖昧にしないことにある。</li>
</ul>
<h2>量子コンピュータ：スイス初のIBM Quantum System Two</h2>
<ul>
<li>IBM、Lockheed Martin、スイス連邦工科大学チューリヒ校は9月10日、ルガーノのスイス国立スーパーコンピューティングセンターに、国内初のIBM Quantum System Twoを設置すると発表した。稼働予定は2026年末である。</li>
<li>装置はIBMのNighthawkプロセッサーを搭載し、IBMが設置・保守・運用する。大学側は電力、冷却、物理セキュリティを用意し、国内の大学や選定企業へ計算資源を割り当てる。契約は当初2029年までの3年間。</li>
<li>資金の経路が特徴的だ。Lockheed Martinとスイス連邦国防調達庁armasuisseのオフセット契約、すなわち防衛調達に伴う国内還元の枠組みで実現した。</li>
<li>Lockheed MartinとIBMは、量子センシングを使う航法と、金属合金の積層造形を改善する共同研究も計画する。材料・化学だけでなく防衛技術との接点が、研究基盤の整備段階から組み込まれている。</li>
<li>前日の中性原子装置のネットワーク化とは異なり、今回は一国の研究者と企業が専用機へアクセスする制度設計が主題だ。装置導入は量子優位性の達成を意味せず、成果は利用枠、教育、古典スーパーコンピューターとの連携から生まれる。</li>
</ul>
<h2>セキュリティ：1億5300万件超の運転免許証画像をうたう闇市場</h2>
<ul>
<li>Krebs on Securityは9月、Nexusと名乗る闇市場が米国とカナダの運転免許証画像1億5300万件超を販売していると報じた。米連邦捜査局ニューオーリンズ支局は調査中であることを認めた。</li>
<li>Nexusはほかに身分証1000万件、旅行・国際身分証約300万件、医療カード57万9000件などを保有すると主張した。件数と流出元の全容は捜査で確定しておらず、販売側の自己申告を含む。</li>
<li>Krebs氏自身と母親の免許証画像が見つかり、両者がレンタカー利用時に提示していたことなどから、ルイジアナ州の本人確認事業者IDScanとの接点が疑われている。同社は月2100万件の確認を処理すると説明しているが、流出元の断定には至っていない。</li>
<li>免許証画像は住所、生年月日、顔写真、署名を一つに束ねる。パスワードのように簡単には変更できず、口座開設や本人確認を装う詐欺の材料として長期間使われ得る。</li>
<li>利用者が取れる対策は、信用情報の凍結、金融口座の通知設定、多要素認証、免許証画像を求める連絡の確認である。企業側には、本人確認画像を取引後も大量保存する必要性と保存期間の再検討が迫られる。</li>
</ul>
<h2>セキュリティ：ScreenConnectのCVE-2026-84869を緊急修正</h2>
<ul>
<li>ConnectWiseは9月8日、遠隔管理ソフトScreenConnectのCVE-2026-84869を修正した。CVSS基本値は9.9で、CISAは実際の悪用が確認された脆弱性一覧へ追加した。</li>
<li>26.6.5未満のクライアントが影響を受ける。既に遠隔セッションへ入れる低い権限の利用者が、ホスト側の確認なしにファイルを転送・実行できる可能性がある。サーバー本体の欠陥ではないが、管理者が多数端末を操作する道具だけに影響範囲は広い。</li>
<li>クラウド版は自動更新されるが、更新後にホストクライアントとアクセスエージェントの再導入が必要。自社運用版は26.6.5へ更新し、利用者、役割、権限を点検する。</li>
<li>すぐ更新できない場合、全役割からファイル転送権限を外す方法が一時緩和策として示された。ただし修正版の代わりではない。</li>
<li>前日のGitLabは未認証の外部者によるファイル読み取り、本日は正規セッション内の権限不足である。どちらも「アクセスできるか」だけでなく「接続後に何を許すか」を細かく制御する必要を示す。</li>
</ul>
<h2>まとめ</h2>
<ul>
<li>AI開発の速度調整、Moonshotの収益化、司法での架空証言は、能力、事業、専門職責任という異なる層でAIの統治を問う。</li>
<li>スイスの量子拠点は、装置性能だけでなく、防衛調達、大学、企業のアクセス設計が国家の量子能力を形作る例である。</li>
<li>免許証画像と遠隔管理ソフトの事件は、集約された本人情報や管理権限ほど、侵害後の被害が大きく長くなることを示した。</li>
</ul>
