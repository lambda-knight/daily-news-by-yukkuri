<h2>通学3時間を30分にした、高さ288メートルの屋外エレベーター</h2>
<ul>
<li>中国雲南省の尼珠河大峡谷では、山村の子どもが寄宿学校へ行くたび、荷物を持って危険な山道を約3時間登っていた。往復なら6時間になる。</li>
<li>2022年に高さ268メートルの「青雲梯」が崖沿いに開業し、子どもは無料で利用できるようになった。ただ、絶景を目当てに観光客が集まり、通学する子どもまで長い列へ並ぶ状況が生まれた。</li>
<li>混雑を減らすため隣に二基目の「扶揺梯」を整備。新しい展望エレベーターは谷底から288メートルの高さで、先代より昇降路が20メートル長く、速く、定員も大きい。</li>
<li>子どもはシャトル、エレベーター、ロープウェーを乗り継ぐが、学校まで約30分になった。危険な登山を減らす生活インフラが、観光名所になったため増設されるという珍しい循環である。</li>
<li>出典: <a href="https://www.odditycentral.com/architecture/china-builds-288-meter-outdoor-elevator-to-help-children-reach-school-easier.html">Oddity Central</a></li>
</ul>
<h2>人には目立ち、監視AIには消える「デジタル迷彩」シャツ</h2>
<ul>
<li>ドイツのデザイナー、ジーモン・ヴェッカートさんは、監視カメラの人物検出を混乱させる「デジタル迷彩」シャツを制作した。見た目は極端に派手なアロハ柄で、人間の目にはむしろよく目立つ。</li>
<li>人物検出AIは「人間」という概念を理解するのではなく、輪郭、明暗、頭と肩、胴体と手足の比率など、学習画像に共通する統計的特徴を手掛かりにする。柄はその組み合わせを崩す。</li>
<li>制作にはAIを使った。候補柄を作り、検出器へ見せ、人物だと判断する確信度を測り、柄を直す工程を繰り返す「敵対的ループ」で確信度を下げた。</li>
<li>ヴェッカートさんによれば、機械の見落とし方は人間の直感では設計できず、検出器自身の反応を使う必要があった。同じ種類のAIが、人を見る側と隠す柄を教える側の双方を担った。</li>
<li>特定の検出器での試験結果であり、あらゆる監視システム、角度、照明で消える保証はない。それでも、人には派手で機械には「人なし」という視覚のずれ自体が作品の核心になっている。</li>
<li>出典: <a href="https://www.odditycentral.com/news/worlds-ugliest-hawaiian-shirt-was-designed-to-make-you-invisible-to-ai-surveillance-cameras.html">Oddity Central</a></li>
</ul>
<h2>長さ1.8キロに最大20万人、予約制になった無料ビーチ</h2>
<ul>
<li>中国深圳市の大梅沙海浜公園は、砂浜の長さが約1.8キロしかない一方、かつて一度に最大約20万人が訪れたとされる。水辺へたどり着けなかったという旅行者の感想まである。</li>
<li>無料の公共ビーチで、複数のバス路線に加え、地下鉄駅が目の前にある。料金の安さと交通の便利さが、海そのものより強力な集客装置になった。</li>
<li>深圳市は混雑対策として、5月から10月の一日当たり入場者を8万人に制限し、事前予約を必須にした。8万人へ減らしても、単純計算では砂浜1メートル当たり約44人である。</li>
<li>普通のビーチはアクセス改善を歓迎するが、大梅沙では便利すぎる公共交通が混雑理由の一つ。無料で行きやすいという公共性を守りつつ、入場を予約で絞る逆説がある。</li>
<li>混雑への不満が続いても人気は衰えず、人で埋まった写真が繰り返し拡散される。静かな海水浴より「その光景を一度見たい」という体験が、新たな客を呼んでいる。</li>
<li>出典: <a href="https://www.odditycentral.com/travel/dameisha-the-worlds-most-crowded-beach.html">Oddity Central</a></li>
</ul>
<h2>まとめ</h2>
<ul>
<li>山のエレベーターは、通学を助ける設備が観光客を集め、子どものために二基目が必要になる意外な成功例だった。</li>
<li>デジタル迷彩は、人間とAIが同じ柄をまったく違って見ることを、服として可視化した。</li>
<li>大梅沙では、無料と交通の便利さが最大20万人を呼び、一日8万人という予約枠まで巨大に見える。</li>
</ul>
