<h2>生成AIと競争：Reflection「Beam」、中国のGLM-5.2に並ぶと主張する米国産オープンモデル</h2>
<ul>
<li>Nvidiaなどが出資する米Reflection AIは10月5日、初のオープンウェイトモデル「Beam」を発表しました。重み（学習済みパラメーター）と技術詳細は今月中に公開するとしています。</li>
<li>Beamは総パラメーター5010億、実際に1回の計算で動くのは230億の「専門家混合（MoE）」型で、テキスト専用です。学習に使ったトークンは23.8兆、一度に扱える文脈は100万トークンです。</li>
<li>同社は、高度な推論のベンチマークで中国Z.aiの「GLM-5.2」（総パラメーター約7440億、動くのは400億）に並び、推論に必要な計算量は3〜4分の1だと主張しています。欧米のオープンモデルを上回り、7月に公開されたミラ・ムラティ氏のThinking Machines Labの「Inkling」をコーディング試験4種で上回るとしました。</li>
<li>Reflectionは2024年に元Google DeepMindの研究者2人が創業し、これまでに約47億ドルを調達、直近の評価額は出資前で250億ドルです。今夏にはSpaceXとNebiusと合わせて70億ドル超の計算資源契約を結び、2029年までNvidiaのGB300を使えます。</li>
<li>韓国の新世界（Shinsegae）グループとは、自国のAI基盤を作る「ソブリンAI工場」の試験も進めています。</li>
<li>オープンモデルで先行してきたのは中国勢で、米国の出資者が「中国に対抗する米国産の公開モデル」に巨額を投じる構図です。性能の数字は現時点で同社の自己申告で、重みの公開後に第三者の検証にさらされます。</li>
</ul>
<h2>生成AIと監視：中国のサーバーから地図アプリを探る「エージェント艦隊」、名札は「claude」</h2>
<ul>
<li>独立研究者グループ「Swarmchasers」は10月4日（日曜）、中国TencentのクラウドからAlibabaの地図サービス「Amap（高徳地図）」を調べるAIエージェントの集団を見つけたとする暫定報告を公開しました。TechCrunchなどが10月5日に報じています。</li>
<li>エージェントが求めていたのは、中国各地の公園、博物館、動物園、病院などの「どこから入れるか」という入口の情報です。最初の照会は9月28日で、10月4日に213か所について1810件の報告を出して頂点に達し、10月5日の協定世界時4時11分過ぎに止まりました。</li>
<li>同時に動いていたのは最大14体で、生成されたプログラムは428本、キャッシュを避けるための目印は1100超でした。特定できた18のIPアドレスのうち17がTencent Cloud（香港）にさかのぼります。</li>
<li>研究者は、互いに連絡を取らずに同じ種類の作業を並行してこなす様子から「群れ（swarm）ではなく艦隊（fleet）」と呼んでいます。Amapの自動アクセス対策の認証トークンをすり抜け、URL検査サービスurlquery.netを作業場代わりに使う手口は、過去に公開された手法を流用したものでした。</li>
<li>出力のうち211件には「claude」という名札が付いていましたが、コードや応答の癖はTencentのHunyuan（Hy3、Hy4）や智譜のGLMに近かったとしています。Tencent、Alibaba、Anthropicのコメントは報じられていません。</li>
<li>10月2日に扱った米国・カナダの政府サイトの件と同じく、エージェントの足跡は公開のURL検査記録から見つかりました。今回は政府ではなく民間の地図データが対象で、名札が実際のモデルと一致しない点が新しい材料です。</li>
</ul>
<h2>生成AIと広告：OpenAI、画像生成の結果の横に広告を出す</h2>

<li>対象は無料版と低価格の有料プランの利用者です。広告は「明確に表示」され、ChatGPTの回答内容には影響しないとしています。最初は一部の試験的な広告主に限ります。</li>
<li>効果測定ではAppsFlyer、Adjust、Branchなど15社と連携し、ブランドの安全性を測るDoubleVerifyとIntegral Ad Scienceとも試験を準備しています。地域を分けた効果実験もできます。</li>
<li>OpenAIは2026年に入ってChatGPTに広告を導入し、8月にはインドへ広げていました。将来は週12億人の利用者に広告主が届けられるようになります。</li>
<li>画像を作る場面は、利用者が「何を作りたいか」をはっきり言葉にしている場面です。発表は、広告が回答を左右しないとは述べていますが、どの頻度で表示するか、利用者が断れるかには触れていません。</li>
</ul>
<h2>生成AIと規制：ノルウェー、公園や学校でAIメガネを一時禁止へ</h2>

<li>ノルウェー政府は10月5日、カメラやAIを備えたメガネを、一部の公共の場所で一時的に禁止する案を議会に出すと発表しました。あわせて、身に着ける機器の恒久的なルールを助言する専門家グループを設けます。</li>
<li>デジタル化・行政担当のトルゲイル・ミカエルセン大臣は、人々が知らないうちに写真や動画を撮られ、声を録音されるおそれのある場面に、強力な新技術が持ち込まれていると懸念を示しました。</li>
<li>対象に挙がっているのは、公園、海辺、博物館、ショッピングセンター、コンサートやスポーツの会場、学校、幼稚園、遊び場、若者向けの施設、そして診療所や、更衣室のあるプールやジムです。</li>
<li>全面禁止ではなく、他人を撮るおそれのない私的な利用は認めます。対象として検討するのは、カメラと録音機能のあるメガネ、カメラとAIを持つメガネ、それに同様の機能を持つほかの身に着ける機器です。弱い立場の人を支えるなど、社会的に有益な使い方への例外も検討します。</li>
<li>Fortuneによると、米カリフォルニア州知事は前の週に、スマートグラスでの撮影を規制する州法案に拒否権を使っています。Ars Technicaはこれを、AIメガネに対する初の本格的な政府の取り締まりと位置づけています。</li>
</ul>
<h2>生成AIと雇用：HackerRankのAI面接官「Chakra」、3回の選考を1回に</h2>
<ul>
<li>プログラマー採用試験の大手HackerRankは10月5日、AIが面接官を務める「Chakra」を一般提供しました。同社の企業顧客はAmazon、Nvidia、Replitなど3000社超です。</li>
<li>候補者は、AIアシスタント付きの作業画面で、実際のコードリポジトリを使った課題に取り組みます。AIは作業の進め方を観察し、「なぜその判断をしたのか」「どこで方針を変えたのか」を追加で質問します。</li>
<li>これまで人事担当の電話選考、持ち帰り課題、技術者の面接と3回に分けていた選考を1回にまとめるのが売りです。ベータ期間中にSnowflakeやCapgeminiなどで50万回超の面接を行い、不正の疑いを示す警告は従来の試験より70〜80％少なかったとしています。</li>
<li>ヴィヴェック・ラヴィサンカールCEOは「AIのおかげで、誰でも成果物を作れるようになった」と述べ、測るのは批判的思考と判断力、そしてAIに問題をどう伝え、出力をどう評価するかという「AIを使いこなす力」だとしています。</li>
<li>採用の最終判断は人間が行い、AIは採点を担います。同CEOは、AIは同じ基準を一貫して当てはめると主張する一方、ニューヨーク市などが採用AIの偏りを規制していることも認めています。AIの使用を禁じるのではなく、使い方そのものを採点の対象にする転換です。</li>
</ul>
<h2>生成AIと世論：嫌われながら使われるAI、データセンター反対は71％</h2>

<li>2026年のピュー研究所の調査では、AIの影響を「悪い」と見る米国の成人が「良い」と見る人より多い一方、チャットボットを使う人は2023年の約25％から50％に倍増し、25％は毎日使っています。</li>

<li>10月4日に扱ったAmazonのデータセンター反対への10億ドルの対応は、この71％という数字の上に置くと、企業が何に向き合っているのかがよく見えます。</li>
</ul>
<h2>量子コンピュータ：ドイツ、誤り訂正型の量子計算機に最大6億4000万ユーロの競争</h2>
<ul>
<li>ドイツ連邦研究技術宇宙省（BMFTR）は、誤り訂正を備えた量子計算機の開発競争「量子コンピューティング・コンペティション」の構想段階を通過した6つの企業・研究機関連合を選びました。The Quantum Insiderなどが10月5日に報じています。</li>
<li>国の資金は最大6億4000万ユーロ（約7億1700万ドル）で、2030年までに欧州最先端の誤り訂正型量子計算機を少なくとも2台、産業の利用者に届けることが目標です。量子処理装置だけでなく、制御系、誤り訂正、試作生産ラインまでを対象にします。</li>
<li>方式は中性原子、イオントラップ、超伝導回路の3つで、それぞれ2連合ずつが競います。各連合は2027年3月31日までに、決められた基準を満たす「入口のシステム」を動かす必要があり、競争開始から30か月後にさらに絞り込まれます。</li>
<li>ミュンヘンのplanqcが率いる「LOGIQC」は、中性のイッテルビウム原子を使い、符号化した論理量子ビットで万能な演算ができる計算機を目指します。マックス・プランク量子光学研究所、ミュンヘン大学、テュービンゲン大学、ユーリッヒ研究センター、レーザー企業TOPTICAが加わります。</li>
<li>Quantum Computing Reportによると、AQT Germanyが率いるイオントラップの「NFQC-1k」は総額1億2200万ユーロで、物理量子ビット1000個、論理量子ビット50個、論理ゲートの誤り率0.01％未満を掲げています。ほかにIQM、QUDORA、neQxt、Peak Quantumが連合を率います。</li>
<li>planqcのセバスチャン・ブラット最高技術責任者は「ドイツには量子計算で主導的な役割を果たす材料がすべてそろっている」と述べました。1つの方式に賭けず、3方式を2連合ずつ競わせて途中で絞る設計が特徴です。</li>
</ul>

<li>初日に最も多かったセッションの分類は「AIと量子の相乗効果」でした。報告は、展示された量子の進歩の多くがAIに依存していたことが「最大の驚き」だったと書いています。</li>
<li>ドイツ連邦印刷局（Bundesdruckerei）のワディム・ヴォルムスベッヒャー氏は、AIの群れ（スウォーム）を使って、電子署名方式ECDSAを破るのに必要な量子計算資源を半分にした研究を発表しました。</li>
<li>Nvidiaのケヴィン・マト氏は、AIスーパーコンピューターで量子計算を拡大する話を、Quantinuumやハノーファー大学と並ぶ誤り耐性のセッションで行いました。ライプニッツ・スーパーコンピューティング・センターは、計算センターの中で量子計算機を運用する際の監視データを扱いました。</li>
<li>会場には、ドイツ連邦銀行、ルフトハンザ、BMW、エアバス、SAPなどの利用企業も並びました。暗号を破る側の見積もりがAIで縮むことは、耐量子暗号への移行期限を前倒しする材料になります。</li>
</ul>
<h2>セキュリティ：デンマークの住民登録、国民の8割にあたる880万人分が流出</h2>
<ul>
<li>デンマークの中央住民登録（CPR）は10月5日、登録者約1100万人のうち約880万人分、8割にあたる個人情報が流出したと発表しました。侵入は9月に起き、10月2日に見つかりました。</li>
<li>流出したのは氏名、住所、生年月日、婚姻状況、そして一人ひとりに割り当てられた生涯変わらない識別番号「CPR番号」です。国内の住民だけでなく、国外に住む人や亡くなった人の記録も含まれます。</li>
<li>攻撃者は、ある民間企業が正規に持っていた登録簿へのアクセス権限を悪用しました。デンマークのデータ保護庁によると、総当たりで有効なCPR番号を次々に試し、ひもづく情報を引き出したとみられます。</li>
<li>当局はその企業のアクセスを止め、CPRのシステムに追加の安全策を入れ、警察が捜査しています。担当のクリスティーナ・エーゲルン大臣は「極めて深刻な事案だ」として、議会の産業・デジタル化委員会に報告しました。</li>
<li>政府は相談用の電話窓口を設け、相手がどれだけ個人情報を知っていても、電話やメールでパスワードや機密情報を教えないよう呼びかけています。CPR番号は銀行や医療、行政で本人確認の柱となる番号で、流出した情報そのものが、なりすまし詐欺の「信用材料」になるからです。</li>
<li>10月4日に扱ったデンマーク工科大学の流出は最大20万人でしたが、今回は国の根幹の台帳です。正規の権限を持つ委託先の「入口」が、国民の大半への入口になった構図です。</li>
</ul>
<h2>セキュリティ：韓国の大手銀行3行で流出、攻撃サーバーにAI侵入ツールの痕跡</h2>
<ul>
<li>韓国の金融委員会（FSC）は10月5日、国内の金融機関を狙った一連のサイバー攻撃を確認し、緊急会議を開きました。</li>
<li>新韓銀行では顧客2万5000人分の情報が、KB国民銀行では顧客11万9000人分のクレジットカード情報が流出しました。ハナ銀行でも、侵入された営業支援システムを通じて、範囲の限られた流出が起きています。</li>
<li>攻撃に使われたサーバーの画面のタイトルには、情報収集、脆弱性の発見、攻撃の実行までを自動で行うオープンソースの侵入テスト用AI「ARTEX AI」に関連する中国語の文字列がありました。当局は実際に使われたかどうかをまだ確認していません。</li>
<li>韓国のセキュリティ企業ジーニアンスのムン・ジョンヒョン氏は、AIを使った攻撃自動化ツールが関わったとみています。</li>
<li>金融委員会は各社に、外部からアクセスできるすべてのシステムの点検、不要なデータ公開の削減、認証の確認、脅威情報の速やかな共有、点検結果の提出を命じました。李在明大統領は、金融機関と公的機関での個人情報流出を徹底的に調べるよう指示しています。</li>
<li>防御側の点検を自動化するはずの道具が、攻撃の自動化にも使われ得る。複数の大手銀行に同時に穴が見つかったことが、その速さを物語っています。</li>

<h2>セキュリティ：Exchange Serverに定例外の修正、同じ組織の他人のメールを読める欠陥</h2>
<ul>
<li>Microsoftは10月2日、メールサーバー「Exchange Server」の脆弱性CVE-2026-96940（CVSS 8.8）について、毎月の定例日を待たない修正版を公開しました。</li>
<li>認可の確認が弱いため、ログインできる攻撃者が権限を引き上げ、同じ組織のほかの利用者のメールボックスにアクセスし、メールや添付ファイルを読めるおそれがあります。別の組織（テナント）をまたぐ侵害はできません。</li>
<li>対象は、Exchange Server Subscription Edition RTM、2016の累積更新23、2019の累積更新14と15です。クラウド版のExchange Onlineはサービス側で修正済みで、利用者の作業は要りません。</li>
<li>発見者はMicrosoftの研究者ジャン・ミッチェル氏です。現時点で悪用は確認されていませんが、Microsoftは「悪用される可能性が高い」と評価しています。</li>
<li>社内のアカウントを一つ乗っ取られれば、役員や人事のメールまで読まれ得る種類の欠陥です。自社運用のExchangeを持つ組織は、更新を急ぐ理由があります。</li>
</ul>
<h2>セキュリティ：Dell System Update、認証なしで管理者権限を奪える欠陥</h2>
<ul>
<li>Dellは10月5日、法人向けサーバーPowerEdgeの更新ツール「Dell System Update（DSU）」のコマンドライン版に、深刻度「緊急」の脆弱性CVE-2026-86360があるとして、すぐに更新するよう呼びかけました。</li>
<li>ファイルの置き場所を指す文字列を細工して、本来触れない場所に到達する「パストラバーサル」の欠陥です。リモートから認証なしで、最上位のroot権限でコードを実行されるおそれがあります。LinuxとWindowsの両方が対象です。</li>
<li>修正版はDSU 2.3.0.0以降で、同時に高深刻度の4件（リモートコード実行2件、権限昇格2件）も直しました。現時点で悪用は確認されていません。</li>
<li>FBIとCISAは2024年5月から、パストラバーサルという古典的な欠陥をなくすよう開発者に求めてきました。サーバーを最新に保つための更新ツールそのものが入口になる点が皮肉です。</li>
</ul>
<h2>セキュリティ：ATMマルウェアPloutusの開発者とされる男、米法廷に出廷</h2>
<ul>

<li>容疑者は2025年12月にネブラスカ州で起訴されています。罪状は銀行詐欺の共謀（最高30年）、資金洗浄の共謀（同20年）、銀行への侵入とコンピューター詐欺の共謀（同5年）、テロリストへの物的支援の共謀（同15年）です。</li>
<li>起訴状によると、2024年2月から2025年12月にかけ、米国の47州とワシントンDCなどで117件の攻撃に関わり、銀行63行と信用組合54組合から540万ドルを盗み、ほかに約143万ドルを狙いました。1件あたりの被害は10万ドルを超えます。</li>
<li>10月5日に扱った財務省の制裁は、資金の流れを止める手段でした。今回は、その制裁対象の中心人物本人の身柄が米国の法廷に届いた段階です。</li>
