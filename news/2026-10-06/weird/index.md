<h2>同じ10月5日生まれ、114歳と113歳の「世界最高齢の男たち」がカード交換</h2>
<ul>
<li>ブラジルのジョアン・マリーニョ・ネトさんが2026年10月5日に114歳、オーストラリアのケン・ウィークスさんが同じ日に113歳になった。2人はちょうど1歳違いの同じ誕生日。</li>
<li>長寿研究団体ロンジェビクエストが両家族の協力を得て、互いの誕生日を祝うカードを持った写真を交換させた。世界最高齢と2番目の男性があいさつを交わした記録は初めてだという。</li>
<li>ネトさんは1912年、ブラジル北東部セアラー州マランゲーペ生まれ。4歳ごろから父の畑を手伝い、トウモロコシと豆を育て、牛・ヤギ・豚・鶏を飼った。2024年11月25日、112歳51日で存命の世界最高齢男性になり、ギネス世界記録にも認定されている。子ども6人、孫22人、ひ孫15人、玄孫3人が存命。</li>
<li>史上114歳に達したと確認された男性は9人だけ。専門家は「男女の寿命差があるため、男性の114歳は女性の117歳より珍しい」と説明する。存命の世界最高齢女性エセル・ケイタハムさんは今年117歳になった。</li>
<li>ウィークスさんはニューサウスウェールズ州グラフトンの介護施設で暮らす。漁船づくり、商店経営、選挙事務所勤務など複数の仕事を経験し、酒もたばこもやらず、白いパンを含む素朴な食事だったと息子は語る。今も1日2回、階上の廊下を2周歩き、食事も着替えの準備も自分でこなす。</li>
<li>誕生日にはクラシックカーで町を巡り、100年以上前に通ったキャリーズ・クリークの学校を訪ねた。孫娘は「ごく普通の人が、これほど長く生きたことが驚き」と話した。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/10/05/brazil-Guinness-World-Records-oldest-man-second-oldest-same-birthday/5051791211877/">UPI</a> / <a href="https://longeviquest.com/2026/10/joao-marinho-neto-worlds-oldest-man-turns-114/">LongeviQuest</a> / <a href="https://www.abc.net.au/news/2026-10-05/australias-oldest-man-ken-weeks-celebrates-113th-birthday/107221240">ABC News</a></li>
</ul>
<h2>自転車道の苦情が祭りに、アイダホで1200頭の羊が目抜き通りを行進</h2>
<ul>
<li>米アイダホ州ウッドリバー渓谷で、第30回の節目となる「トレイリング・オブ・ザ・シープ」祭りが10月6日の前夜祭の夕食会から始まる。本祭は7〜11日、11日正午にケッチャムのメインストリートを羊1200頭が行進する。</li>
<li>起源は苦情だった。1980年代末から90年代初め、地元の郡レクリエーション局が舗装自転車道を整備する際、1900年代初めに指定された羊の通り道の一部を借りた。ところが150年続く移動で羊が通ると、新住民の利用者は「自分たちの道」に羊がいることを理解できなかった。</li>
<li>3代目の羊牧場主ジョン・ピービーさんと妻ダイアンさんは、新住民をカフェでのコーヒーに誘い、羊と一緒に谷を歩きながら歴史を語った。この「コーヒー・チャット」が観光局の支援で1996年に正式な祭りになり、2003年からは非営利団体が運営する。ジョンさんは2024年6月に90歳で亡くなり、名を冠した奨学金が続いている。</li>
<li>今年の羊は、ネバダ州から事業を広げたシュワント家のジャズ牧場から来る。同牧場の行進参加は初めて。9〜11日には全米予選の牧羊犬競技会に80頭のボーダーコリーが出場し、10日の民俗フェアにはバスク、スコットランド、ペルーの演者がそろう。羊毛講座は20以上。</li>
<li>牧場で働いた移民の歴史も柱で、フランス・バスク地方出身者が月40ドルで羊飼いとして働き、のちに1200頭の雌羊で牧場を始めた家族の物語も紹介される。</li>
<li>行進の決まりは「犬は連れて来ない」「歩道の縁石から出ない」「羊の群れに飛び込まない」「声を低く」。番犬はどの犬も脅威とみなし、山の静かな牧草地から下りてきた羊は物音に驚くためだ。主催者は「再現劇ではなく、生きた歴史」だとしている。</li>
<li>出典: <a href="https://www.mtexpress.com/news/ketchum/trailing-of-the-sheep-festival-returns/article_bc13fb62-e373-424c-a696-80b0a71cfa0a.html">Idaho Mountain Express</a> / <a href="https://trailingofthesheep.org/wp-content/uploads/2026/09/TOTS_program2026_WebRevised.pdf">Trailing of the Sheep Festival 2026 公式プログラム</a></li>
</ul>
<h2>過去の出来事に賭ける「事実の予測市場」、ベリファクト・マーケッツが始動</h2>
<ul>
<li>未来の出来事の結果に賭ける予測市場が広がるなか、新興企業ベリファクト・マーケッツは「争いのある事実」を扱う市場として10月2日に開業した。対象はすでに起きた出来事で、利用者は「真」か「偽」に賭ける。</li>
<li>試験期間の目玉は新型コロナウイルスの起源。記事執筆時点で「真」が76セント、「偽」が32セントで取引され、多数派は武漢の研究所起源に賭けていた。ほかに、2025年のロサンゼルス山火事で保険大手ステートファームが保険金支払いを意図的に遅らせたかという市場もある。</li>
<li>利用者は賭けに加えて「証拠」も提出でき、会社は決着に役立つ信頼できる資料に報酬を出す計画。証拠が十分なら会社が判定し、決着がつかなければ市場を「満了」させ、その時点の確率計算で払い戻す。</li>
<li>最高経営責任者ロドリゴ・アキノさんは「全員が真に賭けても、それで真になるわけではない」と説明し、取引価格は証拠と並ぶ材料の一つだとした。判定方法は特許出願中の独自システムで、「多次元的に多数のデータ点を分析する、非常に数学的で非常に秘密」と語った。コロナ起源の解明についても「可能だ」と述べた。</li>
<li>投資家の個人資産運用会社が資金を出し、手数料は当面取らない。米国では取引所の免許がないため米国外の利用者だけに提供し、暗号資産の一種であるステーブルコインで取引する。</li>
<li>予測市場の有名トレーダーは「2020年の大統領選で一生稼ぎ続けられるから、たぶん参加する」と冗談を言った。事実の判定を市場で決めるのか、会社の秘密の方法で決めるのかという矛盾が、この事業の最大の珍しさでもある。</li>
<li>出典: <a href="https://www.wired.com/story/a-prediction-market-about-the-past-sure-why-not/">WIRED</a></li>
</ul>
<h2>最年少の系外惑星、生まれて100万年未満の巨大ガス惑星</h2>
<ul>
<li>チリのディエゴ・ポルタレス大学のアンドレア・ベルナルディさんらの研究チームが、約450光年先の若い星を回る惑星「エライアス2-24b」を確認した。中心星の年齢は100万年未満で、惑星も同じくらい若いとみられる。</li>
<li>これまで直接観測で確認された最年少の系外惑星は、PDS 70とWISPIT 2という星を回るもので、いずれも500万年以上。記録を大きく塗り替えた。</li>
<li>若い惑星はガスとちりの円盤に埋もれて見つけにくい。チームは、成長中の惑星が円盤に溝を刻むという考えから、溝のある7つの円盤に絞り、中心星の光を隠すコロナグラフの観測データを再解析した。</li>
<li>この星の円盤の溝は10年近く前から知られ、欧州南天天文台の超大型望遠鏡が溝の中に光の点を捉えていたが、惑星かどうか議論が続いていた。チームはハワイのケック天文台の2018年と2020年のデータで点の位置を比べ、背景の星や機器の雑音ではなく、星の重力に結びついた天体だと結論づけた。</li>
<li>惑星は中心星から約55天文単位を回り、質量は木星の1.9〜4.0倍以下と推定される。標準的な「コア集積モデル」では、太陽から約5天文単位の木星ほどの惑星ができるのに約500万年かかり、遠い軌道ではさらに時間がかかるとされてきた。</li>
<li>チームはこの惑星もコア集積でできたと考えており、そうならこのモデルは想定より速く巨大惑星を作れることになる。共著者のルーカス・シエサ教授は「最良の惑星形成モデルでも、まだ重要な過程が抜けている」と述べた。NASAが8月に打ち上げたナンシー・グレース・ローマン宇宙望遠鏡は、さらに強力なコロナグラフを積んでいる。</li>
<li>出典: <a href="https://www.wired.com/story/astronomers-confirm-discovery-of-youngest-known-exoplanet-ever/">WIRED</a></li>
</ul>
<h2>まとめ</h2>
<ul>
<li>114年と113年の人生、150年続く羊の移動、すでに起きた出来事、100万年未満の惑星。4本は時間の長さも向きも違う。</li>
<li>長寿は素朴な日課と記録の確認、祭りは苦情を説明の場に変えた夫妻、事実の市場は秘密の判定方法、惑星は2018年と2020年の位置比較という、それぞれ具体的な支えの上に成り立っている。</li>
</ul>
