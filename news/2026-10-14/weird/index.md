<h2>紙飛行機を口で1分間に20機、200を超えるギネス記録を持つデビッド・ラッシュさん</h2>
<ul>
<li>米国アイダホ州のデビッド・ラッシュさんが、13歳のめいのアリさんと組んで「1分間に口で受け止めた紙飛行機の最多数」のギネス世界記録を20機で更新しました。UPIが10月13日に伝えました。</li>
<li>それまでの記録は17機。ギネスの関連記録ページでは、この種目の保持者として、記録破りの第一人者アシュリタ・ファーマンさんの名前が挙がっています。</li>
<li>1回目は14機で届かず、2回目で20機に達しました。挑戦の前に丸1日練習し、何百機も投げています。</li>
<li>投げ役のアリさんはサッカーの有力なゴールキーパーで、ラッシュさんは「放つ角度が高く、投げ方が安定していた」とたたえています。</li>
<li>ラッシュさんは何年も前にこの記録を考えましたが、先のとがった紙飛行機が顔に当たると痛いため、いったん棚上げしていました。先の丸い機体を見つけて再挑戦しましたが、それでも「ひりひりした」と言い、「痛いが危険ではない」と表現しています。</li>
<li>ギネス世界記録の8月31日の記事によると、保持している記録は200件超。200件を超えたのはファーマンさん、イタリアのシルビオ・サッバさんに次いで3人目で、目標は保持件数で世界一になることです。本人は「失敗した挑戦は文字どおり何千回もある」と話します。</li>
<li>最初の記録は2015年10月、目隠しで3つのものをお手玉する6分34秒でした。2023年5月には休まずにお手玉を13時間10分5秒続け、本人はこれを最も過酷だった記録に挙げています。</li>
<li>ギネスが8月に発表した記録では、地元ボイシでTシャツ125枚を重ね着してフルマラソンを5時間54分50秒で完走しています。それまでの記録は100枚でした。熱中症寸前、手は腫れ、腰に強い痛みが出たといいます。3人の子の父で、41歳。最後の区間は子どもたちが一緒に走りました。</li>
<li>動機は理数系の教育の後押しです。15年にわたり、「理科や数学でつまずいても、技術者への道は閉ざされない」「難しい技能も練習で身につく」と生徒に伝えるために記録を重ねています。</li>

</ul>
<h2>0が3つで4917枚が当選、ノースカロライナの宝くじ「ピック3」</h2>
<ul>
<li>米国ノースカロライナ州の教育宝くじが10月12日の月曜夜に行った数字選択式くじ「ピック3」で、当選番号が「0-0-0」になりました。当選券は4917枚、支払総額は約170万ドルです。</li>
<li>ピック3は0〜9の数字を3つ選ぶくじで、どの組み合わせも当たる確率は1000分の1です。0-0-0の賞金は、50セントの券で250ドル、1ドルの券で500ドル（税引き前）です。</li>
<li>当選金は当選者で山分けする方式ではなく、1枚ごとに決まった額が支払われます。人気の組み合わせが出ると、当選者ではなく宝くじ側の支払いが膨らみます。</li>
<li>宝くじ側は、同じ数字が3つ並ぶ組み合わせを「トリップ」と呼び、「プレーヤーに最も人気のある数字の並びのひとつ」と説明しています。</li>
<li>同じくじでは今年3月9日の月曜夜にも0-0-0が出て、4285枚が当たり、支払いは150万ドルを超えました。2月23日には2-2-2が出て、当選券1万4002枚、支払いは590万ドルを超えています。</li>
<li>0-0-0の当選券は、3月から7か月で632枚増えた計算です。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/10/13/lotto-North-carolina-education-lottery-triple-zeros/5831791913596/">UPI</a> / <a href="https://www.lotteryusa.com/news/luckiest-nothing-pick-3-players-strike-gold-with-0-0-0">Lottery USA（3月10日）</a></li>
</ul>
<h2>ダムの上から怪獣の叫び、ゴジラ新作の音響チームが散歩中の人と犬を驚かせる</h2>
<ul>
<li>山崎貴監督のゴジラ新作（英題『Godzilla Minus Zero』）の制作陣が、10月10日のニューヨーク・コミコンのパネルで、怪獣の鳴き声の録り方を明かしました。WIREDが10月13日に伝えています。シリーズ39作目で、司会は俳優のセス・グリーンさんでした。</li>
<li>サウンドデザイナーのイノウエ・ナツコさんのチームは、スピーカーを屋外のダムの上まで転がして運び、ゴジラと三つ首のキングギドラの叫びを流して録音しました。</li>
<li>音響を担当したタケウチ・ヒサフミさんは「ピクニックをしている人も、散歩している人もいた。いちばん気の毒だったのは犬の散歩の人で、犬がおびえてこちらに吠え返してきた」と振り返りました。</li>
<li>イノウエさんは、最初はダムでの録音がうまくいくか不安だったといいます。「最初に叫びをスピーカーから流したとき、みんなの目に安心と自信が見えた。現実の空間に流し、残響やこだま、反射をマイクで拾うことで、怪獣がこの世界に現れる」と話しました。</li>
<li>キングギドラの竜のような翼の音は、ゴム製の釣り用胴長を振った音と、アコーディオンのように伸び縮みするダクトの音を混ぜて作りました。</li>
<li>視覚効果の野島達司さんは、前作『ゴジラ-1.0』で白波の表現に2億個の粒子を計算させたのに対し、今回の予告編の、海から飛び出したゴジラが水上機を追う場面では20億個が必要だったと説明しました。アイマックスの画面比率になり、実写の素材がなく、ほぼ全面がコンピューターグラフィックスだったためです。</li>
<li>前作は世界で1億1400万ドルの興行収入を上げました。新作は日本で11月3日、米国で11月6日に公開予定です。11月3日は1954年に本多猪四郎監督の第1作が日本で公開された日で、「ゴジラの誕生日」とされています。</li>
<li>出典: <a href="https://www.wired.com/story/new-york-comic-con-panel/">WIRED</a></li>
</ul>
<h2>たたいて蹴って豆をぶつける、長野県茅野市の味噌蔵にある貧乏神神社</h2>
<ul>
<li>長野県茅野市の味噌メーカー、丸井伊藤商店の敷地の奥に、貧乏神をまつる「貧乏神神社」があります。英語圏の日本情報サイトSoraNews24が10月13日、記者の参拝体験として紹介しました。看板には右から左へ「社神神乏貧」と書かれています。</li>
<li>参拝の作法は、まず退散料として100円を納め、「貧棒（びんぼう）」と呼ぶ棒で3回たたき、3回蹴ります。続いて用意された豆を貧乏神に投げつけ、「貧乏神、出て行け」などと叫びます。最後に、近くのおかめの面をやさしくなでて福を願います。</li>
<li>神社側は、強くやりすぎると勢いが自分に跳ね返り、かえって運が悪くなると注意しています。</li>
<li>壁には参拝者が追い払いたいものを書いた紙が貼られ、「嫌な上司」「酔っぱらいのおじさん」「体脂肪」などが並びます。</li>
<li>貧乏神は鎌倉時代ごろから日本の民間伝承に現れるとされ、焼き味噌の香りが大好物で、破れたうちわであおいで香りを楽しむと言い伝えられています。江戸時代には、焼き味噌を川に流して貧乏神を送り出す「貧乏神送り」という習俗もありました。</li>
<li>豆をぶつける所作は、節分の豆まきで鬼と災いを払う習慣と重なります。一方、東京都文京区の太田神社には、貧乏な旗本の夢に貧乏神が現れて「世話になった礼に福を授ける」と告げ、まつり方を教えたという江戸時代の由緒が伝わります。同じ貧乏神でも、追い払う神社とまつって福を受ける神社があります。</li>
<li>出典: <a href="https://soranews24.com/2026/10/13/this-shrine-in-japan-invites-you-to-hit-and-kick-its-god-of-poverty-statue-for-good-luck-photos/">SoraNews24</a> / <a href="https://san-tatsu.jp/articles/286009/">さんたつ</a> / <a href="https://allabout.co.jp/gm/gc/389869/3/">All About</a> / <a href="https://intojapanwaraku.com/culture/98003/">和樂web</a></li>
</ul>
<h2>まとめ</h2>
<ul>
<li>ラッシュさんは、痛いと分かっている紙飛行機の受け止めに、先の丸い機体とめいの投球で挑み、17機の壁を越えました。何千回もの失敗も、教室へのメッセージの一部です。</li>
<li>ノースカロライナでは、だれもが思いつく0-0-0に4917人分の賭けが集まり、固定賞金のくじの胴元が約170万ドルを払いました。</li>
<li>ゴジラ新作の音響チームは、合成で済ませず、ダムの上で本当に叫びを響かせて、現実の残響を手に入れました。</li>
<li>茅野の貧乏神神社は、たたく・蹴る・豆をぶつけるという手荒な作法に、強すぎると跳ね返るという加減の教えを組み込んでいます。</li>
</ul>
