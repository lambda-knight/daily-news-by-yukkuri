<h2>オープニング：2026年9月30日 — 世界の珍ニュース</h2>
<p>インドの首都デリーでは、ご近所で世話されている「太った犬」の頂点を決める投票が9月30日に決勝を迎える。東京都心は8月27日から34日続けて雨が降り、1876年以降の統計で最長になった。愛知・名古屋のアジア競技大会では、11歳の小学生が「ぷよぷよ」で金メダルを取った。そして、宇宙飛行士52人の血液から、宇宙で便秘になりやすい理由の手がかりが見つかった。今回は、途切れずに「続く」ことが生む珍しい出来事を四つたどる。</p>
<h2>64匹から「デリーいちの太っちょ犬」を選ぶ投票、決勝はググー対ランバブ</h2>
<ul>
<li>インド・デリーのインスタグラムアカウント「ファット・ドッグス・オブ・デリー」が9月24日、フォロワーから推薦された64匹で勝ち抜き戦を始めた。最初は32組の対戦で、インスタグラムのストーリーの投票機能を使って毎日勝ち残りを決めた。英BBCが9月29日に報じた。</li>
<li>運営者は匿名を希望するデリー大学のジャーナリズム専攻の学生。X（旧ツイッター）で見かけた同種の企画をヒントに「みんながつながれる小さな楽しみに」と始めたが、フォロワーは約1500人から9万人超に急増した（米UPI通信）。支持者は選挙さながらのポスター、応援動画、ミームを作って票を呼びかけた。本人は「ここまで広がるとは思わなかった」と語る。</li>
<li>候補の名前も話題に。北インドの屋台料理にちなむ「ダヒ・バッリ」、神や寺院の名をもじった「マハクッテーシュワル」、直訳すると「犬シン」の「クッタ・シン」など。クッタ・シンには宅配アプリのブリンキットが応援を表明し、優勝犬におやつを無償提供すると約束した。</li>
<li>決勝はサケット地区の「ググー」と、ユスフ・サライ地区の「ランバブ」（別名チョンキー）。ググーは体重46キロの雑種で、2021年に公園で見つけた推薦者によると当時は今の半分以下の大きさだった。現在は動物保護団体の施設で減量の治療を受けており、朝はダリア（砕いた小麦のかゆ）250グラム、昼は牛乳に浸したチャパティ3枚、午後4時に少量の鶏肉という献立（印ビジネス・トゥデイ）。ランバブは地域の世話役からビリヤニをもらい、警備員は約5年前から彼を見てきたという。</li>
<li>出場犬の多くは特定の飼い主を持たず、住民や商店主、働く人たちが世話する「地域の犬」。デリーの野良犬は推計約100万匹で、インド最高裁は2025年、かみつき被害と狂犬病への懸念から施設への移送を命じたが、後に不妊手術とワクチン接種を済ませた犬は地域に残せるよう修正した。運営者は人気を野良犬支援の募金と関心につなげたいとしている。</li>
<li>決勝は9月30日、オンライン投票に加え、デリー市内3か所に設けた投票箱でボランティアが対面投票を受け付ける。優勝犬の発表は10月1日の予定（UPI）。</li>

<h2>東京都心で34日連続の雨、1876年以降の統計で最長</h2>
<ul>
<li>東京都心では8月27日から9月29日まで、34日続けて降水が観測された。これまでの最長は2019年6月27日から7月29日までの33日で、1876年以降の統計で記録を1日更新した（ウェザーニュース、日本気象協会tenki.jp、9月29日）。</li>
<li>8月30日から9月28日までの30日間の降水量は629.5ミリで、平年の275％。9月の日照時間は28日時点で45.8時間と平年の約4割にとどまり、1988年の39.2時間に次ぐ過去2番目の少なさになる可能性がある。</li>
<li>原因は秋雨前線が本州付近に停滞する日が多かったことに、台風24号・25号・26号の接近が重なったため。</li>
<li>9月30日も雨の予想で、35日連続となる見込み。ウェザーニュースは、都心で1か月間すべての日に降水を観測するのは観測史上初とみられるとしている。10月1日以降は高気圧に覆われて日差しが戻り、「久しぶりに洗濯物を安心して外干しできる機会が多くなる」見通し。</li>

</ul>
<h2>11歳の小学生、「ぷよぷよ」でアジア大会史上最年少の金メダル</h2>
<ul>
<li>9月26日、愛知県国際展示場（常滑市）で行われた第20回アジア競技大会のeスポーツ「ぷよぷよ」で、東京都在住の小学5年生、栗原悠輝選手（11歳、東京ヴェルディ所属）が優勝した。決勝は韓国のカン・ドンシン選手に10対2で勝ち、アジア大会史上最年少の金メダリストとなった。eスポーツで日本勢初の金メダル。</li>
<li>決勝では1本目を先取され「まずいと思った」が、その後は突き放した。SoraNews24によると大会全体で失ったのは計4本。決勝の勝負どころで15連鎖を決めた（日本テレビ）。10歳のときには、標準ルールで理論上の最大とされる19連鎖を組んだ経験がある。</li>
<li>始めたきっかけは幼稚園のころに「ぷよぷよテトリス2」を買ってもらったこと。最初はテトリスで遊んでいたが「ちょっと試しに『ぷよぷよ』をやってみたら楽しくて」。練習は「1時間か、やらない」で、練習しない日は塾に通う。好きな科目は社会と算数で、大会の遠征先で土地の産業を知るのが楽しいという（日本テレビ）。</li>
<li>2026年4月、もう一人の小学生選手とともに、ぷよぷよシリーズで初の小学生プロ選手（日本eスポーツ連合公認）に。2月の大会では当時10歳で23歳のプロ選手を破って優勝していた。</li>
<li>優勝直後は無表情だった理由を「表情を変えるのが正直恥ずかしくて、でもめちゃくちゃうれしいです」と説明。9月27日のTBS系「サンデー・ジャポン」へのリモート出演では、連鎖を組むときに「相手に返される前にもう一回、次の連鎖をどう組むかとか、相手の連鎖がどこで終わるかとかを見たり考えたりしています」と語った。</li>
<li>優勝後にしたいことは、集めている鉱物の原石を買うこと、旅行、そして親子丼を食べること（SoraNews24がスポーツ報知の報道として紹介）。</li>

</ul>
<h2>宇宙飛行士はなぜ便秘になるのか、52人の血液が示した腸内細菌の「食べ替え」</h2>
<ul>
<li>デンマークのコペンハーゲン大学は米航空宇宙局（NASA）と共同で、国際宇宙ステーションに数か月滞在した宇宙飛行士52人の血液を分析し、論文を英科学誌ネイチャー・コミュニケーションズに発表した。大学の発表は8月17日、米サイエンスデイリーが9月28日に紹介した。</li>
<li>分析は、あらかじめ狙いを決めずに血液中の代謝物を網羅的に測る方法で行った。その結果、宇宙に着いて数週間のうちに、腸内細菌がふだんより多くのたんぱく質を発酵させている兆候が血液に現れ、地球に戻るまで続いた。</li>
<li>たんぱく質の発酵は、食べ物が腸に長くとどまり、細菌が食物繊維を使い切ったときに起こりやすい。便秘の自覚がなくても起こる。宇宙飛行士には便秘が多いことが知られており、共著者のヘンリク・ローエル准教授は「重力がないことで、食べ物が腸を進むのが遅くなるのだろう」とみている。</li>
<li>発酵でできる代謝物は血液に乗って全身へ運ばれる。大学の発表によると、これらは腎臓の障害、気分の変化、集中力の低下と関連が指摘されている物質だという。</li>
<li>共同筆頭著者の一人、ジョルジア・ラ・バルベーラ准教授は、火星のような長期飛行では腸への悪影響を和らげる対策が必要になり得るとする。候補は食物繊維を増やすこと、プレバイオティクス、腸の動き（ぜん動）を促す処置など。寝たきりで同じような便秘に悩む患者にも役立つ可能性がある。</li>
<li>出典: <a href="https://news.ku.dk/all_news/2026/08/constipation-is-common-in-astronauts--blood-tests-provide-new-answers/">コペンハーゲン大学</a> / <a href="https://www.sciencedaily.com/releases/2026/09/260927225030.htm">ScienceDaily</a> / <a href="https://www.eurekalert.org/news-releases/1140136">EurekAlert!</a></li>
</ul>

<ul>
<li>デリーの太っちょ犬は、一人の飼い主ではなく、ビリヤニやチャパティを差し出す近所の人たちの世話が何年も続いた結果。東京の雨は秋雨前線と三つの台風がつながって34日途切れず、アジア大会の金メダルは、練習日は1時間ほど集中する11歳が、相手より一つ先の連鎖を読んで勝ち取った。</li>

</ul>
