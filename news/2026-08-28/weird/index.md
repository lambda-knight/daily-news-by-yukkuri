<h2>オープニング：2026年8月28日 — 世界の珍ニュース</h2>

<h2>ネタ1 ウサイン・ボルトより速い、と発表された人型ロボット「スーパーマン」</h2>
<ul>
<li>中国のロボット企業ユニツリーは2026年8月17日、人型ロボット「スーパーマン」が秒速12.66メートル、時速にして45.6キロで走ったとする実演動画を公開した。</li>
<li>陸上のウサイン・ボルトが持つ最高速度は秒速12.27メートル、時速44.17キロで、動画の数値が正しければロボットが秒速で0.39メートル上回ったことになる。</li>
<li>同じロボットは垂直跳びでも2メートルを跳んだとされ、2021年にクリストファー・スペルが記録した1.70メートルを超えたという。</li>
<li>ただしこれらの数値はユニツリーの自己申告で、第三者による検証はまだ行われていない。</li>
<li>ユニツリーは以前、数十体の人型ロボットに一斉に武術の演武をさせて注目されたが、その際は動作が乱れて人に当たる場面もあった。</li>
<li>出典: <a href="https://www.odditycentral.com/technology/worlds-fastest-humanoid-robot-can-already-run-faster-than-usain-bolt.html">Oddity Central</a></li>
</ul>
<h2>ネタ2 3年間つかまらなかった伝説の野良猫、ニュージーランド</h2>
<ul>
<li>ニュージーランド北部のプレルア半島で、保護活動団体「ペスト・フリー・プレルア」が「ナイン・ライブズ」と名付けた1匹の野良猫を、3年がかりでようやく2026年に捕獲した。</li>
<li>この猫は絶滅危惧種のカモ、パテケを何十羽も襲っており、2024年に新たに放した20羽のうち15羽が犠牲になった。キーウィのひなや在来のヤモリも食べていた。</li>
<li>団体はおり、わな、暗視カメラを設置し、サーモン、フライドチキン、ウサギの肉をえさに使ったが、猫は数か月おきに現れては姿を消す行動を繰り返した。</li>
<li>プロジェクト責任者のアンディ・メンター氏は「この猫はとても気まぐれで、ある場所に現れたかと思うと、次の2〜3か月は姿を見せなかった」と話す。</li>
<li>同じ場所に3晩続けて現れたところを最終的に捕らえ、その場で苦痛の少ない方法で処分した。胃の内容物を調べたうえで、はく製にして残す予定だという。</li>
<li>出典: <a href="https://www.odditycentral.com/animals/nine-lives-the-legendary-feral-cat-that-feasted-on-endangered-birds-and-eluded-capture-for-3-years.html">Oddity Central</a></li>
</ul>
<h2>ネタ3 完売前に注文したくて2100回、大阪の女性</h2>
<ul>
<li>大阪府の32歳の女性、飲食店従業員が、{集英社|しゅうえいしゃ}のオンライン漫画ストアで2100件以上の空注文を繰り返したとして、業務妨害の疑いで今週逮捕された。</li>
<li>女性は238個のアカウントを使い分け、2024年から2025年にかけて注文を続けた。商品の総額はおよそ43億円にのぼるが、会社が実際に負担した損失は決済や配送の手数料など約750万円だった。</li>
<li>手口は、コンビニ払いを選んで支払わないまま自動キャンセルさせる、または代金引換にして届いた商品の受け取りを拒否する、というものだった。</li>
<li>動機について女性は「売り切れる前に注文すると満足感と爽快感があった」「日々のストレスの解消になっていた」と説明し、容疑を認めているという。</li>
<li>出典: <a href="https://www.odditycentral.com/news/woman-arrested-for-placing-over-2000-fake-orders-on-online-manga-store-in-less-than-a-year.html">Oddity Central</a></li>
</ul>
<h2>ネタ4 境界を測ったら、庭の木12本中11本が越境していた</h2>
<ul>
<li>ある住宅の持ち主が、隣人から「境界沿いにモミの木を並べて植えたい、木は必ず自分の土地側に収める」と持ちかけられ、日当たりへの不安はあったものの了承した、という体験談が英語圏で話題になった。</li>
<li>植えたあと数本が自分の敷地にはみ出して見えたため、持ち主は約3000ドルを払って専門家に境界を測量してもらった。</li>
<li>結果は、12本のうち6本は幹がすべて持ち主側、4本は境界線の真上、1本は枝が大きく持ち主側に張り出しており、完全に隣人側にあったのは1本だけだった。</li>
<li>持ち主は境界にかかる11本すべての撤去を求めたが、隣人は「知らせるのが遅い」「撤去費を二重に負担することになる」と反発した。持ち主は費用の半分を出すことも考えたが、撤去を求める姿勢は変えていない。</li>

</ul>
