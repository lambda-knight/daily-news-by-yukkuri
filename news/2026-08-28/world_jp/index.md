<h1>世界から見た日本（2026年8月28日）</h1>
<h2>オープニング：2026年8月28日 — 世界から見た日本</h2>
<ul>
<li>今日は、歌舞伎の海外展開、東京の芸者を追ったオーストラリアのドキュメンタリー、沖縄県知事選の安全保障フレーム、被爆国日本の核政策への海外の視線という4本を比べる。</li>
<li>政治・安保だけでなく、日本人自身が普段は距離を置いている舞台芸術や花街の内側を、海外の書き手がどこに驚き、何を評価し、どこに違和感を持つかを追う。</li>
</ul>
<h2>映画「国宝」が海を渡す歌舞伎、119カ国配信と欧州公演</h2>
<ul>
<li>CNN（スタイル面）は2026年、映画「国宝」がアカデミー賞国際長編部門の日本代表として動きを強めていると報じ、見出しで「映画『国宝』は歌舞伎という芸能そのものを再生させるかもしれない」と評した。配給は、スタジオジブリ「君たちはどう生きるか」を2024年のオスカー受賞へ導いた米国のGKIDSが担う。</li>
<li>ハリウッド・リポーターによると、「国宝」は公開から6か月で興行収入1億1100万ドルに達し、日本の実写映画で歴代最高を記録した。監督のイ・サンイルは女形（おんながた）への長年の関心を作品の核に置き、記事は女形を「どこにも存在しない、高度に様式化された女性像を体現する存在」と説明した。</li>
<li>記事は、「国宝」の歌舞伎場面が劇場の観客動員を押し上げ、若い世代を含めて主要な歌舞伎劇場で入場者が増えたと伝えた。海外媒体が日本映画のヒットを、舞台芸術の観客回復と結びつけて論じている点が新しい。</li>
<li>国際交流基金は2026年8月5日、動画配信サービスを通じて「連獅子（れんじし）」「二人藤娘（ふじむすめ）」など7演目を119カ国へ無料配信し始めた。字幕は英語、アラビア語、フランス語、ポルトガル語、スペイン語など9言語で、対象の中心はグローバルサウスだという。10月から11月にはフィリピン、ペルー、チリ、アルゼンチン、ブラジル、メキシコ、エジプトの7か国で上映会と、隈取（くまどり）の体験ワークショップを行う。</li>
<li>松竹は2026年4月、中村鷹之資（なかむらたかのすけ）を中心とする女形の実演公演をパリ、ローマ、ケルンの日本文化施設で開いた。松竹による欧州での歌舞伎公演は2018年以来で、化粧と衣裳の実演のあとに「藤娘」「石橋」を上演した。</li>
<li>8月24日には日本外国特派員協会が、市川染五郎（いちかわそめごろう）と尾上辰之助（おのえたつのすけ）という若手の歌舞伎俳優を招いて「若手歌舞伎スターの海外挑戦」と題した記者会見を開いた。海外の記者クラブが歌舞伎の世代交代と国外公演を正面から取り上げた形で、海外の関心が伝統の保存だけでなく、次世代の担い手へ移りつつあることを示す。</li>
</ul>
<h2>「東京の芸者」をオーストラリア公共放送が追う、1万3千人から200人へ</h2>
<ul>
<li>オーストラリア公共放送ABC（ABC）の報道番組「フォーリン・コレスポンデント」は2026年8月4日、記者ナタリー・ホワイティングによる「東京の芸者」を放送した。番組は、閉ざされた花街の共同体に異例の取材許可を得て、現代の芸者の生活、稽古、犠牲を描いたとする。</li>
<li>番組が示す数字は、かつて東京で1万3千人以上いた芸者が、今は約200人にまで減ったというもの。芸者たちは、この芸能を存続させるために外部へ開いていく方針を選び始めていると番組は伝えた。</li>
<li>番組は、芸者の世界が日本国内でもよく知られていないこと、若い女性が友人が享受する自由を手放して古い芸能に人生を捧げている実情に焦点を当てた。海外の書き手が、着物と化粧の華やかさだけでなく、担い手が引き受ける制約と減少という現実を主題にした点が特徴的だ。</li>
<li>同じ8月、日本外国特派員協会は沖縄の県知事選や日本の安全保障と並べて、若手歌舞伎俳優の海外公演を会見のテーマに選んでいる。伝統芸能の内側と世代交代が、海外メディアの取材対象として政治や安保と同じ場に置かれつつある。</li>
</ul>
<h2>沖縄県知事選を「東アジアの安全保障の変数」と見る海外の視線</h2>
<ul>
<li>沖縄県知事選は9月13日投開票で、8月27日に選挙戦が始まった。3期目を目指す現職の玉城（たまき）デニー知事に対し、那覇（なは）市の元副市長で自民党が支援する古謝玄太（こじゃげんた）氏が挑む構図になった。</li>
<li>The Diplomatは2026年8月、この選挙を「東アジアの安全保障に影響しうる」ものと位置づけ、日本の地方選が通常は地域経済や社会福祉を争点にするのに対し、沖縄は地理的な位置ゆえに例外だと論じた。記事は、在日米軍施設のおよそ70%が沖縄に集中していることを前提に置いた。</li>
<li>Nikkei Asiaは、玉城氏が米軍普天間（ふてんま）飛行場の県内移設に強く反対してきた一方、古謝氏が宜野湾（ぎのわん）市の住宅密集地から名護市辺野古（へのこ）沿岸部への移設を進める立場だと整理した。The Japan Timesは、選挙戦の前面に立つのは経済振興策だが、その背後で安全保障をめぐる緊張が争点を形づくっていると報じた。</li>
<li>米外交問題評議会など海外の分析は、日本国内では基地負担の問題として語られる沖縄を、米中対立と第一列島線の防衛という枠組みで読む。同じ選挙が、国内では暮らしと負担、海外では抑止と地政学という別の言葉で説明されている点に、視点の差がはっきり表れている。</li>
</ul>
<h2>被爆国なのに条約に入らない——ナガサキの訴えを海外はどう伝えたか</h2>
<ul>
<li>長崎市の鈴木史朗（しろう）市長は2026年8月9日、被爆81年の平和宣言で核兵器を「絶対悪」と呼び、日本政府に対し、年内に開かれる核兵器禁止条約の第1回再検討会議へ出席し、「戦争で原爆の被害を受けた唯一の国としての歴史的責任」を果たすよう求めた。宣言は、日本国憲法の平和の理念と非核三原則を堅持することも政府に要求した。</li>
<li>鈴木市長は抑止論そのものに踏み込み、核を持つことが核戦争の危険を高めると述べ、核兵器は「必要悪」ではなく人類と共存できないと主張した。宣言は米国との同盟への直接の批判は避け、普遍的な軍縮義務に論点を置いた。</li>
<li>この宣言は、アルジャジーラ、フィリピン通信社、在米日系紙ラフ・シンポなど海外メディアが英語で伝えた。国際平和ビューロー（IPB）の共同代表ジョセフ・ガーソン氏とコーラ・ファブロス氏は8月に来日し、広島・長崎で被爆者と並び、核兵器禁止条約への日本の参加を訴えた。</li>
<li>海外の平和運動や報道は、日本を「唯一の戦争被爆国」と繰り返し呼びながら、その日本が核兵器禁止条約に署名も批准もしていない事実を対比させる。現存する被爆者は平均年齢86歳を超え、証言者が減る中で、条約再検討会議への出席という具体的な一点に海外の期待が集まっている。</li>
</ul>
<h2>まとめ</h2>
<ul>
<li>歌舞伎は海外が「再発見した価値」として119カ国配信や欧州公演に広がり、芸者は担い手の減少と犠牲という「違和感」を含めてオーストラリアの番組が描いた。</li>
<li>沖縄県知事選は暮らしと安保という二つの言葉で内外に読み分けられ、長崎の平和宣言は「被爆国なのに条約に入らない」という海外からの問いを改めて突きつけた。</li>
<li>政治・安保と、舞台芸術・花街という日本人が普段は語らない領域を、海外の媒体は同じ関心の対象として並べて報じている。</li>
</ul>
