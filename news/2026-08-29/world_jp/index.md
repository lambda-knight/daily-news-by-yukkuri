<h1>世界から見た日本（2026年8月29日）</h1>
<h2>オープニング：2026年8月29日 — 世界から見た日本</h2>
<ul>
<li>今日は、8月15日の高市首相の演説を海外がどう伝えたか、オーストラリアの論壇が読む憲法9条、世界的な抹茶不足、ロンドンで開かれた日本の音楽だけの野外フェスという4本を比べる。</li>
<li>政治と平和の話だけでなく、日本人が日常的に飲む抹茶や、国内では長く一部の愛好家のものだった1980年代の音楽が、海外でどう扱われているかを追う。評価の主体、観察した場面、比較の対象を一つずつ明示する。</li>
</ul>
<h2>高市首相の8月15日演説、消えた「反省」を海外はどう伝えたか</h2>
<ul>
<li>米NBCニュース、米PBSニュースアワー、AP通信（記者マリ・ヤマグチ）、マレーシアのザ・スターなどは2026年8月15日、東京の日本武道館で開かれた政府主催の全国戦没者追悼式を報じた。高市早苗首相は就任後初めて式に参列し、平和への誓いを述べたが、式辞で「反省」という言葉を使わなかった。</li>
<li>前年2025年、石破茂首相はこの式辞に「反省」を戻した。AP通信は、日本の首相の8月15日演説で反省への言及が復活したのは、2013年に安倍晋三氏が外して以来初めてだと位置づけていた。海外報道は、高市氏がその語をふたたび落としたという一点を見出しに立てた。日本トゥデイの記事の見出しは「首相演説に『反省』なく」だった。</li>
<li>同じ式で天皇陛下はおことばを述べ、先の大戦への「深い反省」に触れた。首相の式辞と天皇のおことばで、同じ日に語られる言葉が食い違う構図を、複数の海外媒体が並べて示した。</li>
<li>追悼式は約230万人の軍人・軍属と、約80万人の民間人の戦没者を対象にする。高市氏は靖国神社には参拝せず、中国と韓国との関係に配慮したとみられると各社は伝えた。PBSは「戦争の記憶が急速に薄れているという懸念が強まる中で」と前置きし、演説の言葉の選び方を歴史認識の指標として扱った。</li>
<li>国内報道が「参拝したか、しなかったか」を軸にするのに対し、海外報道は式辞の一語の有無を軸にする。同じ8月15日が、行為と言葉という別の物差しで測られている。</li>
</ul>
<h2>「9条は対米戦争の盾」——オーストラリアの論壇が読む日本の平和主義</h2>
<ul>
<li>オーストラリア国立大学が運営する論壇サイト、イースト・アジア・フォーラムは2026年8月上旬、日本の憲法9条をめぐる2本の論考を相次いで載せた。1本目の見出しは「9条は米国の戦争に対する日本の盾であり続ける」、2本目は「日本の9条論争で、米国の予測不能さは両刃だ」だった。これは報道ではなく、研究者による評論である。</li>
<li>背景にあるのは、茂木敏充外相が2026年3月に明らかにした経緯だ。米国とイスラエルによるイラン攻撃のあと、トランプ米大統領は自衛隊をホルムズ海峡へ派遣するよう日本に求めたが、高市首相はこれを断った。論考は、改憲派として知られる高市氏が、9条の制約を根拠に米国の要求を退けた点に注目する。</li>
<li>1本目は、この対応によって憲法上の平和主義が日本の外交・安全保障政策を規定する特徴として立て直された、と評価する。2本目は、米国が同盟国に何を求めるか読めない以上、9条は派兵を断る口実にも、装備増強を迫られる圧力にもなり、方向は一つに定まらないと論じる。</li>
<li>論考は、9条をめぐる国内の対立軸も整理する。左派にとって9条は、戦後日本が国際社会へ復帰する切符であり、軍事的な冒険への歯止めだ。右派にとっては、国を弱めるために押しつけられた条文だ。海外の書き手は、この対立を「保守政権が改憲を掲げながら、実際には9条を使って米国に抵抗する」という逆説として描く。</li>
<li>2本の論考は、日本の安全保障の課題は条文の書き換えより、解釈と制度の運用で対応されてきたし、これからもそうなるだろうと見る。国内では「改憲か護憲か」で語られる9条が、海外の分析では「米国との距離を測る道具」として読まれている。</li>
</ul>
<h2>世界的な抹茶不足、宇治のてん茶と猛暑を海外メディアが追う</h2>
<ul>
<li>カナダ公共放送CBCは「抹茶が脚光を浴び、日本の茶業界に負荷がかかっている」と報じ、米ブルームバーグは「世界的な抹茶不足が朝の定番の価格を押し上げる恐れ」と伝えた。いずれも2024年末から続く品薄を、日本の生産現場と海外の需要の両側から描いている。</li>
<li>業界団体のグローバル・ジャパニーズ・ティー協会は、これを「史上初の抹茶不足」と表現した。足りないのは緑茶全般ではなく、日光を遮って育てる「てん茶」——茶臼でひいて抹茶にする、儀式用の高級な葉に限られる。</li>
<li>CBCによると、抹茶の生産量は2010年から2023年にかけてほぼ3倍になった。牽引したのはソーシャルメディアでの流行と、コロナ後の訪日観光の急増だ。一方、記録的な猛暑と不規則な降雨で、宇治の最高等級のてん茶は収量が4割落ちた年もあり、生産が需要に追いつかない。</li>
<li>取引データでは、宇治の初摘みてん茶の競り値は前年の2倍以上に高騰した。宇治の老舗の中には、新規の卸売り口座の開設を止め、既存客への数量割り当てに切り替えたところもある。海外へ出る抹茶の半分以上が米国向けで、米国は最大の輸出先だ。</li>
<li>日本国内では、抹茶は日常の飲み物であり、和菓子や飲料の材料でもある。海外報道は、その日常品が世界的な争奪戦の対象になり、価格と品質をめぐって偽の「宇治抹茶」が出回る懸念まで生んでいると伝える。日本人が値ごろ感で見ている葉に、海外の書き手は供給の限界という別の顔を見ている。</li>
</ul>
<h2>ロンドンで日本の音楽だけの野外フェス、高中正義が主役に</h2>
<ul>
<li>英ヴァージ・マガジンなどによると、2026年8月7日、ロンドン南部のクリスタル・パレス・ボウルで、日本の「シティ・ポップ」に的をしぼった野外フェス「シティ・ポップ・ウェイブス」が開かれた。主催は米ライブ・ネイションで、7月31日から8月16日まで続く夏の企画「パレス・ボウル・プレゼンツ」の一環だった。</li>
<li>主役はギタリストの高中正義で、約2時間の演奏をした。共演は、1987年のフュージョン作『フライング・ビーグル』を全曲通して披露した鍵盤奏者の菊池ひみこ、日本の楽曲を下敷きにする米国のジンジャー・ルートのDJセット、そして八神純子。記事は「英国で日本の音楽だけを掲げた初の野外フェス」と紹介した。</li>
<li>シティ・ポップは1970年代後半から1980年代の日本の都会派ポップスで、当時は国外でほとんど知られず、国内でも近年まで一部の愛好家のものだった。海外での再評価は、竹内まりやの1984年の曲「プラスティック・ラブ」の非公式動画がユーチューブの推薦機能で広まったのがきっかけとされる。松原みきの「真夜中のドア」も世界的な再生数を集めた。</li>
<li>竹内まりや自身は2024年、ビルボード・ジャパンの取材に、「プラスティック・ラブ」の視聴者を確かめるとロシア語や韓国語のコメントが並んでいたと語り、カナダに住む姪から「歌っているのが叔母だと言うと驚かれる」と聞いたと明かした。</li>
<li>国内では懐メロ、あるいは日本語の歌謡曲として聴かれてきた曲が、海外では「シティ・ポップ」という一つのジャンル名でくくられ、フェスの看板になっている。日本の聴き手が世代の記憶として持っている音楽を、海外の主催者と観客は新しい発見として扱っている。</li>
</ul>
<h2>まとめ</h2>
<ul>
<li>8月15日の演説を海外は「消えた一語」で読み、9条をオーストラリアの論壇は「米国との距離を測る道具」として読んだ。政治の言葉が、国内とは別の軸で解釈されている。</li>
<li>抹茶は日常品が世界的な品薄の対象になり、シティ・ポップは国内の懐メロが海外でジャンルとして再発見された。日本人が値ごろや世代の記憶で見ているものに、海外は供給の限界や新しさという別の顔を見ている。</li>
<li>4本に共通するのは、同じ対象でも、見る国と立場が変われば説明の言葉が変わるということだ。</li>
</ul>
