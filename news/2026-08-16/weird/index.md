<h1>13歳が作った移動支援椅子、375キロの車を運ぶ怪力男、10フィートの毛玉（2026年8月16日）</h1>
<h2>オープニング：2026年8月16日 — 世界の珍ニュース</h2>
<ul>
<li>8月16日の世界の珍ニュースは、300時間かけて幼児用の3Dプリント移動支援椅子を作ったユタ州の13歳、375キロの車をマクドナルドのドライブスルーで運んだストロングマン選手、ニューヨークの街を転がった10フィートの巨大毛玉、カエデの葉を食べるためにロバの背中を踏み台にするヤギの4本を紹介する</li>
<li>4本に共通するのは、公開設計図、店舗スタッフ、広告制作、動物同士の協力が、個人の奇抜な発想を実際の出来事として成立させた点である</li>
</ul>
<h2>ネタ1 13歳が300時間で作った、幼児のための3Dプリント移動支援椅子</h2>
<ul>
<li>米ユタ州リーヒ在住の13歳、ザック・ウォーターズさんは、2026年の夏休みに300時間をかけ、生後21カ月の女児のための移動支援椅子をゼロから設計・印刷・組み立てた</li>
<li>動画で3Dプリント技術を独学したザックさんは、非営利団体「MakeGood」が無償公開している幼児用移動支援トレーナーの設計図をダウンロードし、対象の女児の体格に合わせて寸法をカスタマイズした</li>
<li>現地メディアABC4ユタの取材にザックさんは「困っている人を助けることが好きで、3Dプリントと人助けという自分の二つの好きなことが合わさった」と動機を語り、印刷が完了して女児の家族が実際に椅子を見た瞬間について「家族の笑顔を見るのが本当に幸せだった」と話した</li>
<li>出典: <a href="https://laughingsquid.com/3d-printed-mobility-chair-for-toddler/">Laughing Squid</a></li>
</ul>
<h2>ネタ2 375キロの車をマクドナルドのドライブスルーで運んだストロングマン</h2>
<ul>
<li>ストロングマン競技の選手ジェーデン・レイングさんは、大会に向けたトレーニングの一環として、部品を外して375キロまで軽量化した車を担ぎ、マクドナルドのドライブスルーレーンを最初の注文口から受け取り口まで歩いて運んだ</li>
<li>ドライブスルーの窓口担当スタッフはこの企画に協力し、スタント自体も滞りなく進行した</li>
<li>レイングさんが受け取った対価はチーズバーガー1個で、車を運ぶという非日常的な挑戦と、ファストフード店側の柔軟な対応が組み合わさった一幕になった</li>
<li>出典: <a href="https://laughingsquid.com/strongman-carries-car-drive-thru/">Laughing Squid</a></li>
</ul>
<h2>ネタ3 「私たちが毎日失う髪」10フィートの毛玉がニューヨークを転がった</h2>
<ul>
<li>2026年8月、直径10フィート（約3メートル）の巨大な毛玉「タンブルヘア」がニューヨーク市内の街路を転がる映像が話題になった</li>
<li>制作したのはクリエイティブスタジオUncommon Creative Studioで、ヘアケアブランドK18の新製品「FutureIQ」発売に合わせたマーケティング企画。毛玉は実際の人毛で作られており、ニューヨーク市民が日常の抜け毛で失うとされる1,670億本の髪を1つの塊として可視化した</li>
<li>一見無人で自動的に転がっているように見えたが、実際には撮影用に隠れたスタッフが動かしており、転がるたびに毛が路上に落ちる仕掛けだった。制作側は「見た目は不快かもしれないが、日常的な抜け毛の規模を無視できないものに変えた」とコメントしている</li>
<li>出典: <a href="https://laughingsquid.com/tumblehair-hairball-nyc/">Laughing Squid</a></li>
</ul>
<h2>ネタ4 カエデの葉を食べるため、ロバの背中を踏み台にするヤギ</h2>
<ul>
<li>農場で暮らすヤギの「アンバー」と、ロバの「ドリー」は仲の良い相棒で、アンバーは好物のカエデの葉に届かないとき、ドリーの背中によじ登って踏み台代わりに使う</li>
<li>飼い主のディナさんは、TikTokに投稿した動画で2頭の関係を「美しい相互関係」と表現し、「言葉なしにコミュニケーションを取り、相互尊重を通じて絆を築いた」と説明した</li>
<li>ドリーは背中を踏まれても抵抗せず、アンバーが葉を食べ終わるまでじっと立ち続けているという</li>
<li>出典: <a href="https://laughingsquid.com/goat-uses-donkey-as-step-stool/">Laughing Squid</a></li>
</ul>

<ul>
<li>今日の4題は、13歳の少年が積み上げた300時間の善意、ストロングマンの筋力トレーニングをドライブスルーという日常に持ち込んだ発想、企業のマーケティング企画が生んだ巨大な視覚的インパクト、そして種を超えた動物同士の信頼関係と、それぞれ違う角度の「驚き」を映していた</li>
<li>見出しの奇抜さの先にあるのは、無償の技術と善意の積み重ね、非日常な挑戦を受け入れる現場の柔軟さ、数字を実感させる表現の工夫、動物同士の関係性という具体的な背景だった</li>
<li>13歳の工作も怪力選手の注文も、周囲が協力したことで一人の思いつきに終わらなかった。巨大毛玉と二頭の動物も、数字や関係性を目に見える形へ変えた点で共通する</li>
</ul>
