<h2>OpenAI、サイバー研究者への特別アクセスを一部停止</h2>
<ul>
<li>2026年8月19日（水）、複数のセキュリティ研究者がOpenAIの「Trusted Access for Cyber」プログラムからアクセスを剥奪されたと報告</li>
<li>TechCrunchが確認した研究者は少なくとも5人で、米国・欧州以外の地域の研究者が中心</li>
<li>同プログラムは、審査済みの研究者に通常より制限の少ない高度モデルへのアクセスを与え、脆弱性報告を早めることが目的</li>
<li>OpenAIは「技術的な問題」「こちら側の問題だった」と説明し、対象研究者に再申請と本人確認の完了を要求</li>
<li>8月10日には上位の新階層「Daybreak Blue」「Daybreak Red」を導入し、より高度なセキュリティ研究アクセスを提供開始したばかりだった</li>
</ul>
<h2>AIの「自己改善」実験、専門家が急ブレーキを指摘</h2>
<ul>
<li>プリンストン大学のPeter Kirgis氏とSayash Kapoor氏らが率いる複数機関の研究チームが、「影の評価」という新手法でAIエージェントの研究能力を検証</li>
<li>AnthropicのClaude Opus 4.8に、NeurIPS 2026へ投稿された未公開論文2本のテーマを与え、6日間・Anthropic APIクレジット3,000ドル・GPU予算・仮想マシン・ウェブアクセスを提供</li>
<li>文献レビューや数百件の実験実施など工学的な作業はこなせたが、研究そのものは苦手だった</li>
<li>Kapoor氏は「エージェントは研究の実施そのものに明らかに不得意だった」とし、独創的な発想の探索不足、限られたデータでの早期の仮説放棄、失敗した手法からの方向転換の失敗を挙げた</li>
<li>2本の論文はいずれも査読者に却下された</li>
<li>Anthropic共同創業者のJack Clark氏はニュースレターImport AIで「現在のAIシステムには価値ある直感的な創造性が欠けている」と述べ、短期的な再帰的自己改善のタイムラインへの弱気材料だと位置づけた</li>
</ul>
<h2>AI企業の「利用実態」発表、独立調査と数字が食い違う</h2>
<ul>
<li>スタンフォード大学のAnka Reuel氏は、AnthropicやOpenAIが公表する利用データに独立検証がない点を指摘</li>
<li>Reuel氏とMITメディアラボ出身のShayne Longpre氏が主導する「AI Observatory」プロジェクトは、2023〜2025年の会話24,521件・52モデル・ユーザー5,000人分を分析</li>
<li>Anthropicの「Economic Index」は仕事関連の利用に焦点を当てており、会話の48%をフィルタリングして除外していたことが判明</li>
<li>除外された会話では、健康・人間関係が44.2%（Anthropic発表は31.2%）、成人向けコンテンツが7.9%（同2.1%）、ハラスメント・ヘイトスピーチが27.5%（同5.66%）、性的コンテンツが16.7%（同2.4%）と、いずれもAnthropicの公表値より高かった</li>
<li>GrokとGeminiは情報検索での利用が多く、特にGrokはニュース・政治情報での誤情報が目立った。Claudeはコーディング、Geminiはロールプレイ・交流、ChatGPTは宿題支援での利用が特徴的</li>
<li>データ規模の比較: AI Observatory 24,521件に対し、Anthropic Economic Indexは約100万件、OpenAIのChatGPTレポートは約150万件</li>
<li>テキサス大学オースティン校のDavid Widder助教授は、企業データとは別の「独立した視点」の価値を指摘</li>
</ul>
<h2>Google、検索とGeminiに学習支援ツールを追加</h2>
<ul>
<li>2026年8月19日（水）太平洋時間正午、Googleが検索とGeminiに新しい学習機能を発表</li>
<li>検索では、AI生成の対話型ビジュアルと3Dシミュレーションを提供。例えば「pH」を検索するとAI Overviewが基礎を解説する対話的ビジュアルを表示</li>
<li>「SAT対策の頻出語彙クイズを作成」のような指示でカスタム練習クイズも生成可能に</li>
<li>Gemini側では、複数ステップの調査レポートをGemini Liveで音声対話しながら検討できる機能や、「DNAの仕組みを3Dで見せて」といった指示に応じる3Dシミュレーション生成、ノート・フラッシュカード・クイズを一元管理する専用の学習ハブを追加</li>
<li>OpenAIやKnowt、Gauthなど教育系スタートアップとの競争の中で、Geminiを学生の第一選択AIアシスタントにする戦略の一環</li>
</ul>
<h2>TerraPower、AIデータセンター向け原子炉に「蓄熱」の切り札</h2>
<ul>
<li>ビル・ゲイツ氏が創業したTerraPowerが、今年初のデータセンター向けプロジェクトを2026年8月19日にTechCrunchが報道</li>
<li>同社は1月にMetaと契約し、Natrium発電所8基の購入で合意済み</li>
<li>345メガワットの溶融塩冷却原子炉は、核分裂を継続しながら余剰熱を巨大な溶融ナトリウムタンクに蓄え、需要急増時に柔軟に対応できる設計</li>
<li>従来型原子炉は稼働率92.5%と高いが出力調整は毎分5%程度にとどまる一方、小型モジュール炉は毎分10%まで調整可能。TerraPowerの蓄熱技術はデータセンター特有の不規則な電力需要への最適化を狙う</li>
<li>最初の施設はワイオミング州で建設中、2番目の発電所は2027年に着工予定</li>
</ul>
<h2>シカゴ90億ドルの量子計算拠点、住民が「撤回」要求</h2>
<ul>
<li>2026年8月18日、シカゴのブランドン・ジョンソン市長が、南東部（サウスサイド）住民から総額90億ドル規模の量子計算開発「Quantum Shore」への強い反対を受けた</li>
<li>旧USスチール・サウスワークス跡地が開発地。Southside Togetherなどのコミュニティ団体は、既存許可の取り消し、資金・税優遇の撤回、市によるプロジェクトへの正式な反対表明を要求</li>
<li>懸念点は電力・水インフラへの負荷増加、公共料金の上昇、地域住民の立ち退きリスク</li>
<li>ジョンソン市長は要求に応じず、「イノベーションは環境正義を犠牲にして成り立つものではない」と述べ、データセンター開発に新要件を課す行政命令への署名にも言及</li>
<li>資金投入額はイリノイ州が5億ドル、クック郡が30年間で1億7,500万ドルの税優遇、シカゴ市が500万ドル</li>
<li>PsiQuantum、IBM、Infleqtionが参画予定で、第1段階の工事は2025年10月に開始済み</li>
</ul>
<h2>まとめ</h2>
<ul>
<li>研究能力・利用実態の透明性・インフラ投資という3つの軸で、AI業界の発表と現場の検証結果にずれが見えた一日</li>
<li>自己改善の実験は「まだ人間の創造性に届かない」という結果を示し、利用データは企業発表より雑多な実態を映し出した</li>
<li>原子炉・量子計算という次世代インフラへの巨額投資は、その足元の地域社会との摩擦を伴って進んでいる</li>
</ul>
