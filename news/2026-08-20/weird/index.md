<h2>オープニング：2026年8月20日 — 世界の珍ニュース</h2>
<h2>ネタ1 わずか1.8キロのビーチに20万人、中国「世界一混雑するビーチ」大梅沙</h2>
<ul>
<li>中国・深圳市の大梅沙（ダーメイシャ）ビーチは全長わずか1.8キロメートルだが、混雑時には約20万人が押し寄せ「世界一混雑するビーチ」と呼ばれている</li>
<li>混雑の背景には複数のバス路線とメトロ駅がビーチ正面に位置する好立地、そして入場無料であることがあり、地元住民と観光客の双方に人気が集中する</li>
<li>特に混み合うのは5月から10月の夏季シーズンの週末。この期間、当局は1日あたりの入場者数を8万人に制限する予約制度を導入している</li>
<li>砂浜が人で埋め尽くされ海面がほとんど見えない「人間で埋まった海」の写真がオンラインで定期的に話題になり、TripAdvisorには批判的なレビューも寄せられている</li>
<li>出典: <a href="https://www.odditycentral.com/travel/dameisha-the-worlds-most-crowded-beach.html">Oddity Central</a></li>
</ul>
<h2>ネタ2 「2ドル紙幣は偽物?」ホテルのフロントを巻き込んだ一夜の騒動</h2>
<ul>
<li>米国のホテルでフロント係が接客中、8歳の男の子が「1ドル札に両替してほしい」と使い古した2ドル紙幣を差し出した</li>
<li>忙しさから一度は深く確認しなかったが、後になって紙幣の見た目に違和感を覚え、偽造検知ペンで確認したところ「反応は正常」と出て、いったん疑いを打ち消した</li>
<li>しかし送迎ドライバーも同じ紙幣を怪しみ、フロントスタッフの間で意見が真っ二つに割れる「朝一番の話題」になった</li>
<li>結局、係が銀行に紙幣を持ち込んでUVライトで確認したところ、正真正銘の偽札だと判明。支配人は「たった2ドルだから」と実害を問題にせず、以後の確認用にUVライトの購入を許可した</li>
<li>出典: <a href="https://twistedsifter.com/2026/08/a-hotel-worker-thought-a-2-bill-looked-fake-but-the-counterfeit-pen-proved-her-wrong/">Twisted Sifter</a></li>
</ul>
<h2>ネタ3 「充電が遅い」とホテルの無料充電器にクレーム、宿泊客が無料宿泊を要求</h2>
<ul>
<li>米国のホテルで、宿泊客が「部屋にある無料の充電器が自宅の充電器より遅い」とフロントに苦情を入れ、無料の1泊宿泊を要求した</li>
<li>スタッフは「これは無料でお使いいただける、ホテルからのサービス品です」と説明し、要求をすべて断った上で近くのコンビニでの充電器購入を勧めた</li>
<li>宿泊客は自費で13.99ドルの充電器を購入したが、使ってみるとホテル備え付けの充電器の方が実は速かったことに気づいた</li>
<li>購入した充電器を返品しようとしたが断られ、その後ホテル側からの連絡もなく騒動は静かに終わった</li>
<li>出典: <a href="https://twistedsifter.com/2026/08/guest-complained-the-hotel-charger-was-slower-than-hers-at-home-then-demanded-a-free-night/">Twisted Sifter</a></li>
</ul>
<h2>ネタ4 娘5歳の誕生会は「シーフードボイル」、伝統的でないと姉に文句を言われ退席を求めた母親</h2>
<ul>
<li>米国の33歳の母親が、5歳の娘の希望に合わせてシーフードボイル（魚介の茹で盛り）をメインにした誕生日パーティーを開いた</li>
<li>会場にはシーフード用と、非シーフード派向けにホットドッグやハンバーガー、フライドポテト、カップケーキを並べた2つの食事コーナーを用意していた</li>
<li>しかし姉（36歳）が到着するなり「これは本物の誕生日パーティーじゃない」と伝統的なケーキやピザがないことを批判し、自分の子どもにシーフードを試させることも拒み、「ゲストへの配慮が足りない」と母親を責めた</li>
<li>母親は「文句があるなら来なくてよかったのに」と伝え、姉は子どもを連れて退席。後日SNSで「恥をかかされた」と主張したが、ネット上のコメントは主人公と5歳児の希望を尊重した母親側を支持する声が大勢を占めた</li>
<li>出典: <a href="https://twistedsifter.com/2026/08/her-sister-ruined-the-mood-at-her-daughters-birthday-party-so-she-told-her-to-leave/">Twisted Sifter</a></li>
</ul>
