<h2>オープニング：2026年9月26日 — 世界の珍ニュース</h2>
<p>投票サイトを止めてしまったアラスカの太ったクマ、1日最大150ガロンの水を注いで1006ポンドのカボチャを育てたシアトルの教員、ドイツの畑から出てきた兵士6年分の蓄えに当たるローマ銀貨934枚、そして「知られていない」ことを売り文句に変えた秋田・草津・鳥取。今回は、ため込んだもの、あるいは足りないものが、思わぬ形で人を集めた四題をたどる。</p>
<h2>「クマがネットを壊した」、アラスカのファット・ベア・ウィーク初日にサーバーがパンク</h2>
<ul>
<li>アラスカ州のカトマイ国立公園で、冬眠前にどれだけ太ったかをクマ同士で競わせるオンライン投票「ファット・ベア・ウィーク」が9月22日に始まった。2014年に始まり今年で12回目。国立公園局、中継サイトのエクスプローラー（explore.org）、カトマイ保全協会が共催する。</li>
<li>初日は投票が殺到してシステムが過負荷になり、第1ラウンドの投票を23日まで延長した。公園側は「クマたちがインターネットを壊した。文字通り」と発表し、エクスプローラーは「史上最大の初日参加で、システムに過負荷が起きた」と説明した。昨年は100か国以上から170万票超が集まっている。</li>
<li>出場は例年の12頭から増えて16頭。ブルックス川では今年100頭を超えるクマが確認され、公園長のマーク・スタームさんは「子グマがこれほど多いのは久しぶり。新しい世代の太ったクマが育っている」と話す。</li>
<li>昨年王者の「32番チャンク」は原因不明のけがで下あごが砕けた状態だが、レンジャーのサラ・ブルースさんによれば「それでもしっかり太っている」。第1ラウンドでは、例年なら後半で当たる人気の「164番バッキー」と早くも対戦する組み合わせになった。</li>
<li>第1ラウンド前半の結果は、132番の親子が284番の親子に17万1619票対4万6449票、909番が「428番スチューディアス」（2023・24年王者グレーザーの娘）に15万5899票対5万1493票で勝つなど。クマは冬眠中に体重の約3分の1を失い、4〜6か月食べずに過ごすため、夏のサケでどれだけ脂肪をため込めたかが生死を分ける。決勝は9月29日の「ファット・ベア・チューズデー」。</li>

<h2>「グランドピアノより重いカボチャに秘訣はない」、シアトルの教員が1006ポンドで優勝</h2>
<ul>
<li>シアトルのジョージタウン地区に住むジョセフ・ベアードさんは、18〜22歳の若者に就労訓練を教える教員。妻と2人の子どもと暮らしながら、4月から週およそ25時間をカボチャの世話に充ててきた。本人はこのカボチャを「3人目の子ども」と呼ぶ。</li>
<li>品種はアトランティック・ジャイアント。重さ1006ポンド（約456キロ）で、ワシントン州東部のスポケーン郡インターステート・フェアで優勝し、賞金800ドルを得た。2位は499.5ポンドで、ほぼ2倍の差だった。</li>
<li>日課は、朝早く温室の扉を開けて蒸れを防ぎ、1日最大150ガロン（約570リットル）の水をやり、つるの節を土に埋めて根を広げさせること。日没前には温室を閉め、寒さと虫よけのためにカボチャへ毛布を掛ける。温室は自宅より大きい。</li>
<li>運び出しには合板でそりを作り、三脚とエンジン用ホイスト、ハーネスで持ち上げ、大人8人がかりでトラックのトレーラーまで引いた。シアトルからスポケーンまでは約290マイル（約470キロ）。総費用を聞かれると「言ったら妻にばれる」と答えなかった。</li>
<li>昨年はスカジット・バレーの大カボチャ祭りに1637ポンドを出品しており、今年は土の状態などで軽くなったという。本人は「秘訣はない」とし、「通貨は、大きなカボチャが運んでくる善意と楽しい気分。大きなカボチャはみんな好きだから」と語る。祭りが終わったカボチャは「来た場所へ、土へ帰る」。</li>
<li>出典: <a href="https://www.spokesman.com/stories/2026/sep/22/a-seattle-mans-secret-to-growing-the-largest-pumpk/">The Spokesman-Review</a></li>
</ul>
<h2>兵士6年分の貯金？ ドイツの畑からローマ銀貨934枚、ボンで公開</h2>
<ul>
<li>ドイツ西部ケルンの南、ヴェッセリング近くの畑で、アマチュア考古学者のオリバー・リードルさんが金属探知機で数枚のローマ銀貨を見つけた。探知機が鳴りやまないため当局に連絡し、専門家が掘り進めた結果、デナリウス銀貨が計934枚、重さ3.1キロ出てきた。発見はおよそ1年前。</li>
<li>地元の考古当局によると、ドイツで見つかったハドリアヌス帝時代の貨幣の埋蔵としては最大。2世紀の第2四半期（西暦125〜150年ごろ）に意図的に埋められたとみられる。ケルン周辺は紀元前39年ごろから西暦459年ごろまでローマの支配下にあった。</li>
<li>9月22日からボンのLVRラインラント州立博物館で公開が始まった。</li>
<li>州考古学者のエーリッヒ・クラッセンさんは「動機は推測するしかないが、誰かがお金を安全に保管したかった可能性が非常に高い。当時は銀行がなかった」と話し、持ち主が在りかを誰にも伝えないまま亡くなったのかもしれないとする。</li>
<li>研究員のラヘル・オッテさんの試算では、当時の軍団兵の年俸は300デナリウスで、その約半分が食料や装備代として差し引かれた。この量を貯めるには、自由に使えるお金を約6年間すべて貯金に回す必要があった。</li>
<li>出典: <a href="https://abcnews.com/International/wireStory/amateur-archaeologist-finds-germanys-biggest-hoard-ancient-roman-136647641">ABC News（AP）</a>、<a href="https://globalnews.ca/news/12068289/germany-roman-silver-coins/">Global News</a>、<a href="https://wtop.com/national/2026/09/amateur-archaeologist-finds-germanys-biggest-hoard-of-ancient-roman-silver-coins">WTOP（AP）</a></li>
</ul>
<h2>「まだバレてない秋田県。」「温泉がない方の草津」、知られていないことを売る自治体</h2>
<ul>
<li>秋田県は「まだバレてない秋田県。」というキャッチコピーで5〜7月に観光キャンペーンを実施した。6月の延べ宿泊者数は33万9100人で前年同月比34.4％増と、全国トップの伸び率を記録した。</li>
<li>滋賀県草津市は「温泉がない方の草津」とPRし、マスコットキャラクター「おんせんどろぼう」を活用している。市観光物産協会の阪本佳奈さん（29）は「自虐のように見えるかもしれないが、草津市の魅力を知ってもらうきっかけになれば」と話す。</li>
<li>鳥取県は、牛丼チェーンの松屋が全都道府県で唯一出店していないことを題材にした。県のキャラクター「トリピー」のX投稿は80万超の閲覧を記録し、4月には「#鳥取に松屋が来たら」キャンペーンを展開した。県広報課の中垣咲紀さん（35）は「ネガティブに捉えるのではなく、ポジティブに変えて魅力を発信していきたい」とする。</li>
<li>時事通信が9月19日に配信し、英字紙ジャパンタイムズも9月25日に「自虐的なユーモアで観光を押し上げる自治体」として取り上げた。</li>
<li>出典: <a href="https://www.nippon.com/ja/news/yjj2026091900308/">nippon.com（時事通信）</a>、<a href="https://www.japantimes.co.jp/news/2026/09/25/japan/municipalities-joke-tourism-pr/">The Japan Times</a></li>
</ul>
<h2>まとめ</h2>
<ul>
<li>アラスカのクマは夏に脂肪をため込み、その太り具合を見たい人がサーバーを止めた。シアトルのカボチャは週25時間と大量の水を注ぎ込んだ結果で、ヴェッセリングの銀貨は、誰かがため込んだまま取りに戻れなかった財産だった。</li>
<li>秋田・草津・鳥取は逆に、知名度や温泉や牛丼店が「足りない」ことを看板にした。秋田では宿泊者が前年同月比34.4％増という数字にもつながった。</li>
<li>蓄えも欠けているものも、それだけでは見えない。投票、品評会、博物館、キャッチコピーという「見せる場」があって、初めて人が集まる。</li>
