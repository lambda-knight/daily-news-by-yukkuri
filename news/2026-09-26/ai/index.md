<h2>生成AIとインフラ：Anthropic、Akamaiに7年116億ドル、見返りに最大5％の株</h2>
<ul>
<li>Anthropicは9月25日までに、コンテンツ配信大手Akamaiのクラウド基盤へ7年間で116億ドルを支払う契約を結びました。マイルストーンをすべて満たせば総額は約200億ドルに拡大し得ます。5月に結んだ18億ドルの当初契約を大幅に広げたもので、Akamai史上最大の取引です。</li>
<li>提供されるのはGPUではなく汎用のCPU計算能力です。Akamaiは約55億ドルを投じて設備を建設し、2026年の設備投資にメモリなど部品向けとして17億ドルを上乗せします。売上は2027年後半から立ち始め、同年に1億5000万〜3億ドル、2028年末には年17億ドルのペースに達する見通しです。</li>
<li>異例なのは株式の条件です。AkamaiはAnthropicに、普通株770万株に転換できる無議決権優先株の新株予約権を発行しました。行使価格は1株111.33ドルで、発行済み株式の最大5％に相当します。初回の支払いで約2％が確定し、残る3％は支出の節目に連動し、追加で30億ドル支払うごとに約1％ずつ増えます。</li>
<li>契約はAkamaiが納入と稼働率の要件を満たすことが前提で、一定の条件で双方が解約できます。発表を受け、Akamai株は時間外取引で最大17％上昇しました。</li>
<li>同じ日、英国のAIデータセンター企業Nscaleも、米国での上場を前にThird PointやNvidiaなどから33億6000万ドルの転換社債型の資金を確保しました。AnthropicにはすでにAmazon、Google、Microsoft、AMDが出資しており、計算資源の供給者が株式をセットで差し出す構図が広がっています。</li>
</ul>
<h2>生成AIと社会：米国防総省、AIうそ発見器「Polygraph+」に3030万ドル</h2>
<ul>
<li>米国防総省の予算要求によると、国防防諜保安局（DCSA）は「Polygraph+」（別名Polygraph Next）と呼ぶ改良型うそ発見器に、今後5年で3030万ドルを投じる計画です。目的は職員の身元審査と内部脅威の検知です。</li>
<li>柱は二つです。AIと機械学習による判定スコアの算出と、「スタンドオフ・センシング」と呼ばれる、体に器具を付けずに生理反応を測る技術です。試作企業にはPresage Technologies（一般的なカメラで心拍と呼吸を推定）と、Altec Research（頭の動き、顔の皮膚温度、汗腺の活動を追跡）が選ばれました。</li>
<li>従来のポリグラフは血圧、脈拍、呼吸、発汗を測ります。米ポリグラフ協会は精度80〜94％と主張しますが、1983年の米議会技術評価局は職員選別への使用を支える証拠は「非常に限られる」とし、2003年の全米研究評議会も有効性の証拠は「よく言っても弱い」と結論しました。人は補助なしだと、うそを見抜ける確率が5割をわずかに上回る程度です。</li>
<li>法学者のキリ・コツォグル氏は「複雑なものを手でつかめる何かへ還元しようとする見当違いの試みだ」と批判し、マリオン・オズワルド教授は、もともと信頼性に乏しい技術へAIの不確かさを重ねる「両方の悪いところ取り」だと述べました。</li>
<li>国防総省の職員は約280万人です。誤判定率がわずかでも、数万人規模の人が根拠の弱い疑いをかけられ得る規模です。</li>
</ul>
<h2>生成AI：GPT-6 AstraとClaude Opus 5、未解読だったエニグマ暗号電文2通を解読</h2>
<ul>
<li>1941年7月10日にドイツ陸軍の兵士がローゼノウから送った82文字のエニグマ暗号電文が、OpenAIのGPT-6 Astraの助けで解読されました。この電文は2005年以来、誰も解けていなかったものです。ブルームバーグで製品開発のコーチを務めるカーター・レッフェン氏が9月17日にXで公表しました。</li>
<li>Astraは約10時間の解析で、同じ日に送られ既に解読済みの「ローゼノウ」を含む電文を突き合わせ、エニグマが文字を決して同じ文字に暗号化しないという弱点を使って候補を絞り込みました。自らエニグマのシミュレーターも作っています。設定が合うと残り68文字がドイツ語の文として現れ、「至急無線で返信せよ」「行軍経路を示せ」といった内容でした。</li>
<li>解読文には通信士の打ち間違いと見られる「BTTE」（正しくはBITTE）が含まれ、レッフェン氏はこれを本物である証拠と見ています。未解読電文のデータベースを管理するフローデ・ヴァイエルード氏は「GPT-6 Astraは非常に熟練した暗号解読者であり、公文書館の研究者のようにふるまった」と評しました。ただし調査を主導し目標を定めたのは人間の研究者で、公開資料への独立した専門家の検証はまだ済んでいません。</li>
<li>9月21日には、サイバーセキュリティ企業幹部のジャック・ウィリス氏が、AnthropicのClaude Opus 5で別の未解読電文を解いたとヴァイエルード氏に伝えました。こちらは特定の将校の署名が分かっていたことなど、人間がより多くの手がかりを与えています。</li>
<li>残る未解読電文は7通と、平文は分かっているのに鍵が解けていない1通です。</li>
</ul>
<h2>量子コンピュータ：ドイツ、QUDORA主導の1000量子ビット機に1億2200万ユーロ</h2>
<ul>
<li>ドイツ連邦研究技術宇宙省（BMFTR）は9月23日までに、量子コンピュータ競争プログラムの一環として、QUDORA Technologiesが率いる7者の企業・研究連合による「NFQC-1k」計画を選びました。予算は1億2200万ユーロ（約1億3880万ドル）、期間は5年です。</li>
<li>目標は、イオントラップ方式で物理量子ビット1000個以上、論理量子ビット50個を持ち、論理ゲートの誤り率を0.01％未満に抑える誤り耐性量子コンピュータです。並行して、量子プロセッサーを作る半導体の試作ラインも立ち上げます。</li>
<li>技術の中核は、QUDORA独自の「近接場量子制御（NFQC）」です。イオンを操るのに大がかりなレーザー照射装置ではなく、チップ上のマイクロ波の場を使うため、通常の半導体製造工程に組み込みやすく、光学系が抱える規模拡大の壁を越えられるとしています。</li>
<li>連合にはブラウンシュヴァイク工科大学、ハノーファー大学、ドイツ物理工学研究所（PTB）、NXPセミコンダクターズ・ドイツ、ユーリッヒ研究センター、AQTドイツが加わります。</li>
<li>この計画は、2030年までに欧州製の最先端の誤り耐性量子コンピュータを少なくとも2台配備するというドイツの「ハイテク・アジェンダ」の節目に位置づけられています。国が大学、研究所、半導体メーカーを束ね、製造基盤から作る形です。</li>
</ul>
<h2>生成AIとセキュリティ：Meta「Muse」Mac版、ゼロデイで乗っ取りの恐れ</h2>
<ul>
<li>Metaは9月8日に個人向けAIエージェント「Muse」を公開し、9月17日にローカルファイルへアクセスできるMac版を出しました。Macでは利用者の許可のもとで、ファイル、メッセージ、メモ、カレンダーにアクセスします。アプリは米App Storeで9月18日から、Google Playで9月19日から首位を保ち、調査会社Sensor Towerによればダウンロードは9月24日時点で340万件です。</li>
<li>Macのセキュリティ研究者パトリック・ウォードル氏は9月21日、Mac版のゼロデイ脆弱性を公表しました。音声入力の文字起こしに使う送信先を変える、文書化されていない開発者向け設定が、他のプログラムからも書き換えられる場所に保存されていました。</li>
<li>特別な権限のない不正プログラムがこの設定を書き換えると、利用者がマイクのボタンを押して話した音声は攻撃者のサーバーへ送られ、認証トークンも奪われます。ウォードル氏は、乗っ取ったMuseでファイルを書き込み、写真を撮り、連携したiPhoneの位置がバルセロナにあることまで取得する実演を示しました。</li>
<li>Meta Superintelligence Labsのデビッド・シングルトン氏は「遠隔からの攻撃ではなく、ローカルでの権限昇格だ」と説明し、9月22日未明に該当設定を製品版から削除する修正を配布しました。公表から約16時間後です。</li>
<li>ウォードル氏は、偽の指示でコマンドを実行させる「ClickFix」型の手口を使えば、攻撃の前提となる端末上での実行は難しくないと反論しています。企業向けには、エージェントが社内サービスのどこへアクセスしたかを管理者が一元的に把握する監査記録や管理画面が用意されていない点も指摘されています。</li>
</ul>
<h2>セキュリティ：暗号資産取引所Bitget、北朝鮮系とみられる攻撃で3億5160万ドル流出</h2>
<ul>
<li>暗号資産取引所Bitgetは、9月24日18時31分（協定世界時）に一部のホットウォレットで不正な送金を検知したと発表しました。ネット接続したホット・ウォームウォレットから、3億5160万ドル相当が盗まれました。</li>
<li>流出したのはイーサリアム、XRP、BNB、AVAX、USDT、USDCで、イーサリアム、XRPレジャー、Arbitrum、Avalanche、Optimism、BSC、Baseの7つのチェーンにまたがります。</li>
<li>攻撃者は、ウォレット基盤を担う重要なバックエンドシステムに侵入し、取引データを偽装して承認手続きを発動させました。署名の仕組みそのものではなく、承認に回す前のデータが改ざんされた形です。</li>
<li>グレイシー・チェンCEOは、手口が北朝鮮のハッカー組織の既知の手口と「非常によく一致する」と述べました。手口は、Bybitからの15億ドルの窃取や、KelpDAOのブリッジからの2億9200万ドルの窃取で指摘されたTraderTraitorと呼ばれる集団のものに似ています。</li>
<li>Bitgetは、コールドウォレットと大半の資産は無事で、利用者の残高表示は正確だとし、出金を一時停止して調査しています。調査にはGoogle傘下のMandiantとSlowMistが加わり、一部のチェーン運営団体は攻撃者のアドレスを凍結しました。</li>
</ul>
<h2>セキュリティ：Roundcube Webmailの認証前SQLインジェクション、悪用を確認</h2>
<ul>
<li>カナダ・サイバーセキュリティセンターは9月、オープンソースのウェブメール「Roundcube Webmail」の脆弱性CVE-2026-48842が実際に悪用されていると警告しました。深刻度はCVSSで8.1です。</li>
<li>問題は「virtuser_query」プラグインにあり、文字列置換処理でバックスラッシュのエスケープをすり抜けられるため、ログインしていない攻撃者がデータベースへSQL文を注入できます。メールアカウントの認証情報や保存されたメールが漏れる恐れがあります。</li>
<li>影響を受けるのは1.6.16より前の1.6系と、1.7.1より前の1.7系です。修正版は5月に公開済みで、対策は修正版への更新です。</li>
<li>Roundcubeは標的になり続けています。7月には中国系とみられる集団がウェブシェルと侵入後ツール「VShell」を送り込み、2月にはCISAが別の2件の脆弱性を悪用確認済みに指定しました。Shadowserver財団によれば、インターネットに公開されたRoundcubeは52万3000台を超えます。</li>
</ul>
<h2>まとめ：機械に任せた判断を、何が裏付けているのか</h2>
<ul>
<li>AkamaiはAnthropicの支出に応じて株を渡し、計算資源の取引に資本の結びつきが加わりました。国防総省は、精度の証拠が弱いと繰り返し指摘されてきたうそ発見器に、AIの判定を重ねようとしています。</li>
<li>エニグマの解読は、打ち間違いまで含む解読文と、未解読電文を管理する専門家の確認という、外から検証できる証拠を伴いました。量子の計画も、論理誤り率0.01％未満という測れる目標を掲げています。</li>
<li>MuseとBitgetでは、エージェントの送信先や取引データという「判断の入力」が書き換えられました。今日の七つの話題を結ぶのは、機械の判断そのものより、その入力と結果を誰が検証できるかです。</li>
</ul>
