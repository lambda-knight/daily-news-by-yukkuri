<h1>スペイン文化・フラメンコ便り（2026年9月26日）</h1>
<h2>オープニング：2026年9月26日 — スペイン文化・フラメンコ便り</h2>
<ul>
<li>今日の軸は「舞台で他者の声を生かす技術」。フェルナンド・トルエバとニーニョ・ホセレ、三位一体の公演、ラファエル・リケーニ、ベレン・マジャ、ドゥケンデ、古謡ポロを結ぶ。</li>
</ul>
<h2>国際情勢（スペイン視点）</h2>
<ul>
<li>セウタでは女性と未成年者60人超が一時受け入れ施設ラ・イピカへ移された。スペインとモロッコの境界は欧州連合の外縁でもあり、地中海の移動を抽象的な「欧州問題」でなく、自治都市の住居、学校、福祉の問題にする。政治・一般ニュースはこの一点に絞る。</li>
</ul>
<h2>スペイン国内ニュース</h2>
<ul>
<li>マドリード市は立ち退き問題で、法的に実行不能として民間案を退けつつ仲介を表明した。日本の行政相談より、地域政党、住民団体、市役所が街頭と交渉卓を往復するスペイン型の政治参加が見える。</li>
</ul>
<h2>文化・芸能ニュース</h2>
<ul>
<li>サン・セバスティアン映画祭でフェルナンド・トルエバは、批評家へ水をかけた若い時代から、ギタリストのニーニョ・ホセレへの敬意までを語った。監督の創作生活に音楽家との長期的な対話が入り込む点が重要である。</li>
<li>マドリードでは女性文化人のリセウ・クラブ創設100年展が続く。721人超が参加した議論の場は、作品だけでなく発表・批評の回路を女性自身が作った歴史を示す。</li>
<li>カルタヘナのバンド、アルデ・ボゴタは大型公演の転売や撮影中心の観客に疑問を呈した。ライブを効率よく販売する商品と見るか、同じ場所で音を共有する行為と見るかという、現代の音楽産業の争点である。</li>
</ul>
<h2>フラメンコニュース</h2>
<ul>
<li>リカルド・フェルナンデス・デル・モラルの『Nuestro Flamenco』は、カンテ、ギター、バイレを別々の見せ場でなく相互応答として提示する。</li>
<li>コルドバ・ギターフェスティバル第45回は、市のギター文化70年を祝う。クラシックとフラメンコが同じ都市の教育、製作、劇場を共有する点に厚みがある。</li>
<li>マルチェーナの第52回ギター祭にはエバ・ジェルバブエナ、ヘスス・メンデス、ダビド・パロマールが並ぶ。舞踊、歌、ギターの三本柱を一夜に戻す編成である。</li>
<li>発祥地アンダルシアの固有性と、マドリードが「国の顔」として流通させる力は同じではない。出演者の出身地と師弟関係まで示すことで、フラメンコを単純な国民記号にしない。</li>
</ul>
<h2>フラメンコギタリスト列伝</h2>
<ul>
<li>今日の主役はラファエル・リケーニ（1962年セビリア、トリアナ生）。少年期にニーニョ・リカルドの録音へ惹かれ、マノロ・サンルーカルの作曲観も吸収した。11歳で学び始め、14歳でコルドバ全国コンクールのラモン・モントーヤ賞を得た早熟の奏者である。</li>
<li>右手は速いピカードを誇示するより、親指で低音の旋律を歌わせ、アルペジオの内声をずらして余韻を作る。左手は開放弦を残した和音、半音進行、広い音域の跳躍によって、トリアナの終止に印象派的な色を重ねる。</li>
<li>伴奏者としてロシオ・フラード、エンリケ・モレンテらと仕事をし、独奏では『Juego de Niños』『Mi Tiempo』から『Parque de María Luisa』へ、街の記憶を組曲へ変えた。技巧を一曲ずつ並べず、アルバム全体を建築する発想が後進へ影響した。</li>
<li>本人公式チャンネルの<a href="https://www.youtube.com/watch?v=mCfOoxoiRDg">『Farruca Bachiana』</a>では、バッハを思わせる対位法とファルーカの四拍子が衝突せず、低音と高音が別の声部として進む箇所を聴きたい。長い休止の後も拍の緊張が切れない。</li>
<li>病気による長い中断後の復帰も含め、彼の歴史的位置は「新しさ」を音数で示さなかった点にある。セビリアの旋律、クラシックの構成、カンテ伴奏の呼吸を、一人の独奏の中で会話させた。</li>
</ul>
<h2>フラメンコバイレ列伝</h2>
<ul>
<li>今日の主役はベレン・マジャ（1966年ニューヨーク生）。両親は踊り手マリオ・マジャとカルメン・モラ。マドリードで学び、カルロス・サウラ監督『フラメンコ』の冒頭で踊った身体は、女性舞踊の衣装と姿勢の固定観念を揺さぶった。</li>
<li>サパテアードを連打で押し切らず、胴体の傾き、肘、手首、視線を別々の時間で動かす。ブラソは装飾ではなく、重心が床から上体へ移る経路を見せる。静止の長さが次の足音を強くする。</li>
<li>デューク大学の紹介ページに埋め込まれた<a href="https://danceprogram.duke.edu/visiting-artist/belen-maya">ベレン・マジャの舞踊映像</a>では、身体を正面へ固定せず、横向きの輪郭と小さな手首の変化から足へエネルギーが落ちる過程を見たい。大学による公演・教育資料である。</li>
<li>家系を継ぎながら、伝統的な「女性らしい」線を再演するだけで終わらない。踊り手が音を飾るのでなく、沈黙、呼吸、床音で合奏の時間そのものを組み替えた。</li>
</ul>
<h2>フラメンコカンテ列伝</h2>
<ul>
<li>今日の主役はドゥケンデ、本名フアン・ラファエル・コルテス・サンティアゴ（1965年バルセロナ県サバデル生）。ヒターノ家庭に育ち、8歳の時にカマロン・デ・ラ・イスラに舞台へ招かれた。後にパコ・デ・ルシアの一座で約18年歌った。</li>
<li>声は乾いた高音と息の混じる弱音を往復する。レトラの語尾をきれいに閉じず、次のギター音へ摩擦を残す。ソレアでは十二拍を強拍だけで示さず、長い母音を九、十拍付近へ運んで終止を遅らせる。</li>
<li>スペイン公共放送の<a href="https://www.rtve.es/play/videos/los-conciertos-de-radio-3-en-la-2/conciertos-radio-3-duquende/16090329/">『Los conciertos de Radio 3 — Duquende』</a>では、第一声の子音の硬さ、弱音へ落ちた後にギターが終止を受け取る瞬間を聴きたい。放送局の特定公演へ直接到達できる。</li>
<li>カタルーニャで生まれ、アンダルシアの歌を継いだ経歴は、フラメンコを地理的な純血で説明できないことも示す。移住家族、都市のペーニャ、巡業が伝統を運んだのである。</li>
</ul>
<h2>フラメンコギター工房だより</h2>
<ul>
<li>今日は既出の個人工房を再掲せず、コルドバ・ギターフェスティバルの製作文化を扱う。演奏会と講習が同じ都市に集まることで、製作家は奏者の「立ち上がりが遅い」「一弦が埋もれる」という言葉を、表板、力木、弦高、ネック角度の調整へ翻訳できる。</li>
<li>フラメンコギターは糸杉の側裏板だけで決まらない。軽い表板、低めの弦高、ゴルペ板、塗装の厚みの組合せが、ラスゲアードの分離とバイレの足に負けない応答を作る。日本の楽器職人と同じく、修理が構造を学ぶ教科書になる。</li>
</ul>
<h2>フラメンコのパロ解説</h2>
<ul>
<li>今日のパロはポロ。カーニャと近縁の古いカンテで、19世紀前半の記述に現れる。歌い手トバロ・デ・ロンダに結びつける説がある一方、成立過程は一人へ還元できない。現在はソレア系の十二拍で歌われる希少な型である。</li>
<li>四行の八音節詩を基本とし、二行目と四行目が韻を踏む型が伝えられる。旋律には「アイ」の長い嘆声が入り、歌詞の意味と母音の響きを切り離さない。重厚だが、シギリージャとはアクセント配置が異なる。</li>
<li>十二拍は三、六、八、十、十二付近の重みを感じ、ギターはフリジア系の終止で歌を支える。カーニャとの違いは旋律の細部にあり、現代の上演数が少ないからこそ、名前より実演を聴く必要がある。</li>
<li>教育映像<a href="https://www.youtube.com/watch?v=WWp5adOsvTQ">『Los compases de flamenco』</a>では、ソレア、カーニャ、ポロが共有する十二拍の骨格と、強拍間の細分を聴きたい。ポロだけを孤立させず「ソレア族」の耳で比べる教材になる。</li>
</ul>
<h2>まとめ</h2>
<ul>
<li>今日の三人に共通したのは、独奏、舞踊、歌のどれでも、相手の声が入る余白を技術として設計したこと。スペイン文化の強さは、個性の大きさだけでなく、異なる身体と土地を舞台で結び直す力にある。</li>
</ul>
