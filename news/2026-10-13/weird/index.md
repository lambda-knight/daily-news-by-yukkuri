<li>地下、腸の中、母の胎内と、ふだん外からは見えない場所ばかり。最後は逆に、だれの目からも隠れようのない車です。隠れた場所と、見せる場所の対比が今日の比較軸です。</li>

<h2>地下15メートルに家族で手掘りしたトンネル網、鉄道とロケット型の入口つきで競売へ</h2>
<ul>
<li>英国イングランド南部、レディング郊外のティルハーストにある敷地が、10月28〜29日のオンライン生中継の競売にかけられます。目安価格は30万〜32万5000ポンド。競売会社はBTGエディソンズです。</li>
<li>地上は作業場とプールですが、目玉は地下です。作業場の下に4層、深さ15メートル超のトンネルと部屋が広がり、地下の床面積は1300平方フィート（約120平方メートル）を超えます。</li>
<li>掘ったのは土木技師のトニー・ディーンさん。飛行場や空港の基盤工事に携わってきた人で、1980〜90年代に掘り始め、20年かけて広げました。のちに6人の子どもたちも加わりました。</li>
<li>道具はバケツと手押し車だけ。掘り出した白亜（チョーク）を運ぶために、トンネル内に手作りの鉄道を敷き、地上へ上げる1トン用の4層式貨物リフトも自作しました。</li>
<li>競売人のリチャード・ウォラルさんによると、トンネルの大半は自立しやすい白亜の層を掘ったもので、必要な場所だけ手で型枠を組んでコンクリートを打ちました。「すべてが手作業で掘られた」と話しています。</li>
<li>隠し扉は2か所。1つは重さ1.5トンのスライド式コンクリート壁の裏、もう1つはプール脇に立つ高さ23フィート（約7メートル）のロケット型の塔の中にあります。</li>
<li>一家の地下工事は1960年代、ロケットの陰に作ったプール用の地下更衣室から始まりました。近所にはほとんど知られていなかったとされます。</li>
<li>敷地には2024年12月、プールの場所に5寝室の2階建て住宅を建てる計画許可が出ています。競売会社は地下の使い道として、安全な倉庫、核シェルター、電磁パルスに強いデータセンター、「備える人の楽園」を挙げました。</li>
<li>ウォラルさんは「競売人を長く続けてきたが、こんなものは見たことがない。家族の趣味としてこれを作ったのは偉業だ」と述べています。ネットでは「レディングに隕石もゾンビもゴジラも来たことはない」という反応もありました。</li>
<li>出典: <a href="https://www.mirror.co.uk/news/weird-news/your-very-bond-villain-lair-37755052">Daily Mirror</a> / <a href="https://britbrief.co.uk/business/property/house-with-hand-dug-tunnels-for-sale-at-300k.html">Brit Brief</a> / <a href="https://www.agi.it/estero/news/2026-10-08/casa-tunnel-tilehurst-reading-39433981/">AGI</a></li>
</ul>
<h2>青いマフィンで腸の速さを測る、英サウサンプトン大学の「青いうんちテスト」</h2>
<ul>
<li>英国のサウサンプトン大学の研究チームが、国内の数千人に「ブルー・プー・テスト」への参加を呼びかけています。BBCが10月12日に伝えました。</li>
<li>方法は、食用の青い色素を混ぜたマフィンを食べ、便が青くなるまでの時間を記録するというものです。食べ物が体を通って出るまでには、平均24〜72時間かかります。</li>
<li>便が青くなったら、5分間のオンラインのゲームで、問題解決の力と、時間の圧力の下での判断力を測ります。終わると、全国の参加者と比べた自分の成績の概要が届きます。</li>
<li>マフィンはサウサンプトン市の中心部で配られたほか、ネットで買える食用の青色色素を使い、ビーガン対応のレシピで自宅でも焼けます。対象は5歳の子どもから100歳近い人まで。</li>
<li>率いるジョナサン・スワン教授（生体分子医学）は、「腸の速さは人によって違い、腸の健康の目安になるが、それが脳にとって何を意味するかはまだよく分かっていない」と話します。</li>
<li>年齢・性別・地域で腸の通過時間がどう変わり、頭の働きとどう関係するかを地図のように描くのが狙いです。教授は「速ければよいわけではなく、ちょうどよい速さがあるはず」とも述べています。遅すぎれば食べ物が何日も体に残り、速すぎれば水分や栄養を吸収する時間が減るためです。</li>
<li>研究は英国研究・イノベーション機構の生物工学・生物科学研究会議が資金を出す「腸・免疫・脳軸ネットワーク」が主導し、結果は来年の公表をめざします。</li>
<li>出典: <a href="https://www.bbc.co.uk/news/articles/cmq8nxjpqx1qo">BBC News</a></li>
</ul>
<h2>胎内をまねたサウナ、新生児の沐浴、母のソファ　六本木の「SAUNA MOTHER」</h2>
<ul>
<li>東京・六本木に、一室限定・完全予約制の個室サウナ「SAUNA MOTHER（サウナマザー）」が10月下旬にグランドオープンする予定です。運営は東京都中央区の株式会社WIQOMEDIAN。10月初旬から中旬に先行体験があり、英語圏の日本情報サイトSoraNews24も10月12日に紹介しました。</li>
<li>コンセプトは「おとなをやめる120分。」。利用は1〜4人で120分、料金は1人8500円、2人1万2000円、3人1万5000円、4人2万円です。六本木7丁目の地下1階にあります。</li>
<li>最初は「子宮サウナ」。赤い照明、胎内を再現した音、母の肌を思わせる香りの中で、85度・湿度40％です。丸窓の外から胎児の姿勢で撮る「胎児フォト」や、写真入りの「再出生証明書」の発行も予定されています。</li>
<li>次は「新生児沐浴水風呂」。水深80センチ、水温15度で、新生児のぼやけた視界をまねたカーテンに囲まれ、壁から現れる巨大な母の手が湯をかける演出があります。続いて左右と上の3方向から湯を浴びる「母の膝シャワー」です。</li>
<li>最後の「マザーソファ」は、赤ちゃんのような背中の丸みで全身を預けられ、揺れの速さを3段階から選べます。プロジェクションで「母」が現れ、イザナミ、アニメの母親をイメージした「二次元マザー」、名画から着想した「芸術マザー」、ガイアやイシスなどの「神話マザー」の4種から選びます。</li>
<li>代表の滝祐夏さんは20年以上サウナに通い、最後の休憩で硬い素材や無理な姿勢のせいで現実に引き戻されることに不満がありました。姿勢と素材を考え抜いて「母に抱かれている状態」にたどり着いたと説明しています。</li>
<li>発表資料は、医療施設ではなく、オキシトシンの分泌などの効果を保証するものではないと明記しています。</li>
<li>出典: <a href="https://prtimes.jp/main/html/rd/p/000000003.000189721.html">PR TIMES（株式会社WIQOMEDIAN）</a> / <a href="https://soranews24.com/2026/10/12/new-tokyo-facility-promises-to-make-you-feel-reborn-time-in-the-womb-and-all-photos/">SoraNews24</a></li>
</ul>
<h2>ハート形の排気口から泡、ピンクのテスラで車好きの世界に入った英国の女性</h2>
<ul>
<li>英国エセックス州ウェスト・マーシーに住むジョー・キングさん（45）が、夫のマットさんと一緒に、鮮やかなピンクのテスラ「モデルY」を改造しました。BBCが10月12日に伝えました。</li>
<li>車体価格は4万5000ポンド。もとはロンドンへの通勤でガソリン代を節約するために買った電気自動車です。</li>
<li>ハート形の排気口から泡が出せ、道路で使える泡模様のナンバープレート、ユニコーンのバルブキャップ、花びら形のホイールカバー、装飾したミラーカバーも付けています。ナンバーは「ユニコーン」とほぼ読める並びです。</li>
<li>外観づくりに費やした時間は100時間以上。本人は「とても大胆で、とても女性的」と表現しています。</li>
<li>夫婦の過ごし方について、「ふつうの夫婦は夜にドラマを一気見するけれど、私たちは車の部品や改造を調べて、業界の新しいものを見ている」と話します。</li>
<li>今は全国の自動車ショーを回っています。男性中心の改造車文化に入れたのは、この思い切ったデザインのおかげだと語りました。</li>
<li>反応は「見逃しようがない」。好きになるのは主に女性と子どもで、スーパーの駐車場で女性から「その色が大好き、自分の車もそうしたい」と声をかけられるそうです。「色が好みでない人もいるけれど、無視はされない。色が会話を始めてくれる」とも話しています。</li>
<li>出典: <a href="https://www.bbc.co.uk/news/articles/ck240738gnljo">BBC News</a></li>
</ul>
