<h2>オープニング：2026年10月13日 — スペイン文化・フラメンコ便り</h2>
<ul>
<li>今日のスペイン語は「ケ・タル（¿Qué tal?）」。親しい相手へ「調子はどう？」と軽く尋ねる表現である。</li>
<li>今日の軸は、若い現役世代が伝統を保存物でなく、映画、劇場、録音、教育へ更新する方法である。</li>
</ul>
<h2>国際情勢（スペイン視点）</h2>
<ul>
<li>国王フェリペ6世夫妻が10月13日、19年ぶりにセウタを訪問した。直前にはモロッコ艦船の領海進入と多数の移民到着が報じられ、訪問は王室行事であると同時に、スペインの主権と地中海の移民政策を可視化する出来事となった。</li>
<li>地中海と北アフリカはスペインにとって遠い外交でなく、自治都市の暮らしへ直結する。歓迎の「エスパーニャ」連呼とモロッコ側の反発を並べると、国境管理と隣国関係を同時に保つ難しさが見える。</li>
</ul>
<h2>スペイン国内ニュース</h2>
<ul>
<li>最高裁は「孫法」で国籍を得た16万3020人の11月29日総選挙での投票権停止を維持した。亡命者の子孫を歴史的記憶へ戻す制度と、選挙人名簿の手続きが衝突している。</li>
<li>日本の在外投票も距離と時間が壁になるが、スペインでは内戦・独裁期の移住史が資格問題へ重なる。家族の記憶が現在の一票へ直結する点が独特である。</li>
</ul>
<h2>文化・芸能ニュース</h2>
<ul>
<li>ハビス監督作『ラ・ボラ・ネグラ』は公開3週目で興収2350万ユーロを超え、スペイン映画歴代8位へ入った。ペネロペ・クルスは同作と新作『ラ・インビタシオン』で賞レースが重なる可能性に、返信を書き直すほど緊張したと語った。</li>
<li>作家イバン・ガスタニャガは『ラ・ヘネアロヒア・デル・アバンドノ』で、養子として実親を20年間探した経験を記した。養子縁組を救済の美談だけにせず、喪失とアイデンティティーの側から語り直す。
-レイナ・ソフィア美術館ではパンク歌手アナ・クーラが「ビシオス・モデルノス」を開幕した。地下文化の異議申し立てを国立館が扱うとき、記念品へ無害化せず音量と摩擦を残せるかが焦点になる。</li>
</ul>
<h2>フラメンコニュース</h2>
<ul>
<li>パンプローナ市とフラメンコ・オン・ファイアは、エル・ペレのバルコニー公演、二つの演奏会、未成年向けギター・舞踊講座を組み合わせた。鑑賞者を次の担い手へつなぐ設計である。</li>
<li>マラガ県アロサイナのアルメナ・フラメンカはカンテ、ギター、バイレを一夜へ集める。三部門を分けず、歌の呼吸、足のジャマーダ、ギターのレマーテが応答する共同芸術として提示する。</li>
<li>第65回カンテ・デ・ラス・ミナス国際祭は最終候補を発表した。鉱山地帯の歌を競技、賞金、職業機会へつなぎ、地域の記憶を現役演者の仕事として維持する。</li>
<li>フラメンコをマドリードや国外が「スペインの顔」として広めても、言葉、教授法、コンパスはアンダルシア各地で育つ。発信の中心と文化の所有者を同一視しないことが大切である。</li>
</ul>
<h2>フラメンコギタリスト列伝</h2>
<ul>
<li>今日の主役はジェライ・コルテス。1995年アリカンテ生まれで、ギター奏者の父ミゲルから幼少期に学んだヒターノの音楽家である。家族の集まりで歌と踊りを支えた経験が、独奏でも拍を孤立させない耳を育てた。</li>
<li>2019年、アントニア・ヒメネスらと舞台『フラメンコ・デ・ラ・ルート』に出演し、マドリードのタブラオや劇場へ活動を広げた。転機はラッパーC・タンガナのアルバム『エル・マドリレーニョ』とツアーへの参加で、短いラスゲアードや低音の応答をポップスの間へ差し込んだことである。</li>
<li>2024年にはアントン・アルバレス監督の映画『ラ・ギターラ・フラメンカ・デ・ジェライ・コルテス』がサン・セバスティアン映画祭で特別審査員賞を得た。技巧の成功譚だけでなく、父との距離、家族、創作の痛みを録音過程と一緒に映した。</li>
<li>2025年の初アルバム『ギターラ・コラル』では独奏を孤立した名人芸にせず、複数の声とパルマを集める「合唱的なギター」を掲げた。題名通り、ギターが歌い手を支えるだけでなく、多数の声の一員になる発想である。</li>
<li>公式映像の<a href="https://www.youtube.com/watch?v=ySZagd2n9Xo">『Sonar por Bulerías』</a>では、冒頭の親指が低音を長く残した後、細い和音を裏拍へ置く箇所を聴きたい。パルマが加わると右手を大きく振らず、短いラスゲアードで空白を縁取る。</li>
<li>もう一つの入口は映画<a href="https://www.youtube.com/watch?v=JAhClAr5rlI">『La guitarra flamenca de Yerai Cortés』</a>。演奏前後の沈黙と家族の会話を見ると、彼の音が速弾きの展示でなく、言葉にしにくい関係を受け渡す手段だと分かる。</li>
<li>右手は親指のアポヤンドを骨格にし、ラスゲアードを連続させず必要な場所だけへ置く。左手は開放弦を残した不協和を使い、伝統的なフリジアの重力を保ちながら音を濁らせる。</li>
<li>ダニ・デ・モロンが伴奏の空白を精密に設計する中堅だとすれば、コルテスは家族の声や都市のポップスまで同じ輪へ招く。パコ・デ・ルシア型の長い超絶技巧とは別に、短い動機を反復して周囲の声を立てる。</li>
<li>カンテには句末まで待って低音を返し、バイレには足の着地を和音で二重化する。自分のファルセータへ全員を従わせず、相手が発した合図を即座に曲の構造へ編み直す点が伴奏者としての強みである。</li>
<li>20代で映画と初作を結びつけた現在進行形の奏者であり、録音と生活史を切り離さない。最初は『ギターラ・コラル』のブレリアから入り、低音、パルマ、声が順に増える場所を追うと個性をつかみやすい。</li>
</ul>
<h2>フラメンコバイレ列伝</h2>
<ul>
<li>今日の主役はサラ・ヒメネス。1992年グラナダ生まれで、グラナダの舞踊学校とアンダルシア舞踊センターで学び、フラメンコとスペイン舞踊を身体の基礎にした現役の踊り手・振付家である。</li>
<li>若くしてアンダルシア・フラメンコ・バレエに入り、群舞の線、舞台上の距離、足音を他者と合わせる訓練を積んだ。その後マルコス・モラウ率いるラ・ベロナルへ参加し、現代舞踊の反復と歪んだ姿勢を吸収した。</li>
<li>2016年ごろから自身の短編を発表し、ソロ作品『アベ・デ・プラタ』では鳥の軽さと金属的な足音を対置した。2022年の『バリアシオン・ア・ティエンポ』では、時計のような均等拍と、身体がためらう時間のずれを主題にした。</li>
<li>公式舞台映像の<a href="https://www.youtube.com/watch?v=X6tmIGhoakM">『Ave de Plata』</a>では、腕を翼のように大きく見せた直後、重心を低く落として細かいサパテアードへ移る転換を見る。軽さを装飾で終えず、床の抵抗と組にする振付である。</li>
<li><a href="https://www.youtube.com/watch?v=3t8nY2FKjvc">『Variación a tempo』</a>では、同じ足型を少しずつ遅らせ、音楽とのずれを緊張へ変える箇所が見どころだ。ジャマーダを大きな合図だけにせず、肩、視線、呼吸へ分散する。</li>
<li>サパテアードは音量で押し切らず、踵とつま先の音色を分ける。ブラソは円を完成させる前に角度を変え、古典的な美しい線へ小さな断絶を入れる。この断絶が観客の目を次の動きへ誘う。</li>
<li>パトリシア・ゲレーロが宗教性や制度の圧力を劇場的な構図へ置くのに対し、ヒメネスは時間の微細なずれを身体で測る。ロシオ・モリーナほど即興を爆発させず、反復の内部を少しずつ変える。</li>
<li>群舞経験があるため、共演者を背景へ退けない。ギターのファルセータ中は足を止め、背中や手首で拍を保ち、カンテのレトラでは母音の伸びへブラソの速度を合わせる。</li>
<li>近年も劇場、フェスティバル、共同制作で活動を続け、フラメンコの語彙を現代舞踊へ溶かして名札を消すのでなく、足裏のコンパスで出自を残す。入口には『アベ・デ・プラタ』が適している。</li>
</ul>
<h2>フラメンコカンテ列伝</h2>
<ul>
<li>今日の主役はアンヘレス・トレダノ。1995年ハエン県ビジャヌエバ・デ・ラ・レイナ生まれで、幼いころ祖父母と地元の歌からフラメンコを覚え、ペーニャとコンクールで古いレトラを身につけた。</li>
<li>2013年、18歳でラ・ウニオンの青年部門賞を受け、その後マドリードで歌唱を学んだ。タブラオでは踊り手の呼吸に合わせる実務を重ね、劇場ではロシオ・モリーナらの作品に参加して声を舞台構成の一部へ変えた。</li>
<li>2024年の初アルバム『サングレ・スシア』が大きな転機となった。伝統的なカンテの旋律を電子音、歪んだ低音、身近な女性たちの記憶と結び、血統を純粋さでなく混じり合う経験として捉え直した。</li>
<li>公式映像の<a href="https://www.youtube.com/watch?v=ySZagd2n9Xo">『Sangre sucia』</a>では、低い地声から語尾だけを細く震わせ、電子音が膨らんでも子音を前へ出す箇所を聴きたい。音響が厚くてもレトラの言葉が埋もれない。</li>
<li><a href="https://www.youtube.com/watch?v=X6tmIGhoakM">『Cuando se enreda』</a>では、短い句を一息で押さず、途中に息の割れを残す。整った美声へ磨き上げず、身体の負荷を声のざらつきとして提示する。</li>
<li>声質は中低域に芯があり、高音では音量より金属的な輪郭を選ぶ。メリスマを長く飾るより、同じ音を押し直して言葉を強調し、シギリージャやソレアの重さを現代的な近接音へ変える。</li>
<li>ロシオ・マルケスが音響実験を細密な発声で組み立てるのに対し、トレダノは息、摩擦、話し声に近い子音を残す。エストレージャ・モレンテの明るい旋律線とも異なり、句の切れ目を傷のように聞かせる。</li>
<li>ギター伴奏には和音を埋めず声の後を追う余白を求め、踊りには足の強拍と反対側へ声を滑り込ませる。共演は伴奏を従属させず、声、身体、電子音の摩擦を残す場になる。</li>
<li>古典の型を捨てて新しく見せるのでなく、ペーニャで得た旋律を現在の女性の生活語へつなぐ。今から聴くなら『サングレ・スシア』の表題曲から入り、子音、息、低音の衝突を追いたい。</li>
</ul>
<h2>フラメンコギター工房だより</h2>
<ul>
<li>今日の国外編は静岡県浜松市のヤマハ。フラメンコ用CG182SFは単板スプルース表板、シープレス側・裏板、ゴルペ板を採用し、クラシック用より低い弦高と素早い立ち上がりを狙う。</li>
<li><a href="https://jp.yamaha.com/products/musical_instruments/guitars_basses/cl_guitars/cg_cgx/index.html">CG182SF製品ページ</a>で仕様を標準化する量産メーカーの役割は、個人工房の一点調整とは違う。同じ寸法を各地の学習者や巡演者が入手しやすい。</li>
<li>シープレスの軽い胴、スプルースの反応、透明なゴルペ板は、パルマや足音の間へ短い音を通すための組合せである。日本の製造管理とアンダルシアの演奏要求が、仕様表の中で出会う。</li>
</ul>
<h2>フラメンコのパロ解説</h2>
<ul>
<li>今日のパロはガロティン。20世紀初頭に普及した明るい4拍子系で、アストゥリアスやカタルーニャの歌との関係、旅芸人を通じた形成など複数説がある。フラメンコ化にはファウスティーノ・ブレターニョや踊り手ファイコの名が結びつくが、単独の作者へ固定はできない。</li>
<li>コンパスは「1、2、3、4」と数え、基本の強さは1と3。パルマは「1・2・3・4」を均等に保ち、ギターは2と4の後ろへ短い切れを置く。タンゴと同じ4拍系でも、ガロティンは軽快で舞台的な跳ねを強くする。</li>
<li>調性は明るいCメジャー系がよく使われ、典型的にはC→G7→C、途中でF→C→G7→Cと動く。台本ではシー、ジーセブン、エフと読む。歌い手に合わせてカポを使い、開放弦の明るさを保つ。</li>
<li>レトラは四行を基本に、恋、冗談、機知を扱い、「ガロティン、ガロタン」の反復句が付く。意味内容の深刻さより、反復句を観客と共有し、踊りの帽子や身振りへ合図を渡す働きが大きい。</li>
<li>カンテは反復句の歯切れ、ギターは長調の短いラスゲアード、バイレは腰と帽子の遊び、明確なジャマーダが聴きどころ。舞台ではサリーダ、レトラ、ファルセータ、エスコビージャ、レトラ再現、ブレリア締めの順に展開できる。</li>
<li>公式映像の<a href="https://www.youtube.com/watch?v=JAhClAr5rlI">『Garrotín』</a>では、反復句の直後に踊り手が帽子の角度を変え、ギターが短く閉じる箇所へ注目したい。歌、視線、レマーテが一つの冗談を作る。</li>
<li>別解釈の<a href="https://www.youtube.com/watch?v=3t8nY2FKjvc">『Garrotín de baile』</a>では、エスコビージャを強くして現代の劇場作品へ寄せる。古い録音の素朴な反復に対し、足の細分化が前景化する。</li>
<li>タンゴとの聴き分けは、ガロティン特有の反復句、長調の明るさ、帽子を用いる舞踊語彙で行う。タンゴはヒターノ的な重い裏拍と骨盤の動きを前へ出すことが多い。</li>
</ul>
<h2>まとめ</h2>
<ul>
<li>若い現役世代は、家族から得た拍、声、身振りをそのまま保存せず、映画、電子音、現代舞踊へ通し直している。伝統は変化を拒む箱でなく、誰と演奏するかで形を変える関係である。</li>
<li>別れは「クイダテ（Cuídate）」。「体を大切に」「元気でね」と相手を気遣って別れる日常表現である。</li>
</ul>
