<h1>スペイン文化・フラメンコ便り（2026年9月25日）</h1>
<h2>オープニング：2026年9月25日 — スペイン文化・フラメンコ便り</h2>
<ul>
<li>今日の軸は、劇場を「見る場所」から「記憶を引き継ぐ場所」へ変える人々。リセウ女性クラブの100年、ロス・ハビスのロルカ映画、そしてヘレスのギター、踊り、歌を結ぶ。</li>
</ul>
<h2>国際情勢（スペイン視点）</h2>
<ul>
<li>スペインが直接関わる話として、欧州委員会がスペイン、フランス、イタリアへのロシアのハイブリッド攻撃の脅威を認識していると述べた。エル・ムンドはロシア船から航続約600キロのゲルベラ無人機を発射する可能性を報じた。未発生の攻撃を既成事実にはできないが、地中海沿岸の港湾・通信・空域を一つの防衛圏として扱う問題である。</li>
<li>日本が島国として海空の接近を意識するのと似て、スペインも大西洋、地中海、北アフリカへ同時に開く。ただし欧州連合と北大西洋条約機構の共同防衛が国内対策と直結する点が異なる。</li>
</ul>
<h2>スペイン国内ニュース</h2>
<ul>
<li>住宅からの立ち退きを抑える政令をめぐり、カタルーニャ独立派ジュンツがサンチェス政権との交渉へ戻った。焦点は抽象的な連立維持ではなく、1956年以来同じ家に住むマリカルメンのような入居者を制度がどう守るかである。中央政府が地域政党の票を必要とする構図は、地方の交渉力が暮らしの政策へ直接及ぶスペインらしさを示す。</li>
</ul>
<h2>文化・芸能ニュース</h2>
<ul>
<li>マドリードではリセウ女性クラブ創設100年の展覧会が始まった。同クラブは法律家、作家、画家ら721人超が集う議論の場へ成長した。女性が作品だけでなく、作品を発表し批評する制度を自ら作った歴史であり、日本の女性文化人団体史と比べても「部屋を持つ」ことの政治性が際立つ。</li>
<li>監督・俳優のハビエル・アンブロッシとハビエル・カルボ、通称ロス・ハビスは映画『ラ・ボラ・ネグラ』でフェデリコ・ガルシア・ロルカの生と死を三幕劇へ組み替えた。ロルカを銅像にせず、同性愛嫌悪と現在形で衝突させる作品である。</li>
<li>トレド出身で40年間教師を務めたアントニオ・ルビオが、2026年国民児童・青少年文学賞と賞金3万ユーロを受賞した。教室で子どもの声を聞いてきた経験が、簡潔な言葉と朗読のリズムへつながった点が評価された。</li>
<li>カルタヘナのロックバンド、アルデ・ボゴタは、転売と撮影目的の観客で熱量が薄まる大型公演に対し、窓口販売を含む観客との距離の近さを提案した。音楽を商品として効率配分するか、同じ場所で身体を共有する行為として守るかが争点である。</li>
</ul>
<h2>フラメンコニュース</h2>
<ul>
<li>マドリードのコンデドゥケには三部作形式のフラメンコ公演が登場する。複数夜を通じて作品を育てる企画は、短い見せ場の連続とは異なり、カンテ、ギター、バイレの関係が変わる過程そのものを見せる。</li>
<li>パンプローナの第13回フラメンコ・オン・ファイアは、エル・ペレの市庁舎バルコニー公演、コンデスタブレ宮の二公演、未成年向けギター・舞踊講座を組み合わせた。完成品の鑑賞と次世代教育を同じ祭典へ置いた点が重要である。</li>
<li>アルチドナの「ラ・ポラ・フラメンカ」はカンテ、バイレ、ギターの三本柱を一晩に戻す。別々のスター公演ではなく、歌の長さへギターが追随し、踊りがジャマーダで転換を知らせる共同作業が主役になる。</li>
<li>フラメンコはアンダルシアの都市と共同体から育った。一方、マドリードの劇場は全国文化として編集し、カタルーニャでは「スペイン全体の顔」へ一括されることへの距離もある。発祥地と流通拠点の双方を示すことが、単純な国民文化化を避ける鍵になる。</li>
</ul>
<h2>フラメンコギタリスト列伝</h2>
<ul>
<li>今日の主役はディエゴ・デル・モラオ（1978年ヘレス・デ・ラ・フロンテーラ生）。父はモライート・チコ、祖父はモラオ家のギタリスト、マヌエル・モレノ。サンティアゴ地区の歌と祝宴を身体で覚え、ディエゴ・カラスコ、ホセ・メルセ、ニーニャ・パストーリらの伴奏を経て独自の音を築いた。</li>
<li>右手の特徴は、低音を打つ親指と高音弦のアルペジオを同時に鳴らしても輪郭を潰さないこと。ピカードを一直線に速く走らせるより、短い休止とゴルペを挟み、ヘレスのブレリアで重心が後ろへ残る感覚を作る。左手では開放弦を残した和音、半音の経過音、低いポジションから急に高音へ跳ぶ配置を使い、伝統的な終止へ現代的な濁りを加える。</li>
<li>伴奏では、歌い手のレトラが予定より伸びても和音を先回りさせず、同じコンパスを別の内声で保つ。踊り手の足が密になると音数を競わず、低音と短いラスゲアードで床の打点を囲む。この「空ける技術」が、技巧派なのに歌と踊りを小さくしない理由である。</li>
<li>カナル・アンダルシア・フラメンコの公式映像<a href="https://www.youtube.com/watch?v=fbx6f3DL3eg">『Guitarra. Diego del Morao. 2016』</a>では、冒頭の低音と高音の分離、短い沈黙の後にファルセータが再開する瞬間を聴きたい。パルマと打楽器が加わっても、ギターが拍を埋め尽くさず後ろ側の重心を残す。</li>
<li>父モライートの乾いたヘレスの語彙を継ぎながら、同じファルセータを保存標本にしなかった点が歴史的位置になる。家系を守るとは同じ音をコピーすることではなく、カンテが呼吸できる配置を次代の和声で作り直すことだ。</li>
</ul>
<h2>フラメンコバイレ列伝</h2>
<ul>
<li>今日の主役はメルセデス・ルイス（1980年ヘレス生）。6歳でマヌエル・モラオの舞台へ立ち、エバ・ジェルバブエナ舞踊団などを経て2002年に自らの舞踊団を設立した。ヘレスの足技を核にしながら、作品ごとにギターとの一対一の関係を組み直す踊り手である。</li>
<li>サパテアードは速さだけでなく、踵、足裏、つま先の音色を分ける。ブラソは足と同時に大きく飾らず、上体の静止を保った後で腕の線を開くため、観客は一打ごとの方向を追える。ジャマーダでは視線と肩の角度まで合図になり、ギタリストが次のレマーテへ入る余白を渡す。</li>
<li>メルセデス・ルイス舞踊団の公式プロモーション映像<a href="https://www.youtube.com/watch?v=8-ATOt6BjO0">『Déjame que te baile』</a>では、足がギターへ重なる瞬間だけでなく、彼女が静止してギターの余韻を聞き終えてから動き出す箇所が見どころである。</li>
<li>日本の舞踊で間が振付の一部になるのと同様、ルイスも音のない時間を空白にしない。ただし床を打つ音そのものが合奏の一声部になるため、踊り手は視覚的な主役であると同時に打楽器奏者でもある。</li>
</ul>
<h2>フラメンコカンテ列伝</h2>
<ul>
<li>今日の主役はエル・ペレ、本名マヌエル・モレノ・マヤ（1954年コルドバ生）。15歳でカジェタノ・ムリエル賞を受け、1983年のコルドバ全国フラメンコ芸術大会ではソレアとブレリアの部門賞を得た。ビセンテ・アミーゴとの共演でも知られ、伝統的な節を固定せず、その場のギターへ言葉を押し返す歌い手である。</li>
<li>声にはざらついた金属音と、息がほどける弱音が同居する。ソレアでは語頭を硬く置き、母音を長く伸ばした後、語尾を整え過ぎず落とす。ブレリアでは短い句を拍の表面へ置かず、パルマの隙間へ遅れて差し込むため、同じテンポでも浮遊感が生まれる。</li>
<li>カナル・アンダルシア・フラメンコの公式映像<a href="https://www.youtube.com/watch?v=LVgXHfvQc9s">『Malagueña. El Pele. 1997』</a>では、自由リズムの長い第一声と、フアン・カルロス・ロメロのギターが歌の終止を待つ場面を聴きたい。高音の強さより、息を細くして言葉の痛みを残す箇所に個性が出る。</li>
<li>エル・ペレの価値は、古い型を崩すこと自体ではない。コルドバの節回しを知った上で、レトラの言葉と当日の伴奏者に合わせて長さを変える。その選択が、録音の再現ではない生きたカンテを次世代へ示している。</li>
</ul>
<h2>フラメンコギター工房だより</h2>
<ul>
<li>全履歴で扱った個人工房との重複を避け、今日はセビリア県ヘルベスにあるアンダルシア公共職業訓練の弦楽器製作教育を扱う。個別ブランドの宣伝ではなく、表板の選別、力木の配置、ネック角度、フレット調整、塗装、修復を一つの職業技能として継承する仕組みである。</li>
<li>フラメンコギターは一般に軽い応答と鋭い立ち上がりが求められ、糸杉の側裏板が多用される。しかし木材名だけで音は決まらない。表板と力木の厚み、弦高、ゴルペ板、ネック角度の組み合わせが、ラスゲアードの分離と踊りの足に負けない音量を左右する。</li>
<li>日本の職業訓練と共通するのは、完成品だけでなく修理によって構造を学ぶ点である。割れ、浮いた力木、摩耗したフレットを診断できれば、演奏家が「音が遅い」「一弦が埋もれる」と語る感覚を具体的な調整へ翻訳できる。工房教育は、木工と舞台語彙の通訳を育てる仕事でもある。</li>
</ul>
<h2>フラメンコのパロ解説</h2>
<ul>
<li>今日のパロはシビジャーナス。セビリアと周辺の祭礼・春祭りで踊られる四部構成の歌と踊りで、カスティーリャのセギディーリャがアンダルシアで変化した系譜と説明される。現在の定型は20世紀に録音と祭りを通じて広まったが、起源を一人の作者へ帰すことはできない。</li>
<li>一曲は通常四つのコプラからなり、各コプラで導入、歌、間奏、締めが反復される。二人一組は接近と離反、すれ違い、最後の向かい合いを繰り返す。社交性が強く、深い悲嘆を掘るカンテ・ホンドというより、共同体が同じ型を共有する祝祭の踊りである。</li>
<li>コンパスは三拍子、または六拍を一単位として感じ、アクセントは「一、二、三」の一に戻る。パルマと足は細かく埋めず、旋回の着地を支える。ギターはラスゲアードで周期を明示し、歌の間に短いファルセータを置く。</li>
<li>和声は長調を中心に、例としてA、D、Eの主要和音を往復する型が使える。台本ではエー、ディー、イーと読む。フリジア終止の暗さを主役にするパロとは違い、明るい終止と反復が、初参加の踊り手にも次の動きを予測させる。</li>
<li>実演教材<a href="https://www.youtube.com/watch?v=KGxuvqcVnEU">『Sevillanas — Ritmo &amp; Compás』</a>では、ギターと歌が三拍の一へ戻る箇所、ラスゲアードと手拍子が踊りの旋回を支える箇所に注目したい。速さより、四つのコプラで同じ骨格がどう反復されるかを数えると構造が聞こえる。</li>
</ul>

</ul>
