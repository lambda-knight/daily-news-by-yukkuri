<h1>世界の珍ニュース（2026年9月25日）</h1>
<h2>オープニング：2026年9月25日 — 世界の珍ニュース</h2>
<p>78歳で1日最長6時間ゲーム配信を続けるスコットランドの祖母、朝の駅前通りを歩いて「ダチョウがいる」と通報されたエミュー、便利さを抜き取った品だけを並べるシアトルの元コンビニ、そして標高3454メートルの雪上で蹴られたフィールドゴール。今回は、年齢、住宅街、コンビニ、アルプスという「そこにあるはずのないもの」が現れた四題をたどる。</p>
<h2>78歳の「フォートナイト」配信者、ギネス世界記録に</h2>
<ul>
<li>スコットランド北東部アバディーンに住むキャス・ボウイさん（9月1日に78歳）が、ツイッチで最高齢の女性「フォートナイト」配信者としてギネス世界記録に認定された。2026年9月刊行の『ギネス世界記録 ゲーマーズ・エディション2027』に掲載され、9月24日にギネス側が発表した。</li>
<li>きっかけは2017年、孫がフォートナイトを遊ぶ姿を見て興味を持ったこと。2018年に自分のアカウントを作って配信を始め、9年近く続けている。配信は長い日で1日6時間に及び、ツイッチのフォロワーは2万4000人を超える。</li>
<li>配信名の「グランピー・グラン（不機嫌なおばあちゃん）」は孫娘の提案で、本人は「みんな私が不機嫌じゃないのを知っている」と冗談にしている。孫息子は当初「フォロワーなんて集まらない」と疑っていたという。</li>
<li>勝利数より、試合ごとに自分で決めた目標を達成することを楽しみにしている。ツイッチの自己紹介は「おしゃべりで親しみやすく、決して感じ悪くならない、正真正銘の下手くそ（ボット）」。本人は「年齢を理由にやめたことはない。私にできるなら、あなたにもできる」と語る。</li>
<li>出典: <a href="https://www.guinnessworldrecords.com/news/2026/9/scottish-gamer-gran-celebrates-turning-78-with-her-fortnite-streaming-world-record">Guinness World Records</a>、<a href="https://abcnews.com/Technology/scottish-grandmother-sets-oldest-female-fortnite-streamer-record/story?id=136715423">ABC News</a>、<a href="https://www.upi.com/Odd_News/2026/09/24/scotland-Guinness-World-Records-oldest-Fortnite-streamer/9581790273068/">UPI</a></li>
</ul>
<h2>「ダチョウが歩いている」と110番、滋賀・守山の駅前にエミュー</h2>
<ul>
<li>9月23日午前6時40分ごろ、滋賀県守山市吉身1丁目の駅前グリーンロードで「ダチョウが歩いている」と複数の通行人から110番通報があった。正体はダチョウではなくエミューだった。</li>
<li>守山署などが捜索し、約2時間後に近くの集合住宅の敷地で見つかり、飼育していた施設の職員が捕獲した。けが人はいなかった。</li>
<li>エミューは昨年ふ化した体長約1.8メートルの若い個体。甲賀市の「ジャクソンズ」が守山市岡町で運営する私設動物園で、玄関付近に放し飼いにされていた。施錠できる鉄製の押し扉をゴムロープで引っ張り、エミューが開けられないようにしていたという。</li>
<li>この施設では2010年にカンガルー、2013年にヤマアラシも脱走している。施設は今後もエミューの飼育を続け、安全対策を見直すとしている。この出来事はアメリカのUPIの珍ニュース欄でも報じられた。</li>
<li>出典: <a href="https://www.kyoto-np.co.jp/articles/-/1795596">京都新聞</a>、<a href="https://www.upi.com/Odd_News/2026/09/24/japan-escaped-emu-zoo-Moriyama/2161790267116/">UPI</a></li>
</ul>
<h2>最初から絡まったUSBケーブルを売る、シアトルの「インコンビニエンス・ストア」</h2>
<ul>
<li>シアトル中心部3番街1524番地の元セブンイレブンが、「インコンビニエンス・ストア（不便な店）」という美術展になった。8月28日にプレ開店し、9月19日に街の美術イベントに合わせて正式開幕。土日の正午〜午後4時に無料で公開し、2027年半ばまで続く。</li>
<li>主に地元の70人以上の作家が、コンビニの商品を「抽象化して解釈した」作品を、食品、健康・美容、事務用品など14の売り場に並べる。最初から絡まったUSBケーブル、チートスやレイズの袋で作ったショルダーバッグ、ものさしを兼ねるろうそく、蜜ろうの卵形キャンドル、スナック菓子そっくりのキーホルダー、受話器を取るとU2の曲が流れる「固定電話型iPhone」などがある。</li>
<li>作品はすべて購入でき、価格は1ドルから1万ドルまで。布で作ったキーホルダー（20ドル）や食パン形のクッション、石や貝殻を埋め込んだライターケース（約65ドル）など、実用品の形をした手仕事が並ぶ。</li>
<li>企画はリリア・ディアリングさんとメアリー・アン・カーターさん。2024年にはイケアのパロディー展を開き、3か月で1万人以上が来場、813世帯に5万ドル超の作品を販売した。主催者は「芸術は本質的に不便だ。効率と大量生産が報われる社会で、作家はわざわざ手間のかかる方法を選ぶ」と説明し、ディアリングさんは「作品を買うことを身近にしたい。作家が作り続けるには売れることが大切」と話す。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/09/22/Inconvenience-store-seattle-art-exhibit/1271790098025/">UPI</a>、<a href="https://hoodline.com/2026/09/old-third-avenue-7-eleven-reopens-as-a-10-000-fake-convenience-store/">Hoodline</a></li>
</ul>
<h2>標高3454メートルの雪上フィールドゴール、NFLの名キッカーが世界記録</h2>
<ul>
<li>アメリカンフットボールの元キッカーで殿堂入りのアダム・ビナティエリ氏が9月22日、スイス・アルプスのユングフラウヨッホ（標高3454メートル）で33ヤードのフィールドゴールを決め、「最も標高の高い場所で決めたフィールドゴール」としてギネス世界記録に認定された。</li>
<li>雪に覆われた地面に、ニューイングランド・ペイトリオッツとユングフラウ鉄道がゴールポストを設置した。11月15日にミュンヘンのアリアンツ・アレーナで行われるペイトリオッツ対デトロイト・ライオンズ戦の宣伝企画で、同氏はペイトリオッツのジャージーで蹴った。</li>
<li>ビナティエリ氏はスーパーボウル優勝4回、通算2600点超。ペイトリオッツで10季、コルツで14季プレーした。公式に記録されたキックは、2019年12月1日にコルツで決めたフィールドゴール以来となった。</li>
<li>本人は「息をするたびに標高を感じる。心拍もリズムも違う」「雪はペイトリオッツ時代の一部だったが、3454メートルで蹴るのはまったく別物」と語った。2001年のプレーオフ、降雪の中で決めた45ヤードの同点キックで知られる「雪のキッカー」が、今度は空気の薄さと戦った。</li>
<li>出典: <a href="https://www.patriots.com/news/the-highest-field-goal-in-the-world-patriots-legend-adam-vinatieri-sets-a-guinness-world-recordstm-title-at-3-454-meters-on-the-jungfraujoch-top-of-europe">New England Patriots</a>、<a href="https://www.nfl.com/news/hall-of-famer-adam-vinatieri-kicks-world-record-field-goal-in-swiss-alps">NFL.com</a>、<a href="https://www.upi.com/Odd_News/2026/09/23/switzerland-Guinness-World-Records-Adam-Vinatieri-fild-goal/9571790186297/">UPI</a></li>
</ul>
<h2>まとめ</h2>
<ul>
<li>四題に共通するのは、「ここにはいないはず」のものが現れた驚きだ。若者の遊び場に78歳、駅前通りにエミュー、コンビニに役に立たない品、雪山にゴールポスト。</li>
<li>ボウイさんは勝敗より自分の目標で9年続け、シアトルの作家たちは便利さを外すことで作品を売れる形にした。場違いさは、続ける工夫や売る工夫と結びついていた。</li>
<li>一方でエミューの一件は、押し扉とゴムロープという備えがあっても、放し飼いの若い1羽が住宅街の朝を2時間騒がせた例でもある。</li>
</ul>
