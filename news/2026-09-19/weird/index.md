<h1>世界の珍ニュース（2026年9月19日）</h1>
<h2>オープニング：2026年9月19日 — 世界の珍ニュース</h2>
<p>深センで「掻いてもらう」ことを商売にした32歳、母に音量を絞れと言われた12歳が偶然生み出したDJ技術、100年前のオランダの街頭オルガンが歌うシェールの名曲、そしてデータセンターの騒音を再現する99ドルのぬいぐるみ。今回は「思いがけない発明・発見」が生んだ四題を追う。</p>
<h2>深センの「抓痒師」、1時間300元でリラックスを売る</h2>
<ul>
<li>中国・深セン在住の張小橋（チャン・シャオチアオ）さん（32歳）は、大学卒業後に1年で7回転職し、2回の起業にも失敗した末、「抓痒（そうよう＝爪で背中などを掻く）」を仕事にすることを思いついた。妻が「夫の背中を爪で掻く」動画をSNSで見て、コメント欄に「お金を払ってでも受けたい」という声が多かったことがきっかけだった。</li>
<li>開業前に4か月以上かけて技法を研究し、友人相手に繰り返し試技を重ねたうえ、価格帯や掻いてほしい部位についてのアンケートを1000枚集めて需要を調べた。</li>
<li>現在は深セン市宝安区で2店舗を運営し、料金は60分300元（約6,000円）が基本、80分299元の「安眠パッケージ」が最も人気で、抓痒サービスだけで売上の7割超を占める。2店舗合計の月商は10万元（約210万円）を超える。</li>
<li>「都市部で暮らす人はストレスが強く、この種のサービスへの需要は大きい」「マッサージより癒されると言ってくれる常連客も多い」と語り、「深セン挠痒治癒品牌管理」という会社を登記し、全国100店舗への展開と「抓痒師」を社会に認められた職業にすることを目標に掲げている。</li>
<li>出典: <a href="https://www.odditycentral.com/news/entrepreneur-opens-unique-salons-where-customers-relax-by-being-gently-scratched.html">Oddity Central</a>、<a href="https://news.qq.com/rain/a/20260827V0B6GU00">騰訊新聞</a>、<a href="https://www.sznews.com/news/content/mb/2026-08/27/content_32157240.htm">深圳新聞網</a></li>
</ul>
<h2>母に怒られてレコードを揺らしたら、スクラッチが生まれた</h2>
<ul>
<li>1975年、米ニューヨーク州ブロンクスの自宅でDJの練習をしていた当時12歳のセオドア・リビングストン少年（後のグランド・ウィザード・セオドア）は、母親に「音量を下げなさい」と注意された。</li>
<li>とっさにレコードを針の下で前後に手で揺らして音を止めた結果、擦れるような独特の音が偶然生まれた。</li>
<li>録音を聞き返した本人が「この音を自分の技法に組み込める」と気づき、単なる操作ミスではなく意図的な音楽技法として確立させた。それまでもDJがレコードに触れる行為自体はあったが、これを楽曲を構成する要素として使い始めたのが彼が最初とされる。</li>
<li>この偶然の発見が、現在ヒップホップDJの象徴的技法として世界中に広まった「スクラッチング」の起源になった。</li>
<li>出典: <a href="https://laughingsquid.com/grand-wizzard-theodore-record-scratching/">Laughing Squid</a></li>
</ul>
<h2>100年前のオランダ街頭オルガンが、シェールの名曲を奏でる</h2>
<ul>
<li>英コーンウォールを拠点に20年以上、機械式音楽の楽器を各地で披露してきたジェームズ・ダンドン氏（愛称「メカニカル・ミュージック・マン」）は、3歳の頃から機械式音楽に魅了され続けてきた収集家・演奏家で、「メカニカル・ミュージック・ラジオ」の創設者でもある。</li>
<li>演奏に使う街頭オルガン「ブラウチェ（Blauwtje）」は、1920年代にシャルル・マレンギが製作した49鍵のオルガンで、1930年代にカール・フライが52鍵仕様に改造し、著名なオルガン装飾家フェイテ・ポストゥムスが外装を彩色し直した由緒あるものだ。ダンドン氏は2011年にこの楽器を購入し、英国へ持ち帰った。</li>
<li>演奏は、穴を開けた厚紙の帯を読み取らせる仕組みで、電動プーリーがふいごを動かし、厚紙の穴で開閉するバルブが圧縮空気をパイプへ送って音を出す。今回はこの100年前の機構で、1998年のシェールのヒット曲「ビリーヴ」をオートチューンなしのアコースティックな響きでカバーした。</li>
<li>ダンドン氏はこれまでも同じオルガンでオアシスの「ワンダーウォール」やダフト・パンクの「ゲット・ラッキー」などをカバーしており、古い機構で最新のヒット曲を再現する組み合わせの妙が持ち味になっている。</li>
<li>出典: <a href="https://laughingsquid.com/cher-believe-dutch-street-organ/">Laughing Squid</a>、<a href="https://www.mechanicalmusicman.com/">The Mechanical Music Man</a></li>
</ul>
<h2>データセンターの悲鳴を再現する、99ドルのぬいぐるみ</h2>
<ul>
<li>米国のクリエイティブスタジオ「Basura」と、音楽プロジェクト「Big Data」のプロデューサー、アラン・ウィルキス氏が組み、サーバーラックを擬人化したぬいぐるみ「ベジー（Bezzy）」を発表した。</li>
<li>ベジーを抱きしめると、米バージニア州のデータセンター近隣住民が実際に録音した、施設の甲高い稼働音がスピーカーから流れる仕組みになっている。</li>
<li>手作りで1体99ドル、数量限定20体のみの販売。この「Adopt a Data Center（データセンターを引き取ろう）」と題した企画は、米国各地のデータセンター周辺住民への取材を重ねたうえで作られた風刺プロジェクトで、購入者は施設の土地利用、電力需要、ガス火力発電の増強、地域への影響に関する調査資料へのリンクも受け取る。</li>
<li>おもちゃの形を借りて、データセンターがどこに建てられ、どんな資源を消費しているかを社会に問いかける狙いがある。</li>
<li>出典: <a href="https://www.wired.com/story/adopt-this-data-center-plushie-and-hear-its-piercing-scream/">Wired</a></li>
</ul>
<h2>まとめ</h2>
<ul>
<li>四題に共通するのは、「偶然や不満から生まれた工夫」が独自のかたちに育っていった点だ。</li>
<li>転職と起業の失敗から爪を仕事道具に変えた青年、母の小言から新しい音楽技法を生んだ少年、100年前の機構で最新曲を再現する収集家、住民の不満をぬいぐるみの悲鳴に変えたスタジオ。それぞれ出発点は小さな出来事だった。</li>
<li>「思いがけない発見をどう育てるか」という視点で振り返ると、四題ともに人の執念と工夫の物語として読める。</li>
</ul>
