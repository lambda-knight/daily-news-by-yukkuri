<h1>スペインニュース（2026年9月3日）</h1>
<h2>オープニング：2026年9月3日 — スペインニュース</h2>
<ul>
<li>米国主催のG20会合から再び外されたスペイン、セウタ越境をめぐる警察資料、歌手フデリンの世界的ヒット、地方都市へ渡るフラメンコ、カサシマロの工房継承を追う。</li>
</ul>
<h2>今日のスペイン語ひとこと</h2>
<ul>
<li><strong>No dar puntada sin hilo（ノ・ダル・プンタダ・シン・イロ）</strong>＝「糸なしでひと針も縫わない」。一つ一つの行動に狙いがある、抜け目なく動く、という表現。外交会合の招待や捜査資料の扱いにも意図を読む今日の話題に重なる。</li>
</ul>
<h2>国際情勢（スペイン視点）</h2>
<ul>
<li><strong>米国、G20会合にオランダとポーランドを招きスペインを除外</strong>（El Mundo、9月3日）: 両国はG20正式メンバーではないが招待され、カルロス・クエルポ経済相らスペイン閣僚は今年の会合から引き続き外された。トランプ政権との距離が、多国間外交で目に見える席順になった。</li>
<li><strong>セウタ越境前に二つの警告</strong>（El Mundo、9月2日）: 7月27日の情報報告は大量流入を「非常にあり得る」とし、30日の警察報告は「極度」「差し迫った」危険を記した。北アフリカのスペイン領を守る情報が政策判断へ届いたかが争点である。</li>
<li><strong>警察資料はモロッコ側要員の誘導・容認を指摘</strong>（El País／El Mundo、9月2日）: 外国人警察部門の資料は、制服・私服のモロッコ要員が移民を「誘導」し、流入は計画されたとみる一方、モロッコ政府が命じた証拠までは示していない。右派紙は政府説明の崩壊を強調し、左派紙は証拠の範囲を区切った。</li>
<li>地中海とアフリカを自国問題とみるスペインでは、国境管理、未成年保護、モロッコとの協力が同時に問われる。日本で離島国境を中央政府の課題として捉えやすいのに対し、セウタでは住民の日常と外交が同じ街路で衝突する。</li>
</ul>
<h2>スペイン国内ニュース</h2>
<ul>
<li><strong>セウタ市民2万人が自治市の日に抗議</strong>（El País、9月2日）: 住民はスペインへの帰属を掲げ、移民危機への政府対応を批判した。人口約8万規模の自治市で2万人という参加は、地方の不満が国家政治を動かす大きさである。</li>
<li><strong>エル・トランポリン海岸の1,300メートルに2,000人超</strong>（El Mundo、9月3日）: アジャド少年の水鉄砲を象徴に、行き場のない人々が海岸で暮らす状況を描いた。政策論の裏側で、衛生、住居、子どもの遊び場が一つの浜へ押し込まれている。</li>
<li><strong>サンチェス首相、連立相手・野党双方から追及へ</strong>（El Mundo、9月3日）: スマール、協力政党、国民党、ボックスが、モロッコの責任を軽く扱った政府説明とセウタ対応を問う。左右対立だけでなく連立内部の亀裂が議会へ出る局面だ。</li>
<li><strong>8月の失業者は4万4,419人増、総数235万5,918人</strong>（El Mundo、9月2日）: 月間増加は2022年以来の8月最大だが、総数は2007年以来の低水準。外国人の在留正規化で公共職業安定所の業務も増え、良い長期傾向と夏の雇用調整が同居する。</li>
<li>スペインでは2万人が街頭で帰属と不満を同時に示す。日本の陳情や静かな合意形成とは違うが、中央より地元の暮らしを優先する感覚は、地域祭りや自治会を守る姿勢と通じる。</li>
</ul>
<h2>文化・芸能ニュース</h2>
<ul>
<li><strong>カディス出身のフデリン、『BbY WOW』が世界的ヒット</strong>（El País、9月2日）: コロンビアの歌手カロル・Gとの曲が頂点へ上がった。業界関係者は、配信プラットフォームとアルゴリズム時代の拡散を「予測不能の宝くじ」と説明する。</li>
<li>フデリンはカディス県ヘレス・デ・ラ・フロンテーラ近郊の出身で、フラメンコの土地から現代的なポップと都市音楽へ接続してきた。地域の声が国境を越える一方、再生推薦の一押しが生活と創作の規模を急変させる。</li>
<li><strong>アリシア・ヒメネス・バートレット、ペトラ・デリカード30周年</strong>（El Mundo、9月2日）: 新作『地獄の空の下で』ではバルセロナのラ・ミナ地区でイエズス会士殺害を捜査する。女性刑事をスペイン推理小説の中心へ置いたシリーズが最初の事件から30年を迎えた。</li>
<li><strong>ランブラス通りテロの124時間を映画『クロノス』が再構成</strong>（El Mundo、9月2日）: 制作者はカタルーニャ州警察、遺族、被害者団体に会い、「被害者が安心できること」を倫理的前提にした。事件を娯楽へ変える線と、地域の記憶を残す線を当事者との対話で引いた。</li>
<li>カディスの若い歌手、バルセロナを描き続ける作家、カタルーニャの記憶を扱う映画が並ぶ。東京へ文化産業が集中しやすい日本に比べ、スペインでは出身地と言語圏が作品の輪郭として強く残る。</li>
</ul>
<h2>フラメンコニュース</h2>
<ul>
<li><strong>エヘア・デ・ロス・カバジェロスで『私たちのフラメンコ』</strong>: リカルド・フェルナンデス・デル・モラル率いる舞台が、カンテ、ギター、バイレを一つの公演で紹介する。アラゴン州の町へ、アンダルシアで育った三位一体の構造を運ぶ企画だ。</li>
<li><strong>マラガ県アロサイナのアルメナ・フラメンカ</strong>: 城壁を意味する「アルメナ」を冠した催しに、歌、ギター、舞踊が集う。大都市の劇場ではなく、白い村の歴史的景観と共同体が舞台になる。</li>
<li><strong>ラ・ウニオンのカンテ・デ・ラス・ミナス、2026年の新しい伝説を募集</strong>: 鉱山地域に根を持つ大会が次世代の歌い手、奏者、踊り手を探す。名声の継承を有名人の出演だけでなく競技と選考で支える。</li>
<li><strong>パンプローナでは「アンダルシアのカデンツ」が前面に</strong>: フラメンコ・オン・ファイアがギター、カンテ、バイレの和声とリズムを北部ナバラで示す。フラメンコが全国文化として広がるほど、発祥地アンダルシアの名を消さない設計が重要になる。</li>
<li>マドリードが国の顔として売り、北部が自分の舞台へ招き、アンダルシアの町々が生活の中で守る。この三つは競争であると同時に、演者が一年を通じて働ける巡回路でもある。</li>
</ul>
<h2>フラメンコギター工房だより</h2>
<ul>
<li><strong>ビセンテ・カリージョ工房（クエンカ県カサシマロ）</strong>: 「ギターの町」で約270年続く家族工房。製作家ビセンテ・カリージョは、木材を目で選ぶ力には長い年月が必要で、家具作りの基礎と音響の理解を併せ持つ必要があると説明している。</li>
<li>工房が示すフラメンコ用の弦長は通常660ミリで、クラシックの標準650ミリより1センチ長い。パコ・デ・ルシア向けには強い手に合わせて670ミリを用いたという。寸法は飾りでなく、張力と奏者のタッチを結ぶ注文情報である。</li>
<li>フラメンコギターは素早い立ち上がりでカンテ、バイレ、パルマの隙間へ音を入れる。カリージョ工房はパコ・デ・ルシア、トマティート、カニサレスらへ供給し、演奏家の身体に合わせる共同調整を家業の継承へつないできた。</li>
</ul>
