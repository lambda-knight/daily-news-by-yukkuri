<h2>オープニング：2026年9月3日 — 世界から見た日本</h2>
<ul>
<li>英国紙が注目した生活道路の時速30キロ化、米国の18歳を通して英国・スウェーデンが再発見した日本のノイズ音楽、フランス通信社と国際団体が問う動物カフェを扱う。</li>
<li>「日本の日常や文化は外からどう見えるか」を、安全、深く聴く文化、観光的なかわいさと動物福祉の3面から比較する。</li>
</ul>
<h2>英国紙が「標識のない細道」に見た時速30キロへの転換</h2>
<ul>
<li>英国ガーディアン紙のジャスティン・マッカリー記者は、9月1日に始まった日本の生活道路の新速度規制を、混雑した都市の狭い道路で歩行者を守る転換として報じた。中央線も最高速度標識もない道路では、法定速度が時速60キロから30キロへ半減した。</li>
<li>対象は一般道路の約70%とされる。歩道のない細道が多く、子どもと高齢者が死亡・重傷事故に巻き込まれやすい点を英国の読者へ説明している。</li>
<li>記事が紹介した警察庁データでは、生活道路で制限速度を超えていた車による事故は、速度内の事故より死亡・重傷につながる割合が約3倍だった。</li>
<li>英国側の見出しは「日本が全ての狭い市街地道路で速度を半減」と制度変更を大胆に映す。一方、実際の対象は中央線や個別標識のない道で、幹線道路まで一律30キロになるわけではない。</li>
<li>日本では標識がない道のルール変更として見えやすいが、海外記事は「狭いのに60キロが法定だった」従来制度そのものを意外な点として切り取った。</li>
<li>出典: <a href="https://www.aol.co.uk/articles/japan-halves-speed-limit-30km-051500000.html">The Guardian配信記事（AOL掲載）</a>（2026年9月2日）</li>
</ul>
<h2>米国の18歳が400作を聴き、英国紙が日本のノイズを「深聴き」と読む</h2>
<ul>
<li>英国ガーディアン紙は9月1日、米ジョージア州の18歳サム・アンドリュースさんが、日本のノイズ音楽家メルツバウの全作品を聴く挑戦を2月から続けていると報じた。メルツバウは秋田昌美さんが1979年に始め、発表作は400を超える。</li>
<li>アンドリュースさんは朝7時に起き、朝食後にヘッドホンを着け、作品ごとに色分けした表へ評価を記録する。一部の動画は50万回再生されたが、同年代の視聴者は1.6%で、多くは30〜40代だという。</li>
<li>お気に入りは1990年の「レインボー・エレクトロニクス」で10点中8点。最も厳しかった作品は、後半30分が一つの周波数のように聞こえ「耳鳴りのようだった」と具体的に語る。</li>
<li>英国紙が面白がったのは、強烈な音そのものだけではない。短い動画と推薦アルゴリズムが次々に曲を送る時代に、18歳が40分の作品や全ディスコグラフィーへ集中する「深く聴く」行為を選んだ点だった。</li>
<li>スウェーデン公共放送は5月、メルツバウが2026年だけで当時7作を発表し、同国のサックス奏者マッツ・グスタフソンとも協働した点を紹介した。英国は若い聴き手の集中力、スウェーデンは自国音楽家との接続を入口に、同じ日本人を違って見ている。</li>
<li>出典: <a href="https://www.theguardian.com/music/2026/sep/01/merzbow-noise-artist-sam-andrews-teen-listening-marathon">The Guardian</a>（2026年9月1日） / <a href="https://www.svt.se/kultur/japanska-artisten-merzbow-har-slappt-400-skivor">SVT Nyheter</a>（2026年5月20日）</li>
</ul>
<h2>動物カフェをAFPは「かわいさ」より感染と福祉から見る</h2>
<ul>
<li>フランス通信社は8月28日、日本の環境省が9月にも動物カフェの初の実態調査を始めると報じた。店舗数と飼育動物の種類、十分な広さ、清掃頻度、動物愛護管理法などの順守を調べ、違反が疑われる施設は立入検査も検討する。</li>
<li>英語ニュースサイト「ニュース・オン・ジャパン」は9月2日、東京と大阪だけで、猫や犬以外の動物と触れ合える施設が80店を超えると伝えた。フェネック、カワウソ、フクロウなどを一つの店で扱う例もある。</li>
<li>世界自然保護基金ジャパンの2025年調査は、国際自然保護連合のレッドリスト掲載種やワシントン条約対象種を展示する店があり、複数施設の微生物検査で病原菌が見つかったとした。</li>
<li>動物保護団体ピータ・アジアのライラ・イマイ氏は、触れ合い、騒音、カメラのフラッシュ、見知らぬ人との連続接触が野生動物に不自然な負担を与えると批判する。一方、保護猫や保護犬の譲渡先探しを担う店もあり、全店を同じ性格にはできない。</li>
<li>日本国内では観光や癒やしの場に見える施設を、フランス通信社と国際団体は、希少動物取引、衛生、福祉を同時に調べる規制課題として映した。初の全国像が見えること自体が9月調査の焦点になる。</li>
<li>出典: <a href="https://www.japantimes.co.jp/news/2026/08/28/japan/animal-cafe-survey-hygiene/">AFP / The Japan Times</a>（2026年8月28日） / <a href="https://newsonjapan.com/article/150596.php">News On Japan</a>（2026年9月2日）</li>
</ul>
<h2>まとめ</h2>
<ul>
<li>英国紙は狭い道の従来速度を驚きとして捉え、英国とスウェーデンの文化報道は日本のノイズ音楽を若者の集中力と国際協働から読み、フランス通信社と国際団体は動物カフェを衛生・福祉・取引の問題へ広げた。</li>
<li>海外の視線は日本を一括評価せず、誰がどの場面を見るかで焦点を変える。今日は、生活道路の標識、朝食後のヘッドホン、カフェの清掃頻度という小さな場面から、日本の制度と文化の別の輪郭が見えた。</li>
</ul>
