<h1>世界の珍ニュース（2026年9月3日）</h1>
<h2>オープニング：2026年9月3日 — 世界の珍ニュース</h2>
<ul>
<li>2026年9月3日放送。今日は、機械同士の採用面接、8万人で入場制限する海水浴場、穴だらけのデータ救出依頼、1万部限定の本をめぐる貸し借りの4本。</li>
<li>共通する問いは「便利な仕組みや大切な物が、人間の都合とぶつかると何が起きるか」。</li>
</ul>
<h2>ネタ1 求職者のチャットボットと採用ボットが10分間面接</h2>
<ul>
<li>政府契約の仕事が減ったクリストファーさんは半年で約700件に応募。情報技術会社エバーフォース・エイペックス・システムズの人工知能採用係「ライリー」と4回面接したが、人間から連絡も不採用通知もなかった。</li>
<li>5回目は自分の経歴を音声版チャットジーピーティーへ入力し、電話口で二つの端末を並べた。人工知能同士は10分話し、入社日と身元調査をめぐって同じ話を循環。採用側は「話せてよかった」、応募側は「明確な手続きに感謝」と互いを褒めた。</li>
<li>さらに求人票の条件を詰め込んだ架空の理想候補「ドン・ディクナー」でも23分面接したが、人間の採用担当者から連絡はなかった。</li>
<li>採用サービスのグリーンハウスによると、求職者の63%が人工知能面接を経験。大量応募を処理する企業と人工知能を使う応募者の双方に効率化の動機があり、面接そのものが誰にも届かない会話になる逆説が表れた。</li>
<li>出典: <a href="https://www.wired.com/story/bot-vs-bot-job-interview-ai/">WIRED</a>（2026年9月2日）</li>
</ul>
<h2>ネタ2 長さ1.8キロに最大20万人、ダーメイシャ海岸</h2>
<ul>
<li>中国・深圳のダーメイシャ海岸は長さ1.8キロの公共ビーチ。週末には砂が見えないほど混雑し、過去には同時に約20万人が集まったと報じられている。</li>
<li>深圳市は5月から10月まで、1日の入場者を8万人に制限。利用には予約が必要になった。</li>
<li>入場無料で、複数のバス路線に加え地下鉄駅が正面にある。交通の便利さが混雑をさらに招くという、公共施設ならではの逆説がある。</li>
<li>20万人という過去の数字や「世界一混雑」という呼称は公式記録ではなく記事の表現。一方、8万人の予約制は現在の混雑対策として紹介されている。</li>
<li>出典: <a href="https://www.odditycentral.com/travel/dameisha-the-worlds-most-crowded-beach.html">Oddity Central</a>（2026年8月14日）</li>
</ul>
<h2>ネタ3 データ救出依頼を開いたら、問題が七つ出てきた</h2>
<ul>
<li>退職後に別アカウントで再雇用された外部社員について、元の利用者フォルダーと重要書類をディーブイディーかユーエスビーへ保存してほしい、という社内依頼が技術担当へ届いた。</li>
<li>依頼には対象パソコン名がなく、重要書類はバックアップ対象のサーバーやクラウドではなく個人端末に置かれていた。返却済み端末は初期化されている可能性もあった。</li>
<li>物理媒体への保存を求めながら媒体は渡されず、受取側の端末にディーブイディー読取装置や外部記憶装置の利用権限があるかも不明。担当者は関連する問題を七つ列挙した。</li>
<li>技術的故障ではなく、保管場所、端末特定、受け渡し方法、アクセス権が全部未整理だったという相談投稿。匿名投稿なので企業名や結果は確認できず、職場の一事例として扱う。</li>
<li>出典: <a href="https://twistedsifter.com/2026/09/a-user-made-an-absurd-request-to-tech-support-so-they-listed-everything-wrong-with-it/">TwistedSifter</a>（2026年9月2日）</li>
</ul>
<h2>ネタ4 1万部限定の本を8歳に貸すか、友情まで揺れた</h2>
<ul>
<li>27歳の投稿者が持つのは、アニメ「グラビティフォールズ」の「ジャーナル3」特装版。不可視インクで隠し文が印刷され、発行は1万部とされる高価な収集品だった。</li>
<li>30歳の友人が8歳の息子に貸してほしいと依頼。投稿者は通常版なら貸すと代案を出したが、息子は特装版だけにある隠し文を見たがった。</li>
<li>投稿者が断ると、友人は子ども向け番組に執着する方が子どもじみていると怒り、その後二人は話していないという。</li>
<li>これは匿名の相談投稿で、片方の説明しかない。ただし「子ども向け作品」と「大人の高価な収集品」が同じ一冊に同居し、所有物を守る線引きが友情の評価へ飛び火した点が珍しい。</li>
<li>出典: <a href="https://twistedsifter.com/2026/09/she-refused-to-lend-a-rare-book-to-an-8-year-old-and-was-instantly-called-childish-by-her-friend/">TwistedSifter</a>（2026年9月2日）</li>
</ul>
<h2>まとめ</h2>
<ul>
<li>採用を効率化したら人工知能だけが会話し、海への交通を便利にしたら8万人の予約制になり、データ救出と本の貸し借りでは前提の違いが問題を増やした。</li>
<li>今日の4本は、仕組みや物よりも「誰が何を当然と思っているか」の食い違いが、いちばん珍妙な場面を作ることを示した。</li>
</ul>
