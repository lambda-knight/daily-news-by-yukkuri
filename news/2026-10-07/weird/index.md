<h2>重さ3.5トン、カナダの「口笛ブイ」が大西洋を渡ってアイルランドへ</h2>
<ul>
<li>アイルランド西部メイヨー県のアキル島、パーティーン港近くの海岸に、カナダ沿岸警備隊のブイが打ち上げられた。メイヨー県議会が10月6日に発表した。</li>
<li>重さは約3.5トン。航路標識の灯火を載せるだけでなく、波の動きを利用して独特の「口笛」のような音を鳴らす仕組みを持つ。漂流距離は3000マイル（約4800キロ）を超える。</li>
<li>県議会がカナダ沿岸警備隊に連絡すると、「うちのブイはとても人なつっこく、ときどき故郷から遠くへ旅に出る癖がある」との返答があったという。</li>
<li>県議会の海事担当ディレクター、デビッド・メレットさんは「最優先は安全な回収であり、航行や沿岸施設の危険にならないようにすること」と述べた。ブイは再び浮かべてルーナ桟橋まで曳航し、県の資材置き場へ運ぶ計画。</li>
<li>県議会はカナダ側の技術支援に謝意を示しつつ、「もう一度ブイに会いたければ、メイヨーまで特別に旅をして引き取りに来てもらう必要があるかもしれない」と付け加えた。</li>
<li>メイヨー県からカナダへは何世代にもわたる移民の歴史があり、県議会はこの漂着を両地域の「長く続くつながり」の思いがけない象徴だとしている。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/10/06/ireland-county-mayo-canadian-coast-guard-buoy/1221791304125/">UPI</a> / <a href="https://www.con-telegraph.ie/2026/10/06/canadian-coast-guard-buoy-washes-up-on-mayo-shoreline/">Connaught Telegraph</a> / <a href="https://www.westernpeople.ie/news/unusual-visitor-from-canada-washes-up-on-mayo-coastline_arid-20330769.html">Western People</a></li>
</ul>
<h2>床下から51年ぶりの財布、1975年の「ハムレット」1ドル50セントの券</h2>
<ul>
<li>カナダ・ノバスコシア州ダートマスのビクトリア・ロードの住宅で、改修工事をしていた大工マティ・ゴールドスミスさんが、古い床の下から財布を見つけた。</li>
<li>中身は運転免許証、ダートマス高校の学生証、手書きの出生証明書、1ドル札1枚、そして1975年の舞台「ハムレット」のチケット。値段は1ドル50セントだった。</li>
<li>ゴールドスミスさんは9月23日、フェイスブックに「1958年生まれで1975年にダートマス高校にいたリチャード・ギルロイさんを知りませんか。1975年から壁の中で行方不明だった財布を改修中に見つけた」と投稿した。</li>
<li>投稿に気づいたのは妻のドナ・ギルロイさん。「夫は財布をなくした家がどこか、はっきり覚えている」と応じ、9月26日、現在68歳のリチャードさんの手に財布が戻った。なくした当時は17歳ごろ。</li>
<li>ギルロイさんは51年前にその家で財布をなくしたことを覚えていたが、ハムレットを観に行った記憶はないという。一方で1ドル50セントという値段には「すごい」と感心し、中身はすべて額装して飾るつもりだと話した。</li>
<li>ゴールドスミスさんは、改修工事では「小さな宝物やタイムカプセル」がよく出てくるが、他人の身分証を見つけたのは初めてだと語った。手書きの出生証明書が入っていたことにも驚いたという。</li>
<li>出典: <a href="https://ca.news.yahoo.com/trip-down-memory-lane-n-202153857.html">CBC News（Yahoo News Canada転載）</a> / <a href="https://www.upi.com/Odd_News/2026/10/06/canada-dartmouth-nova-scotia-lost-wallet-51-years/7671791307060/">UPI</a> / <a href="https://www.yahoo.com/lifestyle/articles/man-reunited-high-school-wallet-121546347.html">People（Yahoo転載）</a></li>
</ul>
<h2>2台の電動キックボードにソファ、シャーロット警察「家具の展示はイケアに」</h2>
<ul>
<li>米ノースカロライナ州シャーロットの幹線道路サウス・トライオン通りで、9月25日（金）、2人掛けのソファをシェアサービス「ライム」の電動キックボード2台の上に渡して走っていた男性2人を、シャーロット・メクレンバーグ警察が停止させた。</li>
<li>警察はソーシャルメディアで「そう、本物のソファ」と写真付きで紹介し、こうした乗り物で走る人を止めたのは「間違いなく初めて」とした。</li>
<li>警察は、道路上のソファは周囲の運転者の注意をそらし危険を招くと指摘し、「何を『運転』するにしても、まず安全を考えて」と呼びかけた。</li>
<li>投稿の締めは「動く家具の展示は、イケアに任せておくのがいちばん」。違反切符が切られたかどうか、停止させた正確な地点は公表されていない。</li>
<li>投稿は拡散し、地元テレビ局やラジオ局が相次いで取り上げた。</li>
<li>出典: <a href="https://www.wfae.org/charlotte-area/2026-10-01/living-room-on-the-loose-cmpd-stops-couch-surfers-cruising-down-south-tryon">WFAE</a> / <a href="https://hoodline.com/2026/10/charlotte-police-pull-over-couch-driving-down-south-tryon-street-on-two-lime-scooters/">Hoodline</a> / <a href="https://www.upi.com/Odd_News/2026/10/05/nc-us-Charlotte-Mecklenburg-couch-scooters/8751791210974/">UPI</a></li>
</ul>
<h2>祈りの夜に教会へ入ってきたアライグマ、聖フランシスコの祝日を前に</h2>
<ul>
<li>ニューヨーク・グリニッジビレッジの聖ジョセフ教会で、9月25日に開かれたろうそくの祈りの集い「ナイトファイア」の最中、1匹のアライグマが正面の扉から悠々と入ってきた。この集いは年4回開かれる。</li>
<li>玄関ホールでアライグマに気づいた当番のジョナ・テラー神父が、外へと誘導した。アライグマは階段を下りて6番街を走り去り、通りがかった人が都会の野生動物に驚く様子も映像に残った。</li>
<li>教会がインスタグラムに動画を投稿し、10月5日に報じられた。</li>
<li>訪問は、動物の守護聖人として知られるアッシジの聖フランシスコの祝日（10月4日）のおよそ1週間前だった。テラー神父はニューヨーク・ポスト紙に「聖フランシスコの霊がアライグマの後ろから一緒に歩いてきたのかは分からないが、聖フランシスコと神を思い出させてくれる素晴らしい出来事だった」と語った。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/10/05/raccoon-St-Josephs-church-new-york/7791791220402/">UPI</a></li>
</ul>
<h2>赤いハーネスで家出したサーバル「グスタフ」、自分で帰宅</h2>
<ul>
<li>ポーランド北東部ワルミア・マズールィ県の町オジシュで、個人の飼い主の家からアフリカのサーバル「グスタフ」が逃げ出した。週末の夜のことで、ピシュ郡警察が10月4日に捜索と注意を呼びかけた。</li>
<li>サーバルは中型犬ほどの高さの野生ネコで、体重は7〜18キロ、大きな耳と長い脚、黒い斑点が特徴。3メートル近く跳べる。グスタフは赤い革のハーネスを着けていた。</li>
<li>警察はグスタフを「どちらかといえばおとなしい子猫」と説明しつつ、「自分で捕まえようとしないで」と求め、見かけたら緊急番号112に通報するよう呼びかけた。</li>
<li>10月5日、グスタフは誰にも捕まらず、自分で家へ帰ってきたことが伝えられた。無事で健康だった。</li>
<li>ポーランドではサーバルの飼育に特別な許可は要らないが、市役所か郡役所への届け出が必要とされる。</li>
<li>同じ週末、米ミズーリ州マーシャルでは、郡の会場に設けられた移動動物園から、子どもが開けたままにした門を抜けてカンガルーが逃げた。翌日、目撃者が見失わないよう追い続け、警察と動物管理局、珍しい動物の扱いに慣れた目撃者が協力して捕獲し、飼い主の元へ返した。</li>
<li>出典: <a href="https://www.polsatnews.pl/wiadomosc/2026-10-05/zwrot-w-sprawie-zaginionego-serwala-gustawa-poszukiwania-okazaly-sie-zbedne/">Polsat News</a> / <a href="https://www.upi.com/Odd_News/2026/10/06/poland-escaped-serval-Gustaw-Orzysz/5031791302518/">UPI（サーバル）</a> / <a href="https://www.upi.com/Odd_News/2026/10/06/Marshall-Missouri-kangaroo-escape-petting-zoo/1351791299711/">UPI（カンガルー）</a></li>
</ul>
<h2>まとめ</h2>
<ul>
<li>3.5トンのブイ、51年前の財布、公道のソファ、教会のアライグマ、家出したサーバル。どれも「いるはずのない場所」に現れた。</li>
<li>戻し方はさまざまで、県議会は「引き取りに来て」と冗談を添え、大工は投稿で持ち主を探し、警察はイケアを引き合いに出し、神父は聖人の祝日と結びつけた。グスタフだけは、誰の手も借りずに自分で帰った。</li>
</ul>
