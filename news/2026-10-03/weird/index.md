<h2>オープニング：2026年10月3日 — 世界の珍ニュース</h2>
<p>日本のマクドナルドで55年間「ドナルド」と呼ばれてきた赤い髪のキャラクターが、10月1日から世界共通の「ロナルド」になった。ロンドンでは、日本の不動産会社が大英図書館の隣で始めた2000億円超の再開発で、オランダ人の宮司が日本式の地鎮祭を執り行った。ハンガリーでは、学生寮の棚に並べた空き缶から始まったエナジードリンク缶2000本のコレクションがギネス世界記録に認定され、アメリカでは、遺品整理セールで30ドルだった1枚の絵がオークションで135万ドルの値をつけた。今回は、呼び名、儀式の担い手、空き缶、1枚の絵――同じものが、呼ばれ方や置かれる場所が変わった途端に別の顔を見せた4つの話をたどる。</p>
<h2>55年目の改名、日本の「ドナルド」が10月1日から「ロナルド」に</h2>
<ul>
<li>日本マクドナルドは10月1日、店のキャラクター「ドナルド・マクドナルド」の呼び名を、世界共通の「ロナルド・マクドナルド（Ronald McDonald）」に改めた。公式サイトの表記も統一し、子ども向けの訪問プログラム「ハロードナルド！」も「ハローロナルド！」になった。</li>
<li>日本では1971年の上陸以来、「日本人に発音しやすく覚えやすい」として「ドナルド」の名が使われてきた。創業者の藤田田（ふじた・でん）氏が「ロナルドは日本人には発音しにくい」という意見を採ったと伝えられている。英語圏を含め海外では当初から「ロナルド」で、日本は例外だった。</li>
<li>公式Xは10月1日、ベンチに座るキャラクターの画像に「今日からロナルド」と添え、「ドナルド、どーなるの？」と投稿。表示は250万回を超え、「革命だろこれ」「おかえりって言っていいのかな」などの反応が集まった（ねとらぼ）。</li>
<li>きっかけは、病気の子どもの治療に付き添う家族の滞在施設「ドナルド・マクドナルド・ハウス」の日本開設25周年。第1号の「せたがやハウス」は2001年12月に開設され、国内は12か所、世界では約390か所ある。運営する公益財団法人は10月1日、「ロナルド・マクドナルド・ハウス・ジャパン」に改称し、ロゴも刷新した。</li>
<li>国内のハウスは25年でのべ10万家族、60万泊を受け入れた。2026年4月には利用料（1人1日1000円）を無償にしている。財団は「名称やロゴは変わりますが、病気と向き合う子どもとそのご家族の『第二のわが家』としての使命は変わりません」としている。</li>

</ul>
<h2>ロンドンの大英図書館で日本式の地鎮祭、祝詞をあげたのはオランダ人宮司</h2>
<ul>
<li>三井不動産の英国法人は9月17日、ロンドンの大英図書館の敷地で、図書館の新館と研究所・オフィスを一体にした複合施設の工事に着手し、9月21日に日本式の地鎮祭を行った。場所はセント・パンクラス国際駅の向かい。地上11階・地下1階、延べ床面積約9万6000平方メートルで、2032年の完成を目指す。総事業費は2000億円を超え、同社の英国事業で過去最大となる。</li>
<li>下の階には図書館の新館（公共部分約9300平方メートル）が入り、上の階は研究所やオフィスとして貸し出す。大英図書館の所蔵は1億7000万点を超える。三井不動産の小野雄吾常務執行役員は「周辺に大学研究機関やIT企業が集積している。大英図書館の再開発にかかわることで日本の街づくりのノウハウを生かせる」と述べた（テレビ東京）。</li>
<li>地鎮祭では、酒・塩・米を供えて土地の神を鎮め、設計者が鎌で草を刈り、発注者が鍬で砂の山を崩し、施工者が鋤でならす三つの所作を、英国政府関係者や図書館幹部の前で行った（SoraNews24）。</li>
<li>祭主を務めたのは、オランダの元俳優ポール・デ・レーウ（Paul de Leeuw）さん。1979〜81年に静岡県浜松市の山蔭神道の本部で学び、1981年4月に祭祀を行う資格を得て帰国した。日本の報道では「日本で修行した初のヨーロッパ人宮司」と紹介され、表記は「ポール・ド・レオ」とされている。</li>
<li>アムステルダムで山蔭神道のオランダの社を構え、神棚を北に向ける。北極星で航海したオランダの船乗りにちなむ工夫で、「神道をオランダの社会に合わせて生かすように」と言われたことに沿っている。</li>
<li>日本企業のヨーロッパ進出では前例もある。1996年4月、キッコーマンがオランダ北部ホーゲザント＝サッペメールに初の欧州工場を建てた際も、デ・レーウさんが七角形のテントの中で約20分の地鎮祭を執り行った。工場は1997年秋に稼働した。</li>
<li>出典: <a href="https://www.kensetsunews.com/web-kan/1290713">建設通信新聞</a> / <a href="https://txbiz.tv-tokyo.co.jp/txn/news_txn/post_349138">テレ東BIZ</a> / <a href="https://soranews24.com/2026/10/02/japanese-shinto-ceremony-held-in-london-to-celebrate-start-of-british-library-expansion/">SoraNews24</a> / <a href="https://www.shinto.nl/kikkoman.htm">オランダ山蔭神道（キッコーマン工場の地鎮祭）</a> / <a href="https://en.wikipedia.org/wiki/Yamakage_Shinto">Yamakage Shinto（Wikipedia）</a></li>
</ul>
<h2>寮の棚の空き缶15本から2000本へ、ハンガリーのエナジードリンク缶収集家がギネス世界記録</h2>
<ul>
<li>ハンガリー東部デブレツェンのゲルゲー・ボルベーイさんが、2000本のエナジードリンク缶で「エナジードリンク缶の最大のコレクション」のギネス世界記録に認定された（認定日は2026年4月9日、ギネスとUPIが10月2日に紹介）。500以上のブランド、40か国以上の缶で、すべて種類が違う。それまでの記録は約1100本で、ほぼ倍にした。</li>
<li>始まりは2008年8月の暑い日。学生寮の近くの小さな店で、ハンガリーのブランド「ヘル」のエナジードリンクを好奇心から買い、気に入ってほかの銘柄も試すようになった。空き缶は寮の部屋にたまり、いったんは資源ごみに出すつもりだったが、種類の違うものを1本ずつ棚に戻したところ、約15本が「並べるといい感じ」に見えたという。</li>
<li>コレクションは寮から実家へ、さらに自分の家へと引っ越しを重ね、今は家の中に並べて全点を記録している。いちばん古い缶は1994年の「セムテックス」。1990年代のマイケル・ジャクソンの「ミステリー」というエナジードリンクや、旧ユーゴスラビア製のガラナ飲料もある。</li>
<li>特に思い入れが深いのは、新婚旅行で訪れた日本で集めた缶で、漫画『チェンソーマン』のデザイン缶も含まれる。日本、アメリカ、ヨーロッパ各地の旅先から持ち帰った缶が多い。</li>
<li>ギネス申請を考えたことはなかったが、2024年に娘が生まれ、父親になって「自分の歴史を形に残したい」と思ったのがきっかけになった。本人は「2008年に、あの数本の缶がいつかギネス世界記録になると言われたら、きっと笑っていた」と話し、今後も集め続けるという。</li>
<li>出典: <a href="https://www.guinnessworldrecords.com/world-records/649355-largest-collection-of-energy-drink-cans">Guinness World Records</a> / <a href="https://www.upi.com/Odd_News/2026/10/02/hungary-guinness-world-records-energy-drink-cans/2031790952808/">UPI</a></li>
</ul>
<h2>30ドルの絵が135万ドルに、アバークロンビーの「貝殻」が予想の5倍超で落札</h2>
<ul>
<li>9月21日の本番組で紹介した、ミシガン州の遺品整理セールで30ドルで買われた絵が、10月1日（木）にニューヨークのオークションハウス「フリーマンズ」で135万ドルで落札された。事前の予想価格は15万〜25万ドルで、その上限の5倍を超えた。アーティストの作品として過去最高額と報じられている（Artforum、UPI）。</li>
<li>作品は、シカゴの画家ガートルード・アバークロンビー（1909〜1977年）が1951年に描いた『市議会議員メリアムの貝殻（Alderman Merriam's Shells）』。縦横約20×28センチの小品で、暗い台の上に並んだ小さな貝殻と、ほとんど見えない糸で黒い壁につるされた貝殻を描いている。モデルは、アバークロンビーが暮らしたハイドパーク地区を含むシカゴ第5区の市議会議員ロバート・メリアム氏（在任1947〜55年）の貝殻コレクション。</li>
<li>絵は1952年、医療の謝礼としてミシガン州カラマズーの医師ジョン・レイノルズ氏に渡り、約75年その家族のもとにあった。今夏のセールで、買い手はガレージへ続く廊下に掛かっていたこの絵を見つけ、ミルウォーキー美術館の回顧展カタログと1952年のシカゴ・トリビューンの展評で同じ作品を確かめた。鑑定はルーズベルト大学名誉教授のスーザン・ワイニンガー氏。</li>
<li>アバークロンビーはテキサス生まれで、オペラ歌手の両親を持つ。ハイドパークの自宅は、2人目の夫で音楽評論家のフランク・サンディフォード氏とともに、ディジー・ガレスピー、ソニー・ロリンズ、マックス・ローチらジャズ奏者がセッションに集まる場だった。</li>
<li>2025年3月には1956年の作品が25万6000ドルで売れていた。フリーマンズのザカリー・ウィルサム上級副社長は落札前、「誰もが発見の物語を好む。そして、これは純粋に優れた作品でもある」と話していた。</li>
<li>出典: <a href="https://www.upi.com/Odd_News/2026/10/02/estate-sale-painting-gertrude-abercrombie-auctioned/6081790959629/">UPI</a> / <a href="https://www.artforum.com/news/abercrombie-painting-estate-sale-auctions-for-1-35-million-1234760716/">Artforum</a> / <a href="https://www.wbez.org/arts/2026/09/30/gertrude-abercrombie-auction-alderman-merriams-shells">WBEZ Chicago</a> / <a href="https://freemansauction.com/auction/6572-post-war-contemporary-art/lot/3">Freeman's</a></li>
</ul>
<h2>まとめ</h2>
<ul>
<li>日本の「ドナルド」は、55年目に世界共通の「ロナルド」になった。きっかけは、のべ10万家族を受け入れてきた滞在施設の25周年だった。</li>
<li>ロンドンの大英図書館では、2000億円超の再開発の始まりを、日本で学んだオランダ人宮司が日本式の地鎮祭で清めた。</li>
<li>ハンガリーのボルベーイさんは、寮の棚に残した15本の空き缶を18年かけて2000本にし、娘の誕生をきっかけにギネス世界記録へ届けた。</li>
<li>医師への謝礼として渡った30ドルの絵は、75年後のオークションで135万ドルになり、シカゴの画家の評価を塗り替えた。</li>
</ul>
