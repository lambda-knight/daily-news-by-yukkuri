<h2>ネタ1 ストレス発散で2,100件の偽注文、大阪の女性を書類送検</h2>
<ul>
<li>大阪のレストラン従業員・吉田真由さん（32）が2024年〜2025年の約1年間に、集英社系のオンライン漫画ストアへ238個のアカウントを使い分けて2,100件超の注文を繰り返し逮捕</li>
<li>手口はコンビニ前払いの支払いを完了させない、または代金引換で商品到着時に受け取り拒否するというもので、注文総額は約43億円分に達した</li>
<li>実際の被害額は約750万円で、返送時の物流費・手数料と、品切れによる販売機会の損失が中心</li>
<li>本人は「日常生活のストレス対処法だった。商品が売り切れる前に注文できることが満足感をもたらした」と供述</li>
<li>出典: <a href="https://www.odditycentral.com/news/woman-arrested-for-placing-over-2000-fake-orders-on-online-manga-store-in-less-than-a-year.html">Oddity Central</a></li>
</ul>
<h2>ネタ2 ベルギーの醸造所跡地、下水道工事で1,000万ドル相当の金塊が出土</h2>
<ul>
<li>ベルギーで19世紀の醸造所オーナー、テオフィリュス・ヴァン・アッシュ氏の旧邸宅の地下を下水管敷設工事中、レンガで塗り固められた地下室の壁から金の延べ棒49本と大量の金貨・金塊が発見された</li>
<li>発見のきっかけは、作業員のドリルが金の延べ棒に引っかかったこと。8人の作業チームの中にいた18歳の学生アルバイト、コベさんは最初「ただの古いコイン」だと思っていたという</li>
<li>作業員たちは直ちに当局へ連絡し、財宝は目録化されて政府の保管施設に移送された。現在は検察が出所と法的な所有者を調査中</li>
<li>ベルギー法では、名乗り出る所有者候補に少なくとも5年間の猶予を与えたうえで、発見者が所有権を得られる可能性があると定められている</li>
<li>出典: <a href="https://www.foxnews.com/world/construction-workers-uncover-10-million-gold-building-sewer-former-brewery">Fox News</a></li>
</ul>
<h2>ネタ3 汽笛でホッキョクグマを起こした船の運航者に52万円の罰金</h2>
<ul>
<li>ノルウェー領スバールバル諸島の北緯沖、北極点から約1,000キロの入り江で、船に乗っていた人物が岸で眠っていたホッキョクグマを船の汽笛で起こし、行政庁（governor）から5,255ドル（約52万円）の罰金を科された</li>
<li>罰金の根拠はスバールバル環境法30a条で、「ホッキョクグマを不必要に驚かせ、引き寄せ、または追跡すること」を禁じている</li>
<li>汽笛を鳴らしたのは乗船者の1人だったが、通報したのは同じ船に乗っていた別の乗客だった。熊はその後、別の場所へ移動したという</li>
<li>罰金を科された本人の身元・国籍は公表されておらず、支払いには同意している</li>
<li>出典: <a href="https://www.cbsnews.com/news/sleeping-polar-bear-woken-foghorn-fine-arctic/">CBS News</a></li>
</ul>
<h2>ネタ4 メッツの本拠地シティ・フィールド、観客席の穴から現れる「アライグマ」が名物に</h2>
<ul>
<li>8月19日、ニューヨーク・メッツ対サンディエゴ・パドレスの試合中、観客席下の穴からアライグマの前足がぬっと伸びてきて、落ちたピーナッツの殻を集める様子が撮影され話題になった</li>
<li>動画を撮影したファンのスコット・レイノルズさんによると、家族でピーナッツを食べて殻を床に落としていたところ、動物の前足に気づいたという</li>
<li>周囲のファンは追い払うどころか、靴で殻を穴の方へ寄せたり、最終的にはホットドッグを穴に差し入れたりして「参加」し始めた</li>
<li>このアライグマはシティ・フィールドの観客席下に住み着いているとみられ、複数の米メディアが「トラッシュパンダ（ゴミ漁りアライグマ）」として報じている</li>
<li>出典: <a href="https://bleacherreport.com/articles/25479160-watch-raccoon-grab-fans-hot-dog-peanut-shells-hole-mets-citi-field-video">Bleacher Report</a></li>
</ul>
