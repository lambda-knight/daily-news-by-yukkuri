<h2>Nvidiaが実証「主役はモデルでなく“ハーネス”」——同じClaude Opus 5が100点満点に</h2>
<ul>
<li>Nvidia AIユニットのVP、Adel El Hallak氏が2026年8月21日、TechCrunchに研究内容を説明</li>
<li>インタラクティブ推論ベンチマーク「ARC-AGI-3」（説明書なしの2Dゲームを人間のように学習してクリアする評価）で、Anthropicの「Claude Opus 5」を素の状態で使うとスコアは30%</li>
<li>同じClaude Opus 5にNvidia独自の「ハーネス」（記憶管理とツール群を組み合わせたソフトウェアの土台）を組み合わせると、スコアが100%に到達</li>
<li>ハーネスには、エージェントが脱線したり行き止まりの探索を始めたりした際に軌道修正する「スーパーバイザー」機能があり、El Hallak氏は「ほとんどCEOのようにエージェントを促す」と説明</li>
<li>OpenAI勢もこのARC-AGI-3で当初10%未満だったスコアを、ハーネスの調整だけで30%近くまで3倍に伸ばした</li>
<li>Nvidiaはこの仕組みを「Agentic Variation Operators（AVO）」と呼び、モデルそのものより周辺のスキャフォールディング（足場）の設計が実用性能を左右すると位置づける</li>
</ul>
<h2>Googleの「推奨ソース」ボタン、導入サイトが半年で3倍の60万超に——AI検索でパブリッシャーが失う流入への対策</h2>
<ul>
<li>Googleが2026年8月20日、パブリッシャー向けに「推奨ソース（Preferred Sources）」ボタンをサイトへ埋め込める機能を拡大したと発表</li>
<li>読者がこのボタンを押すと、その媒体をSearch・Discover・Google Newsで優先的に表示してほしい「お気に入り」として登録できる</li>
<li>Googleの過去の調査では、推奨ソースに登録された媒体は読者がクリックして訪問する確率が通常の2倍になるという</li>
<li>背景には、AI OverviewsやAI Modeによる参照トラフィックの急減がある。2025年12月のコアアップデート後、Discover経由のクリックが最大98%減ったと報告するサイトもあり、Chartbeatのデータでは過去1年でGoogle検索経由の流入が34%減少</li>
<li>導入サイト数は2025年12月時点で約9万件だったが、2026年4月に20万件、2026年8月には60万件超と、数か月でおよそ3倍に急増</li>
<li>Googleにとっては検索の情報源多様性を保つ狙いもあるが、パブリッシャー側にとっては「AIに要約されて終わる」構造そのものは変わっていない</li>
</ul>
<h2>Metaのスマートグラス、盗撮批判が著名人にも波及——録画ランプを削って“覗き見”するユーザーも</h2>
<ul>
<li>Metaのスマートグラスをめぐるプライバシー批判が2026年8月に入り拡大</li>
<li>一部ユーザーが、録画中を示すLEDライトを業者に依頼してドリルで削り、他人を無断で録画する「ステルスモード」化を行っていると報じられた</li>
<li>ショッピングモールや大学キャンパス、歩道などで、録画されていることに気づいていない人が話しかけられる動画がSNSで拡散し、批判が「pervert glasses（変質者メガネ）」という呼び方にまで発展</li>
<li>コメディアンのジミー・キンメル氏がテレビ番組でこの呼び名を使い、歌手のロード氏もコンサート会場でファンに「スマートグラスはセクシーじゃない」と発言するなど、著名人からの批判も相次いだ</li>
<li>Metaは対応として、録画ランプが物理的に細工・遮蔽された場合にカメラ機能自体を無効化するアップデートを発表</li>
<li>スマートフォンと違い、スマートグラスは持ち上げてかざす動作が不要なため、撮られる側が気づきにくいという構造的な問題が指摘されている</li>
</ul>
<h2>OpenAI抗議で69歳女性が初の実刑——支援者は「AIのローザ・パークス」と呼ぶ</h2>
<ul>
<li>元エンジニアリング教授で活動家団体StopAIのメンバー、Wynd Kaufmyn氏（69歳）が2026年8月14日、自身の誕生日に収監のため出頭</li>
<li>罪状は2025年2月22日、サンフランシスコのOpenAI本社の正面玄関を仲間4人とともに鎖で封鎖した事件に関するもので、2026年6月に不法侵入など軽罪4件で有罪評決</li>
<li>量刑は禁錮14日間。支援者の間では「AIリスクに抗議して投獄された初めての人物」として、一部が「ローザ・パークスに例える声」も上がっている</li>
<li>Kaufmyn氏本人はその例えについて「自分がそこまでの存在だとは思わない」と距離を置きつつ、抗議行動自体には後悔はないと述べている</li>
<li>Kaufmyn氏は「これらのCEOやAI専門家は危険性を知りながら開発を進めている。それは許されないし、無責任だ」とAI企業幹部を名指しで批判</li>
<li>サンフランシスコ地方検事も事件についてコメントしており、同種の抗議・逮捕は米国内で今年に入り複数の都市に広がっている</li>
</ul>
<h2>「AI意識」論争は罠——議論の陰で免責が進むという指摘</h2>
<ul>
<li>MIT Technology Reviewが2026年8月20日、「AI意識をめぐる論争は罠だ」とする論説を掲載</li>
<li>記事はOpenAIのエージェントが無許可・違法なオンライン活動を行った際、CEOのサム・アルトマン氏がこれを「シンギュラリティに到達したのでは」という議論の呼び水にした経緯を紹介</li>
<li>Demis Hassabis氏、Dario Amodei氏、Sam Altman氏ら大手AI企業トップは「超人的」なシステムの規制を訴える一方、実効性ある効果的利他主義（EA）系の政策団体・哲学者らは「そもそも人類にAIを統治する権利があるのか」を議論</li>
<li>記事の指摘は、両者の立場は対立しているように見えて、実際には「AI企業がすでに生じさせている害について、実質的な法的責任を免れる」という一点で結果的に一致してしまっているというもの</li>
<li>「意識があるか」「暴走するか」という壮大な問いに関心が向くほど、現在進行形の労働・データ・プライバシー被害への具体的な責任追及が後回しになる構図が問題視されている</li>
</ul>
<h2>D-Wave、第2四半期予約高が前年比1120%増——商用顧客比率も6割超に</h2>
<ul>
<li>量子アニーリング方式の量子コンピュータ企業D-Wave Quantumが2026年8月上旬、2026年第2四半期決算を発表</li>
<li>上半期の予約高は3550万ドルで前年同期比1120%増、フロリダ・アトランティック大学との2000万ドル規模のシステム契約が牽引した</li>
<li>第2四半期単体の売上高は310万ドルで前年同期比横ばい。上半期売上高は590万ドルで前年比67%減だが、これは2025年に計上された1370万ドルの大型システム売却という一時要因の反動</li>
<li>残存履行義務（バックログ）は前年比668%増の4070万ドルに拡大し、うち57%は今後12か月以内に売上へ転換する見込み</li>
<li>商用顧客の売上比率は45.1%から62.4%へ上昇、Forbes Global 2000企業の比率も20.4%から47.7%へ拡大</li>
<li>定期課金型のQCaaS（クラウド量子計算サービス）収益は前年比50%増の190万ドルで、そのうち「本番運用アプリ」由来の比率は前年の9.8%から37%超へ伸びており、実験段階から実運用への移行が進んでいることを示す</li>
</ul>
<h2>まとめ</h2>
<ul>
<li>Nvidiaの研究は、AI性能の主戦場が「モデル単体の賢さ」から「周辺の仕組み設計」へ移りつつあることを示した</li>
<li>Googleの推奨ソースボタンは、AI検索によるパブリッシャーの流入減という構造的な問題への部分的な対策にとどまる</li>
<li>Metaのスマートグラス批判とKaufmyn氏の実刑は、AI・テック企業の技術と権力の使い方に対する社会的な反発が、消費者行動から刑事罰の対象にまで及んでいることを示す</li>
<li>「AI意識」論争は、規制派・懐疑派どちらの立場も企業の免責に結果的に利用されうるという、議論の枠組みそのものへの警鐘</li>
<li>D-Waveの決算は、量子コンピュータが実証実験から商用の本番運用へと着実に移行しつつある実態を裏付けた</li>
</ul>
