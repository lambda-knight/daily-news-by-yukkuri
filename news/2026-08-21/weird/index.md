<h2>オープニング：2026年8月21日 — 世界の珍ニュース</h2>

<h2>ネタ1 未経験から4ヶ月、羊1頭分の毛を丸ごとセーターにした女性</h2>
<ul>
<li>ニューヨーク市のクイーンズ郡ファーム博物館で飼われている羊「フラニー」の毛を、メイシー・ギリアムさんが丸ごと1頭分譲り受けた</li>
<li>毛刈り→洗浄→紡績→染色→編み物までの全工程を編み物未経験の状態から独学で実施し、完成まで4ヶ月かかった</li>
<li>本人は「困難で変革的なことをやり遂げ、その過程を多くの人と共有したい」と動機を語っている</li>
<li>完成したのはストライプ柄のセーター。余った毛でイースターの帽子も追加で作った</li>
<li>制作過程で「衣料品の最も高い原価は労働費だが、多くの服ではそれが正当に支払われていない」と労働の実態にも言及した</li>
<li>出典: <a href="https://laughingsquid.com/sheep-fleece-striped-sweater/">Laughing Squid</a></li>
</ul>
<h2>ネタ2 瞬間移動して見える、ピンク色のトビムシ</h2>
<ul>
<li>日本の自然写真家ペンドラ氏が、体長数ミリのスミントゥリデス属（球形トビムシ）の跳躍を撮影・公開した</li>
<li>トビムシは尾のように分かれた器官「フルクラ」を地面に叩きつけてバネのように弾け、跳躍速度が速すぎて肉眼では瞬間移動したように見える</li>
<li>この跳躍は天敵に襲われた瞬間、その場で食べられずに逃げ切るための緊急回避行動とされる</li>
<li>湿った環境に生息する小さな生き物が、高速度カメラでようやく動きの仕組みが分かる速さで動いていたことが話題になった</li>
<li>出典: <a href="https://laughingsquid.com/pink-springtails-appear-to-teleport/">Laughing Squid</a></li>
</ul>
<h2>ネタ3 ミクロネシアの深海で見つかった、しかめっ面の赤いアンコウ</h2>
<ul>
<li>探査船イーブイ・ノーチラスの無人探査機（ROV）が、ミクロネシア連邦沖の深海でチャウナコプス属のアンコウを2匹撮影した</li>
<li>丸い体とピンクがかった赤色、しかめっ面のような顔つきが特徴で、額の中央には小さな白い発光点のような疑似餌がある</li>
<li>泳ぐのではなく、変形した腹びれを使って海底を這うように移動する</li>
<li>深海の限られた環境に生息するため、姿を捉えること自体が珍しいとされている</li>
<li>出典: <a href="https://laughingsquid.com/chaunacops-anglerfish-micronesia/">Laughing Squid</a></li>
</ul>
<h2>ネタ4 モネ没後100年、セーヌ川上空にドローン1000機と昼花火で描いた名画</h2>
<ul>
<li>中国の芸術家ツァイ・グオチャン氏が、フランス・ノルマンディー地方ヴェルノンのセーヌ川上空で、クロード・モネ没後100周年を記念した空中パフォーマンス「春の光彩」を披露した</li>
<li>ドローン1000機とカラフルな昼間花火を組み合わせ、「積みわら」「傘を持つ女性」「ポプラ並木」などモネの代表作のモチーフが空に浮かんでは消えた</li>
<li>制作はスタジオ33、花火デザインはグループFが担当した</li>
<li>2026年8月19日に実施され、絵画そのものではなく光と煙で名画のモチーフを再現する試みとして紹介された</li>
<li>出典: <a href="https://laughingsquid.com/drones-fireworks-monet-gardens/">Laughing Squid</a></li>
</ul>
<h2>ネタ5 特設ランプでトンネル内360度ループ、中国製電気SUV</h2>
<ul>
<li>中国の自動車メーカー・ヴォヤーが、電気SUV「パッションS」でトンネル内での360度縦ループ走行を披露する映像を公開した</li>
<li>特別に建設された傾斜ランプを使い、時速130キロでループへ進入する様子をワンショットで撮影したとしている</li>
<li>2010年にメルセデス・ベンツSLS AMGが同様の演出を行った際にCGI使用の疑いを指摘された経緯があり、ヴォヤー側は「実際の走行」であることを強調している</li>
<li>公式な競技イベントかどうかや、走行時の安全対策の詳細は明らかにされていない</li>
<li>出典: <a href="https://laughingsquid.com/voyah-passion-s-tunnel-loop/">Laughing Squid</a></li>
</ul>
