<h2>ネタ1 中国雲南省の断崖に高さ288メートルのガラスエレベーター、通学3時間が50秒に</h2>
<ul>
<li>中国・雲南省宣威市のニジュ川峡谷（尼珠河大峡谷）で、断崖の壁面に沿って建てられた高さ288メートルの屋外エレベーター「扶揺（ふよう）ラダー」が2026年7月31日に運用を開始した（ニューアトラス、インタレスティング・エンジニアリング、オディティ・セントラルなどが2026年8月末から9月上旬に報道）</li>
<li>峡谷の底にあるニジュ川村の子どもたちは、これまで寄宿学校へ通うために崖沿いの細い山道を上り下りし、片道で数時間かかっていた。エレベーターは360度が透明なガラス張りのかごで、秒速5メートルで上昇し、頂上まで約50秒で着く</li>
<li>定員は81人。2022年に完成した高さ268メートルの先行機「青雲ラダー」と並んで立ち、シャトル車やロープウェーと合わせて1時間あたり約1,200人を運ぶ。総工費は約6,800万元</li>
<li>地元の児童と住民は無料で乗れ、観光客と混み合わないよう優先的に乗車できる</li>
<li>出典: <a href="https://newatlas.com/engineering/watch-epic-cliff-elevator-china/">New Atlas</a> / <a href="https://www.odditycentral.com/architecture/china-builds-288-meter-outdoor-elevator-to-help-children-reach-school-easier.html">Oddity Central</a></li>
</ul>
<h2>ネタ2 ベルリンの作家、AI監視カメラに映らない「世界一ダサいアロハシャツ」を発表</h2>
<ul>
<li>ドイツ・ベルリンのデジタルアーティスト、サイモン・ウェッケルトさんが、AI監視カメラに人間として認識されにくくする柄のアロハシャツ「デジタル・カモフラージュ」を発表した（ペタピクセル、ヒューチャリズム、オディティ・セントラルなどが2026年8月下旬に報道）</li>
<li>濃いピンク・オレンジ・緑の抽象的な形を組み合わせた派手な柄で、価格は88ドル。ベルリンの地下鉄コットブッサー門で2026年8月に始まった、行動を分析するAI監視カメラの試験導入への抗議として作られた</li>
<li>AIは「人間そのもの」を理解しているのではなく、大量の学習画像から「頭と肩のシルエット」「手足と胴体の比率」といった統計的な特徴を覚えているだけで、この柄はそれらの部品を一つの人影としてまとめる処理を妨げるという</li>
<li>ウェッケルトさんは別のAIと柄を試行錯誤で競わせる方法でこの模様を作り、物体検出モデルのYOLOで効果を試した。ただし「どんなカメラからも見えなくなる」とは主張しておらず、AI監視の弱点を示すための作品だとしている</li>
<li>出典: <a href="https://petapixel.com/2026/08/27/this-hawaiian-shirt-tricks-ai-surveillance-cameras-into-thinking-youre-not-human/">PetaPixel</a> / <a href="https://www.odditycentral.com/news/worlds-ugliest-hawaiian-shirt-was-designed-to-make-you-invisible-to-ai-surveillance-cameras.html">Oddity Central</a></li>
</ul>
<h2>ネタ3 全長1.8キロに20万人、世界一混雑する深センのビーチ</h2>
<ul>
<li>中国・深セン市の大梅沙（ダーメイシャ）ビーチは全長わずか1.8キロだが、週末には約20万人の海水浴客で埋まることがあり、「世界一混雑するビーチ」と紹介されている（オディティ・セントラルが2026年8月下旬に特集）</li>
<li>混雑の理由は、目の前に地下鉄の駅があることと、入場が無料であること。地元の人にも観光客にも人気で、砂浜が見えなくなるほど人で埋まる写真がたびたび話題になる</li>
<li>あまりの混雑に、深セン市当局は2026年の5月から10月まで、1日の入場者を8万人に制限している</li>
<li>出典: <a href="https://www.odditycentral.com/travel/dameisha-the-worlds-most-crowded-beach.html">Oddity Central</a></li>
</ul>
<h2>ネタ4 電極を付けた「サイボーグ・ゴキブリ」、災害現場で薬を届ける研究</h2>
<ul>
<li>オーストラリアのクイーンズランド大学とニューサウスウェールズ大学の研究チームが、生きたゴキブリに電極と小型機器を取り付け、遠隔操作で薬を運ばせる「パラボーグ」の実験結果を発表した（アイ・トリプルイー・スペクトラム、ザ・レジスターなどが2026年8月下旬に報道）</li>
<li>ゴキブリの触角と、尾のような感覚器官「尾角（びかく）」に電極を埋め込み、携帯型のゲーム用コントローラーで左右への方向転換や前進・停止を指示する。背中には小型カメラか、注射器を発射する自動注入装置のどちらかを載せる</li>
<li>注入装置はバネで薬入りの注射器を近くの対象に撃ち込み、注射器内の化学反応で発生した二酸化炭素の圧力で中身を注入する仕組み。実験室では、決められた地点に到達する成功率が100パーセント、薬の注入が全体で90パーセント、15センチ以内の近距離では95パーセントだった</li>
<li>崩れた建物や洞窟など、救助隊が入れない場所に閉じ込められた人へ応急処置を届けることを想定している。研究チームは、資源が確保できれば5年から10年以内に実際の災害現場で使える可能性があると話している</li>
<li>出典: <a href="https://spectrum.ieee.org/cyborg-rescue-roach">IEEE Spectrum</a> / <a href="https://www.theregister.com/offbeat/2026/08/27/cyborg-cockroaches-may-soon-deliver-life-saving-drugs-to-disaster-victims/">The Register</a></li>
</ul>
