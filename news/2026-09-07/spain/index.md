<h1>スペインニュース（2026年9月7日）</h1>
<h2>オープニング：2026年9月7日 — スペインニュース</h2>
<ul>
<li>今日はセウタの財政危機、学力テストへの不安、それにトマティートの列伝が待っているのだ！</li>
<li>政治は短く、マラガの村々やマドリードのフラメンコ、そしてマドリードのコンデ兄弟工房にたっぷり時間を使う構成よ。</li>
<li>聞き終わるころには、スペインの芸が「うまい」だけでなく何を評価しているのか分かるのだ？</li>
<li>ええ。今日のスペイン語もそこにつながるわ。芸の神様、ドゥエンデの話から始めましょう。</li>
</ul>
<h2>今日のスペイン語ひとこと</h2>
<ul>
<li>今日の表現は「テネール・ドゥエンデ」。直訳は「ドゥエンデを持っている」よ。</li>
<li>ドゥエンデって、妖精とか小人のことなのだ？</li>
<li>元はそうなの。でもフラメンコでは、聴き手の背筋がぞくっとする、あの説明できない力のことを指すわ。</li>
<li>「歌がうまい」とは違うのだ？</li>
<li>全然違うの。技術があっても、ドゥエンデがなければ最上の褒め言葉はもらえない。詩人ロルカが1933年の講演でこの言葉を論じたのは有名よ。</li>
<li>日本の「わび・さび」みたいに、言葉で説明しにくいものなのだ。</li>
<li>そう。だから「エサ・カンタオーラ・ティエネ・ドゥエンデ」と言えば、あの歌い手には鳥肌が立つ何かがある、という意味になるわ。</li>
</ul>
<h2>国際情勢（スペイン視点）</h2>
<ul>
<li>セウタの危機は、いま経済の数字にも出ているの。市当局は対応の総コストが5億ユーロ近くに達し、「破綻の現実的リスクがある」と警告したわ。</li>
<li>街が一つ、財政破綻しかけているのだ？</li>
<li>ええ。しかもセウタは、ジブラルタルがイギリスとの「ペニョン合意」で得た立場より、EUの中で弱い位置に置かれているとエル・ムンドは指摘しているの。</li>
<li>スペインの街なのに、EUの仕組みの中では守りが薄いのだ。</li>
<li>セウタとメリリャはEUの関税同盟の外側にあって、国境管理でも特例扱い。だから危機のたびに「ヨーロッパの一員なのに一人で耐える」感覚が出てくるの。</li>
<li>EUを誇りにしてきた国だからこそ、そこが痛いのだ。</li>
<li>もう一つ、エル・パイスは「モハメドには計画がある」という論考で、モロッコ・イスラエル・アメリカの利害が結びつく可能性を指摘したわ。</li>
<li>モロッコの王様がモハメド6世なのだ。その「計画」って何なのだ？</li>
<li>西サハラ問題でアメリカとイスラエルの後押しを受けたモロッコが、外交で強気になっているという見立てよ。サンチェス政権の対モロッコ政策が問われている、と筆者は書いているの。</li>
<li>スペインからすると、南の隣国がどんどん有利になるのは落ち着かないのだ。</li>
<li>地中海の対岸は「自分たちの問題」というスペインの感覚が、経済でも外交でも試されている一日ね。</li>
</ul>
<h2>スペイン国内ニュース</h2>
<ul>
<li>国内では、セウタをめぐって司法と政府がまたぶつかったの。担当のタルドン判事が、警察に分析を頼んだ10日後に「その情報を内務省へ上げないように」と電話で求めていたことが分かったわ。</li>
<li>判事が電話で「上に報告するな」と言うのは、かなり異例なのだ。</li>
<li>エル・パイスはこれを「政治の司法化がセウタにまで及んだ」と書いて、正統性のぶつかり合いだと評しているの。</li>
<li>裁判所と政府、どちらが決めるのかという争いなのだ。</li>
<li>一方で、野党PPの地方首長たちは、セウタの未成年およそ2,500人の一部を結局は受け入れざるを得ない、と内々に認め始めたわ。「ノーとは言えない」とね。</li>
<li>昨日まで強く反対していたのに、風向きが変わったのだ。</li>
<li>受け入れの準備を進めつつ、法的な不服申し立ても用意して、「呼び水効果」への警戒も口にする。反対と実務のあいだで揺れているの。</li>
<li>スペインの世論では、セウタへの連帯が対立感情を上回っている、という記事もあったのだ。</li>
<li>もう一つは教育の話。8百万人の子どもが新学期を迎える中で、国際学習到達度調査ピサの結果への不安が広がっているの。</li>
<li>ピサって、日本でもよく報じられるあの学力テストなのだ。</li>
<li>ええ。エル・ムンドは、次の結果がサンチェス政権期の教育をまるごと採点することになる、と書いて、自治州の担当者が「また落ちる」と身構えていると伝えたわ。</li>
<li>国全体じゃなく、州ごとに一喜一憂するのだ。</li>
<li>スペインは教育行政の大半が自治州の権限なの。記事はカタルーニャとバスクが調査対象の選び方で数字を「化粧している」と指摘して、そこも論争になっているわ。</li>
<li>地方に強い権限がある分、比べ方でもめるのだ。日本とはずいぶん違うのだ。</li>
<li>日本は文部科学省が全国一律で動かすでしょう。スペインは17の州がそれぞれ教科書も試験も抱えるから、順位が出るたびに中央と地方の責任の押しつけ合いになるの。</li>
<li>それでも、子どもの学力を心配する親の気持ちは、日本もスペインも同じなのだ。</li>
<li>そこは共通ね。ただスペインの親は不満があれば街頭に出るし、学校選びでも遠慮なく声を上げる。塾通いで静かに競う日本とは表れ方が違うわ。</li>
</ul>
<h2>文化・芸能ニュース</h2>
<ul>
<li>政治の話が続いたのだ。芸能の話が聞きたいのだ。</li>
<li>女優のナタリア・ウアルテが、マドリードのアバディア劇場の新シーズン開幕作『レオノーラ』で主役を務めるの。劇作家アルベルト・コネホーロの新作よ。</li>
<li>どんな経歴の人なのだ？</li>
<li>地方からマドリードへ出てきて、アバディア劇場が何かも知らないまま飛び込み、名だたる演出家と次々に仕事をしてきた人。今その劇場のシーズンを開ける役に立っているの。</li>
<li>下積みが長かったのだ。</li>
<li>本人は「長いあいだ、目立ちたくない、反抗的に見られたくない、悪い意味で目立ちたくないと思ってきた」と語っているわ。その遠慮を抜けて主役に立った、という記事なの。</li>
<li>引っ込み思案だった人が舞台の真ん中に立つのは、応援したくなるのだ。</li>
<li>もう一人、指揮者のパブロ・エラス・カサドが、ワーグナーの聖地バイロイト音楽祭のオーケストラを率いてマドリードの王立劇場に登場するの。</li>
<li>スペイン人がドイツの「聖地」の楽団を指揮するのだ。</li>
<li>グラナダ出身のエラス・カサドは、古楽から現代曲まで振る指揮者で、いまや国際的に引っ張りだこ。スペインの音楽家が外へ出ていく象徴的な一件ね。</li>
<li>日本にゆかりのニュースもあったのだ？</li>
<li>ええ。水玉模様で知られる草間彌生さんが97歳で亡くなって、エル・パイスも大きな追悼記事を載せたの。スペインの美術ファンにも愛された作家だったわ。</li>
</ul>
<h2>フラメンコニュース</h2>
<ul>
<li>フラメンコは今日、小さな町の話が続くわ。まずマラガ県のアルチドナで、「ラ・ポラ・フラメンカ」が土曜に復活するの。カンテ、ギター、バイレをそろえた集まりよ。</li>
<li>「ポラ」って何なのだ？</li>
<li>深夜まで続く、車座の宴のような催しの呼び名。舞台と客席を分けず、みんなで囲むのが持ち味なの。</li>
<li>同じマラガ県のアロサイナでは、「アルメナ・フラメンカ」でカンテ、ギター、バイレが一晩に並ぶわ。城壁跡の広場を使う趣向ね。</li>
<li>村の広場がそのまま舞台になるのだ。</li>
<li>三つ目、マドリードでは10月に「スマ・フラメンカ」が戻ってくるの。3週間かけてカンテ、バイレ、ギターを特集する首都の大型企画よ。</li>
<li>村の宴と、首都の大型フェスティバル、両方あるのだ。</li>
<li>四つ目はレオン県のアストルガ。聖マルタ祭の締めくくりにカンテとバイレが据えられたわ。アンダルシアから遠い北の町でも、祭りの最後はフラメンコなの。</li>
<li>フラメンコはアンダルシアの文化なのに、北の町でも主役なのだ。</li>
<li>そこが難しいところなの。セビリャ、コルドバ、ヘレス、グラナダで育った芸が「スペイン全体の顔」として広がることに、アンダルシアの担い手は誇りと、消費されている感覚の両方を抱くのよ。</li>
<li>マドリードが「国の顔」として売り出すことにも、複雑な思いがあるのだ。</li>
<li>ええ。だから「スマ・フラメンカ」のような首都の企画には、アンダルシア側から静かな警戒も向けられるの。</li>
</ul>
<h2>フラメンコギタリスト列伝</h2>
<ul>
<li>今日の主役は、トマティートなのだ！</li>
<li>本名ホセ・フェルナンデス・トーレス。1958年8月20日、アルメリアのヒターノの音楽一家に生まれたの。祖父も父もギタリストで、「トマテ（トマト）」の愛称を継いで「小さなトマト」でトマティートよ。</li>
<li>若いころは何をしていたのだ？</li>
<li>アルメリアの酒場で弾いていたところを見いだされて、歌い手カマロン・デ・ラ・イスラの伴奏者になったの。パコ・デ・ルシアがツアーから離れたあと、晩年のカマロンを支え続けたわ。</li>
<li>昨日の主役、パコとつながるのだ。</li>
<li>ええ。1992年のカマロン最後の作品『{Potro de rabia y miel|ポトロ・デ・ラビア・イ・ミエル}』では、パコとトマティートが並んで弾いているの。師から弟子へ受け継がれた現場ね。</li>
<li>カマロンが亡くなったあとはどうしたのだ？</li>
<li>独奏と作曲に軸を移して、『{Paseo de los Castaños|パセオ・デ・ロス・カスターニョス}』や『{Aguadulce|アグアドゥルセ}』『{Soy flamenco|ソイ・フラメンコ}』を発表。ラテン・グラミーを何度も受けているわ。</li>
<li>ジャズとの共演もあるのだ？</li>
<li>ドミニカ出身のピアニスト、ミチェル・カミロと組んだ『{Spain|スペイン}』が2000年に大きな話題になったの。続編も作って、フラメンコとジャズの橋渡しを長く続けているわ。</li>
<li>演奏の持ち味はどこなのだ？</li>
<li>音数を絞った深い響き、ブレリアの推進力、歌に寄り添う間の取り方ね。派手さより「歌がそこにいる」ように弾くのが身上なの。</li>
<li>家族も音楽をやっているのだ？</li>
<li>娘のマリ・アンヘレスは歌い手、息子のホセ・デル・トマテはギタリストとして各地を回っているわ。まず聴くならミチェル・カミロとの『{Spain|スペイン}』からがおすすめよ。</li>
</ul>
<h2>フラメンコギター工房だより</h2>
<ul>
<li>今日の工房はどこなのだ？</li>
<li>マドリードのコンデ兄弟、コンデ・エルマノス工房よ。1世紀続くギター製作の一族なの。</li>
<li>どこから始まった一族なのだ？</li>
<li>出発点はドミンゴ・エステソ。1882年生まれで、名門マヌエル・ラミレスの工房で腕を磨いてから、マドリードのグラビナ通りに自分の店を開いたの。</li>
<li>そこから「コンデ」になったのだ？</li>
<li>エステソの死後、未亡人と3人の甥、ファウスティノ、マリアノ、フリオのコンデ兄弟が受け継いで、「ドミンゴ・エステソの甥たち」、のちに「コンデ・エルマノス」を名乗ったの。</li>
<li>有名な弾き手も使っているのだ？</li>
<li>パコ・デ・ルシアが長年の相棒にしたのが1969年製のコンデ。多くのタブラオのギタリストもコンデを選んできたわ。</li>
<li>グラナダの工房とは何が違うのだ？</li>
<li>マドリードはタブラオの街だから、糸杉の軽い胴で音の立ち上がりが速く、ゴルペにも耐える「働く楽器」を磨いてきたの。しっとり鳴らすグラナダ系とは狙いが少し違うわ。</li>
<li>今も家族が作っているのだ？</li>
<li>ええ。一族は分かれて複数の工房を構えつつ、今も手作業で製作を続けているの。王立劇場のそばで、エステソから数えて100年分の型と道具が生きているわ。</li>
</ul>
<h2>まとめ</h2>
<ul>
<li>財政危機も学力テストも、スペインが一人で抱え込む一日だったのだ。</li>
<li>それでもアルチドナの車座では夜通しギターが鳴り、トマティートはカマロンから受け取った間合いで弾き続け、マドリードのコンデ工房はエステソの型を100年守っている。今日のスペインはそんな一日だったわ。</li>
</ul>
