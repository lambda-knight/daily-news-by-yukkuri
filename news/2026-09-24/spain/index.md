<h1>スペイン文化・フラメンコ便り（2026年9月24日）</h1>
<h2>オープニング：2026年9月24日 — スペイン文化・フラメンコ便り</h2>
<ul>
<li>今日の軸は、国立演劇賞を受けた俳優オリオル・プラ、三位一体でフラメンコを届ける各地の公演、そしてギター、バイレ、カンテを支えた20世紀の三人である。</li>
</ul>
<h2>国際情勢（スペイン視点）</h2>
<ul>
<li>9月23日、ベネズエラの暫定大統領デルシー・ロドリゲスが国連で外交的な開放を演出した。スペイン語圏ではベネズエラから移住した家族を身近に持つ人が多く、制度の変化は遠い外交ではなく、帰国や送金、家族再会に直結する問題として受け止められる。ただし今回はスペイン政府の新たな決定がないため、番組ではこの一点だけを短く扱う。</li>
</ul>
<h2>スペイン国内ニュース</h2>
<ul>
<li>12点の宝飾品を巡り、ホセ・ルイス・ロドリゲス・サパテロ元首相は、2007年にサウジアラビア国王から受けた「個人的な贈り物」だと裁判所へ説明した。El Paísは弁護側が国際司法共助を求めた手続きを、El Mundoは押収品への説明責任を強く前面に出す。同じ事実でも、前者は立証の手続き、後者は権力者への疑念に重心がある。</li>
<li>日本の贈答文化にも公私の境界はあるが、元首相と外国君主の贈り物は外交儀礼、課税、所有権が重なる。12点という具体物があるからこそ、政治的な好悪より来歴を示す記録が争点になる。</li>
</ul>
<h2>文化・芸能ニュース</h2>
<ul>
<li>俳優オリオル・プラが2026年の国立演劇賞を受賞した。受賞理由は、共同創作した『Gula (Gola)』でクラウン、アクロバット、演技を横断し、批評と観客の双方をつかんだこと。父から「もっと賞に値する人は大勢いる」と言われたという本人の言葉は、祝賀を家族の率直な会話へ引き戻す。祭りの晴れ舞台でも身内が遠慮なく意見を言うスペインと、謙遜を儀礼化しやすい日本の違いも面白い。</li>
<li>グラナダの文化祭が作家アリアナ・ハルヴィチの講演を中止したことに350人を超す作家が抗議し、ジョン・バンヴィルも参加を辞退した。El Paísは作家間の連帯と表現の自由を、El Mundoは「ボイコット文化」が勝つ構図を強調する。中止そのものだけでなく、出演者が欠席という行動で主催者へ費用を返した点が今回の新しさだ。</li>
<li>サン・セバスティアン映画祭ではブラッド・ピットが『En el corazón de la bestia』を携えて登壇し、「互いの共通点にもっと時間を使おう」と語った。外国スターの話題ではあるが、スペインの地方都市が世界映画の対話の場になる文化基盤を示す催事として位置づけられる。</li>
</ul>
<h2>フラメンコニュース</h2>
<ul>
<li>パンプローナ市は第13回フラメンコ・オン・ファイアと連携し、コンデスタブレ宮での二公演、市庁舎バルコニーからのエル・ペレの歌、未成年向けギター・舞踊講座を組み合わせた。舞台鑑賞と子どもの実技を同じ自治体事業に置く設計が特徴だ。</li>
<li>マラガ県アルチドナでは「ラ・ポーラ・フラメンカ」が9月26日に戻り、カンテ、バイレ、ギターを一晩にそろえる。歌だけ、踊りだけではなく三者の応答を見せる点で、フラメンコを総合芸術として伝える催しになっている。</li>
<li>サラゴサ県エヘア・デ・ロス・カバジェロスでは、リカルド・フェルナンデス・デル・モラルの一座が『Nuestro Flamenco』を上演する。一人の演者をスターとして切り出すより、カンテ、ギター、バイレの関係そのものを観客へ近づける企画だ。</li>
<li>これらは発祥地アンダルシア外のナバラ、アラゴンにも広がる一方、担い手と技法の源流はセビリア、ヘレス、カディス、グラナダなどの地域共同体にある。「スペインの顔」として全国化するほど、アンダルシアの土地と家族が育てた歴史を消さない語り方が重要になる。</li>
</ul>
<h2>フラメンコギタリスト列伝</h2>
<ul>
<li>今日の主役はニーニョ・リカルド、本名マヌエル・セラピ・サンチェス（1904年セビリア生、1972年没）。父もギタリストで、少年期から父に学び、14歳ごろにヘレスの伴奏家ハビエル・モリーナのもとで舞台経験を得た。カフェ・カンタンテから劇場興行、録音、独奏へ移る20世紀前半を生き、伴奏者の名が小さく刷られた時代から、ギター独自の語彙が作品として聴かれる時代への橋を架けた。</li>
<li>彼の核心は、歌を包む伴奏と、一聴して作者が分かるファルセータを分離しなかった点にある。ラ・ニーニャ・デ・ロス・ペイネス、トマス・パボン、ペペ・ピントらのカンテに付き、レトラの長短と息遣いを身体で覚えた。その経験が、独奏でも旋律が歌のように呼吸する設計へつながった。</li>
<li>右手では親指の強い輪郭、ラスゲアードの粒立ち、トレモロの流れを使い分け、左手では開放弦を残しながら和音を動かす響きを好んだ。速さだけで押さず、低音の一打の後に高音の旋律が答えるため、ギター一台でもカンテと伴奏の対話が聞こえる。ファンダンゴ伴奏では歌の終止を先回りせず、声が着地する場所へ和音を置く。</li>
<li>代表作として「Recuerdo a Sevilla」や「Zapateado」が知られる。公開映像・録音で <a href="https://www.youtube.com/watch?v=ItQSG40H0jQ">ニーニョ・リカルドの演奏</a> を聴くと、低音を打った直後に高音の短い装飾を返す箇所、そして強いラスゲアードのあとに音量を落とす間に注目したい。強弱の落差が、舞踊の足を煽るリズムと歌を待つ余白の両方を作る。</li>
<li>後世への影響はパコ・デ・ルシア以前の語彙を整えたことにある。パコはニーニョ・リカルドのファルセータを学び、そこから和声と編成を広げた。つまり革新は伝統の否定ではなく、伴奏で磨かれた短い旋律を、次世代が別の構造へ組み直す連鎖だった。カンテとバイレを支える時間感覚を失わなかったからこそ、独奏ギターの教材にもなり続ける。</li>
</ul>
<h2>フラメンコバイレ列伝</h2>
<ul>
<li>今日の主役はクリスティナ・オヨス（1946年セビリア生）。12歳で踊りを始め、タブラオで経験を積んだ後、アントニオ・ガデス舞踊団の中心的な踊り手となった。カルロス・サウラ監督の映画『血の婚礼』『カルメン』『恋は魔術師』への出演により、劇場の身体表現を映画の画面へ移し、世界の観客へ届かせた。</li>
<li>オヨスの踊りは、上体を大きく崩さず、腕と手首で曲線を描きながら、足の打点を明確に積む。サパテアードを音量競争にせず、カンテの句とギターの締めに応答させるため、静止した一瞬にも緊張が残る。ガデスとの男女の対話では、派手な回転より視線、距離、重心の移動が物語を進める。</li>
<li><a href="https://www.youtube.com/watch?v=vapBU9NzsIA">『Tierra Adentro』</a> はアンダルシアの公共放送系公式チャンネルが公開する2003年の舞台映像である。オヨスが群舞の中央で腕を上げる場面と、足を細かく刻んだ直後に身体を止める場面を見ると、ブラソの線とサパテアードの打点が別々でなく、一つのフレーズを作ることが分かる。</li>
<li>1990年代に自らのカンパニーを率い、のちにセビリアでフラメンコ舞踊博物館の設立にも関わった。踊り手、振付家、教育・展示の担い手をつないだことで、舞台が終わった後にも技法と歴史を渡す回路を残した。個人のスター性を、次世代が学べる制度へ変えた点が歴史的位置である。</li>
</ul>
<h2>フラメンコカンテ列伝</h2>
<ul>
<li>今日の主役はテレモト・デ・ヘレス、本名フェルナンド・フェルナンデス・モンヘ（1934年ヘレス・デ・ラ・フロンテーラ生、1981年没）。サンティアゴ地区で育ち、当初は踊り手として舞台に立ったが、歌へ転じて1950年代から名を上げた。ヘレスの祝宴とペーニャで培われたコンパス感を、劇場と録音へ持ち込んだ歌い手である。</li>
<li>声は粗い倍音を含み、語頭を強く押す一方、語尾をきれいに整え過ぎない。シギリージャやソレアでは苦悩を説明するのでなく、息の圧と音の裂け目で聞かせる。ブレリアでは逆に、短い呼びかけをコンパスの後ろへ置き、パルマとギターの間へ声を滑り込ませる。</li>
<li><a href="https://www.youtube.com/watch?v=GQ5pYfAqH7E">「Soleá」</a> では、歌い出しの声をまっすぐ伸ばした後、語尾を細かく揺らす箇所を聴きたい。ギターが次の和音へ急がず声の着地を待つため、カンタオールが拍の内側を伸縮させてもコンパスが失われない。</li>
<li>息子フェルナンド・テレモトも歌い手となり、ヘレスの家族的継承を次代へ渡した。ただし影響は血縁だけではない。ヘレスの歌は楽譜通りの長さより、祝宴で周囲が返すパルマや掛け声との関係で形になる。テレモトの録音は、その共同体の間合いを後世の歌い手が学ぶ基準になった。</li>
</ul>
<h2>フラメンコギター工房だより</h2>
<ul>
<li>今日は既出工房の再紹介を避け、セビリアの製作家教育という周辺テーマを見る。アンダルシア州の工芸教育では、木材の見極め、表板と力木の調整、ネック角度、フレット、塗装、修理を別工程として学び、完成品だけでなく故障した楽器を診断する力も育てる。</li>
<li>フラメンコギターは、一般に糸杉の側・裏板を用いた軽い反応、低い弦高、ゴルペ板を特徴とする。クラシックギターの長い余韻をそのまま目標にせず、カンテの子音やバイレの足音へ瞬時に返る立ち上がりが求められる。表板を薄くすればよいのではなく、力木と駒の釣り合いが崩れれば音量と耐久性を同時に失う。</li>
<li>日本の工芸教育が鉋や鑿の精度を重んじるのと同様、スペインの製作も手仕事の再現性が土台になる。しかし最終調整では、演奏家がラスゲアードをした時の分離、カンタオールの声量、舞台の床から返る足音までを聞く。工房は木工の場所であると同時に、三者の音量を調停する小さなリハーサル室でもある。</li>
</ul>
<h2>フラメンコのパロ解説</h2>
<ul>
<li>今日のパロはペテネーラ。カディス県パテルナ・デ・リベラの歌い手「ラ・ペテネーラ」に由来するという口承がある一方、人物の実在や中米との往還を含め起源には複数説がある。アンダルシア・フラメンコ研究所は、19世紀末にメディーナ・エル・ビエホが現在のペテネーラ・チカを整えたと説明する。</li>
<li>情感は暗く、運命、喪失、禁じられた愛などを歌うことが多い。四行または六行のレトラを引き伸ばし、同じ語を反復して旋律を深める。舞踊では腕を大きく使う場面と静止を組み合わせ、サパテアードを絶えず打つより、歌の緊張を残す構成が似合う。</li>
<li>コンパスは12拍系で、シギリージャと近いアクセント感を持つと説明されるが、歌い手は旋律を自由に伸ばす。伴奏はフリジア系の響きを軸に、Aマイナー、G、F、Eへ降りるアンダルシア終止型を使うことがある。ギターはレトラの途中で音を詰めず、声の呼吸を待って短いファルセータを差し込む。</li>
<li>アンダルシアの公共放送系公式チャンネルによるホセ・メネセの <a href="https://www.youtube.com/watch?v=yvqAtRIt0RI">「Petenera」</a> では、エンリケ・デ・メルチョールのギターが低音の終止を置いた後、歌が拍をまたいで伸びる箇所に注目したい。周期は保たれているのに、表面では時間が止まったように聞こえるのがこのパロの魅力である。</li>
</ul>
<h2>まとめ</h2>
<ul>
<li>オリオル・プラの越境的な演技、各地の三位一体の公演、ニーニョ・リカルド、クリスティナ・オヨス、テレモト・デ・ヘレスの仕事は、個人技がカンテ、バイレ、ギターの関係の中で初めて生きることを示した。今日のスペイン文化を一言で表せば、「名人芸を共同体へ返す日」である。</li>
</ul>
